## 핵심 개념

THERP(Technique for Human Error Rate Prediction)는 작업을 수행하는 사람의 실수 가능성을 정량적으로 추정하는 기법임 · 작업을 세부 단계로 나누고 각 단계의 성공·실패 확률과 작업 조건, 의존관계를 사용해 인간실수확률(HEP)을 계산함

THERP의 기본 흐름은 다음과 같음

1. 분석할 작업과 성공 기준을 정의함
2. 작업을 관찰 가능한 인간 행동 단계로 분해함
3. 각 행동의 성공확률 또는 인간실수확률을 할당함
4. 단계 사이의 의존성, 작업 조건, 회복 가능성을 반영함
5. 조합된 결과로 전체 작업의 인간실수확률을 추정함

인간신뢰도는 사람이 오류 없이 과업을 수행할 가능성을 뜻하고, 인간실수확률 `HEP`는 그 실패 쪽 확률임 · 단순한 성공·실패의 상보 관계를 전제하는 한 단계에서는 `성공확률 = 1 - HEP`로 읽을 수 있지만, 여러 단계의 전체 확률은 단계 의존성과 회복 가능성을 반영해 조합해야 함

## 판별 기준

| **기법** | 중심 대상 | 접근 |
| --- | --- | --- |
| **THERP** | 인간 행동과 인간실수확률 | 작업 분해와 확률 정량화 |
| **FTA** | 시스템의 정상 상태 상실 또는 사고 톱 이벤트 | 톱다운 논리 조합 |
| **ETA** | 초기 사건 뒤의 가능한 결과 경로 | 사건 진행 분기 |
| **FMEA** | 부품·기능의 고장 형태와 영향 | 고장 형태별 검토 |
| **MORT** | 관리·조직 요인을 포함한 사고 원인 | 관리 체계 중심 분석 |
| **OAT** | 운전원 행동의 성공·실패 경로 | 행동나무 전개 |
| **HCR·SLIM·CES** | 인지 신뢰도·성공가능성·인지오류 | 인간신뢰도 평가의 인접 기법 |

2020년 8월 시험 31번은 THERP의 특징과 작업 단계의 조합을 물음 · THERP는 시스템 분석 챕터에서 다루는 FTA·ETA와 함께 사용될 수 있지만, 인간 행동 확률을 직접 추정한다는 점이 구별점임

## 자주 틀리는 포인트

### 확률 모델의 주의점

작업 단계가 여러 개이면 각 단계의 확률을 단순히 더하거나 평균 내지 않음 · 문제에서 제시한 성공·실패 사건의 관계와 의존성을 먼저 확인하고, 해당 관계에 맞는 조합을 적용함 · 데이터가 없는 단계의 수치를 임의로 만들거나 최신 통계처럼 해석하지 않음

> **확정 주의**  THERP는 인간실수확률을 추정하는 기법임 · FMEA, FTA, ETA 또는 MORT의 이름을 THERP의 계산값으로 바꾸어 쓰지 않음

### 범위와 제외

이 챕터는 THERP의 목적, 작업 분해, 인간실수확률과 의존성의 정량화 개념을 다룸 · 특정 조직의 실제 오류율, 새로운 확률표, 최신 규정 또는 현장 위험성 평가 결과를 대신하지 않음
