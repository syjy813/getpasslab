## 핵심 개념

Swain의 인간실수 분류는 해야 할 작업을 빠뜨렸는지, 잘못 수행했는지, 순서·시간을 어겼는지, 불필요한 행동을 했는지로 오류를 구분함

| **유형** | 의미 |
| --- | --- |
| **Omission error** | 필요한 작업이나 절차를 수행하지 않음 |
| **Commission error** | 필요한 절차 대신 잘못된 행동을 수행함 |
| **Sequential error** | 필요한 작업의 순서를 잘못 수행함 |
| **Time error** | 작업 시점이나 타이밍이 잘못됨 |
| **Extraneous act** | 필요하지 않은 작업이나 절차를 추가로 수행함 |

2019년 8월 시험 23번은 해야 할 단계의 생략을, 2021년 3월 시험 38번은 불필요한 작업을 수행한 경우를 물음 · 2020년 9월 시험 22번은 가스밸브를 잠그는 것을 잊은 사례를 생략 오류와 연결함

2020년 8월 시험 22번처럼 각 영어 용어의 설명을 비교하는 문제에서는 omission·commission·sequential·extraneous의 정의와 시간 오류를 혼동하지 않음

## 휴먼에러의 심리적·물리적 요인

휴먼에러의 원인은 작업자의 인지·심리 상태에서 시작되는 요인과 작업 자체·설비·환경에서 주어지는 요인으로 구분함

| 구분 | 주요 요인 | 대응 방향 |
|---|---|---|
| **심리적 요인** | 서두르거나 절박한 상황, 지식·의욕 부족, 체험적 습관·선입관, 주의 소홀·피로 | 각성 수준 유지, 교육·훈련, 적재적소 배치 |
| **물리적 요인** | 지나치게 단순하거나 복잡한 일, 생산성의 과도한 강조, 같은 형상의 나열, 과도한 자극·소음·진동 | 위험요인 제거, 설비·환경 개선, 안전을 고려한 설계 |

`서두르거나 절박한 상황`은 심리적 요인이고 `일이 너무 복잡함`이나 `같은 형상의 물체가 나란히 있음`은 물리적 요인임

## 판별 기준

Swain의 작업 수행 오류와 Slip·Mistake·Lapse·Violation 또는 James Reason의 분류는 서로 다른 체계임 · 선택지에 인접 개념이 섞여 있으면 문제에서 요구하는 분류 기준을 먼저 확인함 · THERP는 인간실수확률을 정량화하는 기법이고 FMEA·FTA·ETA는 다른 분석 목적을 가지므로 이 챕터의 분류와 동일시하지 않음

> **확정 주의**  “작업을 하지 않음”은 omission, “불필요한 작업을 함”은 extraneous act임 · 순서를 잘못 지킨 경우와 시점을 놓친 경우도 별도로 구분함

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| Sequential error | **필요한 작업의 순서를 잘못 수행함** |
| Omission error | **필요한 작업이나 절차를 수행하지 않음** |
| Commission error | **필요한 절차 대신 잘못된 행동을 수행함** |
| Time error | **작업 시점이나 타이밍이 잘못됨** |
| Extraneous act | **필요하지 않은 작업이나 절차를 추가로 수행함** |
| Swain 인간 실수 분류 | **수행 순서와 수행 시점을 바꾸어 읽지 않음** |
| 서두르거나 절박한 상황 | **심리적 요인** |
| 지나치게 단순·복잡한 일, 같은 형상의 나열 | **물리적 요인** |

## 자주 틀리는 포인트

이 챕터는 Swain의 omission, commission, sequential, time, extraneous 오류 분류와 심리적·물리적 발생요인의 구분을 다룸 · THERP 계산, FMEA·FTA·ETA, Rasmussen 등 다른 이론의 상세 설명은 범위에서 제외함
