## 핵심 개념

ECRS — 작업 개선의 4원리 · 개선 검토는 반드시 이 순서로

| 순서 | 원리 | 질문 |
|------|------|------|
| **E** | **Eliminate (제거)** | 이 작업을 없앨 수 없는가? |
| **C** | **Combine (결합)** | 다른 작업과 합칠 수 없는가? |
| **R** | **Rearrange (재배치·재편성)** | 순서·장소·담당을 바꿀 수 없는가? |
| **S** | **Simplify (단순화)** | 더 간단하게 할 수 없는가? |

## 판별 기준

| 원리 | 개선 강도 | 예 |
|------|-----------|-----|
| **Eliminate** | 최대 (작업 자체 소멸) | 불필요한 검사 폐지 |
| **Combine** | 큼 | 두 공정을 한 번에 |
| **Rearrange** | 중간 | 공구 위치 변경 |
| **Simplify** | 기본 | 동작 수 축소 |

## 동작경제 3원칙

ECRS가 개선안을 검토하는 순서라면 동작경제는 작업자의 움직임과 작업장·공구를 어떻게 설계할지 판단하는 기준임

| 구분 | 핵심 원칙 |
|---|---|
| **신체 사용** | 두 손은 함께 시작·종료하고 서로 반대방향으로 대칭 이동 · 자연스러운 동작과 리듬 활용 |
| **작업장 배치** | 공구·재료의 위치를 정하고 이동거리를 줄이며 작업 높이와 공간을 적절히 구성 |
| **공구·장비 설계** | 기능을 결합하고 자동화·관성·중력을 활용해 에너지 사용을 줄이며 안전하고 편안하게 설계 |

두 팔을 동시에 `같은 방향`으로 움직이거나 공구 기능을 각각 분리하는 설명은 동작경제 원칙과 반대됨

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| R | **Rearrange (재배치·재편성)** · 순서·장소·담당을 바꿀 수 없는가? |
| E | **Eliminate (제거)** · 이 작업을 없앨 수 없는가? |
| C | **Combine (결합)** · 다른 작업과 합칠 수 없는가? |
| S | **Simplify (단순화)** · 더 간단하게 할 수 없는가? |
| Eliminate | **최대 (작업 자체 소멸)** · 불필요한 검사 폐지 |
| Combine | **큼 · 두 공정을 한 번에** |
| ECRS에 포함되지 않는 것 | **Standard** |
| 두 팔의 동작 | **동시에 서로 반대방향으로 대칭 이동** |
| 공구 기능 | **가능하면 결합** · 각각 분리한다는 설명은 오답 |
| 동작경제 3원칙 | **신체 사용·작업장 배치·공구 및 장비 설계** |

## 자주 틀리는 포인트

- ECRS와 이름이 비슷한 개선 용어를 목록에 추가하지 않음
- `Rearrange`를 단순화가 아니라 순서·장소·담당의 재배치로 구분함
- 기존 작업을 더 쉽게 만드는 `Simplify`와 작업 자체를 없애는 `Eliminate`를 바꾸어 읽지 않음
- ECRS 4단계와 동작경제 3원칙을 같은 목록으로 합치지 않음

> ⚠️ **함정 주의**: `Standardize`나 `Reduce`처럼 그럴듯한 용어가 섞였는지 먼저 확인하고, E→C→R→S 순서를 함께 대조함
