## 핵심 개념

Murrell 방법은 작업 중 소비하는 에너지와 휴식 중 소비하는 에너지의 차이를 이용해 8시간 작업에서 필요한 휴식시간을 산정하는 방식임 · 문항에서 제시한 성별과 산소소비량의 조건을 그대로 사용함

## 계산 기준

일반식은 다음과 같음

$$R = \frac{T(E-S)}{E-1.5}$$

- **(R)**: 휴식시간(분)
- **(T)**: 전체 작업시간(분)
- **(E)**: 작업 시 에너지 소비량
- **(S)**: 휴식 시 에너지 소비량

기출문항은 8시간 근무와 산소소비량 (1.3\ \text{L/min})을 주고 남성 작업자의 Murrell 계산 결과를 물음 · 문제에서 정한 남성 기준과 단위를 적용하면 정답 보기인 144분에 해당함

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 휴식시간 산정 (Murrell) R | **$R = \frac{T(E-S)}{E-1.5}$** |
| (R) | **휴식시간(분)** |
| (T) | **전체 작업시간(분)** |
| (E) | **작업 시 에너지 소비량** |
| (S) | **휴식 시 에너지 소비량** |
| 8시간·남성 기준 계산 | **144분** · 성별 기준을 바꾸어 계산하지 않음 |

## 자주 틀리는 포인트

분모 (E-1.5)를 (E+1.5)로 바꾸거나 전체 작업시간을 시간 그대로 대입하지 않음 · 산소소비량의 단위를 임의로 kcal로 바꾸지 말고 문항에서 사용하는 환산 조건을 유지함
