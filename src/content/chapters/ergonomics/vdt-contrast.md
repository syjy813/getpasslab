## 핵심 개념

<strong>VDT 화면 대비</strong>는 문자와 배경의 휘도 관계를 나타냄 · 수록 기출의 부호 convention에서는 문자 휘도를 배경 휘도로 나눈 뒤 음수 부호를 붙여 네거티브 대비를 표시함

$$C=-\frac{L_{\mathrm{char}}}{L_{\mathrm{bg}}}$$

## 계산 기준

배경 휘도는 조도와 반사율로 계산함

$$L_{\mathrm{bg}}=\frac{E\rho}{\pi}$$

문항 값 (E=350\ \text{lux}), (\rho=0.85)이면 (L_{배경}\approx94.6\ \text{cd/m^2})임 · 문자 휘도 (400\ \text{cd/m^2})를 대입하면

$$C\approx-\frac{400}{94.6}\approx-4.2$$

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| VDT 화면 대비 C | **$C=-\frac{L_{\mathrm{char}}}{L_{\mathrm{bg}}}$** |
| Lbg | **$L_{\mathrm{bg}}=\frac{E\rho}{\pi}$** |
| 반사율 85% | **0.85로 대입** |
| 문자 휘도 400cd/m² | **문제값 그대로 대입** |
| 계산 입력 | **조도·반사율·문자 휘도만 사용** |
| 네거티브 표시 | **부호 유지** · 분자·분모 순서 확인 |
| 반사율 85%·조도 350lux·문자 휘도 400cd/m² | 배경 휘도 약 94.7cd/m² → 대비 약 **−4.2** |

## 자주 틀리는 포인트

반사율을 백분율 85가 아니라 소수 (0.85)로 사용함 · 배경 휘도와 문자 휘도의 분자·분모를 바꾸면 값의 크기가 달라지고, 네거티브 표시의 부호도 빠뜨리기 쉬움
