## 핵심 개념

<strong>MTTF(Mean Time To Failure)</strong>는 수리하지 않고 사용하는 부품이나 시스템이 고장날 때까지의 평균 동작시간임 · 고장률이 일정한 지수분포 모델에서는 평균 고장률의 역수로 표현할 수 있음

$$MTTF = \frac{1}{\lambda}$$

## 계산 기준

기출문항처럼 동일 부품 (1000)개를 합계 (100000)시간 운전하고 (5)개가 고장났다면 총 운전시간을 고장 수로 나눔

$$MTTF = \frac{1000\times100000}{5} = 2\times10^7\ \text{시간}$$

- MTTR은 평균수리시간임
- MTBF는 수리 가능한 장비의 고장 간 평균 운전시간으로, MTTF와 용어 적용 대상이 다름

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| MTTF | **$MTTF = \frac{1}{\lambda}$** |
| 1,000개·각 100,000시간·고장 5건 | **$MTTF = \frac{1000\times100000}{5} = 2\times10^7\ \text{시간}$** |
| MTTR | **평균수리시간임** |
| MTBF | **수리 가능한 장비의 고장 간 평균 운전시간** · MTTF와 적용 대상이 다름 |
| 개수와 총 운전시간을 곱하지 않거나 고장 수로 나누 | **단계를 빠뜨리지 않음** |
| 시간 단위 | **계산 전후 동일하게 유지** |

## 자주 틀리는 포인트

개수와 총 운전시간을 곱하지 않거나 고장 수로 나누는 단계를 빠뜨리지 않음 · 시간 단위는 계산 전후 동일하게 유지함
