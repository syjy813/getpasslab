## 핵심 개념

안전성 평가는 자료를 검토한 뒤 위험을 정성적으로 파악하고, 필요한 경우 정량적으로 확인한 다음 대책과 재평가로 이어지는 순서로 이해함 · 이 챕터에서는 기출에 나타난 기본 흐름만 다룸

## 절차 및 판별 기준

1. 자료를 검토하고 평가 범위와 설비 조건을 확인함
2. 정성적 평가로 위험요인과 설계·운전 관련 항목을 분류함
3. 정량적 평가가 필요한 위험을 수치로 확인함
4. 위험 저감 대책을 세움
5. 대책 적용 후 결과를 재평가함
6. 필요하면 FTA와 같은 분석으로 원인 구조를 추가 확인함

### 설계관계와 운전관계 구분

설계관계 항목은 건조물, 공장 내 배치, 입지조건처럼 설비를 계획하고 배치하는 단계의 조건임 · 원재료와 중간제품은 운전 과정에서 취급·관리되는 대상이므로 설계관계 항목과 구분함

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 안전성 평가 제2단계 | **정성적 평가** |
| 위험 저감 대책 | **평가 결과에 따라 수립** |
| 대책 적용 후 | **결과 재평가** |
| 설계관계 항목 | **건조물·공장 내 배치·입지조건** |
| 설계관계 항목이 아닌 것 | **원재료·중간제품** · 운전관계 대상 |
| 평가 흐름 | **자료 검토** → **정성 평가** → 필요 시 **정량 평가** → **대책** → **재평가** |

## 자주 틀리는 포인트

정성적 평가를 정량 계산으로 오해하지 않음 · 또한 평가 단계의 이름과 항목의 분류를 섞지 말고, 문제에서 ‘설계’인지 ‘운전’인지 확인함
