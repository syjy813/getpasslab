## 분석 기법을 고르는 기준

시스템 안전분석은 사고의 원인이나 결과를 살펴 위험을 찾는 방법임

문제에서 **무엇을 출발점으로 삼는지**, **설비·인간·관리 중 무엇을 분석하는지**를 먼저 확인함

| 기법 | 판별 단서 |
|---|---|
| PHA<br />예비위험분석 | 구상·개발 초기의 위험 식별 |
| FHA<br />결함위험분석 | 서브시스템의 결함과 영향 |
| FMEA | 부품의 고장형태에서 영향을 검토하는 귀납적 분석 |
| FTA | 사고인 톱사상에서 원인을 거슬러 찾는 연역적 분석 |
| ETA | 초기 사상 뒤의 성공·실패에 따른 결과 분기 |
| HAZOP | 가이드워드로 설계 의도에서 벗어난 이탈 탐색 |
| THERP | 인간 행동의 실수확률을 정량적으로 추정 |
| OHA<br />운용위험분석 | 저장·이동·운용 중 과업과 활동의 위험 |
| CA<br />치명도 분석 | 고장에 따른 손실·인명 피해의 위험도 평가 |

FTA와 FMEA·ETA의 **연역·귀납 방향**을 바꾸어 읽지 않음

## MORT의 판별 단서

MORT는 관리·설계·생산·보전을 포함하는 광범위한 안전을 검토하는 기법임

원자력 산업처럼 이미 상당한 안전이 확보된 분야에서 **추가적인 고도의 안전 달성**, **관리까지 포함한 분석**을 묻는다면 MORT로 연결함
