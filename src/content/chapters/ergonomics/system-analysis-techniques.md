## 핵심 개념

주요 시스템 안전 분석 기법

| 기법 | 방향·성격 | 핵심 |
|------|-----------|------|
| PHA | 정성적 | 예비위험분석, 구상 단계 최초 적용 · 식별 4범주: 파국적·중대(위기)·한계적·무시가능 |
| FHA | 서브시스템 | 결함위험분석, 서브시스템의 고장위험과 영향을 분석 |
| FMEA | 귀납적·정성적 | 부품 고장형태 → 영향 분석 |
| FTA | 연역적·정량적 | 톱사상에서 원인 전개 |
| ETA | 귀납적·정량적 | 초기 사상에서 결과 분기(사건나무) |
| HAZOP | 정성적 | 가이드워드로 설계 의도와의 이탈 탐색 |
| THERP | 정량적 | 인간 과오율(HEP) 예측 기법 |
| MORT | 관리 중심 | 원자력 등 고도 안전 확보 분야에서 관리·설계·생산·보전의 광범위한 안전 도모 |
| OHA | 운용 중심 | 시스템이 저장·이동·운용되는 과정의 과업·활동에서 생기는 위험 분석 |
| CA | 정량적 | 치명도 분석 — FMEA 보완 |

## 수명주기 적용 시점

| 기법 | 적용 범위·시점 |
|---|---|
| **PHA** | 모든 시스템 안전분석의 첫 단계 · 구상단계에서 시스템 고유의 위험상태와 예상 재해수준을 식별 |
| **FHA** | 시스템을 서브시스템으로 구체화하는 단계에서 결함의 위험과 영향을 분석 |

PHA는 시스템 수명주기에서 가장 먼저 적용되는 기법이고 FHA는 **서브시스템 분석**에 사용됨 · 두 약어의 영문 첫 글자가 비슷하더라도 적용 범위를 바꾸어 읽지 않음

## 인간신뢰도 관련 기법

인간신뢰도는 사람이 오류 없이 과업을 수행할 가능성을 평가하는 영역임 · 함께 출제되는 약어는 다음처럼 목적을 구분함

| 기법 | 영문·의미 | 판별 기준 |
|---|---|---|
| **CIT** | Critical Incident Technique · 위급사건기법 | 사고·위급사건 사례에서 중요한 행동을 수집 |
| **TCRAM** | Task Criticality Rating Analysis Method · 직무위험도 분석법 | 과업의 중요도·위험도를 평정 |
| **THERP** | Technique for Human Error Rate Prediction | 작업을 분해해 인간실수확률을 정량화 |
| **HCR** | Human Cognitive Reliability | 인지과정에서 오류 없이 수행할 가능성을 평가 |
| **SLIM** | Success Likelihood Index Method | 작업 조건을 이용해 성공 가능성 지수를 산정 |
| **CES** | Cognitive Error Scoring | 인지 오류를 유형화·점수화 |
| **OAT** | Operator Action Tree | 운전원 행동의 성공·실패 경로를 나무 형태로 전개 |

`OHA`의 `O`도 Operator/Operating 계열로 보이지만, OAT처럼 인간행동 확률만 계산하는 기법이 아님 · OHA는 **시스템 운용 과정의 위험**, OAT는 **운전원 행동 경로**를 중심으로 봄

HAZOP 가이드워드

| 워드 | 의미 |
|------|------|
| No/Not | 설계 의도의 완전한 부정 |
| More/Less | 양의 증가/감소 |
| As well as | 성질상의 증가(부가) |
| Part of | 성질상의 감소(일부만 수행) |
| Reverse | 설계 의도의 논리적 반대 |
| Other than | 완전한 대체 |

HAZOP는 공정의 변수마다 가이드워드를 적용해 설계 의도에서 벗어난 이탈을 찾고, 가능한 원인과 결과·기존 방호·개선안을 팀 단위로 검토함 · 다양한 관점을 반영하기 좋지만 회의와 기록에 인력·시간·비용이 많이 들고 반복 검토가 길어질 수 있음

## 기법별 구분

| 축 | 구분 | 기법 |
|------|------|------|
| 방향 | 연역 vs 귀납 | FTA vs FMEA·ETA |
| 정량성 | 정량 vs 정성 | FTA·ETA·THERP vs PHA·HAZOP |
| 대상 | 설비 vs 인간 vs 관리 | HAZOP vs THERP vs MORT |

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| PHA | **정성적** · 예비위험분석, 구상 단계 최초 적용 · **식별 4범주: 파국적·중대(위기)·한계적·무시가능** |
| FMEA | **귀납적·정성적** · 부품 고장형태 → 영향 분석 |
| FTA | **연역적·정량적** · 톱사상에서 원인 전개 |
| ETA | **귀납적·정량적** · 초기 사상에서 결과 분기(사건나무) |
| HAZOP | **정성적** · 가이드워드로 설계 의도와의 이탈 탐색 |
| THERP | **정량적** · 인간 과오율(HEP) 예측 기법 |
| FHA | **서브시스템의 결함위험 분석** |
| OHA | **운용 중 과업·활동에서 생기는 위험 분석** |
| CA | **치명도 분석** · 고장이 손실·인명 피해로 이어질 위험도를 평가 |
| HAZOP `OTHER THAN` | **완전대체** · 기타 환경요인이 아님 |
| HAZOP 단점 | 다학제팀·회의가 필요해 **시간과 비용이 큼** |
| MORT | 관리·설계·생산·보전을 망라한 **고도의 시스템 안전분석** |

## 자주 틀리는 포인트

> ⚠️ **함정 주의**: 가이드워드 교차 매칭이 최다 함정 — "완전대체"는 Other than, "완전 부정"은 No/Not · PHA 4범주에 "통제적" 등 비범주를 끼운 선지, FTA를 귀납으로 서술한 선지가 반복 정답
