## 핵심 개념

인간-기계 시스템 설계의 6단계.

| 단계 | 명칭 | 주요 활동 |
|------|------|-----------|
| **1** | **목표 및 성능명세 결정** | 시스템의 목적·성능 요건 설정 |
| **2** | **시스템(체계)의 정의** | 목표 달성에 필요한 기능 결정 |
| **3** | **기본설계** | **기능 할당(인간 vs 기계), 직무분석, 인간성능 요건 명세, 작업설계** |
| **4** | **계면(인터페이스)설계** | 표시장치·조종장치·작업공간 설계 |
| **5** | **촉진물(보조물)설계** | 매뉴얼·교육훈련 프로그램 등 지원 수단 |
| **6** | **시험 및 평가** | 성능 검증, 개선 |

기능 할당의 원칙 — 인간은 융통성·판단·귀납이 우수, 기계는 반복·신속·정밀·연역이 우수. 비용·신뢰도를 고려해 배분하며, 모든 기능을 기계에 할당하는 것이 항상 유리한 것은 아님.

## 단계별 판단

| 단계 | 키워드 | 주의점 |
|------|--------|--------|
| **3단계** | 할당·직무분석·작업설계 | 최다 출제 |
| **4단계** | 표시·조종장치 (C/R비 등) | 계면 = 인터페이스 |
| **5단계** | 매뉴얼·훈련 | `촉진물` 명칭 단답 |

## 시험 포인트

- 순서는 <strong>목표·성능명세 → 시스템 정의 → 기본설계 → 계면설계 → 촉진물설계 → 시험·평가</strong>다.
- 기능 할당·직무분석·인간성능 요건 명세·작업설계는 <strong>3단계 기본설계</strong>에 속한다.
- 표시장치·조종장치·작업공간은 4단계 계면설계에 속한다.
- 매뉴얼과 교육훈련 프로그램은 5단계 촉진물설계에 속한다.
- 인간과 기계의 강점을 비교하고 비용·신뢰도를 고려해 기능을 할당한다.
- 시스템 수명주기 5단계와 설계 작업 6단계를 서로 다른 체계로 구분한다.

## 자주 틀리는 포인트

- 기능 할당과 직무분석을 시스템 정의나 계면설계 단계로 이동시키지 않는다.
- 첫 단계를 시스템 정의로 시작하지 않는다.
- 모든 기능을 기계에 할당하는 것이 항상 유리하다고 단정하지 않는다.

> ⚠️ **함정 주의**: 3단계의 <strong>기능 할당·직무분석</strong>과 4단계의 <strong>표시·조종장치 설계</strong>를 분리해 기억한다.
