## 핵심 개념

인체측정 자료의 설계 원칙은 사용자의 신체 치수 분포와 설비의 조절 가능성을 함께 고려하는 것임 · 어떤 치수를 기준으로 할지는 설비의 기능과 사용자의 움직임에 따라 달라짐

## 판별 기준

### 설계 원칙

- **조절식 설계**: 의자나 책상처럼 사용자가 직접 높이·위치를 조절할 수 있을 때 적용함
- **평균치 설계**: 조절이 어렵고 극단치보다 대표 사용자의 편의가 중요한 경우 평균치를 사용함
- **최대치 설계**: 출입문처럼 큰 사람이 통과해야 하는 치수에는 큰 집단의 값을 기준으로 함
- **최소치 설계**: 손잡이 간격이나 조작거리처럼 작은 사람이 도달해야 하는 항목에 적용함

### 시험 판단 기준

2020년 9월 시험 34번의 의자·책상은 조절식 설계가 적합함 · 2021년 5월 시험 21번의 은행 접수대와 공원 벤치는 평균치 적용 사례임 · 2021년 8월 시험 29번의 출입문은 최대집단치를 기준으로 하며, 2021년 3월 시험 21번은 인체측정 응용원칙이 아닌 항목을 고르는 문제임

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 조절식 설계 | 의자나 책상처럼 사용자가 직접 **높이·위치를 조절할 수 있을 때** 적용 |
| 평균치 설계 | 조절이 어렵고 극단치보다 **대표 사용자의 편의가 중요한 경우** 평균치 사용 |
| 최대치 설계 | 출입문처럼 **큰 사람이 통과해야 하는 치수**에 큰 집단의 값 적용 |
| 최소치 설계 | 손잡이 간격이나 조작거리처럼 **작은 사람이 도달해야 하는 항목**에 적용 |
| 인체측정·설계원칙 | **모든 설비를 평균치로 설계한다고 단정하지 않음** |
| 출입문 치수 | 큰 사용자가 통과해야 하므로 **최대치 방향**으로 설계함 |

## 자주 틀리는 포인트

- 모든 설비를 평균치로 설계한다고 단정하지 않음
- 출입문과 같이 큰 사용자가 통과해야 하는 치수는 최대치 방향임
- 조절식 설계는 평균치의 대체가 아니라 사용자 차이를 흡수하는 방법임
