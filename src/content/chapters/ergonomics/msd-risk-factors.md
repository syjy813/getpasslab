## 핵심 개념

근골격계 부담작업은 한 가지 위험만으로 판단하지 않고 작업의 반복성·자세·힘·진동·접촉을 함께 살핌 · 기출에서 정리하기 쉬운 기억법은 `반·부·과·진·접`임

| **기억어** | 위험요인 | 판단 예 |
| --- | --- | --- |
| **반** | 반복동작 | 같은 손·팔 동작을 계속 반복 |
| **부** | 부자연스러운 자세 | 허리 굽힘, 쪼그림, 무릎 굽힘, 팔을 지지하지 않은 자세 |
| **과** | 과도한 힘 | 무거운 물체 들기, 강한 밀기·당기기·쥐기 |
| **진** | 진동 | 국소 또는 전신 진동에 지속적으로 노출 |
| **접** | 접촉 스트레스 | 신체 일부가 단단한 모서리·공구에 눌리거나 닿음 |

작업시간과 회복시간은 같은 위험요인의 노출 정도를 판단하는 조건임 · 반복 횟수, 작업 지속시간, 물체 무게와 자세를 함께 읽으며 단일 숫자만으로 결론 내리지 않음

## 판별 기준

2022년 3월 시험 32번과 2018년 8월 시험 21번은 반복 작업, 중량물 들기, 쪼그림·무릎 굽힘, 자료입력 등 부담작업의 범위를 비교함 · 2019년 8월 시험 39번은 국소진동으로 나타날 수 있는 말초혈관 장해를 물음

2022년 4월 시험 32번은 OWAS의 평가요소를 묻는 표·자세 판독형 문제임

> **확정 주의**  반복·부자연스러운 자세·과도한 힘·진동·접촉 스트레스는 서로 겹칠 수 있음 · 문제에서 요구한 주된 위험요인을 선택지의 작업 조건과 대조함

## 진동 노출과 레이노병

전신진동은 시각 기능·추적능력과 정밀한 근육 조절에 영향을 줄 수 있음 · 국소진동에 지속적으로 노출되면 말초혈관 장해로 손가락이 창백해지고 통증을 느끼는 **레이노병**이 발생할 수 있음

문제에서 `국소진동`, `손가락 창백`, `동통`이 함께 제시되면 레이노병으로 연결함 · 전신진동의 영향과 국소진동으로 인한 말초혈관 장해를 같은 증상으로 읽지 않음

## 신체 부위 운동 용어

| 용어 | 움직임 |
|---|---|
| **굴곡(flexion)** | 신체 부위 사이의 각도가 감소 |
| **신전(extension)** | 신체 부위 사이의 각도가 증가 |
| **외전(abduction)** | 신체 중심선에서 멀어짐 |
| **내전(adduction)** | 신체 외부에서 중심선 쪽으로 이동 |
| **외선(lateral rotation)** | 신체 중심선에서 바깥쪽으로 회전 |

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 반 | **반복동작** · 같은 손·팔 동작을 계속 반복 |
| 부 | **부자연스러운 자세** · 허리 굽힘, 쪼그림, 무릎 굽힘, 팔을 지지하지 않은 자세 |
| 과 | **과도한 힘** · 무거운 물체 들기, 강한 밀기·당기기·쥐기 |
| 진 | **진동** · 국소 또는 전신 진동에 지속적으로 노출 |
| 접 | **접촉 스트레스** · 신체 일부가 단단한 모서리·공구에 눌리거나 닿음 |
| 근골격계 유해요인 5종 | **진동 노출**과 **접촉 스트레스**를 단순한 자세 문제로 바꾸지 않음 |
| OWAS 평가요소 | **허리·팔·다리 자세와 하중** |
| 국소진동·손가락 창백·동통 | **레이노병** |
| 부담작업이 아닌 예시 | 하루 2시간 이상·시간당 5회 손·무릎 충격이라는 **낮은 빈도 조건** |
| 집중 자료입력 | 하루 총 **4시간 이상**이 기준 · 2시간은 오답 |
| 굴곡·신전 | **굴곡은 각도 감소 / 신전은 각도 증가** |
| 외전·내전 | **외전은 중심선에서 멀어짐 / 내전은 중심선으로 이동** |
