## 핵심 개념

<strong>양립성(compatibility)</strong>은 사용자가 기대하는 자극과 조작 반응의 관계가 실제 반응과 일치하는 정도임 · 기대와 실제의 불일치가 작을수록 학습과 반응에 필요한 부담이 줄어듬

## 판별 기준

- 개념 양립성은 표시나 기호가 사용자의 의미 해석과 맞는지 봄
- 운동 양립성은 조작 방향과 결과 움직임의 방향이 기대와 맞는지 봄
- 공간 양립성은 표시장치와 조작장치의 위치 관계가 대응하는지 봄
- 양립성이 높으면 코딩과 반응에 필요한 시간이 짧아지는 방향으로 이해함

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 개념 양립성 | **표시나 기호가 사용자의 의미 해석과 맞는지 봄** |
| 운동 양립성 | **조작 방향과 결과 움직임의 방향이 기대와 맞는지 봄** |
| 공간 양립성 | **표시장치와 조작장치의 위치 관계가 대응하는지 봄** |
| 양립성 | **높을수록 코딩·반응 시간이 짧아짐** |
| `양립성이 높을수록 반응시간 증가` | **방향을 뒤집은 오답** |
| 장치의 물리적 크기 | 양립성보다 **인간의 기대와 자극·반응 관계**를 먼저 봄 |
| 양립성 효과가 클수록 반응시간이 길어짐 | **틀린 설명** |

## 자주 틀리는 포인트

양립성이 높을수록 반응 시간이 길어진다는 서술은 방향을 뒤집은 것임 · 양립성은 단순한 장치의 물리적 크기가 아니라 인간의 기대와 자극·반응 관계를 다룸
