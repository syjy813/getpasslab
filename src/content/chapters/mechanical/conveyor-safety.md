## 핵심 개념

컨베이어 안전장치 4종

| 장치 | 목적 |
|------|------|
| 화물 이탈 및 역주행 방지장치 | 정전·전압강하 시 화물·운반구의 이탈과 역주행 방지 · 무동력 또는 수평 전용으로 위험 우려가 없으면 예외 |
| 비상정지장치 | 신체 말림 등 위험 우려가 있는 경우 비상시 즉시 정지 · 무동력 전용으로 위험 우려가 없으면 예외 |
| 덮개·울 | 화물 낙하로 근로자가 위험해질 우려가 있는 부위 방호 |
| 건널다리 | 운전 중인 컨베이어 위로 근로자가 넘어가야 하는 경우 설치 |

역전방지장치의 분류

| 방식 | 종류 |
|------|------|
| 기계식 | 라쳇식, 롤러식, 밴드식 |
| 전기식 | 전기 브레이크, 스러스트 브레이크 |

작업시작 전 점검사항 — 원동기·풀리 기능, 이탈 등 방지장치 기능, 비상정지장치 기능, 원동기·회전축·기어·풀리 등의 덮개·울 이상 유무

## 장치 구분

| 용어 | 의미 | 주의점 |
|------|------|--------|
| 라쳇식 | 톱니 걸림으로 역회전 저지 | 기계식 대표 |
| 스러스트 브레이크 | 전동 유압 제동 | 전기식 — 기계식 아님 |
| 건널다리 | 컨베이어 위 횡단 통로 | 점검 항목 아님, 설비 기준 |

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 화물 이탈 및 역주행 방지장치 | **정전·전압강하 시 화물·운반구의 이탈과 역주행 방지** · 무동력 또는 수평 전용으로 위험 우려가 없으면 예외 |
| 비상정지장치 | **신체 말림 등 위험 우려가 있는 경우 비상시 즉시 정지** · 무동력 전용으로 위험 우려가 없으면 예외 |
| 덮개·울 | **화물 낙하로 근로자가 위험해질 우려가 있는 부위 방호** |
| 건널다리 | 운전 중인 컨베이어 위로 근로자가 **넘어가야 하는 경우 설치** |
| 기계식 | **라쳇식** · 롤러식, 밴드식 |
| 전기식 | **전기 브레이크** · 스러스트 브레이크 |
| 컨베이어 방호장치가 아닌 것 | **반발예방장치** |
| 작업 시작 전 점검 | 원동기·회전부·비상정지·역주행방지·이탈 상태 확인 · **유압장치 기능은 일반 항목 아님** |
| 구동부 측면 | 롤러 안내가이드 등 **이탈방지장치 설치** |
| 보도·난간·계단·사다리 | 컨베이어 **정지 후 설치** |
| 전동식 포터블 이동 | 전원 차단 → **최저 위치로 내림 → 이동** |

## 자주 틀리는 포인트

> ⚠️ **함정 주의**: "정전·전압강하 등에 의한 위험 방지 장치"의 답은 이탈 및 역주행 방지장치임 · 과부하방지·권과방지는 양중기 장치이며, 역전방지 기계식 종류에 스러스트 브레이크(전기식)를 섞은 선지도 구분함
