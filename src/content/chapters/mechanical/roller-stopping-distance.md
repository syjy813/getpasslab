## 핵심 개념

롤러기의 급정지거리는 위험점에 손이 접근했을 때 롤러가 정지하기까지 표면이 이동한 거리임 · 먼저 롤러의 표면속도를 계산하고, 속도 구간에 맞는 급정지거리 기준을 적용함

## 표면속도 계산

롤러의 표면속도는 롤러 둘레가 단위 시간에 이동하는 거리임

$$
v = \frac{\pi DN}{1{,}000}\;(\mathrm{m/min})
$$

`D`는 롤러 지름(mm), `N`은 회전수(r/min)임 · 지름과 회전수의 단위를 확인한 뒤 `m/min`으로 환산함 · 지름이나 회전수가 커지면 표면속도도 같은 비율로 증가함

## 급정지거리 기준

수록 기출에서는 표면속도 30m/min을 경계로 급정지거리를 구분함

| 표면속도 | 급정지거리 기준 |
|---|---:|
| 30m/min 미만 | $\pi D/3$ 이내 |
| 30m/min 이상 | $\pi D/2.5$ 이내 |

여기서 `D`는 롤러의 지름임 · `πD`는 롤러 한 바퀴의 원주이므로, 계산 결과는 롤러 표면이 정지할 때까지 이동할 수 있는 최대 거리로 읽음

## 판단 순서

1. 롤러 지름과 회전수의 단위를 확인함
2. `πDN/1000`으로 표면속도를 계산함
3. 계산값이 30m/min 미만인지 이상인지 구분함
4. 해당 구간의 `πD/3` 또는 `πD/2.5` 기준을 적용함
5. 조작부 위치나 복귀장치 조건은 정지거리와 별도로 판단함

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 롤러기 급정지거리 v | **$v = \frac{\pi DN}{1{,}000}\;(\mathrm{m/min})$** |
| 30m/min 미만 | **$\pi D/3$ 이내** |
| 30m/min 이상 | **$\pi D/2.5$ 이내** |
| 표면속도 | **정확히 30m/min**이면 **`이상` 구간인 `πD/2.5` 적용** |
| πDN/1000 | **표면속도** · **`πD/3`과 `πD/2.5`는 급정지거리 기준임** |
| 표면속도 vs 급정지거리 | **모두 롤러 지름 사용** · 결과 단위는 속도와 거리로 구분 |
| 지름 36cm·50rpm | 표면속도 30m/min 이상 → 약 **45cm 이내** |
| 지름 300mm·30rpm | 표면속도 30m/min 미만 → 약 **314mm 이내** |
| 원주 6m·표면속도 30m/min | 최대 2.4m이므로 **2.6m 이내는 부적합** |
| 급정지장치 종류가 아닌 것 | **어깨조작식** |

## 자주 틀리는 포인트

30m/min 경계에서 미만과 이상을 바꾸지 않음 · 표면속도 계산식의 회전수 `N`을 급정지거리 식에 다시 넣거나, 지름과 반지름을 바꾸어 계산하지 않음 · 로프 조작부의 재질·지름 기준은 별도 학습 항목임
