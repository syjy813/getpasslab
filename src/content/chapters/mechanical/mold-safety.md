## 핵심 개념

프레스 금형 설치·해체·운반 작업에서는 체결 기준을 지키고, 신체가 위험한계에 들어가면 안전블록을 사용해야 함

| 항목 | 기준 |
|------|------|
| T홈 안길이 | 설치 볼트 직경의 2배 이상 |
| 고정볼트 | 고정 후 나사산이 3~4개 정도 짧게 남도록 (슬라이드 면과의 협착 방지) |
| 고정용 브래킷(물림판) | 브래킷은 수평, 고정볼트는 수직으로 고정 |
| 설치용구 | 프레스 구조에 적합한 형태 사용 |

안전블록 — 금형 부착·해체·조정 작업 시 슬라이드가 갑자기 하강하는 것을 막는 받침 · 신체 일부가 위험한계 내에 들어가는 작업에서 사용 의무

금형 파손 위험 방지 — 맞춤핀은 억지끼워맞춤, 쉽게 파손되는 부위 커버, 운반 시 상하 금형 고정

## 조치 기준

| 항목 | 값 | 주의점 |
|------|------|--------|
| T홈 안길이 | 볼트 직경 × 2 이상 | "이하"로 변조 |
| 남는 나사산 | 3~4개 | 협착 방지 목적까지 세트 |
| 안전블록 | 슬라이드 낙하 방지 | 부착·해체·조정 시 사용 |

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| T홈 안길이 | **설치 볼트 직경의 2배 이상** |
| 고정볼트 | 고정 후 **나사산이 3~4개 정도 짧게 남도록**(슬라이드 면과의 협착 방지) |
| T홈 안길이 · 볼트 직경 × 2 이상 | **볼트 직경 × 2 이상** · "이하"로 변조 |
| 남는 나사산 | **3~4개** · 협착 방지 목적까지 세트 |
| 고정용 브래킷(물림판) | **브래킷은 수평** · 고정볼트는 수직으로 고정 |
| 설치용구 | **프레스 구조에 적합한 형태 사용** |
| 금형 부착·해체·조정 중 신체가 위험한계 내 | **안전블록 사용** |
| 안전블록 대상이 아닌 것 | **금형 가공작업** |
| 금형 스프링 | 파손 비산 위험을 줄이는 **압축형 사용** |

## 자주 틀리는 포인트

> ⚠️ **함정 주의**: "T홈 안길이는 설치 볼트 직경 이하"는 틀린 설명이며, 직경의 2배 이상이 맞음 · 안전블록은 금형 가공 자체가 아니라 금형의 부착·해체·조정 중 신체 일부가 위험한계에 들어가는 경우 사용하는 임시 안전조치임
