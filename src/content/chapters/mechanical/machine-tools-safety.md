## 핵심 개념

선반의 방호장치·부속장치

| 장치 | 역할 |
|------|------|
| 칩 브레이커 | 연속 발생하는 칩을 짧게 끊는 공구 부착형 장치 |
| 덮개(실드) | 칩·절삭유 비산 방호 |
| 척 커버 | 척 회전부 접촉 방지 |
| 브레이크 | 급정지 |
| 방진구 | 지름에 비해 긴(길이가 지름의 12배 이상) 일감의 절삭 진동 방지 |

기계별 안전수칙 핵심

| 기계 | 수칙 |
|------|------|
| 선반 | 장갑 착용 금지, 치수 측정·수리·청소는 정지 후, 칩은 브러시로 제거, 긴 일감은 방진구 |
| 밀링 | 커터 교환·측정은 정지 후, 칩은 회전 정지 후 브러시 제거, 커터에 얼굴 접근 금지, 장갑 금지 |
| 드릴 | 장갑 금지, 작은 일감은 바이스·클램프로 고정(손으로 잡지 않기), 구멍 관통 직전 이송 감속, 칩은 정지 후 제거 |
| 플레이너 | 베드 위에 물건을 두지 않고 바이트 돌출을 짧게 하며 피트에는 뚜껑 설치 · 칩 브레이커는 칩을 **짧게** 끊는 방향 |

### 기계별 세부 판별

| 기계 | 옳은 조치 | 반복되는 오답 |
|---|---|---|
| 선반 | 바이트 돌출 길이를 짧게 고정하고 치수 측정·주유·청소 전 정지 | 저속 회전 중 측정·주유, 바이트를 길게 장착 |
| 선반 | 옷자락을 정리하고 소매는 단추 등으로 밀착 | 회전체에 감길 수 있는 끈으로 소매를 묶음 |
| 밀링 | 커터를 컬럼 가까이 설치하고 일감을 충분히 물려 고정 | 커터를 컬럼에서 멀리 설치, 강력 절삭인데 일감을 짧게 물림 |
| 밀링 | 절삭을 멈춘 뒤 치수 측정과 칩 제거 | 절삭 중 치수 측정, 선반용 칩 브레이커로 칩 제거 |
| 드릴 | 기동 전에 척 렌치를 제거하고 작은·긴 일감은 바이스나 클램프로 고정 | 일감을 손으로 잡고 천공 |
| 휴대용 드릴 | 드릴·리머는 전용 공구로 고정·분리 | 금속 망치로 타격해 고정·분리 |

선반·밀링·드릴의 공통 판단 순서는 **회전체 정지 → 일감·공구 고정 → 손 대신 브러시·전용공구 사용**임 · 이 세 절삭기계는 장갑을 끼고 회전체에 접근하지 않는 것이 핵심이며, 이들과 전기용접을 비교해 장갑 착용 작업을 고르는 수록 기출에서는 **전기용접작업**이 정답임 · 장치 이름을 묻는 문제와 작업 행동을 묻는 문제를 먼저 구분하면 선지 소거가 쉬움

## 장치·수칙 구분

| 용어 | 소속 | 주의점 |
|------|------|--------|
| 칩 브레이커 | 선반 (바이트 부착) | "방호장치의 일종인 칩 제거 기구" 표현으로 출제 |
| 방진구 | 선반 부속장치 | 진동 방지 — 방호장치와 구분 |
| 아버 | 밀링 커터 고정축 | 형삭기 구조부 함정과 교차 |

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 방진구 | **길이가 지름의 12배 이상인 일감**의 **절삭 진동 방지** |
| 칩 브레이커 | **연속 발생하는 칩을 짧게 끊는 공구 부착형 장치** |
| 덮개(실드) | **칩·절삭유 비산 방호** |
| 척 커버 | **척 회전부 접촉 방지** |
| 브레이크 | **급정지** |
| 선반 | **장갑 착용 금지** · 치수 측정·수리·청소는 정지 후, 칩은 브러시로 제거, 긴 일감은 방진구 |
| 선반·밀링·드릴 vs 전기용접 | 장갑 착용 작업을 고르면 **전기용접작업** |
| 플레이너 | **베드 위 물건 금지·바이트 짧게·피트 뚜껑·칩은 짧게 처리** |

## 자주 틀리는 포인트

> ⚠️ **함정 주의**: 선반·밀링·드릴의 공통 원칙은 장갑 금지, 정지 후 접촉, 브러시로 칩 제거임 · 플레이너 문제에서는 `칩 브레이커로 칩이 길게 되도록 한다`는 표현이 반대 방향의 오답임 · "장갑을 끼고 작업한다", "회전 중 칩을 손으로 제거한다"는 설명을 고르지 않음 · 절삭가공 분류에서는 소성가공 기계인 프레스를 제외함
