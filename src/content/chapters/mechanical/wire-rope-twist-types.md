## 핵심 개념

와이어로프는 가는 **소선(wire)** 여러 가닥을 꼬아 **스트랜드(strand)**를 만들고, 여러 스트랜드를 **심강(core)** 둘레에 다시 꼬아 구성함

| 구성요소 | 역할·관계 |
|---|---|
| **소선** | 와이어로프를 이루는 가장 가는 강선 |
| **스트랜드** | 여러 소선을 한 묶음으로 꼰 가닥 |
| **심강** | 로프 중심에서 스트랜드를 지지하고 형태를 유지하는 중심부 |

구성요소의 포함 관계는 `소선 → 스트랜드 → 와이어로프` 순서임 · 심강은 이 스트랜드들이 둘러싸는 중심부이므로 소선·스트랜드와 같은 명칭으로 바꾸어 읽지 않음

와이어로프의 꼬임은 스트랜드의 꼬임 방향과 로프 전체의 꼬임 방향 관계로 구분함

- **보통꼬임(ordinary lay)**: 스트랜드와 로프의 꼬임 방향이 서로 반대임 · 취급이 비교적 안정적이고 킹크가 덜 생기는 방향의 특징이 있음
- **랭꼬임(lang lay)**: 스트랜드와 로프의 꼬임 방향이 같음 · 마모에 강하고 유연성이 좋지만 끝단 회전이나 킹크에 주의함
- S·Z는 꼬임 방향을 나타내는 표현이며, 보통꼬임과 랭꼬임의 분류와 혼동하지 않음

## 판별 기준

2019년 4월 시험 46번은 랭꼬임의 용도 설명 중 틀린 것을 고르는 문제임 · 끝이 자유롭게 회전하거나 킹크가 생기기 쉬운 곳에는 랭꼬임이 적합하다고 단정할 수 없으므로 3번을 판단함

2019년 3월 시험 44번은 보통꼬임과 랭꼬임의 차이를 물음 · 내마모성과 유연성이 우수하다는 설명은 랭꼬임의 특징이므로 보통꼬임의 특징으로 제시한 2번이 틀림

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 내마모성·유연성 우수 | **랭꼬임**의 특징 |
| 보통꼬임 | **방향이 반대이고 랭꼬임은 방향이 같음** |
| 꼬임 종류와 로프 구성요소 | **로프 지름 기준을 서로 바꾸지 않음** |
| 부정형 꼬임 문제 | **스트랜드와 로프 전체의 꼬임 방향 관계부터 확인** |
| 와이어로프의 꼬임 | **스트랜드 꼬임 방향**과 **로프 전체 꼬임 방향**의 관계로 구분 |
| 소선·스트랜드·심강 | **소선 → 스트랜드 → 와이어로프**, 중심에는 **심강** |
| 와이어 로프 꼬임 종류 · 보통 | **보통·랭·S·Z꼬임** |

## 자주 틀리는 포인트

- 보통꼬임은 방향이 반대이고 랭꼬임은 방향이 같음
- 마모 저항성과 유연성은 랭꼬임의 장점으로 읽음
- 꼬임 종류와 로프 구성요소, 로프 지름 기준을 서로 바꾸지 않음
