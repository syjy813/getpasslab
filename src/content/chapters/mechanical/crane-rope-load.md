## 핵심 개념

가속하여 물체를 들어 올릴 때 로프에 걸리는 총 하중은 질량에 중력가속도와 상승가속도를 더한 값임

$$P = m(g+a)$$

이 식은 수직으로 들어 올리는 단일 총하중을 계산하는 관계임 · 여러 가닥의 장력 분배, 슬링 각도, 안전율은 별도 조건이므로 섞지 않음

## 계산 기준

### 핵심 검산

- 2021년 3월 시험 50번: `2,000 × (9.8 + 10) = 39,600 N = 39.6 kN` → 4번
- 2018년 8월 시험 46번: `100 × (9.8 + 5) = 1,480 N` → 2번

### 시험 판단 기준

- 질량은 kg, 가속도는 m/s², 결과는 N으로 계산함
- kN 선택지이면 N을 1,000으로 나눔
- 정지 상태의 중량 `mg`와 가속 상승 하중 `m(g+a)`를 구분함

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 크레인 로프 하중 P | **$P = m(g+a)$** |
| 2,000 × (9.8 + 10) | **39,600N = 39.6kN** |
| 100 × (9.8 + 5) | **1,480N** |
| N → kN 변환 | **1,000으로 나눔** |
| 크레인 로프 하중 | **정지 상태 중량 `mg`와** **가속 상승 하중 `m(g+a)`을** 구분 |
| 가속 상승 | **가속도를 중력가속도에 더함** · 부호를 바꾸지 않음 |

## 자주 틀리는 포인트

- 가속도를 중력가속도에 더하지 않거나 부호를 바꾸지 않음
- 질량 kg을 힘 N으로 바로 읽지 않음
- 로프 한 가닥 장력과 물체에 작용하는 총하중을 혼동하지 않음
