## 핵심 개념

파괴시험 — 시험편을 파괴하며 성질 측정

| **시험** | 측정 대상 |
|------|-----------|
| **인장시험** | 항복점·인장강도·연신율 |
| **충격시험** | 인성(취성) |
| **피로시험** | 반복하중 수명 |
| **경도시험** | 표면 경도 |

비파괴시험(NDT) — 제품을 파괴하지 않고 결함 검출

| **기호** | 명칭 | 원리 | 적합 결함 |
|------|------|------|-----------|
| **VT** | 육안검사 | 외관 관찰 | 표면 |
| **PT** | 침투탐상 | 침투액의 개구 결함 침투 | 표면 개구 |
| **MT** | 자분탐상 | 강자성체 자화 후 누설자속 검출 | 표면·표면 직하 |
| **UT** | 초음파탐상 | 초음파 반사 | 내부 균열 |
| **RT** | 방사선투과 | 투과 사진 (콘트라스트·명료도) | 내부, 기록 보존 |
| **ET** | 와류(와전류) | 코일 접근 시 유기 전압·전류 변화 | 도체 표면 |
| **AE** | 음향방출 | 변형·균열 시 방출되는 응력파 감지 | 진행성 결함 |
| **LT** | 누설검사 | 기밀 확인 | 관통 결함 |

## 판별 기준

| **용어** | 의미 | 주의점 |
|------|------|--------|
| **누설자속** | 결함부에서 새어 나오는 자속 | MT의 원리 키워드 |
| **응력파** | 변형 과정에서 방출되는 파동 | AE의 원리 키워드 |
| **콘트라스트·명료도** | RT 투과사진의 상질 요소 | 세부 출제 이력 |

## 시험 포인트

### 우선 암기

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 인장시험 | **항복점·인장강도·연신율** |
| 충격시험 | **인성(취성)** |
| 피로시험 | **반복하중 수명** |
| 경도시험 | **표면 경도** |
| VT | **육안검사** · 외관 관찰 · 표면 |
| PT | **침투탐상** · 침투액의 개구 결함 침투 · 표면 개구 |
| MT·누설자속 | **자분탐상** · 강자성체의 표면·표면 직하 결함 |
| UT·초음파 반사 | **초음파탐상** · 내부 균열 |
| RT·투과사진 | **방사선투과** · 콘트라스트·명료도 |

### 추가 확인

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| ET·코일의 유기전압·전류 변화 | **와류탐상** · 도체 표면 결함 |
| AE·변형 시 응력파 | **음향방출시험** · 진행성 결함 |
| 항복점 | **인장시험** |
| 고속회전체 사전 비파괴검사 | 회전축 중량 **1톤 초과** + 원주속도 **120m/s 이상** |
| 비파괴시험이 아닌 것 | **인장·충격·피로시험** |
