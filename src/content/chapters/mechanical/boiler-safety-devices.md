## 핵심 개념

<strong>보일러 안전장치</strong>는 압력·수위·연소 상태를 감시하고, 허용 범위를 벗어나면 표시·경보·차단·방출로 사고의 진행을 막는 장치임 · 하나의 장치가 모든 위험을 처리하는 것이 아니라 압력 상승, 저수위, 실화와 같은 이상 상태마다 서로 다른 장치가 대응함

문제에서는 장치 이름만 외우게 하기보다 `무엇을 감지하는가`와 `감지 후 무엇을 하는가`를 바꾸어 제시함 · 예를 들어 압력계는 압력을 표시하지만 압력을 직접 방출하지 않고, 안전밸브는 설정압력에서 유체를 방출함 · 이 기능 차이를 먼저 잡으면 생소한 선택지도 판별할 수 있음

## 절차 및 판별 기준

### 주요 장치와 기능

| 감시 대상 | 장치 | 주된 기능 |
|---|---|---|
| 압력 | 압력계 | 현재 압력을 표시해 운전자가 상태를 확인하게 함 |
| 압력 | 압력제한스위치 | 설정 범위에서 버너·연료 공급을 차단해 정상압력으로 유도 |
| 압력 | 압력방출장치·안전밸브 | 설정압력에서 증기·유체를 방출해 파열 위험을 줄임 |
| 수위 | 수면계·수위계 | 보일러의 수위를 표시 |
| 수위 | 고저수위 조절·저수위 차단 | 위험 수위를 경보하고 급수·단수 또는 연소 차단으로 대응 |
| 화염 | 화염검출기 | 화염 소실을 감지해 미연소 연료의 계속 공급을 차단 |

방폭문은 연소실에서 급격한 압력 상승이 생겼을 때 압력을 완화하는 별도 보호수단임 · 언로드밸브, 아웃트리거, 과부하방지장치처럼 다른 기계의 안전장치를 보일러 방호장치 목록에 섞은 선택지를 제거함

### 수록 기출의 설정·검사 포인트

- 압력방출장치가 2개 이상 설치된 조건에서 수록 기출은 하나가 최고사용압력 이하, 다른 하나가 최고사용압력의 **1.05배 이하**에서 작동하도록 한 값을 물음
- 압력방출장치 검사 후 봉인 재료는 수록 기출에서 **납**으로 반복됨
- 압력방출장치를 7년마다 작동시험한다는 문장은 부적절한 안전수칙 선택지로 제시됐음 · 검사주기를 임의의 긴 기간으로 외우지 않음
- 바이메탈을 이용해 화염 상태를 검출하는 장치는 수록 기출에서 **스택 스위치**로 제시됨

이 숫자와 검사 표현은 2018~2022년 수록 문항의 조건을 설명하는 자료임 · 현재 모든 보일러의 설치·검사 기준으로 확대하지 않음

### 판단 순서

1. 문제에서 이상 상태가 압력, 수위, 화염 중 무엇인지 표시함
2. 요구 기능이 단순 표시인지, 경보인지, 연료 차단인지, 압력 방출인지 구분함
3. 해당 기능을 수행하는 장치를 연결함
4. 법령 수치가 포함되면 장치 개수와 최고사용압력 조건을 함께 읽음

압력제한스위치와 압력방출장치는 모두 압력 상승에 대응하지만 작동 결과가 다름 · 전자는 연소를 차단해 압력이 더 올라가는 원인을 줄이고, 후자는 유체를 방출해 압력을 직접 낮추는 최종 보호수단임

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 압력방출장치 작동시험 주기 7년 | **부적절한 안전수칙** · 임의의 긴 검사주기로 외우지 않음 |
| 이상 상태 | **압력·수위·화염 중 이상 유형 먼저 구분** |
| 압력 | **압력계** · 현재 압력을 표시해 운전자가 상태를 확인하게 함 |
| 압력 · 압력방출장치 | **압력방출장치·안전밸브** · 설정압력에서 증기·유체를 방출해 파열 위험을 줄임 |
| 수위 | **수면계·수위계** · 보일러의 수위를 표시 |
| 수위 · 고저수위 조절 | **고저수위 조절·저수위 차단** · 위험 수위를 경보하고 급수·단수 또는 연소 차단으로 대응 |
| 압력방출장치 2개 | 하나는 최고사용압력 이하 · 다른 하나는 **1.05배 이하**에서 작동 |
| 압력방출장치 봉인 | **납** 사용 |
| 상용압력 이상 상승 시 연소 차단 | **압력제한 스위치** |
| 바이메탈 화염검출 | **스택 스위치** |
| 보일러 방호장치가 아닌 것 | **아웃트리거·언로드밸브·과부하방지장치** |

## 자주 틀리는 포인트

- 압력계가 압력 초과를 자동 차단하거나 방출한다고 해석하지 않음
- 언로드밸브·아웃트리거처럼 이름이 기계장치처럼 보인다는 이유만으로 보일러 방호장치에 포함하지 않음
- 압력제한스위치와 안전밸브를 모두 `압력을 낮춘다`는 한 문장으로 외우지 말고 차단과 방출의 차이를 유지함
- 보일러 전체 구조나 압력용기 일반 이론은 이 챕터의 직접 범위가 아님 · 장치별 기능과 상호 차이를 중심으로 학습함
