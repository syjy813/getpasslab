## 검사 원리로 구분

비파괴검사(NDT)는 검사 대상을 파괴하지 않고 결함을 확인하는 방법임

| 기호·검사 | 원리와 대상 |
|---|---|
| VT · 육안 | 외관의 표면 상태 관찰 |
| PT · 침투 | 침투액으로 표면에 열린 결함 검출 |
| MT · 자분 | 강자성체의 결함부에서 생기는 누설자속 검출 |
| UT · 초음파 | 초음파의 반사 등으로 내부 결함 검출 |
| RT · 방사선 | 방사선 투과사진으로 내부 결함 확인 |
| ET · 와류 | 도체에 접근시킨 교류 코일의 유기전압·전류 변화 이용 |
| AE · 음향 | 변형 과정에서 방출되는 응력파 검출 |
| LT · 누설 | 관통 결함의 기밀·누설 확인 |

재료 **내부의 균열**은 연결 문제에서 UT로, **강자성체의 누설자속**은 MT로 판단함

## 검사별 세부 구별

### 초음파·자분탐상

- 초음파 탐상법: **반사식·투과식·공진식**이며 침투식은 제외함
- 자분탐상의 자화방법: **축통전법·전류관통법·극간법**이며 임피던스법은 제외함

### 방사선 투과사진

콘트라스트는 사진의 명암도, 명료도는 상의 선명함을 뜻함

- 콘트라스트에 영향을 주는 요인: **방사선의 선질·필름의 종류·현상액의 강도**
- 초점과 필름 사이의 거리는 위 명암도 요인과 구분함
- 상질 점검 항목: **투과도계 식별도·시험부의 사진농도 범위·계조계의 값**
- 주파수의 크기는 위 상질 점검 항목이 아님

## 고속회전체의 사전 검사 조건

연결 기출의 고속회전체 기준은 회전축 중량 **1톤 초과**와 원주속도 **120m/s 이상**을 함께 충족하는 경우임

중량의 `초과`와 속도의 `이상`을 구분함
