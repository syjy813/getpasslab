## 핵심 개념

<strong>크레인 안전장치</strong>는 하중·권상 위치·주행 상태를 감시하여 과부하, 권과, 충돌과 같은 위험 동작을 제한함 · 장치의 감지 대상과 차단 동작을 짝지어 이해함

## 판별 기준

### 주요 장치

- 과부하방지장치는 정격하중을 넘는 인양을 감지하여 경보 또는 동작 정지를 수행함
- 권과방지장치는 훅이나 달기기구가 상한에 접근할 때 권상 동작을 제한함
- 비상정지장치는 위험 상황에서 동력을 차단해 즉시 정지시킴
- 주행·횡행 제한장치와 충돌방지장치는 이동 범위와 인접 설비 충돌을 제한함
- 보호장치는 크레인 종류와 동작 방향에 따라 적용 대상이 달라짐
- 직동식 권과방지장치가 아닌 경우 달기구 윗면과 권상장치 아랫면의 간격은 **0.25m 이상**으로 조정함

### 적용 판단

문제의 위험이 하중 초과인지 상한 접근인지, 이동·충돌인지 먼저 분류함 · 과부하방지와 권과방지, 비상정지는 서로 대체되는 장치가 아님 · 탑승용 운반구의 추락 방지는 전용 탑승 안전 챕터에서 다룸

### 양중기 종류 구분

양중기는 **크레인(호이스트 포함)·이동식 크레인·리프트·곤돌라·승강기**로 구분함 · 승강기는 다시 승객용·화물용·소형화물용 엘리베이터와 에스컬레이터 등으로 세분함

`양중기`는 상위 설비 분류이고 `크레인 방호장치`는 특정 설비의 위험동작을 제한하는 장치임 · 곤돌라·승강기를 크레인의 방호장치 이름으로 고르지 않음

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 과부하방지장치 | **정격하중 초과 인양 감지** → **경보 또는 동작 정지** |
| 권과방지장치 | **훅이나 달기기구가 상한에 접근할 때 권상 동작을 제한** |
| 비상정지장치 | **위험 상황에서 동력을 차단해 즉시 정지** |
| 주행·횡행 제한장치와 충돌방지장치 | **이동 범위와 인접 설비 충돌을 제한** |
| 보호장치 | **크레인 종류와 동작 방향에 따라 적용 대상이 달라짐** |
| 모든 전원 차단·급정지 | **비상정지장치** |
| 달기구 윗면과 권상장치 아랫면 | 직동식 제외 시 **0.25m 이상** |
| 크레인 방호장치가 아닌 것 | **자동보수장치** |
| 이동식 크레인 방호장치가 아닌 것 | **파이널 리미트 스위치** |
| 양중기의 종류 | **크레인·이동식 크레인·리프트·곤돌라·승강기** |
| 승강기의 예 | **승객용·화물용·소형화물용 엘리베이터·에스컬레이터** |

## 자주 틀리는 포인트

정격하중 계산이나 와이어로프 자체 기준은 이 챕터의 직접 범위가 아님 · 이 문서의 수치·작동 조건은 기출에서 요구되는 기준으로만 확인함
