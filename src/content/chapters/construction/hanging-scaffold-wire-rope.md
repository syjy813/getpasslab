## 소선과 공칭지름

**달비계**는 위쪽 구조물에 매달아 사용하는 작업용 비계임

**소선**은 와이어로프를 구성하는 가는 철선이며, 여러 소선을 한 묶음으로 꼰 가닥을 **스트랜드**라고 함

**공칭지름**은 로프의 규격에 표시된 기준 지름임

## 와이어로프의 사용 금지 기준

| 점검 항목 | 사용 금지 기준 |
|---|---|
| 이음매 | **이음매가 있는 것** |
| 소선의 단선 | 일반 와이어로프의 **한 꼬임에서 끊어진 소선 수가 10% 이상**인 것 |
| 지름 감소 | **공칭지름의 7%를 초과하여 감소**한 것 |
| 꼬임 | **비정상적으로 꼬인 것** |
| 변형·부식 | **심하게 변형되거나 부식**된 것 |
| 열·전기충격 | **열과 전기충격으로 손상**된 것 |

단선 기준은 로프 전체가 아니라 **한 꼬임의 소선 수**를 기준으로 보며, 필러선은 제외함

**단선 10%는 사용 금지**에 해당하지만, **지름 감소 7%는 ‘7% 초과’ 조건에 해당하지 않음** · 두 기준의 대상과 경계값을 바꾸어 읽지 않음

현행 규칙은 위 와이어로프 기준을 **곤돌라형 달비계**에 적용하며, **비자전로프는 별도의 단선 기준**을 적용함

## 기출의 사용 가능 조건

2019년 8월 기출에서 <strong>한 꼬임의 소선 단선율 5%</strong>는 일반 와이어로프의 사용 금지 기준인 10% 미만이므로 **②를 선택함**

다른 보기의 이음매, 공칭지름 대비 10%의 지름 감소, 열·전기충격 손상은 각각 사용 금지에 해당함

단선율이 10% 미만이라는 이유만으로 다른 결함이 있는 로프까지 사용할 수 있는 것은 아님
