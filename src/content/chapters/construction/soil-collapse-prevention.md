## 핵심 개념

토사붕괴의 원인 분류

| 구분 | 내용 |
|------|------|
| 외적 원인 | 사면·법면의 경사 및 기울기 증가, 절토·성토 높이 증가, 공사에 의한 진동·반복하중, 지표수·지하수의 침투에 의한 토사 중량 증가, 지진·차량·구조물의 하중 작용, 토사·암석의 혼합층 두께 |
| 내적 원인 | 절토 사면의 토질·암질, 성토 사면의 토질 구성·분포, 토석의 강도 저하 |

전단응력 증대 원인 — 외적 하중 증가(건물·강우·눈), 함수비 증가에 따른 단위중량 증가, 균열 내 수압 증가, 인장응력에 의한 균열, 지진·폭파 진동

붕괴 예방 조치

| 조치 | 내용 |
|------|------|
| 기울기 준수 | 적절한 경사면 기울기 계획 (별표 11) |
| 하중 관리 | 활동할 가능성이 있는 토석 제거, 상부 하중 경감 |
| 배수 | 지표수·지하수 배제, 말비탈면 배수시설 |
| 보강 | 하단 압성토(성토로 눌러 저항 증대), 옹벽·흙막이 지보공 설치 |

## 굴착 지반의 이상 현상

| 현상 | 발생 조건·모습 | 구분 단서 |
|---|---|---|
| **파이핑** | 수위차가 있는 사질토에서 물길이 파이프처럼 형성되고 흙막이 배면의 물과 토사가 굴착면으로 빠져나옴 | 물길·토사 유출 |
| **동상** | 지반 온도가 내려가 간극수가 얼면서 부피가 커지고 지표면이 부풀어 오름 | 동결·간극수·지표 융기 |
| **히빙** | 연약한 점토지반 굴착 시 굴착면과 배면의 토압 차이로 굴착 저면이 솟아오름 | 연약 점토·저면 융기 |
| **보일링** | 지하수위가 높은 사질지반 굴착 시 상향 침투수가 모래와 함께 솟아오름 | 사질토·지하수·모래 분출 |

동상은 물이 **어는 온도 변화**, 히빙은 연약점토의 **토압 불균형**, 보일링과 파이핑은 사질토에서의 **침투수 흐름**이 중심임 · 네 현상을 단순히 모두 지하수 유입으로 묶지 않음


## 원인·예방 구분

| 용어 | 의미 | 주의점 |
|------|------|--------|
| 전단응력 | 활동면을 미끄러뜨리는 힘 | 증대 = 붕괴 방향 |
| 전단강도 | 활동에 저항하는 힘 | 저하 = 내적 원인 |
| 압성토 | 하단부 성토로 저항 모멘트 증대 | 공법명 단답 출제 |

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 기울기 준수 | **적절한 경사면 기울기 계획 (별표 11)** |
| 전단응력 | **활동면을 미끄러뜨리는 힘** · 증대 = 붕괴 방향 |
| 전단강도 | **활동에 저항하는 힘** · 저하 = 내적 원인 |
| 외적 원인 | **사면·법면의 경사 및 기울기 증가** · 절토·성토 높이 증가, 공사에 의한 진동·반복하중, 지표수·지하수의 침투에 의한 토사 중량 증가, 지진·차량·구조물의 하중 작용, 토사·암석의 혼합층 두께 |
| 내적 원인 | **절토 사면의 토질·암질** · 성토 사면의 토질 구성·분포, 토석의 강도 저하 |
| 하중 관리 | **활동할 가능성이 있는 토석 제거** · 상부 하중 경감 |
| 강우 대비 직접 대책 | 배수용 **측구 설치** |
| 비탈면 하단 성토로 붕괴 방지 | **압성토공** |
| 비탈면 상부 토사 적재 | 상부하중을 늘리므로 **금지** |
| 물길을 따라 토사 유출 | **파이핑** |
| 동결로 지표면 융기 | **동상** |
| 연약점토 굴착 저면 융기 | **히빙** |
| 사질토에서 물과 모래가 솟음 | **보일링** |

## 자주 틀리는 포인트

> ⚠️ **함정 주의**: "토사의 강도 저하"는 내적 원인 — 외적 원인 목록에 끼우거나 그 반대로 배치하는 것이 표준 함정 · 압성토는 비탈면 하단을 성토해 붕괴를 막는 공법 — 상단 성토로 바꾸면 오히려 붕괴 촉진
