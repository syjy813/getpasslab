여러 시트 선택은 **연속이면 Shift, 떨어져 있으면 Ctrl**, 여러 시트를 선택하면 그룹 상태가 되어 제목 표시줄에 `[그룹]`이 표시될 수 있음

## 연속된 시트 선택

1. 첫 번째 시트 탭 선택
2. `Shift`를 누른 채 마지막 시트 탭 선택

첫 시트부터 마지막 시트까지 연속으로 선택됨

## 떨어진 시트 선택

1. 첫 번째 시트 탭 선택
2. `Ctrl`을 누른 채 원하는 시트 탭을 각각 선택

비연속 시트 선택에 `Shift`를 사용한다고 판단하지 않음

## 모든 시트 선택

시트 탭의 바로 가기 메뉴에서 **모든 시트 선택**을 사용할 수 있음

현재 Microsoft Excel에서도 시트 탭을 우클릭해 `Select All Sheets`를 사용할 수 있음

## 그룹 상태

여러 시트를 선택하면 그룹으로 처리되어 동일한 위치의 셀 입력·서식 등이 여러 시트에 함께 적용될 수 있음

기출에서는 제목 표시줄의 파일명 뒤에 `[그룹]`이 표시된다고 출제됨

현재 Microsoft 문서에서도 여러 시트 선택 시 제목 표시줄에 `Group`이 표시되는 것으로 안내함

## 그룹 해제

선택되지 않은 시트 탭을 클릭하거나, 상황에 따라 시트 탭 바로 가기 메뉴의 **시트 그룹 해제**를 사용함

그룹 상태에서 입력·편집하면 여러 시트에 동시에 반영될 수 있으므로 작업 후 그룹 여부를 확인함

## 새 시트 삽입과 선택 단축키 구별

`Shift + F11`

→ 새 워크시트 삽입

비연속 시트 선택 단축키가 아님
