Excel 입력 키 문제는 **데이터 입력 중인지, 입력을 확정한 뒤 이동하는지, 여러 셀이 선택된 상태인지, Scroll Lock이 켜졌는지**를 먼저 확인해야 함

## Esc — 입력 취소

셀에 값을 입력하는 도중 `Esc`

→ 현재 입력 취소

입력값을 확정한 뒤 다른 셀로 이동하는 키로 보지 않음

## Enter — 입력 확정 후 이동

일반적인 기본 설정에서 값을 입력하고 `Enter`

→ 입력 확정 후 아래 셀로 이동

예

`A1` 입력 후 Enter → `A2`

`C5` 입력 후 Enter → `C6`

Enter 이동 방향은 Excel 옵션에서 변경될 수 있으므로 **기출의 기본 설정 문맥**으로 판단함

## 방향키 — 입력 확정 후 해당 방향 이동

일반 셀 입력 상태에서 값을 입력한 뒤 오른쪽 방향키

→ 값을 확정하고 오른쪽 셀로 이동하는 것으로 출제됨

예

`A1` → 오른쪽 방향키 → `B1`

`C5` → 오른쪽 방향키 → `D5`

단, 수식 편집 등 특정 편집 모드에서 방향키의 역할이 달라질 수 있으므로 상태를 확인함

## Home — 현재 행의 A열

일반 선택 상태에서 `Home`

→ 현재 행의 첫 번째 열인 A열로 이동

원본 기출

`D5`에서 Home → `A5`

`D1`이나 `A1`로 이동하는 것이 아님

## 입력 도중 Home은 이동 확정 키가 아님

기출의

`C5에 값을 입력하고 Home → C5 값 확정 후 C1 이동`은 틀림

값을 직접 편집하는 상태의 Home은 텍스트 커서 위치 이동과 관련될 수 있으며, 입력을 확정하고 같은 열의 1행으로 이동시키는 키가 아님

## 셀 안 줄바꿈

`Alt + Enter`

→ 한 셀 안에서 줄바꿈

여러 선택 셀에 같은 값을 한꺼번에 입력하는 키가 아님

## 여러 셀에 같은 값 입력

1. 여러 셀 선택
2. 값 입력
3. `Ctrl + Enter`

→ 선택한 여러 셀에 동일 데이터 입력

`Shift + Enter`나 `Alt + Enter`가 아님

## Shift + Enter

기본 Enter 이동 방향이 아래쪽일 때

`Shift + Enter`

→ 반대 방향인 위쪽 셀로 이동

## Scroll Lock

Scroll Lock이 켜진 상태에서 방향키

→ 셀 포인터는 고정되고 워크시트 화면이 스크롤되는 동작으로 기출에 출제됨

Scroll Lock이 꺼져 있을 때의 일반 방향키 셀 이동과 구별함

## Ctrl + 마우스 휠

화면 확대/축소

셀 값·열 너비·인쇄 배율 자체를 변경하는 것이 아님

## 자동 완성

Excel의 셀 자동 완성은 같은 열에서 이미 입력된 **텍스트 항목**과 일치하는 내용을 바탕으로 나머지 문자를 제안하는 기능으로 이해함

연결 기출의

`텍스트, 텍스트/숫자 조합, 날짜, 시간 데이터가 모두 자동 완성`이라는 설명은 틀린 것으로 출제됨

자동 채우기 핸들을 사용한 숫자·날짜 계열 채우기와 **AutoComplete**를 같은 기능으로 보지 않음

## 날짜 표시가 ####로 보이는 경우

날짜·시간 값이 셀 너비보다 길어 표시되지 못하면 `####`가 나타날 수 있음

값이 삭제되었다는 의미가 아님

## 선택 범위 안에서 Enter 이동

한 행의 여러 셀을 선택한 상태라면 `Enter`로 **선택 범위 안의 셀을 오른쪽으로 차례로 이동** · 범위 선택이 없는 기본 아래쪽 이동과 구별
