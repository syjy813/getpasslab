Excel에서 **통합문서와 워크시트는 다른 대상**이므로 새 파일을 만드는 단축키와 현재 파일에 새 시트를 추가하는 단축키를 구별함

## 새 통합문서

`Ctrl + N`

→ 새 통합문서 생성

현재 열려 있는 통합문서에 시트를 추가하는 동작이 아님

## 새 워크시트

`Shift + F11`

→ 현재 통합문서에 새 워크시트 삽입

따라서

`Shift + F11 → 새 통합문서 생성`

은 틀림

## 현재 통합문서 창 닫기

연결 기출에서는 다음 두 단축키를 현재 통합문서 창 닫기로 출제함

- `Ctrl + W`
- `Ctrl + F4`

Excel 프로그램 전체 종료와 현재 통합문서 닫기를 같은 대상으로 보지 않음

## 앱 실행·파일 열기·새 문서 구별

출제기준 보완 범위에서는 다음을 구별함

- Excel 프로그램 실행
- 기존 통합문서 열기
- 새 통합문서 만들기
- 현재 통합문서에 시트 삽입
- 현재 통합문서 닫기

`새 파일`과 `새 시트`를 같은 동작으로 보지 않는 것이 핵심임
