Excel 옵션은 **모든 설정이 같은 범위에 적용되는 것이 아니므로 옵션 이름보다 `이 프로그램`, `열린 통합문서`, `이 통합문서`, `이 워크시트`처럼 적용 대상을 먼저 확인**함

## 옵션마다 적용 범위가 다름

Excel의 옵션 화면에는 프로그램 전체에 영향을 주는 설정과 특정 통합문서·워크시트를 대상으로 하는 설정이 함께 존재함

따라서

`Excel 옵션에서 변경했다 → 무조건 현재 파일에만 적용`

또는

`Excel 옵션에서 변경했다 → 모든 파일에 항상 적용`

처럼 판단하면 안 됨

## 화면의 대상 문구를 먼저 읽음

옵션 설정 문제에서 확인할 순서

1. 옵션 항목 이름 확인
2. 적용 대상 선택 상자·설명 확인
3. 현재 통합문서인지 특정 시트인지 프로그램 전체인지 구별
4. 입력·표시·계산 등 세부 기능은 해당 담당 챕터로 연결

## 계산 옵션의 대표 상황

학습 예시에서는 데스크톱 Excel에서 계산 방식을 수동으로 변경한 상황을 대표 사례로 제시함

데스크톱 Excel의 계산 옵션 변경은 **열린 모든 통합문서에 영향** · 현재 보고 있는 파일 하나에만 적용된다고 판단하지 않음

웹용 Excel에서는 계산 옵션이 현재 통합문서에 적용되므로 **데스크톱 앱과 웹용 Excel의 조건을 구별**

핵심은 **옵션마다 적용 대상이 다르므로 화면의 대상 표시를 확인**하는 것임

실제 기출이 아닌 계산 옵션의 적용 범위 비교 예시

## 옵션 전체 암기 금지

Excel 고급 옵션 전체 목록을 암기하는 챕터가 아님

현재 문제 해결에 필요한 판단

**무엇을 설정하는가 + 어디에 적용되는가**

만 구별함

## 학습 예시

`이 워크시트의 표시 옵션` 아래에서 특정 시트를 선택했다면 **선택된 워크시트에 적용되는 설정**으로 판단

실제 기출이 아닌 적용 범위 비교 예시
