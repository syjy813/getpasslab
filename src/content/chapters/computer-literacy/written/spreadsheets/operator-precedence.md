## 연산자 우선순위

괄호로 묶인 부분을 먼저 처리한 뒤 아래 순서 적용

1. 참조 `:` · 공백 · `,`
2. 음수 부호 `-` → 백분율 `%` → 거듭제곱 `^`
3. 곱셈·나눗셈 `*` · `/` → 덧셈·뺄셈 `+` · `-`
4. 텍스트 결합 `&` → 비교 `=` · `<>` · `<` · `>` · `<=` · `>=`

맨 앞 `=`는 수식 입력 표시, 수식 안의 `=`는 값 비교  
함수 괄호 안의 쉼표는 인수 구분자로도 사용

## 계산 예시

학습용 수식의 중간값을 차례로 대입

- `=8+3*4` → `8+12` → **20**
- `=(8+3)*4` → `11*4` → **44**
- `=18/3*2` → `6*2` → **12** — 같은 순위는 왼쪽부터
- `=200*10%` → `200*0.1` → **20**
- `="합계 "&2+3` → `"합계 "&5` → **합계 5**
- `=2+3=5` → `5=5` → **TRUE** — 비교 결과는 TRUE·FALSE

## 음수 부호와 뺄셈

Excel에서는 **음수 부호가 거듭제곱보다 우선**

- `=-2^2` → `(-2)^2` → **4**
- `=0-2^2` → `0-4` → **-4**

첫 수식의 `-`는 음수 지정, 둘째 수식의 `-`는 뺄셈
