워크시트 변경 문제는 **이름·탭 색·삽입·이동·복사·숨김·삭제의 결과를 구별**하고, 특히 **시트 삭제는 일반 실행 취소로 복원할 수 없다는 점**을 확인함

## 시트 이름 변경

시트 탭을 더블클릭하거나 이름 바꾸기 명령을 사용해 변경할 수 있음

현재 Excel의 대표 제한

- 이름은 비워 둘 수 없음
- 최대 31자
- `/ \ ? * : [ ]` 사용 불가
- 이름 앞·뒤에 작은따옴표를 둘 수 없음
- `History`는 예약된 이름으로 사용할 수 없는 경우가 있음

과거 기출 선택지는 `/ \ ? * [ ]`만 나열했지만 현재는 `:`도 금지 문자에 포함됨

## 시트 탭 색

시트마다 탭 색을 지정할 수 있으나 **각 시트가 반드시 서로 다른 색이어야 하는 것은 아님**

따라서 해당 설명은 틀림

## 이동·복사

워크시트는 현재 통합문서 안에서 위치를 옮기거나 다른 통합문서로 이동·복사할 수 있음

기출의 대표 키 구별

- `Ctrl`을 누른 채 시트 탭 드래그 → 복사에 사용
- 단순 드래그 → 이동

`Shift`를 누른 채 드래그가 시트 복사 기본 동작이라는 설명은 틀림

## 새 시트 삽입

`Shift + F11` → 현재 선택 시트 앞쪽에 새 워크시트 삽입

## 시트 삭제와 실행 취소

시트를 삭제하면 일반적인 `Ctrl + Z` 실행 취소로 시트를 되살릴 수 없다는 점이 반복 출제됨

따라서 삭제 전 필요한 데이터가 있는지 확인함

기출 그림에 실행 취소 아이콘이 있어도 `시트 삭제를 바로 복원 가능`이라고 판단하지 않음

## 시트 숨김과 삭제 구별

시트 숨김은 화면에서 시트 탭을 감추는 표시 제어임

시트 데이터 자체를 삭제하는 동작이 아님

다른 수식이 숨겨진 시트를 참조하는 경우 참조가 자동으로 끊긴다고 일반화하지 않음

## 과거 `최대 255개 시트` 주의

2015년 10월 기출 35번 선택지 ①은 당시 시험에서 맞는 설명으로 취급됨

그러나 현재 Microsoft Excel 사양에서 **통합문서의 시트 수는 사용 가능한 메모리에 따라 제한**됨

따라서 **현재 Excel도 통합문서당 최대 255개**라고 외우지 않음

## 복사된 시트 이름

같은 통합문서에서 시트를 복사하면 원래 시트 이름에 일련번호가 붙는 형태로 새 이름이 만들어질 수 있음

기출에서는 이를 맞는 설명으로 출제함

**시트 전환:** 다음 시트 `Ctrl+Page Down`, 이전 시트 `Ctrl+Page Up` · `Shift+Page Down`·`Shift+Page Up`과 구별

여러 시트 선택 시 제목 표시줄에 `[그룹]` 표시 · 시트 탭의 바로 가기 메뉴에서 모든 시트를 선택 가능
