Excel 화면 문제는 **제목 표시줄·상태 표시줄·리본·빠른 실행 도구 모음·이름 상자의 역할**과 **화면 확대가 인쇄 배율과 다른 설정**임을 구별함

## 제목 표시줄과 상태 표시줄

제목 표시줄은 통합문서·프로그램 창의 제목과 관련된 영역임

현재 작업 상태나 선택한 명령의 기본 정보를 표시하는 대표 영역은 **상태 표시줄** 쪽으로 판단함

따라서 `화면 상단 제목 표시줄에 현재 작업 상태나 선택한 명령 정보가 표시`라는 설명은 기출에서 틀림

## 리본

리본은 Excel 명령을 탭과 그룹 단위로 모아 제공하는 인터페이스임

창 크기·해상도에 따라 명령의 표시 형태가 축약될 수 있음

활성 탭을 더블클릭해 리본을 접거나 다시 펼치는 동작이 기출에 출제됨

## 빠른 실행 도구 모음

자주 사용하는 명령을 모아 두고 사용자가 추가·제거하여 구성할 수 있는 도구 모음임

## 이름 상자

일반적으로 현재 선택한 셀의 주소·정의된 이름 등을 표시함

차트 요소·그리기 개체 선택 시 해당 개체 이름이 표시될 수도 있음

## 화면 확대/축소와 인쇄 크기

화면 확대/축소는 **화면에서 보는 크기**를 바꾸는 기능임

화면을 200%로 확대했다고 실제 인쇄물이 200% 크기로 출력되는 것이 아님

인쇄 배율은 별도의 페이지/인쇄 설정으로 판단함

## 선택 영역 확대

선택한 셀 범위를 창에 맞게 확대하여 보는 기능으로 출제됨

데이터 자체의 값이나 인쇄 크기를 바꾸는 기능이 아님

## 페이지 나누기 미리 보기

페이지 나누기 미리 보기에서는 인쇄 페이지 구분선을 확인·조정할 수 있음

해당 보기에서도 셀 데이터 입력·편집이 가능하므로 `페이지 나누기 미리 보기에서는 데이터를 편집할 수 없다`는 설명은 틀림

## 화면 작업 단축키 연결

- `Ctrl + 마우스 휠` → 화면 확대/축소
- `Scroll Lock` 활성 + 방향키 → 셀 포인터 대신 화면 이동
- `Alt + Enter` → 셀 안 줄바꿈
- 선택 영역 동일 값 입력 → `Ctrl + Enter`

마지막 두 항목은 「셀 입력·편집과 선택 위치 이동」에서 상세 설명함
