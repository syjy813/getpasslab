## 함수와 인수

학습 예시 `=SUM(A1:A3,10)`

- `SUM`: 합계 함수 · 괄호 안: 인수 · 쉼표: 인수 구분
- `A1:A3`과 `10`: **인수 2개** — 범위의 셀 3개와 인수 개수는 별개

인수로 숫자·텍스트·셀 참조·범위·계산식·다른 함수의 결과 사용 가능

## 중첩 계산

`=SUM(2,SUM(3,4))`의 안쪽부터 계산

1. 안쪽 `SUM(3,4)` → **7**
2. 바깥 `SUM(2,7)` → **9**

`=SUM(SUM(1,2),SUM(3,4))`는 함수가 3개여도 **중첩 2수준**  
가장 깊은 경로의 함수 단계를 세며, Excel 2021의 한도는 **64수준**

‘함수를 다른 함수의 인수로 사용’은 맞지만 **‘최대 3수준’은 오답**

## 함수 입력

- **함수 삽입:** 수식 탭의 함수 삽입 또는 수식 입력줄의 `fx`
- **함수 라이브러리:** 범주에서 함수 선택 후 인수 지정
- **함수 자동 완성:** 기능이 켜진 상태에서 이름의 앞부분 입력 → 일치하는 함수 후보 선택
