## 단계를 세어 1024 적용

연결된 2015·2018년 기출의 계산 관례

**Byte → KB → MB → GB**

- 작은 단위로 변환 → 한 단계마다 **1024 곱함**
- 큰 단위로 변환 → 한 단계마다 **1024 나눔**

`GB → MB → KB → Byte`는 3단계이므로 **1GB = 1024 × 1024 × 1024 Byte**

학습 예시: `2MB → Byte`는 2단계 → `2 × 1024 × 1024 Byte`

## 기출 관례와 현재 표기

- 현재 SI 표기: **1GB = 1,000,000,000B**
- 현재 이진 접두어: **1GiB = 1,073,741,824B = 1024³B**

연결 기출은 GB에 1024³B 관례를 사용한 문제이므로 해당 조건으로 풀이
