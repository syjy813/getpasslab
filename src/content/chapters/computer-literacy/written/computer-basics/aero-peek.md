## 문제에서 찾을 핵심 단서

다음 표현이 나오면 Aero Peek와 연결함

- 모든 창을 최소화하지 않음
- 바탕 화면을 빠르게 미리 봄
- 작업 표시줄의 프로그램 아이콘을 가리켜 열린 창을 미리 봄

**창을 그대로 둠 → 잠깐 미리 봄 → Aero Peek**

## 비슷한 기능과 구별

| 보기의 설명 | 해당 기능 |
|---|---|
| 저장 위치와 관계없이 종류별로 파일을 모아 접근 | 라이브러리 |
| 창을 최소화하지 않고 바탕 화면·열린 창 미리보기 | Aero Peek |
| 여러 배경 사진을 번갈아 표시 | 바탕 화면 슬라이드 쇼 |
| 프로그램 아이콘 우클릭 후 최근 항목 확인 | 점프 목록 |

문제는 기능 이름보다 **무엇을 하려는 기능인가**를 먼저 보면 쉽게 구별됨

## 작업 표시줄 미리보기 단축키

보조 기출에서는 작업 표시줄에 열려 있는 프로그램의 미리보기를 차례대로 표시하는 바로 가기 키를 **Windows 로고 키 + T**로 출제함

`Windows 키+T`는 작업 표시줄의 프로그램 미리보기를 순서대로 확인하는 단축키임 · Aero Peek라는 기능 이름과 구별함

## 버전 주의

Aero Peek의 이름과 세부 조작은 **Windows 7·10 기출 기준**임

Windows 11의 메뉴 이름·위치·동작과는 다를 수 있음
