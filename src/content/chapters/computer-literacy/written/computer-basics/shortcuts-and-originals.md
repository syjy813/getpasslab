## 하나의 원본에 여러 바로 가기 가능

하나의 원본 파일에 대해 바로 가기는 여러 위치에 여러 개 만들 수 있음

따라서

`하나의 원본 파일에는 바로 가기 하나만 만들 수 있다`

는 설명은 틀림

## 바로 가기를 실행하면 원본 실행

바로 가기는 원본 경로를 기억하고 있으므로 정상적인 연결 상태라면 바로 가기를 실행할 때 연결된 원본을 열거나 실행함

## 바로 가기 삭제와 원본 삭제는 다름

바로 가기 아이콘을 삭제해도 **원본 파일·프로그램 자체가 삭제되는 것은 아님**

반대로 원본 파일을 삭제하면 바로 가기가 남아 있어도 정상적으로 원본을 실행할 수 없음

- **바로 가기 삭제:** 원본은 남음
- **원본 삭제:** 바로 가기가 남아도 원본을 실행할 수 없음

## 확장자

연결 기출에서는 바로 가기 아이콘의 확장자를

**`.LNK`**

로 구별함

`.exe`는 실행 파일 확장자이므로 바로 가기 자체의 확장자가 아님

## 바로 가기 생성 드래그

과거 기출에서는

**Ctrl + Shift + 드래그 → 바로 가기 생성**

으로 출제됨

현재 Microsoft 문서에서는 **Alt + 드래그 → 바로 가기 생성** 동작도 명시되어 있음

시험에서는 문항에 제시된 보조키 조합을 그대로 판단함
