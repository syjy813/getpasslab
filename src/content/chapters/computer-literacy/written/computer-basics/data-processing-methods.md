## 처리 방식의 단서

| 방식 | 핵심 단서 |
|---|---|
| 일괄 처리 | 일정량·일정 시간 동안 모아서 한꺼번에 처리 |
| 실시간 처리 | 데이터 발생·요청에 필요한 결과를 즉시 처리·반영 |
| 분산 처리 | 연결된 여러 컴퓨터·처리 자원이 일을 나누어 처리 |

연결 기출의 발달 순서: **일괄 처리 → 실시간 처리 → 분산 처리**

해당 기출의 비교 순서이며 모든 컴퓨팅 방식이 이 순서로만 발전했다는 뜻은 아님

## 임베디드 시스템과 구별

임베디드 시스템은 TV·냉장고처럼 **특정 장치의 기능을 제어하도록 컴퓨터를 내장한 시스템**

- 마이크로프로세서와 특정 기능 프로그램의 결합
- 하드웨어와 소프트웨어로 구성한 전용 제어 시스템

`일정 시간 모아 한꺼번에 처리`는 임베디드의 특징이 아니라 **일괄 처리**의 특징
