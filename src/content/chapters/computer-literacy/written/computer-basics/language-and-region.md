## 표시 언어

Windows 표시 언어는 설정·파일 탐색기 등 Windows 인터페이스에 표시되는 언어와 관련됨

예

표시 언어를 한국어로 사용

→ Windows 메뉴와 인터페이스가 한국어로 표시

## 키보드·입력 레이아웃

키보드 레이아웃은 키를 눌렀을 때 어떤 문자 입력 방식이 사용되는지와 관련됨

현재 Microsoft 문서에서도 **키보드 레이아웃을 바꾸는 것만으로 Windows 표시 언어가 바뀌지 않음**을 명시함

따라서

`Windows 메뉴가 한국어인데 영어 키보드 레이아웃을 선택함`

→ 메뉴가 반드시 영어로 바뀌는 것이 아님

## 지역 형식

지역 형식은 날짜·시간·숫자·통화 등을 어떤 관례로 표시할지에 영향을 줌

예

- 날짜 순서
- 소수점·천 단위 구분 방식
- 통화 기호

등의 표시 형식과 연결됨

## 세 설정 구별

| 변경하려는 것 | 설정 개념 |
|---|---|
| Windows 메뉴·인터페이스 언어 | 표시 언어 |
| 키보드로 입력하는 문자 배열·방식 | 키보드/입력 레이아웃 |
| 날짜·숫자·통화 표시 관례 | 지역 형식 |

한 설정을 바꿨다고 나머지 둘이 반드시 모두 함께 바뀌는 것은 아님

## Excel 데이터와 구별

지역 형식은 프로그램의 날짜·숫자 표시 방식에 영향을 줄 수 있음

하지만 기존 Excel 셀의 실제 저장값이 어떻게 변하는지까지 이 챕터에서 일괄 단정하지 않음

## 학습 예시

Windows 표시 언어가 한국어인 상태에서 영어 키보드 배열을 선택함

→ 키보드 입력 배열은 바뀔 수 있음  
→ Windows 메뉴가 자동으로 영어로 바뀌는 것은 아님

실제 기출이 아닌 학습 예시임
