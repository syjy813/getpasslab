## 같은 폴더 안의 이름

같은 폴더 안에서는 **확장자까지 포함한 전체 이름**이 같은 항목을 그대로 중복해 만들 수 없음

`보고서.txt`와 `보고서.xlsx`는 전체 이름이 다르므로 함께 존재 가능

따라서 `하나의 폴더 안에 같은 이름의 파일이나 폴더가 존재할 수 있다`는 설명은 틀림

## 이름에 사용할 수 없는 문자

Windows 파일·폴더 이름에는 다음 예약 문자를 사용할 수 없음

`\ / : * ? " < > |`

이 규칙은 현재 Windows 파일 이름 규칙에서도 유지됨

## 폴더 속성에서 확인하는 내용

연결 기출에서는 [속성] 창과 다음 항목을 연결함

- 폴더 크기
- 포함된 파일·하위 폴더 수
- 만든 날짜
- 읽기 전용 관련 속성
- 공유 관련 설정

반대로 속성 창 자체에서 **특정 하위 폴더를 골라 삭제하는 기능**을 수행하는 것으로 보지 않음

## 바로 가기 만들기와 구별

`폴더 속성 창에서 바로 가기 아이콘을 만든다`는 설명도 연결 기출에서 틀린 선택지임

바로 가기 생성은 폴더 속성 확인과 다른 작업임
