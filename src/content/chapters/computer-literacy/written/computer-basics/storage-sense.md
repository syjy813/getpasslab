## 저장 공간 확인

Windows의 저장소 설정에서는 시스템 드라이브의 사용량과 저장 항목을 확인할 수 있음

현재 Windows에서는 다른 드라이브의 저장 사용량도 별도로 확인 가능함

## Storage Sense

Storage Sense는 임시 파일·휴지통 등의 불필요한 항목을 조건에 따라 자동 정리하여 공간을 확보하는 기능임

중요한 조건

- 기본적으로 시스템 드라이브를 대상으로 동작
- 다운로드 폴더와 클라우드 콘텐츠의 정리 여부는 설정·Windows 버전에 따라 다름 · 자동으로 항상 제외되는 것은 아님
- 모든 드라이브의 모든 파일을 같은 규칙으로 지우는 기능이 아님

## 온라인 전용과 영구 삭제 구별

OneDrive 등의 클라우드 파일을 **온라인 전용**으로 바꾸면 로컬 디스크 공간은 확보할 수 있음

하지만 클라우드 원본이 영구 삭제되는 것은 아님

즉 **로컬 사본 제거 ≠ 클라우드 원본 삭제**임

네트워크 연결과 계정 상태가 갖춰지면 다시 파일에 접근하거나 로컬로 내려받을 수 있음
