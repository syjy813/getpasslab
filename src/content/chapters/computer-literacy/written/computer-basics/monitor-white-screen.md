모니터에 **전원은 정상적으로 들어오지만 화면 전체가 하얗게 보이는 백화 증상**이라면 단순 전원 코드·해상도보다 액정 패널·내부 보드 계통의 이상을 우선 비교함

## 문제에서 가장 먼저 볼 조건

연결 기출은 단순히 `화면이 안 나옴`을 묻지 않음

문제에 이미 **모니터 전원은 정상**, **화면이 하얗게 나옴**이라는 조건이 주어짐

따라서 전원이 아예 들어오지 않는 경우의 점검 항목과 분리해야 함

## 전원 코드

전원 코드에 문제가 있어 전원이 공급되지 않는 상황이라면 모니터 전원이 정상이라는 문제 조건과 맞지 않음

따라서 ①은 우선 제외함

## 해상도 설정

해상도 설정 문제는 화면 크기·표시 범위·지원하지 않는 모드와 관련될 수 있음

하지만 `전원은 정상인데 화면 전체가 백색으로 보이는 증상`의 대표 원인으로 보기 어려움

## 그래픽 드라이버와 내부 하드웨어

그래픽 드라이버 문제도 화면 출력 장애를 만들 수 있으나 연결 기출에서는 백화 증상의 가장 적절한 원인으로 **액정 패널이나 모니터 내부 보드 문제**를 선택함

따라서 시험에서는 **전원 정상 + 백색 화면 → 패널·보드 계통**으로 판단함

실제 장비의 백색 화면 원인은 모델·증상에 따라 다를 수 있으므로 이 문항 하나로 모든 모니터의 고장 원인을 확정하지 않음
