브라우저는 **웹페이지 열기·저장·인쇄·즐겨찾기 관리** 등을 수행하며, 과거 Internet Explorer의 `인터넷 옵션` 탭별 설정은 당시 UI 문맥으로 구별함

## 과거 [일반] 탭

연결 기출에서 일반 탭으로 판단하는 범위

- 시작 페이지 관련 설정
- 임시 파일·방문 기록·쿠키 삭제
- 웹페이지의 색·언어·글꼴·접근성

`기본 웹 브라우저와 HTML 편집 프로그램 지정`은 해당 일반 탭 범위가 아님

## 과거 [프로그램] 탭

기출에서는 다음 기능을 연결함

- HTML 편집 프로그램 지정
- 추가 기능 관리
- 기본 웹 브라우저 지정

`수정 홈페이지 업로드용 FTP 서버 지정`은 이 탭 기능이 아님

## 현재 브라우저와 분리

이 문항들은 Internet Explorer 시대 UI를 묻는 문제임

현재 Edge·Chrome 등의 설정 메뉴와 같은 화면이라고 재현하지 않으며 IE11 데스크톱 앱은 많은 Windows 10 환경에서 지원 종료 상태임
