## 보조키 없이 드래그

과거 기출의 기본 규칙

- 같은 드라이브의 다른 폴더로 드래그 → 이동
- 다른 드라이브로 드래그 → 복사

따라서 USB에서 바탕 화면으로 끌어다 놓는 상황처럼 드라이브가 달라지면 복사로 판단함

## Ctrl 드래그

**Ctrl + 드래그 → 복사**

현재 Microsoft 문서에서도 Ctrl을 누른 채 파일을 드래그하면 복사본을 만드는 동작으로 안내함

## Shift 드래그

**Shift + 드래그 → 이동**

현재 Microsoft 문서에서도 Shift 드래그는 파일을 해당 위치로 이동하는 동작으로 안내함

## Alt 드래그

**Alt + 드래그 → 바로 가기 생성**

현재 Microsoft 문서에서도 Alt를 누른 채 파일을 드래그하면 원본 파일의 바로 가기를 만드는 동작으로 안내함

따라서 연결 기출의

`Alt를 누른 채 같은 드라이브의 다른 폴더로 끌어 놓으면 이동된다`

는 설명은 틀림

## Ctrl + Shift 드래그

보조 기출 2020년 2월 19번에서는

**Ctrl + Shift를 누른 채 드래그 → 바로 가기 아이콘 생성**

으로 채점함

해당 문항에서는 **Ctrl+Shift 드래그를 바로 가기 생성**으로 판단함
