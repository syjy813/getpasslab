## 창 조작의 결과

- **최소화:** 화면에서 창 감추기 — 앱 종료나 파일 삭제가 아님
- **최대화:** 사용 가능한 작업 영역에 창 펼치기 — 글자 확대가 아님
- **이전 크기로 복원:** 최대화 전 크기로 되돌리기 — 파일 복원이 아님
- **닫기:** 해당 창을 닫도록 요청 — 저장 완료를 뜻하지 않음

## 닫기와 저장

`Alt+F4`는 **현재 조작 중인 활성 창**의 닫기 요청

저장 여부를 묻는 창에서는 마지막 선택까지 확인

- **저장:** 수정 내용 저장 후 닫기
- **저장하지 않음:** 저장하지 않은 수정 내용 제외 후 닫기
- **취소:** 닫기 중단

자동 저장·백그라운드 실행은 앱마다 달라, 닫기만으로 저장이나 앱 종료를 확정할 수 없음
