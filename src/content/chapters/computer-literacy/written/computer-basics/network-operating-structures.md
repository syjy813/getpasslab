네트워크 운영 구조는 **처리와 자원을 어디에 두는지**, 정보통신 시스템 구성요소는 **데이터를 이동시키는가 처리하는가**를 기준으로 구별함

## 중앙 집중 방식

처리 기능과 자원을 중앙 시스템에 집중시키는 방식임

중앙에서 관리하기 쉬운 장점이 있지만 중앙 시스템 의존도가 커질 수 있음

## 클라이언트/서버 방식

클라이언트가 서비스를 요청하고 서버가 필요한 자원·처리를 제공하는 구조임

과거 컴활 기출에서는 **분산 처리 환경에 적합한 네트워크 운영 방식**으로 클라이언트/서버 방식을 정답 처리함

따라서 2016년 3월 기출 11번에서는 ②를 선택함

다만 현대 컴퓨팅 관점에서 P2P도 분산 구조를 가질 수 있으므로

**분산 처리 = 언제나 클라이언트/서버만 가능**

이라고 일반화하지 않음

## P2P — 동배간 처리

각 참여 컴퓨터가 필요에 따라 서비스를 제공하거나 이용하는 동등한 관계의 구조임

별도의 중앙 서버가 항상 필요한 구조는 아님

## 반이중은 운영 방식이 아님

반이중은 **송수신 방향과 동시성**을 나타내는 통신 방식임

중앙 집중·클라이언트/서버·P2P와 같은 운영 구조와 분류 축이 다름

## 데이터 전송계와 데이터 처리계

과거 정보통신 시스템 분류에서

- 데이터 전송계 → 데이터를 이동시키는 통신 장치·회선 등
- 데이터 처리계 → 데이터를 실제 처리하는 컴퓨터 하드웨어와 관련 소프트웨어

로 구별함

## 운영 방식과 전송 방식 혼동 금지

`클라이언트/서버와 동배간(P2P)은 데이터 전송 방식이다`

라는 설명은 연결 기출에서 틀림

이 둘은 **네트워크의 처리·운영 구조**에 가까운 개념이며 단방향·반이중·전이중처럼 신호 전송 방향을 뜻하지 않음
