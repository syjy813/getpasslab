## 프로그램 제거·변경·복구

Windows 7 기출의 [프로그램 및 기능]에서는 설치된 응용 프로그램에 대해

- 제거
- 변경
- 지원되는 경우 복구

작업을 수행할 수 있는 것으로 출제됨

현재 Windows 10/11에서도 프로그램 제거 기능은 유지되지만 설정 앱의 `설치된 앱` 등 다른 경로도 함께 사용됨

따라서 **과거 제어판 경로와 현재 설정 앱 화면을 동일한 UI로 외우지 않음**

## 설치된 업데이트 제거

Windows 7 기출에서는 [프로그램 및 기능]에서 설치된 업데이트 목록을 확인하고 제거할 수 있는 것으로 출제됨

현재 Windows에서는 Windows Update의 업데이트 기록에서 제거 가능한 업데이트를 선택하는 방식도 사용됨

일부 업데이트는 제거할 수 없을 수 있음

## Windows 기능 켜기/끄기

Windows에 포함된 일부 기능은 별도의 일반 응용 프로그램처럼 제거하는 것이 아니라 **Windows 기능 사용/사용 안 함**에서 켜거나 끄는 방식으로 출제됨

2016년 기출의 기본 게임 프로그램이 대표 사례임

## 기능 끄기와 디스크 공간 주의

2017년 Windows 7 기출의

`Windows 기능을 해제하면 하드 디스크 공간의 크기도 줄어든다`

는 설명은 틀린 선택지임

해당 기출에서는 **기능을 끄는 것과 구성 파일을 제거하여 저장 공간을 줄이는 것을 같은 동작으로 보지 않음**

현재 Windows의 선택적 기능은 실제 제거 가능한 항목도 있으므로 이 과거 선택지를

`현재 Windows에서 기능을 끄거나 제거해도 절대 공간이 줄지 않는다`

라고 일반화하지 않음

## Windows Update 자동 수행 설정과 구별

Windows 7 기출에서 Windows Update 자동 수행 설정은 [프로그램 및 기능]의 기능이 아님

즉

**프로그램·Windows 기능 관리 ≠ Windows Update 설정**
