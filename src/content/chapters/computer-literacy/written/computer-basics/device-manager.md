## 설치 장치 확인

Windows 7 연결 기출에서는 컴퓨터에 설치된 하드웨어 장치를 확인할 항목으로 **장치 관리자**를 선택함

사용자 프로필·작업그룹은 장치 목록을 확인하는 도구가 아님

## 드라이버 관리

하드웨어가 정상 작동하지 않을 때 장치 관리자에서 해당 장치와 드라이버 상태를 확인하고 드라이버 업데이트 등의 조치를 검토할 수 있음

따라서 `장치 문제 → 장치 관리자 → 드라이버 상태 확인`의 흐름을 기억함

## 2015년 ‘노란색 물음표’ 문항 주의

2015년 6월 13번은 장치 관리자에서 표시될 수 있는 **노란색 물음표**의 원인을 묻고 저장 정답을 `드라이버 미설치`로 보존하고 있음

현재 Microsoft의 Device Manager **Code 28** 문서도

`장치 드라이버가 설치되어 있지 않음`

을 뜻한다고 확인됨

다만 이것으로 **2015년 Windows의 노란 물음표 아이콘 모양 자체까지 공식 확인된 것은 아님**

따라서 본문에서는

- 드라이버 미설치 상태 → 확인됨
- 과거 `노란 물음표` 아이콘 표현 → 해당 기출 문맥으로 보존
- 현재 노란 느낌표 등 다른 아이콘과 동일하다고 재구성하지 않음

으로 구별함

## 다른 오답과 구별

연결 기출의 노란 물음표 원인을

- 인터페이스 장치 충돌
- 시스템 고장
- 전원 공급 부족

으로 판단하지 않음

해당 문항에서는 **드라이버 미설치**가 정답임
