인터넷은 **TCP/IP를 기반으로 수많은 독립 네트워크가 상호 연결된 분산형 네트워크**이며 하나의 중앙 기관이 전체 인터넷을 운영하는 구조가 아님

## 인터넷의 상호 연결

인터넷은 서로 다른 수많은 네트워크가 공통 프로토콜 체계를 사용하여 연결된 구조임

시험에서는 **TCP/IP 기반의 네트워크 간 상호 연결**을 핵심으로 봄

## 중앙통제기구가 인터넷 전체를 운영하는가

기출의 `인터넷은 상업용 네트워크이며 중앙통제기구 InterNIC에 의해 운영된다`는 설명은 틀림

현재 ICANN도 글로벌 인터넷은 단일 개인·기업·조직·정부가 통제하지 않으며 여러 이해관계자와 독립 네트워크의 분산 협력으로 운영된다고 설명함

ICANN은 도메인 이름·IP 주소 등 **고유 식별자 체계의 조정 역할**을 담당하지만 인터넷 전체를 중앙에서 운영하는 기관은 아님

## URL

URL은 인터넷상의 웹 자원 위치를 나타내는 주소 표현임

URL의 프로토콜·호스트·포트·경로 상세는 「HTTP 전송과 URL의 구성」에서 다룸

## IP 주소

IP 주소는 네트워크에서 인터페이스를 식별하고 패킷을 전달하는 데 사용하는 주소임

`컴퓨터 한 대가 평생 하나의 IP 주소만 갖는다`는 식으로 고정된 개인 식별자처럼 설명하지 않음

## WWW

WWW는 웹 브라우저와 웹 서버를 통해 하이퍼텍스트 기반 자원을 이용하는 인터넷 서비스임

즉 **인터넷 = 기반 네트워크**, **WWW = 인터넷 위에서 사용하는 서비스**로 구별함
