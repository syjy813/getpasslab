## 사운드 카드의 샘플링

샘플링은 연속적인 아날로그 소리 파형을 일정한 시간 간격으로 측정하여 디지털 데이터로 표현하는 과정임

시험에서는

**아날로그 소리 → 일정 간격 측정 → 숫자로 표현 → 디지털 데이터**

의 흐름을 확인함

## MPEG 보드

기출에서 MPEG 보드는 **압축된 동영상 데이터를 빠르게 복원하여 재생하는 장치**로 설명됨

따라서 `압축 동영상의 복원·재생`이 핵심 단서임

## 비디오 오버레이 보드

TV·비디오 등의 동영상 데이터와 컴퓨터 그래픽 데이터를 합성하여 같은 화면에 표현하는 장치로 출제됨

핵심은 **동영상 + 그래픽 화면의 합성**임

## 그래픽 카드

그래픽 카드는 컴퓨터의 **디지털 그래픽 데이터**를 처리하여 디스플레이로 출력

아날로그 모니터에 연결할 때의 변환 방향은 **디지털 → 아날로그**

기출의 `CPU가 처리한 아날로그 데이터를 디지털로 변환`은 데이터의 성격과 변환 방향을 뒤바꾼 설명
