AI가 자연스럽고 자신 있게 답해도 **그 내용이 사실이라고 자동으로 보장되지 않으므로 원자료·조건·최신성을 다시 확인**해야 함

## 오류가 생기는 이유

- 학습 데이터의 오류·편향
- 질문 조건의 누락·모호함
- 최신 정보 미반영
- 모델의 잘못된 추론·생성

등 여러 원인이 있을 수 있음

## 확인 순서

1. 핵심 수치·날짜·인용의 원자료 확인
2. 질문의 조건과 단위 재확인
3. 최신 정보가 필요한 내용은 최신 공식 자료 확인
4. 중요한 의사결정은 해당 분야 사람의 검토 추가

## 판단 원칙

- 자연스러운 문장 = 검증 완료 아님
- 출처 링크 존재 = 그 출처가 실제 주장을 뒷받침한다는 뜻은 아님
- AI 결과 = 최종 책임을 AI에 넘길 수 있다는 뜻이 아님

NIST AI RMF도 신뢰성·투명성·설명가능성·개인정보·공정성 등을 함께 고려하도록 제시함
