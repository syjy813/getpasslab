스풀은 **인쇄할 데이터를 먼저 저장장치의 대기 영역에 보내고 CPU·응용 프로그램이 프린터의 느린 출력 완료를 계속 기다리지 않도록 하는 방식**이며, 대기열에서는 인쇄 작업을 취소·일시 중지하는 등의 관리가 가능함

## 스풀의 목적

프린터는 CPU보다 훨씬 느린 출력 장치임

스풀을 사용하면 인쇄 데이터를 대기 영역에 저장한 뒤 프린터가 순서대로 처리하므로

- 프린터가 출력 중이어도 다른 작업을 계속 수행 가능
- CPU와 느린 입출력 장치의 작업을 병행
- 전체 시스템 이용 효율 향상

으로 연결함

## 대기열에서 할 수 있는 작업

과거 기출에서는 사용자가 자신의 인쇄 문서에 대해

- 일시 중지
- 계속
- 다시 시작
- 취소

등을 수행할 수 있는 것으로 출제됨

현재 Windows에서도 인쇄 대기열에서 대기 작업을 확인하고 취소할 수 있음

## 인쇄 중인 작업도 취소 가능

2016년 기출의 핵심 오답은

`인쇄 중인 작업은 취소할 수는 없으나 잠시 중단할 수 있다`

라는 설명임

인쇄 중인 작업도 취소할 수 있으므로 ④가 틀림

## 대기 중 문서와 프린터 설정 구별

2015년 기출의 핵심 오답은

`이미 인쇄 대기 중인 문서에서 용지 방향·용지 종류·인쇄 매수 등을 자유롭게 변경할 수 있다`

라는 설명임

이러한 인쇄 조건은 보통 문서를 인쇄 요청할 때 또는 프린터 기본 설정·인쇄 기본 설정에서 정하는 항목이며, 이미 스풀된 대기 문서의 속성을 대기열에서 모두 다시 편집하는 기능으로 보지 않음

## [고급] 탭과 [보안] 탭 구별

2015년 Windows 7의 프린터 속성 [고급] 탭에는 다음과 같은 스풀 관련 설정이 출제됨

- 인쇄된 문서 보관
- 기본값으로 인쇄
- 문서 스풀 관련 설정

반면 **보안을 위한 사용 권한 설정**은 [고급] 탭의 기능이 아니라 별도의 보안 범위로 구별함

현재 Windows에서도 프린터 속성의 Advanced 탭에 스풀 관련 설정이 존재할 수 있으나 드라이버·프린터에 따라 항목은 달라질 수 있음
