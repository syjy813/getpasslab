AI는 **사람의 지능적 판단·인식·생성 등을 컴퓨터로 수행하려는 넓은 분야**, 기계학습은 **데이터에서 규칙을 학습하는 AI 접근**, 딥러닝은 **다층 신경망을 사용하는 기계학습의 한 분야**로 이해함

## 포함 관계

`AI ⊃ Machine Learning ⊃ Deep Learning`

이 관계는 학습 범위를 구별하기 위한 기본 구조임

## 모든 자동화가 AI인가

모든 자동화 프로그램이 AI인 것은 아님

미리 정한 규칙대로 반복 수행하는 자동화 프로그램은 학습 기능 없이도 동작할 수 있음

## 모든 AI가 기계학습인가

모든 AI가 기계학습을 사용하는 것은 아님

전통적인 규칙 기반·탐색 기반 AI도 존재함

따라서 `AI = 기계학습 = 딥러닝`처럼 세 용어를 같은 크기의 개념으로 보지 않음
