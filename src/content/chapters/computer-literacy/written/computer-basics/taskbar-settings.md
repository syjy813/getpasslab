**Windows 7·10 기출 기준** — 과거 속성 창과 배열 메뉴를 Windows 11에 그대로 적용하지 않음

<h2 id="잠금숨김묶기">잠금·숨김·단추 묶기</h2>

- **잠금:** 작업 표시줄의 위치·크기 변경 방지
- **자동 숨김:** 평소 숨기고 가장자리에 포인터를 대면 표시
- **꽉 차면 단추 하나로 표시:** 같은 앱의 단추 묶기

‘꽉 차면 **단추 크기를 자동 조정하도록 선택**’은 단추 묶기를 잘못 설명한 선택지

<h2 id="창-배열과-아이콘-정렬">창 배열·바탕 화면 구별</h2>

- **계단식·가로 정렬:** 열린 창의 배치 변경
- **아이콘 자동 정렬:** 바탕 화면 아이콘의 배치 변경 — 작업 표시줄 메뉴의 항목이 아님
- **오른쪽 끝 바탕 화면 보기:** 창에 가려진 바탕 화면 표시

작업 표시줄에 앱 **고정**과 바탕 화면에 **바로 가기 생성**은 별개  
‘작업 표시줄 아이콘 만들기로 바탕 화면에 설정’하는 설명은 오답

## Windows 7 속성 창

‘작업 표시줄 및 시작 메뉴 속성’에서 설정 가능한 항목

- 시작 메뉴의 링크·아이콘·메뉴 모양과 동작
- 알림 영역에 표시할 아이콘과 알림
- **시작 메뉴 전원 단추**의 동작 — 본체 전원 버튼과 구별
