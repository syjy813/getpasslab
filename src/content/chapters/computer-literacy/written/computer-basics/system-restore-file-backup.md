Windows의 **시스템 복원은 복원 지점으로 시스템 파일·설정·레지스트리·설치 프로그램의 변경을 되돌리는 기능**이며 개인 문서·사진을 백업해 복구하는 기능이 아님

## 복원 지점

시스템 복원은 특정 시점의 시스템 상태를 기록한 복원 지점을 사용함

복원 지점은 중요한 시스템 변경 때 자동으로 만들어질 수 있고 사용자가 수동으로 만들 수도 있음

## 시스템 복원이 되돌리는 것

대표적으로

- 시스템 파일
- 레지스트리 설정
- 설치된 프로그램·드라이버와 관련된 시스템 변경
- 복원 지점 이후의 일부 업데이트·시스템 설정 변경

등에 영향을 줄 수 있음

따라서 연결 기출의

`Windows Update에 의한 변경 사항은 복원되지 않는다`는 설명은 틀린 것으로 출제됨

## 개인 파일은 백업하지 않음

전통적인 Windows **System Restore**는 개인 문서·사진 등의 백업 기능이 아님

삭제되거나 손상된 개인 파일을 시스템 복원 지점에서 되살리는 기능으로 보면 안 됨

개인 파일 복구가 목적이면 별도의 백업 기능을 사용해야 함

## 최신 Windows의 특정 시점 복원과 구별

현재 일부 Windows 11 환경에는 `Point-in-time restore`라는 별도 복구 기능이 존재하며 Windows 설치 드라이브의 파일·앱·설정을 이전 상태로 되돌릴 수 있음

다른 드라이브나 OneDrive 같은 클라우드에 저장된 파일에는 영향을 주지 않음

이 기능은 기존 `System Restore`와 다름

따라서 기출에서 묻는 **시스템 복원**(System Restore)의 `개인 파일은 영향을 받지 않음` 규칙을 현재의 모든 복구 기능에 확대하지 않음

## 시스템 복원과 백업

| 목적 | 기능 |
|---|---|
| 프로그램·드라이버·설정 변경 이후 시스템 문제 되돌리기 | 시스템 복원 |
| 삭제·손상된 개인 문서·사진 등을 되찾기 위한 사본 확보 | 파일 백업 |
| Windows 설치 드라이브의 파일·앱·설정을 이전 상태로 되돌리기 | Point-in-time restore |
