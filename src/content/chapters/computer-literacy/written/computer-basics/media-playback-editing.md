Windows 7의 Windows Media Player는 **미디어 재생·CD 리핑·음악 CD 굽기**에는 사용할 수 있지만 사진·영상을 편집해 UCC를 제작하는 편집 도구는 아님

## 기출 당시 가능한 작업

- 오디오·비디오 파일 재생
- 오디오 CD에서 디지털 음악 파일 추출
- 음악 파일을 이용한 오디오 CD 제작

## 편집 도구와 구별

`사진과 영상 파일을 편집해 UCC 제작` → Windows Media Player의 주 기능이 아님

과거 Windows 환경에서는 Windows Movie Maker 같은 별도 편집 도구와 구별함

## 현재 버전 주의

현재 Windows의 Media Player 앱은 Windows 7의 Windows Media Player와 UI·기능 구성이 달라졌으므로 이 기출을 현재 앱의 메뉴 암기 문제로 바꾸지 않음
