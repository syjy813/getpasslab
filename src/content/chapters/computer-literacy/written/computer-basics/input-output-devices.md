## 입력과 출력

- 입력장치 → 사용자의 정보나 외부 데이터를 컴퓨터로 전달
- 출력장치 → 컴퓨터가 처리한 정보를 사용자에게 전달

| 장치 | 판단 |
|---|---|
| 키보드 | 입력 |
| 스캐너 | 입력 |
| OCR | 문자 정보를 읽어 컴퓨터에 입력 |
| 터치패드 | 입력 |
| 트랙볼 | 입력 |
| LCD | 출력 |
| 터치스크린 | 화면 출력과 터치 입력을 함께 수행할 수 있음 |

문제에서 여러 장치 중 `성격이 다른 것`을 묻는다면 정보 이동 방향을 먼저 확인함

## 펌웨어는 입출력장치가 아님

펌웨어는 하드웨어를 제어하기 위한 프로그램·코드의 성격을 가지므로 키보드·스캐너·터치스크린 같은 **입력장치 이름이 아님**

따라서 **입력장치가 아닌 것**을 묻는 문제에서는 **펌웨어 선택**
