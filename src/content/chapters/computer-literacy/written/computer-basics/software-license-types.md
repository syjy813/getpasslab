## 프리웨어

과거 기출에서는 **사용 기간과 기능에 특별한 제한 없이 무료로 사용할 수 있는 소프트웨어**로 구별함

원본 그림의 `(ㄱ)` 설명은 `누구나 임의의 용도로 사용할 수 있는 프로그램`으로 제시되며 프리웨어에 대응함

## 셰어웨어

먼저 사용해 볼 수 있도록 배포하되 다음 제한을 두고 이후 구매를 유도하는 방식으로 출제됨

- 일정 사용 기간 제한
- 일부 기능 제한

원본 그림의 `(ㄴ)` 설명은 `일정 기간 동안 일부 기능을 제한한 상태로 먼저 사용해 보고 적합한 프로그램을 구입`하는 방식으로 셰어웨어에 대응함

## 상용 소프트웨어

정상적인 대가를 지불하고 구입·사용하는 소프트웨어로 출제됨

원본 그림의 `(ㄷ)`은 `프로그램을 구입하여 사용`하는 방식으로 상용 소프트웨어에 대응함

## 오픈소스

오픈소스는 **소스 코드를 공개하고 정해진 라이선스 조건에 따라 사용·수정·배포할 수 있도록 한 소프트웨어**를 뜻함

핵심은 **소스 코드 공개와 라이선스 조건**임

- 오픈소스라고 반드시 무료인 것은 아님
- 프리웨어라고 소스 코드가 공개되는 것은 아님

## 한 번에 구별

| 분류 | 핵심 단서 |
|---|---|
| 프리웨어 | 기간·기능 제한 없이 무료 사용 |
| 셰어웨어 | 일정 기간·기능 제한 후 구매 유도 |
| 상용 소프트웨어 | 대가를 지불하고 사용 |
| 오픈소스 | 소스 코드 공개와 라이선스에 따른 사용·수정·배포 |
