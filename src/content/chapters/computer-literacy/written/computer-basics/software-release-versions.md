## 알파 버전

정식 출시 전 **개발사 내부에서 먼저 시험·평가**하는 초기 시험 버전으로 구별함

단서

**개발사 내부 테스트 → 알파**

## 베타 버전

정식 출시 전 사용자나 외부 평가자에게 배포하여 실제 사용 환경에서 문제점과 의견을 확인하는 시험 버전임

단서

**출시 전 외부 사용자 평가 → 베타**

## 트라이얼·데모 버전

정식 제품을 사용해 볼 수 있도록

- 사용 기간 제한
- 기능 제한

등을 두어 체험·홍보 목적으로 제공하는 버전으로 출제됨

기출에서는 Trial과 Demo가 모두 체험·홍보 목적의 제한판으로 나타나므로, 세부 상업적 명칭보다 **제한된 체험**이라는 공통 판단을 우선함

## 번들

특정 하드웨어나 다른 소프트웨어를 구매했을 때 함께 제공되는 프로그램을 번들로 구별함

따라서

`특정 하드웨어나 소프트웨어를 구매했을 때 무료로 주는 프로그램`

을 Trial Version이라고 하면 틀림

## 패치와 구별

패치는 출시 전 시험판이 아니라 **이미 배포된 프로그램의 오류 수정·성능 개선을 위한 변경**임
