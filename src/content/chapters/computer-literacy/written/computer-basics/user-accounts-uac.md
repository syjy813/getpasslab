## 관리자와 표준 사용자

현재 Windows에서도 관리자 계정과 표준 사용자 계정은 권한 수준이 다름

- 관리자 → 시스템 설정 변경·소프트웨어 설치 등 높은 권한의 작업 가능
- 표준 사용자 → 일상적인 프로그램 사용·개인 설정 중심

시스템 전체 보안에 영향을 주는 작업을 표준 사용자가 자유롭게 변경할 수 있다고 판단하지 않음

## 표준 사용자의 개인 작업

과거 Windows 7 기출에서는 표준 사용자가 다음과 같은 개인 작업을 수행할 수 있는 것으로 출제됨

- 자신의 암호 변경
- 마우스 포인터 모양 변경
- 자신의 바탕 화면 설정
- 설치된 대부분의 프로그램 사용

반면 관리자가 설정한 프린터를 임의로 제거하거나 컴퓨터 보안에 영향을 주는 시스템 설정을 자유롭게 변경하는 것은 표준 사용자 권한으로 보지 않음

## 과거 자녀 보호 문항 주의

2017·2020년 기출에서는 관리자 계정이 다른 계정의

- 컴퓨터 사용 시간
- 게임 등급·콘텐츠
- 계정 유형·이름·암호

등을 관리하는 설명이 정답 판단에 사용됨

이 내용은 **해당 Windows 7/10 기출의 계정 관리 문맥으로 보존**함

현재 Windows의 Family Safety·Microsoft 계정 관리 체계가 과거 제어판 기능과 동일한 메뉴·권한 구조라고 일반화하지 않음

## UAC

사용자 계정 컨트롤(UAC)은 프로그램이나 사용자가 Windows에 **관리자 수준의 변경**을 시도할 때 승인 또는 거부를 요구하는 보안 기능임

현재 Microsoft 공식 문서에서도 UAC의 목적을

**무단 Windows 설정 변경 방지**

로 설명함

따라서 다음 단서가 나오면 UAC로 판단함

**프로그램이 설정 변경 시도 → 사용자에게 알림 → 승인/거부**

## Defender·BitLocker·시스템 복원과 구별

| 기능 | 핵심 목적 |
|---|---|
| UAC | 관리자 수준 변경 승인·알림 |
| Windows Defender / Windows Security | 악성코드·보안 위협 방어 |
| BitLocker | 드라이브 암호화 |
| 시스템 복원 | 시스템 변경을 이전 상태로 되돌림 |

문제에서 `설정 변경을 알려 사용자가 제어`가 핵심이면 UAC임

## 로그인 수단과 권한은 다름

PIN·비밀번호·얼굴·지문은 로그인 방법임

관리자·표준 사용자는 권한 수준임

PIN을 설정했다고 관리자 권한을 얻는 것이 아님

표준 사용자의 권한 상승에는 관리자 자격 증명이 필요할 수 있음 · 알림에서 단순 승인만 하면 언제나 관리자가 되는 것은 아님

보조 기출의 프린터 사용 권한은 보안 설정으로 구별 · 고급 탭의 스풀·인쇄 문서 보관 같은 옵션과 다름
