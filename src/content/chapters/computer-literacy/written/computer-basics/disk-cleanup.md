## 기출의 대표 정리 대상

연결 기출에서는 다음을 디스크 정리 대상으로 제시함

- 임시 인터넷 파일
- 휴지통의 파일
- 다운로드한 프로그램 파일

반면 `사용하지 않은 폰트(*.TTF) 파일`은 해당 기출의 디스크 정리 대상이 아님

## 디스크 정리와 RAM 부족은 다른 문제

휴지통 파일을 지우면 저장장치 공간은 확보할 수 있음

하지만 **RAM 용량 자체가 늘어나는 것은 아님**

따라서 RAM 부족 해결 방법을 묻는 문제에서 `휴지통 비우기`는 직접적인 해결책이 아님

## 디스크 정리와 바이러스 예방은 다른 목적

디스크 정리는 불필요한 저장 파일을 정리하는 기능임

방화벽·의심 메일 삭제·백신 업데이트와 같은 **바이러스 예방 기능**과 목적이 다름

따라서 정기적인 디스크 정리를 바이러스 감염 예방법으로 판단하지 않음

## 현재 Windows와 연결할 때

현재 Windows에서는 저장소 설정·Storage Sense·정리 권장 사항 등으로 공간 정리 기능이 확대됨

과거 `디스크 정리` 창의 모든 항목을 현재 UI와 동일하게 외우지 않음
