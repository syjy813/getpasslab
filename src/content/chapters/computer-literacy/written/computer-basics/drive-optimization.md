## 과거 HDD 조각 모음

Windows 7 기출에서는 하드 디스크에 흩어진 파일 조각을 재정렬하여 파일 읽기·쓰기 성능을 향상시키는 기능을 **디스크 조각 모음**으로 출제함

단서

**단편화 제거 → 파일 위치 재정렬 → HDD 읽기·쓰기 성능 개선**

## 디스크 정리·오류 검사·포맷과 구별

| 기능 | 목적 |
|---|---|
| 디스크 조각 모음/최적화 | 파일 배치·저장장치 최적화 |
| 디스크 정리 | 불필요한 파일 삭제로 공간 확보 |
| 오류 검사 | 파일 시스템·디스크 오류 확인·복구 |
| 포맷 | 볼륨을 사용할 파일 시스템 구조로 초기화 |

`파일 손상 복구`와 `단편화 제거`를 같은 작업으로 보지 않음

## 최적화해도 디스크 용량이 증가하는 것은 아님

조각난 파일을 재정렬한다고 디스크의 물리적 저장 용량이 늘어나지 않음

따라서 연결 기출의 `최적화 후 디스크 용량이 증가한다`는 설명은 틀림

## HDD와 SSD를 구별

현재 Windows의 `드라이브 조각 모음 및 최적화`는 저장장치 종류에 따라 처리 방식이 다름

- HDD → 조각 모음으로 파일 배치를 재정렬
- SSD → TRIM을 이용한 최적화

따라서 최신 SSD를 HDD와 똑같이 조각 모음한다고 설명하지 않음

## 예약 최적화

현재 Windows에서도 드라이브 최적화 일정을 설정할 수 있음

과거 기출의 예약 실행 설명과 현재 기능의 큰 방향은 이어지지만 메뉴 화면을 동일하게 제시하지 않음

시스템이 느리다는 이유로 Windows 프로세스를 임의 종료하거나 파티션을 재설정하는 것은 일반적인 최적화 방법이 아님
