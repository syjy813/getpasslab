연결 기술 문제는 **무선 핫스팟 접속인지, 주변기기 무선 연결인지, 유선 LAN 구성인지**를 장면에 대응하면 됨

## Wi-Fi

노트북·스마트폰 등이 무선 LAN이나 무선 핫스팟에 접속할 때 대표적으로 사용하는 기술임

기출의 `노트북을 무선 핫스팟(hotspot)에 연결` → **Wi-Fi**

## Bluetooth

키보드·마우스·헤드폰 등 기기 사이의 무선 연결에 널리 사용하는 기술임

기출의 `무선 마우스를 PC에 연결` → **Bluetooth**

Bluetooth는 흔히 가까운 거리의 주변기기 연결에 사용됨

실제 통신 가능 거리는 기기 설계·출력·환경에 따라 달라질 수 있음

따라서 `Bluetooth = 항상 10m 이내` 같은 고정 거리로 외우지 않음

## Ethernet

유선 LAN에서 대표적으로 사용하는 네트워크 기술임

기출의 `비즈니스 네트워크나 유선 홈 네트워크 구성` → **Ethernet**

Ethernet을 모든 비즈니스 네트워크의 유일한 기술이라고 일반화하지 않고, 문제의 `유선 LAN` 단서와 연결함

## 세 장면 대응

| 장면 | 기술 |
|---|---|
| 무선 핫스팟 접속 | Wi-Fi |
| 무선 마우스 연결 | Bluetooth |
| 유선 LAN 구성 | Ethernet |
