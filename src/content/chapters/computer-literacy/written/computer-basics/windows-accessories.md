## 작업 결과로 도구 구별

| 작업 | 우선 선택할 도구 |
|---|---|
| 기본 산술 계산 | 계산기 |
| 간단한 텍스트 작성·저장 | 메모장 |
| 화면 전체·창·일부 영역을 이미지로 캡처 | 캡처 도구 |

도구 이름보다 **최종 결과물의 종류**를 보면 빠르게 구별 가능함

## 계산기

Windows 계산기는 기본 산술 계산을 수행하는 도구임

공학·그래프·날짜 계산·단위 변환 등 추가 기능은 버전에 따라 다름 · 문제에서는 **수치 계산**이라는 목적을 먼저 확인함

예

`18 × 7 계산`

→ 계산기

## 캡처 도구

캡처 도구는 화면 전체·창·일부 영역을 이미지로 남기는 기능임

캡처 도구의 추가 기능은 Windows·앱 버전에 따라 다르므로 과거 기출에 그대로 적용하지 않음

예

`화면 일부를 이미지로 저장`

→ 캡처 도구

## 메모장

간단한 텍스트 작성·저장은 메모장 범위임

메모장의 세부 기능·버전 차이는 다음 「메모장에서 할 수 있는 작업」에서 다룸
