정보보안의 기본 목표는 **기밀성·무결성·가용성**이며, 기출의 침해 유형은 **가로채기·수정·가로막기·위조**가 무엇을 해치는지로 대응함

## 기밀성 Confidentiality

허가받지 않은 사람이 정보를 보거나 얻지 못하도록 보호

침해 예

**가로채기 Interception** → 전송 중 데이터를 몰래 봄·도청함

## 무결성 Integrity

정보가 허가 없이 변경되지 않고 정확한 상태를 유지하도록 보호

침해 예

**수정 Modification** → 원래 데이터를 다른 내용으로 바꿈

## 가용성 Availability

정당한 사용자가 필요할 때 정보·서비스를 사용할 수 있도록 보호

침해 예

**가로막기 Interruption** → 전달·서비스 이용을 방해함

## 위조 Fabrication

존재하지 않던 가짜 데이터나 메시지를 만들어 정상 송신자에게서 온 것처럼 꾸미는 유형임

인증·진위성과도 연결되며 기출에서는 수정과 구별함

## 빠른 대응

- 몰래 봄 → 가로채기
- 중간에서 바꿈 → 수정
- 전달을 막음 → 가로막기
- 가짜로 만들어 넣음 → 위조
