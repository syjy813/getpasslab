## RAM 부족과 디스크 공간 연결

**필요한 기억 공간이 RAM보다 큼 → 디스크 일부 활용 → 주기억 용량 부족 보완**

이 단서가 나오면 **가상 메모리**로 판단

실제 RAM 부품의 용량이 늘어나는 것은 아님

## 다른 메모리와 비교

| 개념 | 구별할 목적 |
|---|---|
| 캐시 | CPU와 주기억장치의 속도 차이 완화 |
| 버퍼 | 장치 사이 처리·전송 속도 차이 완화 |
| 연관 메모리 | 저장된 내용의 일부로 검색 |
| 플래시 메모리 | 전원을 꺼도 유지되는 반도체 저장 |

가상 메모리의 목적은 캐시처럼 CPU의 접근 속도를 높이는 것이 아니라 **기억 공간 부족 보완**

과거 Windows 기출의 `가상 메모리 크기 조정`도 이 목적에 해당하며 현재 Windows의 메뉴 위치나 자동 관리 설정과는 구별
