모핑은 **두 이미지나 3차원 모델 사이의 중간 형태를 계산하여 한 대상이 다른 대상으로 서서히 변하는 모습**을 만드는 기법임

## 판단 단서

`이미지 A → 여러 중간 형태 → 이미지 B`

→ **Morphing**

## 다른 애니메이션 방식과 구별

- Cel animation → 그림을 셀 등에 옮겨 프레임 단위로 촬영하는 전통 방식
- Key frame → 중요한 프레임을 지정하고 사이 프레임을 보간
- Clay animation → 점토 모형을 조금씩 움직여 촬영
- Morphing → 서로 다른 두 형태 사이를 부드럽게 변환

모핑은 단순한 페이드인·페이드아웃과 달리 **형태 자체의 중간 변형**이 핵심임
