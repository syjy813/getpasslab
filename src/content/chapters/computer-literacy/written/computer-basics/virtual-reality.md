가상현실 VR은 **컴퓨터가 만든 3차원 환경을 사용자가 실제 공간처럼 지각하고 상호작용하도록 구성하는 기술**임

## 핵심 요소

- 컴퓨터 그래픽으로 가상 공간 생성
- 3차원 표현과 시뮬레이션
- 시각·청각·동작 추적 등 여러 인터페이스를 결합할 수 있음
- 사용자가 공간 안에 있는 듯한 몰입 경험 제공

## 오답 구별

- 고화질 영상을 TV에 표시 → 단순 영상 표시
- 여러 영상을 2차원으로 통합 → 영상 편집·합성에 가까움
- 복잡한 데이터를 화면에 단순화 → 데이터 시각화에 가까움

`현실 세계처럼 구현된 3차원 경험`이 핵심 단서임
