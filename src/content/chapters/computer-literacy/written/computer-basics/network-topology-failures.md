네트워크 토폴로지는 **노드가 어떻게 연결되는지와 어느 지점의 고장이 전체 통신에 영향을 주는지**를 함께 보면 구별하기 쉬움

## 성형 Star

여러 노드가 중앙 장치에 각각 연결되는 형태임

핵심

- 한 단말의 연결 문제 → 보통 해당 단말에 한정
- 중앙 노드·중앙 연결 장치 문제 → 전체 네트워크에 큰 영향

연결 기출의

`중앙의 주 컴퓨터에 이상이 발생하면 전체 기능이 마비`

라는 단서는 성형으로 판단함

다만 현대 성형 LAN의 중앙에는 반드시 `주 컴퓨터`가 있는 것이 아니라 스위치 같은 중앙 연결 장치가 사용될 수 있음

## 망형 Mesh

여러 노드 사이에 다수의 경로를 구성하는 형태임

경로가 다양하므로 연결성이 높고 일부 링크 장애에 강한 구조를 만들 수 있음

대신 연결 수와 구축 비용이 증가할 수 있음

## 버스형 Bus

하나의 공통 전송 회선을 여러 노드가 공유하는 전형적 구조임

과거 시험에서 다음 설명은 틀린 것으로 판단함

`기밀 보장이 우수하고 회선 길이의 제한이 없다`

공유 매체라는 특성상 기밀성이 자동으로 보장되는 구조가 아니며 실제 전송 매체에는 물리적 길이·신호 조건이 존재함

## 링형 Ring

각 노드가 고리 형태로 연결되는 전형적 구조임

과거 단순 링 구조에서는 한 구간의 장애가 전체 통신에 영향을 줄 수 있는 것으로 출제됨

현대의 이중 링·우회 구조까지 포함해

`모든 링 네트워크는 한 링크 고장 시 반드시 전체가 중단`

이라고 일반화하지 않음

## 문제 판단표

| 형태 | 핵심 연결 | 전형적 장애 영향 |
|---|---|---|
| Star | 중앙 장치에 개별 연결 | 중앙 장치 장애가 전체에 큰 영향 |
| Mesh | 다수 경로 | 우회 경로 구성 가능 |
| Bus | 공통 회선 공유 | 공통 회선 문제의 영향 큼 |
| Ring | 고리 형태 | 고전적 단일 링은 한 구간 장애가 전체에 영향 가능 |

**트리형:** 노드를 가지가 갈라지는 계층 구조로 연결 · 모든 단말이 하나의 중앙 장치에 직접 연결되는 성형과 구별
