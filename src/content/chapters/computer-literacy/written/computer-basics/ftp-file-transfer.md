FTP는 **원격 서버와 파일을 업로드·다운로드하고 서버 권한 범위 안에서 파일을 관리하는 파일 전송 프로토콜**임

## 가능한 작업

- 파일 업로드
- 파일 다운로드
- 권한이 허용된 파일 삭제·이름 변경
- 계정이 필요한 서버에 로그인
- 전통적인 FTP에서 ASCII·Binary 전송 모드 사용

## 할 수 없는 작업

FTP의 목적은 파일 전송·관리임

`FTP 서버에 있는 응용 프로그램을 원격으로 실행`하는 기능으로 보지 않음

원격 명령 실행은 별도의 원격 접속 기술 영역임

## 현재 보안 주의

고전적인 FTP는 인증정보와 내용을 암호화하지 않는 구성으로 사용될 수 있으므로 실제 보안 환경에서는 암호화된 파일 전송 방식을 별도로 사용함

시험에서는 우선 **파일 전송 역할**을 판단함
