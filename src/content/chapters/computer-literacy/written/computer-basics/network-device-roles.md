네트워크 장비는 **신호를 다시 전달하는가, 여러 장치를 묶는가, 프레임을 연결하는가, IP 경로를 선택하는가, 서로 다른 네트워크를 중계·변환하는가**를 기준으로 구별함

## 리피터 Repeater

전송 과정에서 약해진 신호를 다시 증폭·재생하여 다음 구간으로 전달하는 장비임

기출 단서

**감쇠된 신호 → 다시 전달 → 리피터**

라우팅 경로 선택이나 프로토콜 변환이 핵심 기능이 아님

## 허브 Hub

여러 컴퓨터·회선을 한 지점에 연결하는 장비로 과거 기출에서 설명됨

전통적인 허브는 수신 신호를 연결된 여러 포트로 반복 전달하는 성격을 가짐

## 브리지 Bridge

LAN 구간을 연결하고 데이터 링크 계층 수준에서 프레임 전달 여부를 판단하는 장비임

과거 기출의 핵심 오답

`디지털 신호를 아날로그로 바꾸고 다시 원래 신호로 변환`

→ 브리지가 아니라 **모뎀의 전형적 설명**

## 라우터 Router

IP 네트워크 사이에서 패킷을 전달할 경로를 선택하는 장비임

기출 단서

**최적의 IP 경로 설정 → 라우터**

다만 과거 선택지의 `네트워크를 구성하기 위해 반드시 필요한 장비` 같은 표현을 모든 네트워크의 절대 조건으로 일반화하지 않음

## 게이트웨이 Gateway

과거 컴활 기출에서는

- 한 네트워크에서 다른 네트워크로 가는 출입구
- 서로 다른 네트워크 사이 연결
- 경우에 따라 서로 다른 프로토콜·체계 사이 중계

의 넓은 의미로 사용함

현대 IP 네트워크의 `기본 게이트웨이`는 흔히 라우터가 담당하므로

**게이트웨이와 라우터는 언제나 완전히 다른 물리 장비**라고 외우지 않음

시험에서는 선택지의 **경로 선택**과 **네트워크 사이 출입구·변환** 단서를 비교함

## 모뎀 Modem

전통적인 시험 설명에서는 디지털 데이터를 아날로그 통신 회선에 맞게 변조하고 수신 시 복조하는 장비로 구별함

따라서 `디지털 ↔ 아날로그 변환` 단서가 나오면 브리지보다 모뎀을 먼저 판단함

## AP Access Point

무선 단말이 무선 LAN에 접속하도록 연결 지점을 제공하는 장비임

2017년 기출에서는 WLAN의 주요 구성요소로 다음을 제시하고 리피터를 정답으로 제외함

- 무선 LAN 카드
- AP
- 안테나

다만 현재 실제 무선망에는 무선 리피터·익스텐더를 사용할 수도 있으므로

**리피터는 무선망에 절대 사용되지 않는다**라고 일반화하지 않음

## 장비 비교

| 장비 | 핵심 단서 |
|---|---|
| Repeater | 약해진 신호 재생·전달 |
| Hub | 여러 장치 연결·신호 반복 |
| Bridge | LAN 구간 연결·프레임 전달 |
| Router | IP 경로 선택·네트워크 간 패킷 전달 |
| Gateway | 다른 네트워크로 나가는 출입구·넓은 의미의 중계/변환 |
| Modem | 전통적 디지털↔아날로그 변조·복조 |
| AP | 무선 LAN 접속 지점 |
