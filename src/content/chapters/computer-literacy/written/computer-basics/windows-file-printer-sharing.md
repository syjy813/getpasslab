공유 문제는 **네트워크 검색, 파일·프린터 공유, 공용 폴더 공유**를 구별하고, `홈 그룹`은 Windows 7 시기의 과거 기능으로 따로 읽어야 함

## 고급 공유 설정의 대표 항목

2018년 기출에서는 Windows의 네트워크 및 공유 관련 고급 설정 항목으로 다음을 구별함

- 네트워크 검색
- 파일 및 프린터 공유
- 공용 폴더 공유

반면 `이더넷 공유`는 해당 보기의 고급 공유 설정 항목이 아님

따라서 이 문제는 **이더넷이라는 네트워크 연결 방식**과 **공유 설정 항목**을 구별하면 됨

## 네트워크 검색

같은 네트워크에서 다른 컴퓨터·장치를 찾고 자신의 컴퓨터가 검색될 수 있도록 하는 공유 관련 설정임

## 파일 및 프린터 공유

네트워크를 통해 다른 사용자와 파일·프린터를 공유하기 위한 설정임

현재 Windows에서도 파일과 프린터 공유 기능 자체는 유지됨

## 공용 폴더 공유

공용 폴더를 네트워크의 다른 사용자와 공유하는 설정으로 기출에서 구별함

## Windows 7의 홈 그룹

홈 그룹은 Windows 7 시기에 홈 네트워크의 여러 PC가 라이브러리와 프린터 등을 쉽게 공유하도록 만든 기능임

연결 기출에서 기억할 조건

- 이미 홈 그룹이 있으면 기존 홈 그룹에 연결 가능
- 공유 파일은 부여된 권한 범위에서 사용
- 전원이 꺼졌거나 절전·최대 절전 상태인 PC는 당시 홈 그룹에서 이용 가능한 상태로 표시되지 않을 수 있음
- `파일 및 프린터 공유 끄기`를 선택했다고 자동으로 홈 그룹에서 나가기 마법사가 실행되는 것은 아님

따라서 `공유 기능 하나를 끔 → 홈 그룹 탈퇴가 자동 실행됨`으로 연결하지 않음

## 현재 Windows에서는 홈 그룹을 사용하지 않음

HomeGroup은 Windows 10 버전 1803에서 제거됨

현재 Windows에서 파일·프린터를 공유할 때는 파일 탐색기 공유, 네트워크 프린터 공유 등 다른 기능을 사용함

따라서 이 챕터에서 홈 그룹을 **현재 Windows의 일반 공유 방법**처럼 설명하지 않음
