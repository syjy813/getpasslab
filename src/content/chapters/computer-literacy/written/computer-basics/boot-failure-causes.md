부팅 실패 문제는 **전원 공급 → BIOS/POST → 부팅 장치·운영체제 시작** 단계 중 어디에서 막혔는지 구별해야 하며, 2015년 키보드 선택지는 보편 규칙으로 일반화하면 안 됨

## 전원 공급 문제

전원 공급 장치 이상은 컴퓨터가 정상적인 부팅 과정을 시작하지 못하게 할 수 있는 직접적인 원인임

전원이 들어오지 않거나 전압 공급에 문제가 있으면 POST와 운영체제 시작 단계까지 진행하지 못할 수 있음

## BIOS 문제

BIOS/UEFI는 부팅 초기에 하드웨어를 초기화하고 다음 부팅 단계로 넘기는 역할을 함

따라서 BIOS 자체 이상도 부팅 실패 원인이 될 수 있음

## 악성코드·바이러스

부팅 영역이나 운영체제 파일이 악성코드에 의해 손상되면 정상 시작을 방해할 수 있음

따라서 바이러스 감염도 기출에서 부팅 실패 가능 원인으로 판단함

## 2015년 키보드 연결 선택지의 조건

2015년 3월 기출 19번의 저장 정답은 **③ 키보드 연결의 이상**임

즉 해당 문항에서는 네 보기 가운데 키보드 연결 이상을 `가장 적절하지 않은 원인`으로 채점함

하지만 이 정답을 근거로

**키보드 오류는 절대로 부팅에 영향을 주지 않는다**라고 외우면 안 됨

일부 BIOS에는 키보드 오류 등 특정 POST 오류가 있을 때 부팅을 중단하거나 예외 처리하는 설정이 존재함

따라서 이 문항은 **당시 시험의 상대 비교 문제**로 처리하고 현재 모든 PC의 고장 진단 규칙으로 확대하지 않음

## 문제 풀이 순서

1. 전원 자체가 들어오는지
2. BIOS/POST 단계까지 진행되는지
3. 저장장치·운영체제 시작 단계에서 멈추는지
4. 주변장치 오류가 해당 BIOS에서 부팅 중단 조건인지

순서로 원인을 좁힘
