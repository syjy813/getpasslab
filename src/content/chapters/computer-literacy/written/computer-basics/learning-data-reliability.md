AI 결과의 신뢰성은 **학습 데이터가 실제 상황을 얼마나 잘 대표하는지, 오류·편향이 있는지, 평가 데이터를 학습과 분리해 확인했는지**에 영향을 받음

## 대표성

학습 데이터가 특정 집단·상황에만 치우치면 다른 상황에서 성능이 떨어질 수 있음

## 오류·라벨 품질

잘못 기록된 값이나 잘못 붙인 정답 라벨은 모델이 잘못된 패턴을 학습하게 만들 수 있음

## 학습 성능과 실제 성능 구별

학습에 사용한 자료에서 점수가 높다고 새로운 자료에서도 같은 성능이 보장되는 것은 아님

따라서 별도의 검증·평가 자료와 실제 사용 환경 점검이 필요함

## 판단 원칙

`데이터가 많다 = 자동으로 신뢰 가능`이 아님

양뿐 아니라 **관련성·대표성·정확성·최신성**을 함께 봄
