## 기출에서 찾을 단서

- 고선명 멀티미디어 인터페이스
- 영상 + 음향 통합 전송
- 디지털 방식
- 기출 표현상 비압축 영상·음향 신호 전송
- S-Video·Composite 같은 아날로그 연결과 구별

이 단서가 함께 나오면 HDMI를 선택함

## 다른 보기와 구별

- DVI → 영상 연결과 관련되지만 기출의 `영상·음향 통합 전송` 단서에 맞지 않음
- USB → 범용 주변장치 연결 인터페이스
- IEEE-1394 → 고속 직렬 인터페이스로 사용된 규격
- HDMI → 영상·음향 통합 전송
