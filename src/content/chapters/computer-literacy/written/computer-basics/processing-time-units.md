## 같은 숫자라면 단위 비교

| 단위 | 초로 표현 |
|---|---|
| ms | 10⁻³ s |
| μs | 10⁻⁶ s |
| ns | 10⁻⁹ s |
| ps | 10⁻¹² s |

**1ps < 1ns < 1μs < 1ms**

처리 시간은 짧을수록 빠르므로 연결 기출의 보기 중 **1ps가 가장 빠름**

숫자가 다르면 같은 단위로 변환한 뒤 시간의 크기 비교
