## 텍스트 저장

연결 기출에서는 메모장에서 작성한 문서를 저장할 때 기본 확장자를 `.txt`로 판단함

핵심

**메모장 → 텍스트 문서 → `.txt`**

## 문자열 찾기

문서 안에서 특정 문자열을 찾는 기능을 사용할 수 있음

따라서 `특정 문자열 검색이 불가능하다`는 방향으로 판단하지 않음

## 날짜·시간 삽입

연결 기출에서는 현재 날짜와 시간을 삽입하는 기능이 있는 것으로 출제됨

현재 Microsoft 문서에도 메모장의 로그 기능과 날짜·시간 관련 기능이 남아 있음

## OLE 개체는 구별

연결 기출의 핵심 오답은 `그림, 차트 등의 OLE 개체를 삽입할 수 있다`라는 설명임

해당 기출 시점의 메모장은 Word 같은 복합 문서 편집기가 아니므로 **OLE 개체 삽입 기능으로 보지 않음**

## 현재 버전 주의

Windows 11 메모장은 앱 버전에 따라 Markdown 기반의 가벼운 서식 기능을 지원함

따라서 `메모장은 현재도 아무 서식도 지원하지 않는다`라고 일반화하지 않음

다만 **가벼운 텍스트 서식 지원과 OLE 개체 삽입은 다른 기능**이므로 연결 기출의 정답은 그대로 유지함
