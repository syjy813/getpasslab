쿠키는 **사이트가 로그인 상태·사용자 설정 같은 작은 상태 정보를 브라우저에 저장하는 방식**, 캐시는 **이미 받은 웹 자원을 재사용하기 위한 임시 사본**, 방문 기록은 **방문한 주소 목록**임

## 쿠키

기출 단서

- 매번 ID·비밀번호를 다시 입력하는 번거로움 감소
- 사이트가 사용자의 기본 설정을 기억

→ **Cookie**

쿠키에 비밀번호 자체가 반드시 그대로 저장된다고 단정하지 않음

## 캐시

이미 받은 이미지·스크립트·문서 일부를 다시 사용할 수 있도록 저장해 다시 불러오는 시간을 줄이는 기능임

## 방문 기록과 즐겨찾기

- 방문 기록 → 사용자가 실제 방문한 웹페이지 기록
- 즐겨찾기 → 사용자가 나중에 다시 찾기 위해 직접 저장한 주소

로그인 유지 문제에서는 네 개념 중 **쿠키**를 먼저 판단함
