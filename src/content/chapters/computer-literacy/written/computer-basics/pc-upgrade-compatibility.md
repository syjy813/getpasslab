## 목적에 맞는 부품과 호환성 확인

학습 예시

| 개선 목적 | 부품 | 호환 조건 |
|---|---|---|
| 작업 중 메모리 부족 | RAM | 메모리 종류·메인보드 지원 규격 |
| 저장 공간 부족 | 저장장치 | 연결 인터페이스 지원 여부 |
| CPU 교체 | CPU | 메인보드 소켓·지원 범위 |

**무엇이 부족한지 → 어떤 부품이 해결하는지 → 현재 시스템에서 지원하는지** 순서로 판단

저장 공간 부족에 CPU를 교체하는 식으로 목적과 부품 역할을 혼동하지 않음

성능 수치가 높아도 호환되지 않으면 교체 대상으로 선택할 수 없음
