## 로그인 수단

현재 Windows에서 로그인에 사용할 수 있는 대표 수단

- 비밀번호
- PIN
- Windows Hello 얼굴 인식
- Windows Hello 지문 인식
- 보안 키 등

이 기능들은 **사용자가 누구인지 확인하여 로그인하는 방법**임

## 관리자 계정

관리자 계정은 시스템 설정 변경·소프트웨어 설치 등 높은 권한이 필요한 작업을 수행할 수 있는 계정 유형임

현재 Microsoft도 관리자 계정은 시스템에 대한 높은 수준의 제어 권한을 갖는다고 설명함

## 표준 사용자

표준 계정은 일상적인 사용에 적합하며 시스템 전체에 영향을 주는 변경은 제한될 수 있음

높은 권한이 필요한 작업은 관리자 승인이나 자격 증명이 필요할 수 있음

## PIN과 계정 권한

PIN을 설정해도 관리자 권한이 생기지 않음 · PIN은 로그인 방식이며 계정 유형을 바꾸지 않음

즉 **로그인 수단 변경 ≠ 계정 권한 상승**임

## 생체 인증 조건

얼굴·지문 로그인을 사용하려면 호환 카메라·지문 판독기 등 필요한 하드웨어 조건이 있어야 함

따라서 모든 PC에서 모든 생체 인증을 사용할 수 있다고 단정하지 않음

## 학습 예시

표준 사용자가 PIN 로그인을 설정함

→ 로그인 방식만 추가·변경됨  
→ 관리자 계정으로 바뀌지 않음

실제 기출이 아닌 학습 예시임
