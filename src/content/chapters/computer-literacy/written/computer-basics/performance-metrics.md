## 무엇을 측정한 값인지 확인

| 측정값 | 같은 조건에서의 비교 |
|---|---|
| 저장 용량 | 클수록 많은 데이터 저장 |
| CPU 클럭 | 클수록 높은 동작 빈도 |
| 전송률·배속 | 클수록 빠름 |
| **접근 시간** | **작을수록 빠름** |

학습 예시: 접근 시간 `10ns`와 `5ns` 중 **5ns가 빠름**

## 기출의 ‘RAM 접근 속도’ 표현

연결 기출의 `RAM 접근 속도`는 **접근에 걸리는 시간값**을 뜻하는 표현

수치가 작을수록 유리한 항목을 묻는 경우 RAM의 접근 시간을 선택

이를 모든 속도 수치가 작을수록 좋다는 규칙으로 확대하지 않음

보조 기출의 **성능 비교·평가**와 **프로그램 수정**도 구별

- 벤치마크 → 하드웨어·소프트웨어의 성능 측정·비교
- 패치 → 오류 수정·성능 개선을 위해 프로그램 일부 변경
