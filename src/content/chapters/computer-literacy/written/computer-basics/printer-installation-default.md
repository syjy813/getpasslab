프린터 설치 문제는 **프린터를 어떻게 추가하는가, 로컬 연결인지 네트워크 연결인지, 어느 프린터를 기본 출력 대상으로 사용할지**를 나누어 판단함

## 프린터 추가

2019년 기출에서는 Windows의 [장치 및 프린터]에서 [프린터 추가] 마법사를 사용해 프린터를 설치하는 방식으로 출제됨

당시 보기에서는 설치 유형을 다음과 같이 구별함

- 로컬 프린터
- 네트워크·무선·Bluetooth 프린터

현재 Windows 11에서는 `설정 → Bluetooth 및 장치 → 프린터 및 스캐너`에서 연결된 프린터를 검색·추가하는 방식이 사용됨

따라서 과거 마법사의 화면을 현재 Windows UI로 바꿔 설명하지 않음

## 로컬 프린터의 포트

로컬 프린터를 수동으로 추가할 때는 프린터가 연결된 포트를 지정하는 절차가 존재함

USB·LPT·COM 등 연결 방식에 따라 포트를 선택할 수 있음

## 네트워크 프린터와 포트 선택지

2019년 기출의 핵심 오답은

`네트워크 프린터를 선택한 경우에는 연결할 프린터의 포트를 지정한다`라는 설명임

이 기출의 설치 흐름에서는 네트워크 프린터를 검색·선택하는 과정과 로컬 프린터의 포트 지정 절차를 구별함

따라서 ③이 틀린 설명임

현재 Windows에서는 자동 검색되지 않는 프린터를 수동 추가할 때 네트워크 주소·TCP/IP 등 다양한 방법을 사용할 수 있으므로

**네트워크 프린터에는 포트 개념이 절대 없다**라고 일반화하지 않음

## 기본 프린터

Windows 7 기출에서 기본 프린터의 특징은 다음과 같이 출제됨

- 여러 설치 프린터 중 기본 출력 대상으로 지정
- 특정 프린터를 고르지 않고 인쇄하면 기본 프린터 사용
- 아이콘에 기본 프린터 표시
- 네트워크 프린터도 기본 프린터로 지정 가능

따라서

`로컬 프린터만 기본 프린터로 지정 가능`은 틀림

## 현재 Windows의 기본 프린터 자동 관리

현재 Windows에서는 사용자가 특정 프린터를 기본으로 지정할 수도 있고, `Windows에서 내 기본 프린터를 관리하도록 허용`을 켜서 **마지막 사용 프린터를 자동으로 기본값으로 관리**하게 할 수도 있음

따라서 과거 기출의 `기본 프린터 한 대` 규칙을 현재 Windows의 모든 기본 프린터 동작 설명으로 확대하지 않음
