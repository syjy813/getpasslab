OSI는 **서로 다른 시스템 사이 통신 기능을 7개 계층으로 나누어 표준화 작업의 공통 기준을 제공하는 참조 모델**임

## OSI의 핵심 목적

서로 다른 제조사·시스템 사이에서도 네트워크 기능을 공통 구조로 이해하고 표준을 조정할 수 있도록 통신 기능을 계층화한 모델임

시험에서는 **ISO가 정의한 네트워크 통신 7계층 → OSI 7계층**으로 판단함

## OSI는 하나의 특정 통신 프로토콜인가

정확히는 하나의 프로토콜 이름이라기보다 **Open Systems Interconnection의 기본 참조 모델**임

ISO/IEC 7498-1도 OSI 모델을 시스템 상호 연결을 위한 표준 개발의 공통 기반으로 설명하며 특정 구현 명세 자체로 보지 않음

따라서 기출이 `통신 규약 명칭`이라고 표현하더라도 **OSI 7계층 참조 모델**로 정확히 이해함

## ISO와 OSI 구별

- ISO → 국제표준화기구
- OSI → ISO가 표준화한 개방형 시스템 상호 연결 참조 모델

따라서 `ISO 7계층`이 정식 모델 이름이 아님

## TCP/IP와 구별

TCP/IP는 실제 인터넷 통신에 사용되는 프로토콜 집합임

OSI 7계층은 네트워크 기능을 설명·비교하기 위한 참조 모델임

두 개념을 같은 이름으로 보지 않음

## 문제에서 필요한 수준

이 챕터의 두 기출은 계층별 이름보다 다음 관계를 구별하면 풀 수 있음

**ISO → OSI → 7계층 → 상호 운용·표준화의 공통 모델**
