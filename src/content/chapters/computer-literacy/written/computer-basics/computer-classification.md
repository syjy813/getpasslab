## 분류 기준부터 확인

| 기준 | 해당 컴퓨터 |
|---|---|
| 처리하는 데이터 형태 | 디지털·아날로그·하이브리드 |
| 처리 능력 | 슈퍼컴퓨터·메인프레임·퍼스널 컴퓨터 |
| 휴대 크기·형태 | 팜톱·랩톱·노트북·데스크톱 |

`처리 능력에 따른 분류가 아닌 것` → 데이터 형태로 나눈 **하이브리드**

`데이터 형태에 따른 분류가 아닌 것` → 처리 능력으로 나눈 **슈퍼컴퓨터**

## 디지털과 아날로그 비교

| 구분 | 디지털 | 아날로그 |
|---|---|---|
| 데이터 | 불연속적인 값 | 연속적으로 변하는 양 |
| 대표 회로 | 논리회로 | 증폭회로 |
| 주된 연산 | 산술·논리 | 미분·적분 |
| 기출의 전형적 용도 | 범용 | 특수 목적 |

전압·전류·온도처럼 연속적으로 변하는 양 → 아날로그 데이터

디지털 컴퓨터는 프로그램과 기억 기능을 사용하므로 `프로그래밍 불필요`, `기억 기능 없음`은 틀린 설명

## 스마트폰과 팜톱

2015년 연결 기출은 **휴대 크기·형태**를 기준으로 스마트폰을 **팜톱 컴퓨터**에 대응

현재 모든 스마트폰의 공식 제품 분류가 팜톱이라는 뜻은 아님
