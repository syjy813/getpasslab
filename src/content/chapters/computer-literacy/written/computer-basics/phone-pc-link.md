## 연결의 목적

현재 Microsoft의 Phone Link 계열 기능은 휴대전화와 Windows PC를 연결하여 기기별 지원 범위 안에서 다음과 같은 기능을 제공할 수 있음

- 메시지
- 알림
- 통화
- 일부 사진·파일·앱 관련 연동

핵심은 **휴대전화의 모든 기능을 PC에서 그대로 복제하는 기능이 아니라 기기 간 연동 기능**이라는 점임

## 연결만 했다고 모든 기능이 열리는 것은 아님

사용 가능한 기능은 다음 조건에 따라 달라질 수 있음

- 연결한 휴대전화 종류와 지원 여부
- PC와 휴대전화의 연결 상태
- 기능별 필요한 권한 허용 여부
- 해당 기능 자체의 지원 범위

따라서

`PC와 휴대전화를 연결했으므로 어느 휴대전화에서도 모든 앱·사진·통화 기능을 동일하게 사용할 수 있다`

라고 판단하면 안 됨

## 권한 조건

알림·메시지·연락처 등 일부 기능은 휴대전화에서 필요한 권한을 허용해야 사용할 수 있음

즉,

**연결 완료 ≠ 모든 기능 사용 가능**

임

## 2026 출제기준과 현재 제품의 구별

이 챕터는 2026 출제기준의 `전화 설정` 공백을 보완하기 위해 설계됨

현재 Microsoft 문서는 Phone Link를 기준으로 설명하지만, 이를 2026 시험용 과거 전화 설정 화면과 동일한 메뉴라고 표현하지 않음

특정 과거 메뉴 이름이나 최소 OS 버전 숫자를 시험 필수 암기로 새로 추가하지 않음

## 학습 예시

PC와 휴대전화를 연결했지만 알림이 표시되지 않음

→ `연결 실패`만 확인할 것이 아니라 **알림 기능 지원 여부와 권한 조건**도 구별해서 확인함

실제 기출이 아닌 학습 예시임
