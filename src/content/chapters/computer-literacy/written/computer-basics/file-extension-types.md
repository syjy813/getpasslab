## 기출에서의 확장자 구별

| 확장자 | 기출에서의 판단 |
|---|---|
| `.exe` | 실행 파일 계열 |
| `.ini` | 설정 정보 파일 계열 |
| `.sys` | 시스템 관련 파일 계열 |
| `.tmp` | 임시 파일 계열 |

연결 기출은 `삭제할 때 시스템에 영향을 줄 수 있는 파일 확장자에 해당하지 않는 것`을 묻고 있으며 `.tmp`를 정답으로 채점함

따라서 이 문항에서는 **`.exe`·`.ini`·`.sys`는 주의 대상 / `.tmp`는 임시 파일 계열**로 구별함

## 삭제 영향은 파일의 용도와 상태에 따라 다름

모든 `.exe`, `.ini`, `.sys` 파일을 삭제하면 반드시 Windows가 고장 난다는 의미는 아님

반대로 모든 `.tmp` 파일을 어떤 상황에서도 무조건 지워도 된다는 뜻도 아님

## 확장자를 바꿔도 파일 형식이 변환되는 것은 아님

파일 이름의 확장자만 바꿔도 **파일 내용과 실제 형식은 변환되지 않음**

확장자의 **표시 여부**와 **파일 형식 변환**도 구별해야 함
