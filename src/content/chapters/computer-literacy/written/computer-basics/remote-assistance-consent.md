원격 지원은 **도움을 받을 사용자가 지원을 요청하고, 신뢰하는 지원자가 연결하며, 화면 공유·제어는 도움 받는 사용자의 동의를 거치는 흐름**으로 이해함

## 먼저 도움을 요청하는 사람을 구별

2017년 Windows 7 기출의 핵심 함정은

`도움을 주는 사용자가 먼저 원격 지원을 시작한 뒤 도움 받을 사용자의 연결을 기다린다`라는 설명임

원격 지원의 기본 흐름은 **도움이 필요한 사용자가 지원 요청을 시작**하는 방향으로 이해함

따라서 ①이 틀린 선택지임

## Windows 7의 간단한 연결과 도움 요청 파일

연결 기출에서는 도움을 요청하는 방법으로 다음 두 가지를 제시함

- `간단한 연결(Easy Connect)`
- `도움 요청 파일`

`도움 요청 파일`은 상대가 해당 요청 정보를 사용해 원격 지원 연결을 시작할 수 있게 하는 특수한 지원 파일로 출제됨

`간단한 연결`은 Windows 7 시기의 원격 지원 연결 방법으로 취급함

## 현재 원격 지원과 구별

현재 Windows에는 Windows Remote Assistance와 Quick Assist가 존재하며, Quick Assist는 다음 흐름을 사용함

1. 지원자가 코드 생성
2. 도움 받는 사용자가 코드 입력
3. 도움 받는 사용자가 화면 공유를 허용
4. 원격 제어가 필요하면 별도로 제어 요청
5. 도움 받는 사용자가 제어를 다시 허용

따라서 현재 환경에서도 **상대 동의 없이 지원자가 바로 PC를 제어하는 기능**으로 보면 안 됨

## 신뢰할 수 있는 지원자만 허용

원격 지원은 화면 공유나 제어가 가능하므로 사용자가 직접 요청한 신뢰할 수 있는 상대에게만 연결해야 함

이 보안 주의는 현재 Microsoft 문서에서도 강조됨
