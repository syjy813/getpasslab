## 문자 코드의 비트와 목적

| 코드 | 기출에서 찾을 단서 |
|---|---|
| 표준 ASCII | 7비트 · 128가지 · Zone 3비트 + Digit 4비트 |
| 확장 ASCII | 8비트 · 256가지 |
| EBCDIC | IBM 계열 대형 컴퓨터의 8비트 문자 코드 |
| Unicode | 여러 언어의 문자를 공통 체계로 표현 |

ASCII는 영문 대·소문자, 숫자, 문장 부호, 제어 문자를 표현하는 코드

- `대형 컴퓨터의 대표 코드` → EBCDIC과 구별
- `멀티미디어 표현을 위해 확장` → 확장 ASCII의 목적과 다름
- `오류 검출·교정용` → 문자 코드의 목적과 다름 · 추가 패리티 비트는 오류 **검출**용

연결된 전자우편 기출의 기본 문자 코드는 **7비트 ASCII** · `8비트 Unicode`, `8비트 EBCDIC`과 구별

한글 등은 MIME·UTF-8 등의 확장으로 지원하므로 모든 전자우편을 ASCII 문자로만 작성한다는 뜻은 아님

## Unicode의 과거 기출 표현

2019년 8월 10번의 제시 정답은 **④ 1개 문자를 16비트로 표현**

**Unicode 전체를 고정 16비트로 설명하는 것은 2019년 당시에도 부정확** · 제시 정답과 표준을 구별해 학습

문자에 부여한 번호인 **코드 포인트**와 저장 방식인 **UTF-8·UTF-16·UTF-32**를 구별

UTF-16도 코드 포인트에 따라 16비트 코드 단위 1개 또는 2개를 사용하므로 `모든 문자 = 2바이트`로 일반화하지 않음

`최대 256자`, `오류 검출용 코드`도 Unicode의 특징이 아님
