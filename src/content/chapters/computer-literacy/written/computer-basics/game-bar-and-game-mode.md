## 게임 바

현재 Windows의 Game Bar는 게임 중 필요한 도구를 호출하고 게임 화면 캡처·기록 기능과 연결됨

다음 단서는 Game Bar·Captures 쪽으로 판단함

- 게임 화면 기록
- 캡처
- 게임 관련 오버레이 도구 호출

## 게임 모드

Game Mode는 게임 실행 중 시스템 성능을 게임에 맞게 최적화하는 목적의 설정임

**게임 모드는 화면 녹화 기능이 아님**

## 둘을 비교

| 목적 | 기능 |
|---|---|
| 게임 화면 캡처·기록·게임 도구 호출 | Game Bar / Captures |
| 게임 실행 중 시스템 성능 최적화 | Game Mode |

## 실제 성능 효과는 환경에 따라 다름

게임 모드를 켜도 다음 결과를 보장하지 않음

- 모든 컴퓨터에서 FPS가 반드시 상승
- 모든 앱이 빨라짐
- 게임 화면이 자동 녹화됨

게임 모드의 목적은 **게임 환경 최적화**이며 실제 성능 효과는 시스템·게임 환경에 따라 달라질 수 있음

## 학습 예시

`게임 화면을 녹화하고 싶음`

→ Game Bar·캡처 기능 검토

`게임 실행 중 시스템 자원을 게임에 맞게 최적화하려 함`

→ Game Mode 검토

실제 기출이 아닌 학습 예시임
