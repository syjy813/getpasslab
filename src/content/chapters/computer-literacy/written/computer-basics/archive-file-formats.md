## 기출의 압축 파일 형식

연결 기출에서 압축 파일 형식으로 묶는 항목

- ZIP
- ARJ
- RAR

따라서 이 세 확장자는 **파일 보관·압축 형식**으로 구별함

`SAS`는 이 기출에서 압축 파일 형식에 해당하지 않는 보기임

## 압축 파일과 미디어 압축은 다른 범위

ZIP·RAR 같은 압축 파일은 여러 파일을 묶거나 파일 크기를 줄여 보관·전송하기 위한 형식임

JPEG·MP3·동영상 코덱처럼 이미지·음성·영상 자체를 특정 방식으로 압축하여 표현하는 형식과는 문제의 분류 축이 다름

따라서

- ZIP·ARJ·RAR → 파일 보관·압축 형식
- JPEG·음성·동영상 압축 → 멀티미디어 형식 챕터

로 범위를 분리함
