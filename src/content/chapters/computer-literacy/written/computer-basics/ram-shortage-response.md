RAM 부족 문제는 **실행 중 메모리 사용을 줄이거나 시작 프로그램을 줄이거나 가상 메모리를 활용**하는 방향으로 해결하며, 휴지통 비우기는 저장장치 공간 확보이므로 직접적인 RAM 확보 방법이 아님

## 불필요한 프로그램 종료

실행 중인 프로그램은 RAM을 사용함

따라서 사용하지 않는 프로그램을 종료하면 해당 프로그램이 사용하던 메모리를 반환할 수 있어 RAM 부족 완화에 도움이 됨

## 불필요한 자동 시작 프로그램 정리

Windows 시작과 함께 자동 실행되는 프로그램이 많으면 부팅 후부터 메모리를 계속 사용할 수 있음

불필요한 시작 프로그램을 줄이면 상시 메모리 사용을 낮추는 데 도움이 될 수 있음

## 가상 메모리

가상 메모리는 저장장치 일부를 이용해 실제 RAM이 부족할 때 사용할 수 있는 메모리 공간을 보완하는 방식임

과거 기출에서는 시스템 속성에서 가상 메모리 크기를 적절히 설정하는 것을 RAM 부족 대응 방법으로 제시함

현재 Windows에서는 페이지 파일을 시스템이 자동으로 관리하는 경우가 있으므로 **RAM 부족이면 사용자가 항상 수동으로 가상 메모리 크기를 늘려야 함**이라고 일반화하지 않음

핵심은 **가상 메모리 = RAM 부족을 보완하는 메모리 관리 기능**임

## 휴지통 비우기

휴지통의 파일을 삭제하면 저장장치의 빈 공간은 늘어날 수 있음

하지만 실제 RAM 용량이나 현재 실행 중인 프로그램의 RAM 사용량이 직접 줄어드는 것은 아님

따라서 **디스크 공간 부족 ↔ RAM 부족**을 혼동하지 않음
