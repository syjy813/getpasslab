## 확장자 표시

`보고서`가 확장자 표시 설정 후 `보고서.txt`로 보이더라도 **파일 내용은 그대로**임

원래 이름에 있던 확장자를 **화면에 표시한 것**임

따라서

**확장자가 안 보임 ≠ 확장자가 없음**

임

## 숨김 항목 표시

숨김 항목 표시를 켜면 숨김 속성이 있는 파일·폴더를 탐색기에서 볼 수 있게 됨

이 역시 파일 내용 자체를 바꾸는 작업이 아님

## Windows 10과 Windows 11 경로 구별

2026 기준 Windows 10과 Windows 11의 화면을 같은 메뉴라고 외우지 않음

Windows 10 계열에서는 파일 탐색기의 보기·폴더 옵션에서

- 알려진 파일 형식의 확장명 숨기기
- 숨김 파일·폴더 표시

설정을 조정하는 방식이 사용됨

현재 Windows 11에서는 파일 탐색기에서

- **보기 → 표시 → 파일 이름 확장명**
- **보기 → 표시 → 숨긴 항목**

으로 접근 가능함

**표시 설정 변경과 파일 내용 변경**을 구별함

## 보호된 운영체제 파일과 구별

일반 `숨긴 항목` 표시와 보호된 운영체제 파일의 별도 표시 옵션을 같은 기능으로 단정하지 않음

## 학습 예시

`보고서`가 설정 변경 후 `보고서.txt`로 보임

→ 파일 형식이 변환된 것이 아니라 **확장자 표시가 켜진 것**

실제 기출이 아닌 학습 예시임
