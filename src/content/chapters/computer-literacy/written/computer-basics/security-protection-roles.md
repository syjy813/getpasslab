보안 기술은 **신원을 확인하는 인증, 내용을 읽지 못하게 하는 암호화, 네트워크 트래픽을 통제하는 방화벽, 악성코드를 탐지·차단하는 백신**으로 역할을 구별함

## 인증 Authentication

사용자·장치 등이 주장하는 신원이 맞는지 확인하는 절차임

비밀번호, 인증서, 생체정보 등 다양한 수단을 사용할 수 있음

핵심 단서: **누구인지 확인 → 인증**

## 암호화 Encryption

데이터를 허가되지 않은 사람이 바로 읽기 어렵게 변환하여 기밀성을 보호하는 기술임

핵심 단서: **내용을 알아볼 수 없게 변환 → 암호화**

## 방화벽 Firewall

현재 Windows 방화벽은 네트워크 트래픽을 필터링하고 조건에 따라 연결을 허용·차단하는 기능임

기출 단서

- 통신 허용 프로그램 설정
- 네트워크 위치에 따른 연결 차단
- 외부 접근 통제

방화벽은 네트워크 경계에서 통신을 제어하는 기능임

**바이러스 감염을 검사해 감염 사실을 알려 주는 백신**과 같은 기능이 아님

## Defender·백신

현재 Windows 보안에는 Microsoft Defender Antivirus가 포함되어 있으며 바이러스·랜섬웨어·기타 악성코드 탐지·차단 역할을 수행함

과거 기출의 `Windows Defender` 선택지는 당시 Windows에 포함된 악성·원치 않는 소프트웨어 보호 기능을 가리킴

현재 제품 명칭과 구성은 달라졌으므로 **2018년 문항의 제품 이름을 현재 Windows 보안 구조 전체와 동일시하지 않음**

## BitLocker

BitLocker는 드라이브 암호화 기능임

악성코드 탐지 프로그램이 아님

## Bridge

Bridge는 네트워크 구간을 연결하고 프레임을 전달하는 네트워크 장비임

인증·암호화·방화벽처럼 보안 기술 분류로 보지 않음
