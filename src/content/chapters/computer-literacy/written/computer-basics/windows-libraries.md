## 실제 저장 폴더와 구별

라이브러리에 폴더를 포함한다고 해서 해당 폴더의 파일이 라이브러리라는 새 물리 위치로 모두 복사되는 것은 아님

원래 파일은 각 저장 위치에 그대로 존재하고, 라이브러리가 그 내용을 **하나의 통합된 보기로 표시**함

따라서

**라이브러리 = 여러 위치의 콘텐츠를 모아 보는 구조**

로 이해함

## 현재 Windows에서도 라이브러리 개념은 유지됨

현재 Microsoft 문서에서도 Windows 라이브러리를 **여러 저장 위치의 콘텐츠를 하나의 통합된 보기로 모으는 가상 컨테이너**로 설명함

Windows 11에서도 라이브러리 기능은 존재하지만 기본 탐색 화면에서 항상 보이는 것은 아니므로 과거 Windows 7 화면과 같은 위치에 있다고 단정하지 않음

## 다른 선택지와 구별

- 시작 메뉴 검색 상자 → 검색 기능
- 작업 표시줄 프로그램 우클릭 최근 항목 → 점프 목록
- 자녀의 사용 시간·프로그램 제한 → 자녀 보호
- 여러 저장 위치를 실제 이동 없이 모아 표시 → 라이브러리
