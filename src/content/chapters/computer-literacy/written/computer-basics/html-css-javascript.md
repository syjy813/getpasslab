웹페이지에서 **HTML은 의미와 구조, CSS는 모양과 배치, JavaScript는 동작과 상호작용**을 담당함

## 하나의 페이지로 비교

사용자가 버튼을 눌러 안내 문구가 나타나는 페이지라면

- HTML → 제목·문단·버튼 등 문서 구조 작성
- CSS → 색·크기·간격·배치 등 표현 지정
- JavaScript → 클릭 이벤트를 처리하고 내용을 바꾸는 동작 구현

## 판단 기준

`글의 의미·구조를 만든다` → HTML

`보이는 스타일을 바꾼다` → CSS

`사용자 입력에 반응해 동작한다` → JavaScript

세 기술은 함께 사용될 수 있으며 **동적인 페이지 = JavaScript 하나만으로 만드는 페이지**라는 뜻은 아님
