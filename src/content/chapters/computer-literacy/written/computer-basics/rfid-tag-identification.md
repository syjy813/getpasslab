RFID는 **사물에 전자 태그를 부착하고 리더가 무선 주파수를 이용해 태그의 식별 정보 등을 읽는 기술**임

## 기본 구성

- 태그 Tag → 사물에 부착되는 식별 정보 저장 장치
- 리더 Reader → 무선 신호로 태그 정보를 읽음
- 관리 시스템 → 읽은 정보를 업무에 활용

태그는 전원 방식에 따라 수동형·능동형 등으로 나뉠 수 있음

## 오답 구별

- 텔레매틱스 → 차량·통신·정보 서비스를 결합한 영역
- DMB → 디지털 멀티미디어 방송
- W-CDMA → 이동통신 방식
- RFID → 전자 태그 무선 식별

기출의 `주변 상황 정보를 감지하는 센서 기술` 표현을 **모든 RFID 태그가 환경 센서를 내장함**이라는 뜻으로 확대하지 않음
