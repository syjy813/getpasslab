## 파일 형식과 기본 앱

현재 Windows에서는 파일 확장자나 링크 형식에 대해 기본으로 열 앱을 지정할 수 있음

예: `.txt`의 기본 앱을 메모장에서 다른 텍스트 편집기로 변경

→ **같은 `.txt` 파일을 기본적으로 여는 앱만 바뀜**

## 파일 내용은 변하지 않음

기본 앱을 변경했다고 기존 문서 내용이 자동으로 수정되는 것은 아님

`어떤 앱으로 열 것인가`와 `파일 내용 편집`은 다른 작업임

## 확장자도 자동으로 바뀌지 않음

`.txt`의 기본 앱을 바꿔도 파일 이름이 자동으로 `.docx`나 다른 확장자로 변하지 않음

**앱 연결 변경 ≠ 파일 형식 변환**임

## 이전 앱도 제거되지 않음

기본 앱을 다른 앱으로 선택했다고 이전 프로그램이 삭제되는 것도 아님

프로그램 설치·제거는 「프로그램 제거·복구와 Windows 기능 설정」의 별도 작업임

## 프로토콜 연결

현재 Windows는 파일 확장자뿐 아니라 링크·프로토콜 형식에도 기본 앱을 지정할 수 있음

시험에서는 **무엇으로 열 것인가를 정하는 설정**이라는 핵심만 판단함

## 학습 예시

`.txt` 기본 앱을 메모장에서 다른 편집기로 변경함

→ `.txt` 파일 내용과 확장자는 그대로임  
→ 기본으로 여는 앱만 변경됨

실제 기출이 아닌 학습 예시임
