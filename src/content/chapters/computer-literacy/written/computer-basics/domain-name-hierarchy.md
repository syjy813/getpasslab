도메인 이름은 **오른쪽으로 갈수록 상위 계층**이 되며, 전체 도메인 이름과 IP 주소는 같은 것이 아님

## 도메인 계층 읽기

예: `www.example.co.kr`

오른쪽부터 보면

- `kr` → 대한민국 국가 최상위 도메인
- `co` → `.kr` 아래의 중간 단계 분류
- `example` → 등록한 도메인 문자열
- `www` → 호스트·서비스 이름으로 사용할 수 있는 하위 이름

과거 교재식 표현으로 왼쪽에서 오른쪽을 읽으면 **호스트 → 기관 이름 → 기관 종류 → 국가** 방향이 됨

기출의 `국가명 → 기관명 → 기관 종류 → 호스트명 순` 설명은 반대 방향이므로 틀림

## IP 주소와 도메인 이름

도메인 이름은 사람이 읽기 쉬운 **이름 체계**임

IP 주소는 네트워크 전달에 사용하는 **숫자 주소 체계**임

둘은 서로 대응될 수 있지만 동일한 값이나 동일한 개념이 아님

DNS의 실제 이름→주소 변환은 다음 「DNS의 도메인 이름 변환」에서 다룸

## 퀵돔 QuickDom

연결 기출의 `퀵돔`은 중간 단계 분류를 넣지 않은 짧은 **2단계 영문 `.kr` 도메인**을 뜻함

예: `example.kr`

현재 KRNIC에서도 `영문.kr` 2단계 도메인을 **퀵돔**으로 표시하고 있음

따라서 2017년 선택지 ③은 현재도 개념상 확인 가능함

## 교육기관 도메인

2015년 기출의 핵심 대응

| 도메인 | 교육기관 |
|---|---|
| `es.kr` | 초등학교 |
| `ms.kr` | 중학교 |
| `hs.kr` | 고등학교 |
| `ac.kr` | 대학·대학원 |

따라서 `sc - 고등학교`는 틀림

현재 KRNIC 기준으로도 다음과 같이 구별됨

- `hs` → 고등학교·고등기술학교 등
- `sc` → 기타 교육·훈련기관

따라서 해당 기출 정답 **③**은 현재 등록 체계와도 충돌하지 않음

## 도메인 이름의 유일성

인터넷에서 **완전한 도메인 이름**(FQDN)은 동일한 DNS 이름 공간 안에서 하나의 이름을 식별함

다만 같은 문자열 자체는 서로 다른 상위 도메인 아래에서 사용할 수 있음

예: `example.com`과 `example.kr`은 `example`이라는 라벨은 같지만 **전체 도메인 이름은 서로 다름**

기출의 `국가가 다르면 중복된 도메인 네임을 사용할 수 있다`는 표현을 `완전히 같은 전체 도메인 이름을 중복 등록할 수 있다`는 의미로 받아들이면 틀림
