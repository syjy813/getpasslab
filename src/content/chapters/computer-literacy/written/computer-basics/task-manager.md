## 실행 중인 앱과 프로세스 확인

작업 관리자에서는 현재 실행 중인 앱과 백그라운드 프로세스를 확인할 수 있음

현재 Windows에서도 프로세스 화면에서 다음 자원 사용량을 확인할 수 있음

- CPU
- 메모리
- 디스크
- 네트워크

따라서 문제에서 `CPU 사용 정도 확인`이 나오면 작업 관리자의 대표 기능으로 판단함

## 작업 종료

응답하지 않는 앱이나 종료가 필요한 프로세스를 선택하여 **작업 끝내기**를 실행할 수 있음

과거 기출에서도 프로그램이 응답하지 않을 때 작업 관리자를 사용해 프로그램을 직접 종료할 수 있다고 출제됨

## 서비스 확인

작업 관리자에서는 실행 중인 서비스 목록을 확인할 수 있음

현행 작업 관리자에도 서비스 관련 정보가 제공됨

## 실행 순서 변경과 구별

연결 기출의 핵심 오답은 `실행 중인 응용 프로그램의 실행 순서를 변경할 수 있다`라는 설명임

작업 관리자는 프로세스의 상태·자원 사용을 확인하고 종료하는 기능을 제공하지만 **응용 프로그램이 실행되는 순서를 사용자가 줄 세워 바꾸는 기능으로 보지 않음**

프로세스 우선순위 설정은 **응용 프로그램의 실행 순서를 바꾸는 기능과 다름**
