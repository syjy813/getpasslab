IoT는 **사물·사람·공간을 네트워크로 연결해 데이터를 수집하고 분석하여 상태 확인·제어·자동화 같은 서비스를 제공하는 구조**임

## 정보 흐름

`센서·디바이스 → 데이터 수집 → 네트워크 전달 → 저장·분석 → 판단·제어`

이 흐름으로 이해하면 단순히 `인터넷에 연결된 물건`과 데이터 활용까지 포함한 IoT 서비스를 구별하기 쉬움

## 다른 용어와 구별

- Cloud computing → 컴퓨팅 자원을 네트워크로 제공
- Big data → 대규모·다양한 데이터 처리 영역
- IoT → 사물과 네트워크 연결을 중심으로 데이터 수집·활용

IoT에서 클라우드·AI·빅데이터 기술을 함께 사용할 수 있지만 **모든 IoT 시스템이 반드시 같은 클라우드·AI 구조를 갖는 것은 아님**

## 보안 오답

연결이 많아질수록 장치·계정·네트워크의 공격 지점도 늘 수 있음

따라서 `IoT를 사용하면 정보보안 기술 적용이 자동으로 쉬워진다`는 설명은 부적절함
