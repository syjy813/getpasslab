## 선택 항목과 활성 창

바탕 화면·파일 탐색기의 파일이나 폴더를 선택한 상태 기준

- **속성 표시:** `Alt+Enter` — 선택 항목 실행이 아님
- **이름 변경:** `F2`
- **선택 항목의 바로 가기 메뉴:** `Shift+F10`
- **활성 창의 창 메뉴:** `Alt+Space` — 모두 선택이 아님
- **모두 선택:** `Ctrl+A` — 파일 목록에 초점이 있으면 항목, 입력 칸이면 텍스트

<h2 id="창-전환과-작업-표시줄">창 전환·시작·탐색</h2>

- **열린 창을 미리 보며 전환:** `Alt+Tab`
- **열린 순서로 전환:** `Alt+Esc`
- **작업 표시줄 앱을 차례로 확인:** `Windows 키+T`
- **작업 보기:** `Windows 키+Tab` — Windows 10·11 기준
- **시작 메뉴:** `Ctrl+Esc`
- **파일 탐색기:** `Windows 키+E`
- **바탕 화면 표시·숨기기:** `Windows 키+D`
- **컴퓨터 잠금:** `Windows 키+L`

Windows 7의 ‘작업 표시줄 프로그램 미리 보기 순회’도 **Windows 키+T**로 판단  
과거 화면 모양을 현재 Windows의 작업 보기와 동일시하지 않음

## 돋보기

- **실행·확대:** `Windows 키+플러스(+)`
- **실행 중 축소:** `Windows 키+마이너스(-)`
- **종료:** `Windows 키+Esc`

**렌즈:** 화면 일부를 렌즈처럼 확대 · **도킹:** 화면의 일정 부분에 확대 영역 고정  
‘도킹은 포인터 주위를 렌즈처럼 확대’하는 설명은 두 보기 방식을 혼동한 오답
