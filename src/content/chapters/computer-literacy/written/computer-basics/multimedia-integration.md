멀티미디어는 **텍스트·그래픽·음성·영상 등 여러 미디어를 디지털 형태로 통합 처리하고 사용자와 상호작용할 수 있는 정보 표현 방식**임

## 디지털 통합

여러 아날로그 원천 자료를 컴퓨터에서 처리할 수 있는 디지털 데이터로 변환하여 통합함

`멀티미디어 = 여러 매체를 아날로그화한 것`은 반대 방향의 설명임

## 상호작용과 비선형성

사용자가 메뉴·링크·검색 등을 선택해 원하는 순서로 정보를 탐색할 수 있음

따라서 단방향성이 강화된다는 설명은 멀티미디어의 대표 특성과 맞지 않음

## 대용량·압축·표준

영상·음성은 데이터량이 크므로 압축 기술이 널리 사용됨

서로 다른 기기·소프트웨어에서 데이터를 주고받기 위해 파일 형식과 통신 표준도 중요함

## 오답 포인트

- 사운드와 영상을 반드시 분리 전송해야 함 → 틀림
- 미디어별 파일 형식이 하나로 획일화됨 → 틀림
- 텍스트·그래픽·사운드·동영상 통합 처리 → 맞는 방향
