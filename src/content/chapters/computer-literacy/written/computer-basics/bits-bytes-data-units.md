## 비트·니블·바이트·워드

| 단위 | 판단 기준 |
|---|---|
| 비트(Bit) | 0 또는 1을 나타내는 정보의 최소 단위 |
| 니블(Nibble) | 4비트 |
| 바이트(Byte)·옥텟(Octet) | 8비트 |
| 워드(Word) | CPU가 한 번에 처리하는 기본 단위 · 크기는 시스템 구조에 따라 다름 |

**1바이트 = 8비트 → 표현 가능한 조합은 2⁸ = 256가지**

`4비트` → 니블, `한 번에 처리하는 기본 단위` → 워드

## 자료가 모이는 순서

**필드 → 레코드 → 파일 → 데이터베이스**

- 필드: 이름·부서·사번 같은 하나의 항목
- 레코드: 한 사람의 이름·부서·사번처럼 관련 필드의 모음
- 파일: 관련 레코드의 모음
- 데이터베이스: 관련 데이터 파일들의 집합

기출의 `영문 1Byte·한글 2Byte`는 당시 문자 코드 문맥의 표현이며 모든 문자 인코딩에 적용되는 규칙은 아님
