정보를 공유하기 전에는 **사실인지, 맥락이 맞는지, 공유 권리가 있는지, 개인정보·명예 등 타인의 권리를 침해하지 않는지**를 확인함

## 사실 확인

- 원출처가 무엇인지 확인
- 제목만이 아니라 본문·맥락 확인
- 날짜가 오래된 정보인지 확인
- 사실·의견·광고를 구별

## 권리 확인

- 사진·문서·영상의 저작권 확인
- 개인을 식별할 수 있는 정보가 포함됐는지 확인
- 공개 범위가 제한된 자료인지 확인

## 예상 피해 확인

공유하면 사생활 침해·명예 훼손·오해·금전 피해가 발생할 수 있는지 검토함

`많은 사람이 이미 공유함 = 자유롭게 다시 공유 가능`

으로 판단하지 않음
