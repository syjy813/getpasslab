## 업데이트 확인

새 업데이트가 있는지 Windows Update에서 확인하는 단계임

업데이트가 검색됐다는 사실만으로 설치가 완료된 것은 아님

## 다운로드

업데이트 파일을 PC로 받는 단계임

**다운로드 완료 ≠ 적용 완료**

임

## 설치

다운로드된 업데이트를 시스템에 적용하는 단계임

업데이트에 따라 설치 과정에서 재시작이 필요할 수 있음

## 재시작 필요

일부 업데이트는 **설치를 완료하려면 PC 재시작이 필요**함

따라서

`다운로드가 100% 완료됐고 재시작 필요라고 표시됨`

이라면 아직 **재시작까지 필요한 업데이트 상태**로 판단함

## 사용 시간

사용 시간은 사용자가 보통 PC를 사용하는 시간대를 Windows에 알려 **업데이트 재시작으로 인한 작업 방해를 줄이는 설정**임

사용 시간의 목적은

- 업데이트를 영구 차단
- 업데이트 파일 백업
- 모든 업데이트 취소

가 아님

**업데이트 자체를 막는 기능이 아니라 재시작 시점을 관리하는 기능**

으로 이해함

## 학습 예시

업데이트 화면에 `재시작 필요` 표시가 있음

→ 다운로드만 끝난 상태와 구별  
→ 해당 업데이트 적용을 마치려면 재시작 단계가 남아 있을 수 있음

실제 기출이 아닌 학습 예시임
