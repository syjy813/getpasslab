## 전체 선택

현재 폴더의 모든 항목 선택

**Ctrl + A**

따라서 `Alt + A`를 전체 선택 단축키라고 하면 틀림

## 연속된 여러 항목 선택

첫 번째 항목을 선택한 뒤 **Shift**를 이용해 마지막 항목까지 연속 범위를 선택함

핵심

**Shift = 연속 범위**

## 떨어진 여러 항목 선택

연속되지 않은 여러 파일·폴더를 각각 고를 때는 **Ctrl**을 누른 상태에서 원하는 항목을 선택함

핵심

**Ctrl = 개별 추가 선택**

## 이미 선택한 항목 하나 제외

여러 항목이 선택된 상태에서 Ctrl을 누른 채 선택된 항목을 다시 클릭하면 해당 항목을 선택 상태에서 제외하는 방식으로 출제됨

즉 Ctrl은 **개별 항목의 선택 상태를 추가·해제**할 때 사용함
