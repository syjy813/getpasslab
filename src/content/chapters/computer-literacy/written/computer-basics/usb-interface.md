## 연결 방식과 확장

- **직렬 방식**의 범용 인터페이스
- 기출의 기존 직렬 포트보다 빠른 전송
- 허브를 통해 여러 장치 확장
- **핫 플러그·PnP** 지원

기출의 `최대 127개`는 USB 버스에서 허브를 포함한 장치의 주소 한계 · 컴퓨터의 물리 포트 수나 실제 연결 보장 수가 아님

## 색상 선택지 판단

USB 3.0 Standard-A 커넥터의 권장 색상은 **파란색**

따라서 기출의 **USB 3.0은 빨간색·USB 2.0은 파란색**이라는 선택지는 틀림

색상은 권장 사항이므로 제품의 색만 보고 규격을 확정하지 않음
