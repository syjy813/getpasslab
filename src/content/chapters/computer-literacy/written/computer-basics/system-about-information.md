## 과거 Windows 7의 [시스템]

연결 기출에서는 [제어판]-[시스템]의 `컴퓨터에 대한 기본 정보 보기`에서 다음을 확인하는 것으로 출제함

- Windows 버전
- 설치된 메모리 용량
- Windows 정품 인증
- 시스템 종류 32비트/64비트
- CPU 등 기본 정보

반면 `Windows 업데이트 날짜`는 이 기본 정보 항목이 아님

## 32비트·64비트 확인

2017년 Windows 7 기출에서는 `[컴퓨터] 바로 가기 메뉴 → [속성]`으로 시스템 정보를 열어 32비트·64비트 여부를 확인하는 경로가 정답임

현재 Windows 10/11에서는 **설정 → 시스템 → 정보(About) → 시스템 종류**에서 확인할 수 있음

따라서 과거 경로와 현재 경로를 같은 화면으로 제시하지 않음

## 현재 Windows의 기본 정보

현재 Microsoft 문서 기준 `설정 → 시스템 → 정보`에서 확인할 수 있는 대표 정보

- 장치 이름·모델
- Windows 버전·에디션
- 프로세서
- 설치된 RAM
- 32비트/64비트 시스템 종류

Windows 11의 정품 인증은 **설정 → 시스템 → 정품 인증**, Windows 10은 **설정 → 업데이트 및 보안 → 정품 인증**에서 확인 · 버전별 경로 구별

## 컴퓨터 이름과 로그인 사용자 구별

2020년 기출의 ④는 `컴퓨터 이름과 현재 로그인한 사용자 계정`을 한 묶음으로 제시함

컴퓨터 이름은 시스템 기본 정보와 연결되지만 **현재 로그인 사용자 계정까지 같은 기본 시스템 정보 항목으로 보지 않으므로** 선택지 전체가 틀림
