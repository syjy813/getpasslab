기출에서는 **HTML5의 브라우저 내 멀티미디어 기능**, **DHTML의 동적 웹 표현**, **ActiveX의 과거 Internet Explorer 실행 환경**을 서로 구별함

## HTML5

과거 기출의 핵심 단서

- 웹 표준
- 비디오·오디오 등 멀티미디어 기능 확대
- ActiveX 같은 외부 플러그인 의존을 줄이고 브라우저에서 처리

현재 HTML은 Living Standard로 계속 발전하고 있으며 `audio`, `video` 같은 미디어 요소가 표준에 포함됨

## DHTML

DHTML은 독립된 하나의 프로그래밍 언어 이름이라기보다 **HTML·CSS·JavaScript·DOM 등을 결합해 문서 내용을 동적으로 바꾸는 과거의 통칭**으로 이해함

기출의 `동적인 웹페이지 제작` 단서 → DHTML

## ActiveX는 과거 기술

ActiveX는 Internet Explorer 중심의 레거시 기술임

현재 Microsoft Edge 자체는 ActiveX 컨트롤을 지원하지 않으며 일부 기업용 레거시 사이트는 IE 모드로 호환하는 방식이 사용됨

따라서 과거 기출을 현재 웹 개발 방식으로 일반화하지 않음

**XML**은 데이터 구조 표현, **VRML**은 과거 3차원 가상 공간 표현, **JSP**는 서버에서 웹 응답을 만드는 기술 · 브라우저의 표준 오디오·비디오 요소를 묻는 단서와 구별
