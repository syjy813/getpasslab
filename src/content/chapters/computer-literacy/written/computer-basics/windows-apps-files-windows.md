## 대상별 역할

학습 예시: Excel로 `견적서.xlsx` 열기

- **앱:** Excel — 파일을 열고 수정하는 프로그램
- **파일:** 견적서.xlsx — 이름을 붙여 저장한 데이터
- **창:** 문서가 표시된 작업 화면
- **폴더:** 파일과 하위 폴더를 담는 위치
- **아이콘:** 파일·앱 등의 대상을 나타내는 작은 그림

**창을 감추거나 닫는 동작과 파일 저장·삭제는 별개**

## 화면 영역별 기능

- **시작 메뉴:** 실행할 앱 찾기
- **파일 탐색기:** 폴더를 따라 파일 찾기
- **작업 표시줄:** 앱 고정·실행 중인 앱으로 전환

앱을 종료해도 고정 아이콘은 남을 수 있음 — 아이콘만 보고 실행 여부를 판단하지 않음
