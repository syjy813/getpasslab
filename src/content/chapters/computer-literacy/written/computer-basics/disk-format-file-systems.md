## 파일 시스템의 역할

파일 시스템은 파일·폴더를 저장하고 이름·위치·공간 사용 등을 관리하는 구조임

포맷 창의 파일 시스템 선택은 **NTFS·FAT32·exFAT 등 저장 관리 구조를 정하는 것**임

연결 기출의 제시 정답은 ②이나, 원문의 `문자 파일·영상 파일·데이터 파일 등을 관리`한다는 설명만으로 파일 시스템과의 차이가 명확하지 않음

①의 `트랙 및 섹터 초기화`도 저수준 포맷과 Windows의 논리 포맷을 혼동하기 쉬운 표현임 · 제시 정답을 보존하되 두 표현을 엄밀한 정의로 암기하지 않음

## 포맷과 데이터

과거 기출에서는 포맷을 실행하면 디스크의 데이터가 지워진다고 판단함

다만 빠른 포맷은 현재 Microsoft 문서 기준으로

**새 파일 테이블을 만들지만 볼륨 전체를 완전히 덮어쓰지는 않음**

따라서

`포맷 = 모든 비트를 완전 소거`

라고 설명하지 않음

시험 판단에서는 **사용자가 기존 파일을 정상 접근할 수 없게 되는 초기화 작업**이라는 점이 핵심임

## 빠른 포맷

빠른 포맷

- 새 파일 테이블 생성
- 전체 볼륨을 완전히 덮어쓰지 않음
- 일반 포맷보다 빠름

이라는 차이를 기억함

## 포맷 창에서 설정하는 항목

연결 기출에서 포맷 창에서 설정 가능한 항목

- 볼륨 레이블
- 파일 시스템
- 빠른 포맷

반면 **파티션 제거**는 포맷 창의 설정 항목이 아님

파티션 생성·삭제는 디스크 관리의 별도 작업으로 구별함
