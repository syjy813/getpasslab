## 시스템 요약

컴퓨터와 운영체제의 대표 정보를 빠르게 확인하는 범주임

기출의 예

- 컴퓨터 이름·제조업체
- BIOS 정보
- 설치 메모리
- 운영체제의 일반 정보

## 하드웨어 리소스

하드웨어가 사용하는 시스템 자원에 대한 고급 정보를 표시하는 범주임

기출에서는 IT 전문가용 하드웨어 리소스 정보로 설명됨

## 구성 요소

구성 요소는 단순히 `CPU와 저장장치를 제외한 입출력장치`만 보여주는 범주가 아님

저장소·디스플레이·네트워크 등 여러 하드웨어 구성 요소의 상세 정보를 포함함

따라서 연결 기출의 ③이 틀림

## 소프트웨어 환경

드라이버·서비스·네트워크 연결·실행 프로그램 등 소프트웨어 관련 환경 정보를 확인하는 범주임

## 현재 Windows에서도 유지되는 도구

현재 Windows 10/11에도 `msinfo32` 시스템 정보 도구가 존재함

Microsoft 문서에서도 이 도구를 **하드웨어·시스템 구성 요소·소프트웨어 환경의 종합 정보 도구**로 설명함
