## 컴파일러

기출 기준 특징

- 프로그램 전체를 한꺼번에 번역
- 목적 프로그램 생성
- 번역 과정은 상대적으로 시간이 더 걸릴 수 있음
- 번역된 목적 프로그램을 실행할 때는 빠른 편

## 인터프리터

기출 기준 특징

- 한 줄 또는 한 문장씩 번역하며 실행
- 별도의 목적 프로그램을 만들지 않는 방식으로 설명
- 번역 과정은 즉시 진행되는 편
- 반복 실행 시 매번 해석하므로 실행 속도는 상대적으로 느린 것으로 출제

## 번역 속도와 실행 속도를 혼동하지 않기

기출의 핵심 함정

- 컴파일러 → **번역은 상대적으로 느림 / 실행은 빠름**
- 인터프리터 → **번역은 상대적으로 빠름 / 실행은 느림**

따라서 `컴파일러는 번역 속도가 빠르고 인터프리터는 느리다`는 설명은 반대임

이 비교는 해당 시험의 전형적인 교육용 분류를 위한 것이며 JIT 등 현대 실행 방식까지 확장하지 않음
