## 현재 시각

PC가 표시하는 날짜와 시간 자체를 의미함

자동 시간 설정을 사용하면 Windows가 시간 정보를 자동으로 맞추도록 설정할 수 있음

수동으로 날짜·시간을 지정하려면 자동 시간 설정 조건을 먼저 확인해야 함

## 시간대

시간대는 **같은 순간을 어느 지역의 시각으로 표시할지 정하는 기준**임

예

같은 순간이 `UTC 00:00`이라면

`UTC+9` 지역에서는 `09:00`으로 표시됨

실제로 9시간이 새로 경과한 것이 아니라 **같은 순간의 지역별 표시가 달라진 것**임

## 자동 시간과 자동 시간대

현재 Windows에서는

- 시간 자동 설정
- 시간대 자동 설정

을 별도로 관리할 수 있음

따라서 둘을 같은 토글로 이해하지 않음

## 수동 변경

자동 설정을 끄고 사용자가 날짜·시간 또는 시간대를 직접 지정하는 방식이 존재함

핵심은

**현재 시각 변경과 시간대 변경은 목적이 다름**

이라는 점임

## 서머타임 주의

일부 지역의 서머타임 적용 여부는 지역·설정에 따라 달라질 수 있음

이 챕터에서는 특정 국가의 서머타임 규칙을 암기 대상으로 확장하지 않음

## 학습 예시

UTC 00:00인 같은 순간을 UTC+9 시간대로 표시

→ 09:00

시간대에 따른 표시 차이이며 실제 경과 시간이 9시간 늘어난 것이 아님

실제 기출이 아닌 학습 예시임
