## 핵심 공식

강도율은 재해로 발생한 <strong>근로손실일수</strong>를 <strong>총근로시간</strong>으로 나누고 1,000을 곱한 값임

$$\text{강도율} = \dfrac{\text{근로손실일수}}{\text{총근로시간}} \times 1{,}000$$

단위는 <strong>1,000근로시간당 근로손실일수</strong>임 · 강도율이 높다는 것은 같은 근로시간을 기준으로 손실된 근로일수가 많다는 뜻임

## 계산 기준

### 단위·기호

| 항목 | 의미 |
| --- | --- |
| 근로손실일수 | 재해로 일을 하지 못한 일수 또는 문제에서 정한 환산일수 |
| 총근로시간 | 강도율을 산출하는 분모 |
| 1,000 | 기준 근로시간 배율 |
| 강도율 | 1,000근로시간당 근로손실일수 |

### 계산 순서·예시

먼저 기출문제에서 제시하는 재해 구분에 따라 근로손실일수를 환산함

| 재해 구분 | 근로손실일수 |
| --- | ---: |
| 사망 또는 영구 전노동 불능(1~3급) | **7,500일** |
| 영구 일부 노동 불능(4~14급) | **신체장해등급별 기준일수** |
| 일시 전노동 불능 | **휴업일수 × 300 / 365** |

1. 재해별 근로손실일수를 환산해 합산함
2. 총근로시간을 확인함
3. `근로손실일수 / 총근로시간 × 1,000`을 계산함
4. 선택지의 단위가 일수인지, 1,000근로시간당 일수인지 확인함

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 강도율 | **$\text{강도율} = \dfrac{\text{근로손실일수}}{\text{총근로시간}} \times 1{,}000$** |
| 강도율 · 1,000근로시간당 근로손실일수 | **1,000근로시간당 근로손실일수** |
| 사망 또는 영구 전노동 불능(13급) | **7,500일** |
| 일시 전노동 불능 | **휴업일수 × 300 / 365** |
| 근로손실일수 | **재해로 일을 하지 못한 일수 또는 제시된 환산일수** |
| 총근로시간 | **강도율을 산출하는 분모** |
| 평생근로시간 100,000시간 | 예상 손실일수 = 강도율 × 100 → **1.15면 115일 · 7이면 700일** |
| 영구 일부 노동불능 | 장해등급 환산일수를 그대로 적용 · **300/365를 곱하지 않음** |
| 강도율 2.0 | **1,000근로시간당 근로손실 2일** |

## 자주 틀리는 포인트

- 영구 일부 노동 불능에는 신체장해등급별 기준일수를 그대로 사용함
- `300 / 365`는 <strong>일시 전노동 불능의 휴업일수에만 적용</strong>함
- 강도율을 도수율처럼 재해 건수로 계산하지 않음

> ⚠️ **함정 주의**: 강도율의 기준은 1,000근로시간임 · 근로손실일수 환산이나 마지막 `× 1,000`을 누락하면 선택지가 달라짐
