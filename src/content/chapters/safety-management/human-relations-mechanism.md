## 핵심 개념

집단에서의 인간관계 메커니즘 5가지.

| 메커니즘 | 정의 |
|------|------|
| **동일화** | 다른 사람의 행동 양식이나 태도를 자기에게 투입하거나, 다른 사람 가운데서 자기와 비슷한 것을 발견하는 것 |
| **모방** | 남의 행동이나 판단을 표본으로 하여 그것과 같거나 가까운 행동·판단을 취하는 것 |
| **암시** | 다른 사람의 판단이나 행동을 논리적·사실적 근거 없이 받아들이는 것 |
| **투사** | 자기 속의 억압된 것을 다른 사람의 것으로 생각하는 것 |
| **커뮤니케이션** | 언어·몸짓·표정 등으로 의사·감정을 전달하는 것 |

## 판별 기준

| 용어 | 키워드 | 주의점 |
|------|--------|--------|
| **동일화** | 투입·비슷한 것 발견 | 태도의 내면화 |
| **모방** | 행동·판단을 표본으로 삼음 | 행동의 표면 복제 |
| **암시** | 논리적 근거 없이 수용 | 유행·군중심리의 기제 |
| **투사** | 자기 것을 남에게 전가 | 방어기제와 공유 개념 |
| **커뮤니케이션** | 의사·감정 전달 | 언어·몸짓·표정 |

## 시험 포인트

- 동일화는 `자기와 비슷한 것을 발견`, 모방은 `표본과 같은 행동·판단`으로 구분한다.
- 암시는 **논리적·사실적 근거 없이 받아들이는 것**이다.
- 투사는 자기 속의 억압된 것을 다른 사람의 것으로 생각하는 것이다.
- `동모암투커`와 정의의 핵심 키워드 1개씩인 발견·표본·근거 없이·전가·전달을 연결한다.

## 자주 틀리는 포인트

- 동일화의 내면화와 모방의 표면 복제를 바꾸어 읽지 않는다.
- 암시와 커뮤니케이션을 모두 단순 전달로 해석하지 않는다.
- 경쟁·도피 같은 사회행동 기본형태를 인간관계 메커니즘에 포함하지 않는다.

> ⚠️ **함정 주의**: 사회행동 기본형태 4종과 인간관계 메커니즘 5종은 서로 다른 목록이다.
