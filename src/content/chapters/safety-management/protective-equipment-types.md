## 핵심 개념

보호구는 작업에서 예상되는 위험과 보호해야 할 신체 부위에 맞춰 선택함 · 보호구를 착용했다는 사실만으로 모든 위험이 제거되는 것은 아니며, 작업 전 위험을 확인하고 적합한 종류·등급·사용법을 함께 판단함

| **위험 또는 보호 부위** | 대표 보호구 |
| --- | --- |
| **머리 충격·낙하물** | 안전모 |
| **발의 충격·미끄럼** | 안전화 |
| **눈의 비산물·광선** | 보안경·차광용 보안경 |
| **분진** | 방진마스크 |
| **유기용제·유해가스** | 방독마스크와 해당 정화통 |
| **소음** | 방음 보호구 |
| **추락** | 안전대·추락방지대 |

## 판별 기준

방진마스크는 입자상 물질을, 방독마스크는 가스나 증기를 대상으로 함 · 방독마스크는 물질별 정화통과 표시 색을 확인해야 하며, 2022년 3월 시험 20번과 2021년 5월 시험 7번은 이 연결을 선택지에서 구분하는 유형임

차광용 보안경은 자외선용·적외선용·복합용·용접용처럼 광선의 종류와 작업에 따라 구분함 · 방음 보호구의 기호, 안전모의 성능시험 항목, 방진마스크의 사용 조건도 보호 대상과 사용 환경을 먼저 확인함

### 수록 기출의 인증·등급 기준

- 전로·평로 작업용 방열두건의 차광도 번호는 **#3~#5**임
- 유기화합물용 방독마스크 정화통의 외부 측면 표시 색은 **갈색**, 암모니아용은 **녹색**임
- 고음은 차음하고 저음은 차음하지 않는 방음보호구 기호는 **EP-2**임
- 방진마스크 사용 조건의 산소농도 최소기준은 **18%**, 석면 취급장소는 **특급** 방진마스크를 적용함
- AE·ABE종 안전모에만 실시하는 시험은 **내전압성시험·내수성시험**, AE형 내전압성은 **7,000V 이하**임

2022년 4월 시험 3번은 자율안전확인 보호구의 표시를 그림으로 구분하는 문제임 · 표시의 모양과 보호구 종류를 함께 확인함

> **확정 주의**  산소결핍 장소를 방독마스크만으로 해결한다고 판단하지 않음 · 문제의 유해요인과 산소 조건을 먼저 확인함

## 시험 포인트

### 우선 암기

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 머리 충격·낙하물 | **안전모** |
| 발의 충격·미끄럼 | **안전화** |
| 눈의 비산물·광선 | **보안경·차광용 보안경** |
| 분진 | **방진마스크** |
| 유기용제·유해가스 | **방독마스크와 해당 정화통** |

### 추가 확인

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 방열두건·전로 또는 평로 | 차광도 번호 **#3~#5** |
| 유기화합물용 / 암모니아용 정화통 | **갈색 / 녹색** |
| 고음 차음·저음 비차음 | **EP-2** |
| 방진마스크 산소농도 / 석면 취급 | **18% 이상 / 특급** |
| AE·ABE종 안전모 | **내전압성시험·내수성시험** |
| AE형 내전압성 | **7,000V 이하** |
| 차광용 보안경 종류 | **자외선용·적외선용·복합용·용접용** |

## 자주 틀리는 포인트

수록 기출의 표시 색·등급·시험값은 해당 문항 기준으로 구분함 · 산소결핍 장소를 방독마스크만으로 대응하거나 회전체 작업에 장갑을 일률 적용하지 않음
