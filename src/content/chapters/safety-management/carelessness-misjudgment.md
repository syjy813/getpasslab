## 핵심 개념

주의는 여러 자극 중 필요한 대상을 골라 집중하는 기능임

| 주의의 특성 | 의미 |
|---|---|
| **선택성** | 여러 자극 중 소수의 필요한 자극을 선택해 집중 |
| **변동성** | 높은 주의를 오래 유지하기 어려워 주의 수준이 주기적으로 변함 |
| **방향성** | 한 대상에 집중할수록 다른 대상에 대한 주의가 약해짐 |

주의·의식 수준은 다음 5단계로 구분해 판별함

| 단계 | 의식상태 | 기출 판별 |
|---|---|---|
| **Phase 0** | 무의식 | 수면·무의식 상태 |
| **Phase I** | 의식 이완 | 의식이 몽롱한 상태 |
| **Phase II** | 정상·이완 | 일상적·습관적 작업이 가능한 상태 |
| **Phase III** | 명료 | 적극 활동, 주의가 가장 명료하게 집중되는 상태 |
| **Phase IV** | 과긴장·의식의 과잉 | 긴급·돌발 상황의 순간적 긴장으로 판단능력이 둔화·정지될 수 있는 상태 |

Phase III의 높은 주의는 오래 지속하기 어렵고, Phase IV는 주의가 한곳에 고정되어 판단 범위가 좁아질 수 있음

기출에서 부주의의 발생 원인은 다음 세 가지로 분류함

| 발생 원인 | 의미 |
|-----------|------|
| **의식의 단절** | 작업에 향하던 주의가 순간적으로 끊긴 상태 |
| **의식의 우회** | 주의가 작업 이외의 대상으로 벗어난 상태 |
| **의식수준의 저하** | 피로·단조로움 등으로 각성과 주의 수준이 낮아진 상태 |

`의식의 지배`는 이 기출 분류의 부주의 발생 원인에 포함되지 않음

## 사고방지대책 구분

| 구분 | 대책 |
|------|------|
| **기능 및 작업측면** | 작업표준의 습관화, 적성배치, 작업조건의 개선 |
| **교육 및 태도측면** | 안전의식의 제고 |

기능 및 작업측면은 작업자의 적성과 실제 작업 방법·조건을 개선하는 대책임 · 안전의식의 제고는 교육과 태도 형성에 가까우므로 기능 및 작업측면의 대책으로 분류하지 않음

## 부주의 요인과 재해누발자

부주의 요인은 작업·환경처럼 외부에서 주어지는 조건과 작업자 내부의 상태로 나누어 살필 수 있음

| 구분 | 주요 요인 | 예방 방향 |
|---|---|---|
| **외적 요인** | 작업·환경조건 불량, 부적절한 작업순서 | 작업환경·근로조건·작업순서 개선, 신체 특성에 맞는 설비 제공 |
| **내적 요인** | 부적절한 적성배치, 걱정·고민·불만, 주의력 이완, 경험·지식 부족 | 적성배치, 건강 확인, 안전교육, 집중훈련, 스트레스 관리 |

재해누발자는 원인에 따라 **미숙성·습관성·상황성·소질성**으로 구분함 · 기능이 미숙하거나 환경에 익숙하지 않으면 미숙성, 과거의 경험 때문에 위험을 가볍게 보면 습관성, 작업이 어렵거나 설비에 결함이 있으면 상황성, 주의력·성격·감각운동 특성이 맞지 않으면 소질성으로 판단함

## 범위 구분

이 챕터는 <strong>주의의 특성, 부주의의 발생 원인·방지대책, 재해누발자 유형</strong>을 다룸 · 인지·판단·조작 과정별 착오요인과 억측판단의 발생 배경은 `인간 동작특성 - 과정별 착오요인` 챕터의 범위임

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 의식의 단절 | **작업에 향하던 주의가 순간적으로 끊긴 상태** |
| 의식의 우회 | **주의가 작업 이외의 대상으로 벗어난 상태** |
| 의식수준의 저하 | **피로·단조로움 등으로 각성과 주의 수준이 낮아진 상태** |
| 기능 및 작업측면 | **작업표준의 습관화** · 적성배치, 작업조건의 개선 |
| 교육 및 태도측면 | **안전의식의 제고** |
| 발생 원인 | **`단절·우회·저하` 세 단어로 묶음** |
| 주의의 특성 | **선택성·변동성·방향성** |
| Phase 0 | **수면·무의식 상태** |
| Phase I | **의식이 몽롱한 이완 상태** |
| Phase III | **주의가 가장 명료한 상태** |
| Phase IV · 의식의 과잉 | **과긴장으로 판단능력이 둔화·정지될 수 있음** |
| 재해누발자 | **미숙성·습관성·상황성·소질성** |

## 자주 틀리는 포인트

- 의식의 `우회`와 `지배`를 비슷한 표현으로 보고 바꾸지 않음
- 적성배치를 교육 대책으로 이동시키지 않음
- 부주의 대책과 억측판단의 발생 배경을 한 목록으로 합치지 않음
- Phase가 높을수록 항상 안전하다고 판단하지 않음 · 과긴장 상태에서는 주의가 한곳에 고정될 수 있음

> ⚠️ **함정 주의**: 대책의 효과가 아니라 출제된 분류 기준이 `기능·작업`인지 `교육·태도`인지 먼저 확인함
