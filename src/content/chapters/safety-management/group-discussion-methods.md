## 핵심 개념

집단토의법은 발표자와 참가자의 역할, 토의의 진행 방식으로 구분함 · 명칭이 비슷해도 전문가가 먼저 발표하는지, 참가자가 자유롭게 의견을 교환하는지를 확인해야 함

| **방식** | 판단 기준 |
|---|---|
| **심포지엄** | 여러 전문가가 한 주제에 대한 견해를 차례로 발표하고 참가자가 질문·의견을 제시 |
| **포럼** | 발표 또는 주제 제시 뒤 청중의 질문과 의견을 받는 공개 토의 |
| **패널 토의** | 소수의 토의자가 한 주제를 서로 논의하고 청중이 이를 듣는 방식 |
| **버즈 세션** | 참가자를 작은 집단으로 나누어 짧게 토의한 뒤 결과를 공유 |
| **자유토의** | 정해진 발표자보다 참가자들의 자유로운 의견 교환을 중심으로 진행 |

## 판별 기준

‘몇 사람의 전문가가 주제에 대한 견해를 발표하고 참가자에게 의견이나 질문을 하게 한다’는 표현은 심포지엄의 핵심 단서임 · 발표자와 청중의 역할이 분명하고, 전문가 발표가 복수라는 점을 확인함

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 심포지엄 | **여러 전문가가 차례로 발표**하고 참가자가 질문·의견 제시 |
| 포럼 | **발표 뒤 청중의 질문과 의견**을 받는 공개 토의 |
| 패널 토의 | **소수 토의자가 서로 논의**하고 청중이 듣는 방식 |
| 버즈 세션 | **소집단으로 짧게 토의**한 뒤 결과 공유 |
| 자유토의 | 정해진 발표자보다 **참가자의 자유로운 의견 교환** 중심 |
| ‘전문 발표 후 참가자 의견·질문’ | **심포지엄**에 해당 |

## 자주 틀리는 포인트

- 포럼은 청중의 질문·의견 참여가 핵심이지, 여러 전문가의 순차 발표 자체가 핵심은 아님
- 버즈 세션은 소집단 토의이며 전문가 발표 방식이 아님
- 자유토의는 참가자 중심의 교환이므로 ‘전문가 발표 후 질문’이라는 문장과 구분함
