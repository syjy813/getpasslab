## 주의의 세 가지 특성

주의는 여러 자극 중 필요한 대상을 선택하여 집중하는 기능임

| 특성 | 뜻 |
|---|---|
| 선택성 | 여러 자극 중 일부를 선택하여 집중 |
| 변동성 | 높은 주의를 오래 유지하기 어려워 수준이 변함 |
| 방향성 | 한 대상에 집중하면 다른 대상에 대한 주의가 약해짐 |

## 의식 수준 5단계

| 단계 | 의식상태 |
|---|---|
| Phase 0 | 수면·무의식 |
| Phase I | 몽롱한 의식 이완 |
| Phase II | 정상·이완, 일상적 작업 상태 |
| Phase III | 명료하며 주의가 가장 적극적으로 집중 |
| Phase IV | 과긴장·의식의 과잉 |

의식의 과잉은 긴급 이상상태나 돌발 사태의 과도한 긴장으로 **판단능력이 둔화·정지**하는 상태임
