## 핵심 공식

대전체에 축적되는 정전기 에너지

$$E = \frac{1}{2}CV^2 = \frac{1}{2}QV = \frac{Q^2}{2C}$$

착화한계전압 역산형 — 최소착화에너지 E와 정전용량 C가 주어질 때

$$V = \sqrt{\frac{2E}{C}}$$


## 기호·단위

| 기호 | 명칭 | 단위 | 주의점 |
|------|------|------|--------|
| E | 축적(착화) 에너지 | J (줄) | mJ = 10⁻³ J 환산 |
| C | 정전용량 | F (패럿) | pF = 10⁻¹² F |
| V | 대전 전위 | V (볼트) | kV 제시 시 ×10³ |
| Q | 전하량 | C (쿨롱) | Q = CV로 상호 변환 |

대표 계산: C = 1,000 pF, E = 0.019 mJ → V = √(2×0.019×10⁻³ / 10⁻⁹) ≈ 195 V

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 정전기 축적 에너지 E | **$E = \frac{1}{2}CV^2 = \frac{1}{2}QV = \frac{Q^2}{2C}$** |
| 정전기 축적 에너지 V | **$V = \sqrt{\frac{2E}{C}}$** |
| E | **축적(착화) 에너지** · J (줄) · **mJ = 10⁻³ J 환산** |
| C | **정전용량** · F (패럿) · **pF = 10⁻¹² F** |
| V | **대전 전위** · V (볼트) · **kV 제시 시 ×10³** |
| Q | **전하량** · C (쿨롱) · Q = CV로 상호 변환 |
| 0.019mJ·1,000pF | 착화한계전압 약 **195V** |
| 0.2mJ·10pF | 착화한계전압 약 **6,325V** |
| 20μF·2kV | 축적 에너지 **40J** |
| 0.26mJ·100pF | 착화한계전압 약 **2,280V** |

## 자주 틀리는 포인트

> ⚠️ **함정 주의**: Q = CV를 대입한 3가지 형태 중 문제가 준 변수 조합에 맞는 식을 선택 · ½ 누락과 pF·mJ 승수 처리가 오답의 양대 원인
