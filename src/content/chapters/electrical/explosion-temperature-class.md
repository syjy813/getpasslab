## 핵심 개념

온도등급 `T`는 방폭기기가 정상적인 사용 조건에서 도달할 수 있는 **최고표면온도의 상한**을 나타냄 · 가스의 발화온도 등급이나 기기 내부의 동작온도를 뜻하는 기호가 아님 · 기호 뒤의 숫자가 커질수록 허용되는 기기 표면온도는 더 낮아지므로, `T6`가 `T1`보다 엄격한 온도 조건임

방폭기기를 고를 때는 가연성 가스의 발화온도와 기기의 최고표면온도를 비교함 · 기기 표면이 가스의 발화원이 되지 않도록 **기기의 최고표면온도가 가스의 발화온도보다 낮아야 함** · 따라서 가스의 발화온도가 낮을수록 더 낮은 표면온도 등급, 즉 숫자가 큰 T등급이 필요함

| 등급 | 최고표면온도 |
|------|------|
| T1 | 450℃ 이하 |
| T2 | 300℃ 이하 |
| T3 | 200℃ 이하 |
| T4 | 135℃ 이하 |
| T5 | 100℃ 이하 |
| T6 | 85℃ 이하 |

선정 원칙은 다음 한 줄로 정리할 수 있음

`기기 최고표면온도 < 가스의 발화온도`

예를 들어 발화온도가 120℃인 가스에 T4 기기를 사용하면 기기 표면이 135℃까지 올라갈 수 있으므로 조건을 만족하지 못함 · T5는 최고표면온도가 100℃ 이하이므로 조건을 만족함 · 수록 기출에서는 이 비교를 통해 최소 요구 등급인 T5를 고르게 함


## 등급 판별

| 판별 항목 | 기준값 | 주의점 |
|------|------|--------|
| 온도등급 | T1~T6 | 번호가 클수록 표면온도 상한은 낮음 |
| T4 | 135℃ | 150℃ 변조 주의 |
| 기본 주위온도 | −20~+40℃ | 범위를 벗어나면 별도 표시 |

### 선택 순서

1. 문제에 제시된 가스의 발화온도를 찾음
2. 각 T등급의 최고표면온도와 비교함
3. 발화온도보다 표면온도 상한이 낮은 등급 중 문제에서 요구한 답을 고름
4. 별도 주위온도 표시나 기호 `X` 조건이 있는지 마지막으로 확인함

별도의 주위온도 표시가 없고 기호 `X`도 없는 기기에 대해 수록 기출이 사용하는 기본 범위는 <strong>−20℃~+40℃</strong>임 · 이 숫자는 온도등급 표의 최고표면온도와 서로 다른 조건이므로 한 표의 값처럼 섞어 외우지 않음

## 자주 틀리는 포인트

> **숫자 함정**: T4는 135℃이며 150℃가 아님 · 또한 T등급 숫자가 커지는 방향과 최고표면온도가 커지는 방향은 반대임

- 가스의 발화온도와 기기의 최고표면온도를 같은 값으로 맞추는 것이 아니라, 기기 상한이 더 낮아야 함
- `T6`를 가장 뜨거운 등급으로 해석하지 않음 · T6는 표면온도 상한이 가장 낮음
- 주위온도 −20℃~+40℃를 가스의 발화온도 범위나 T등급 기준으로 오해하지 않음
