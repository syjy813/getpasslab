## 핵심 공식

Dalziel의 심실세동 위험한계 전류식은 통전시간에 따라 허용 한계 전류가 달라진다는 관계를 나타냄

$$I_k = \frac{165}{\sqrt{T}}\;(\mathrm{mA})$$

`T`는 통전시간(s), `Ik`는 한계 전류(mA)임 · 이 전류가 인체저항 `R`을 통해 시간 `T` 동안 흐를 때 전기에너지는 다음과 같이 계산함

$$W = I^2 \times R \times T\;(\mathrm{J})$$

`Ik`가 mA로 주어진 경우에는 A로 바꾸어 대입함

$$W\,[\mathrm{J}] = \frac{I_k^2}{1{,}000{,}000} \times R \times T$$

### 대표 계산

`T = 1s`, `R = 500Ω`이면 `Ik = 165mA = 0.165A`이고,

$$W = 0.165^2 \times 500 \times 1 \approx 13.61\ \mathrm{J}$$

기사 계산 관례대로 `1J ≈ 0.24cal`을 적용하면 약 `13.61J`는 약 `3.27cal`임 · 2022년 4월 시험 77번은 이 단위 변환까지 포함하는 문제임

## 계산·단위

| 기호 | 의미 |
| --- | --- |
| `Ik` | 심실세동 위험한계 전류, 식에서는 mA로 표시될 수 있음 |
| `T` | 통전시간(s) |
| `R` | 인체저항(Ω) |
| `W` | 전기에너지(J 또는 문제에서 요구하는 cal) |

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| Ik | **$I_k = \frac{165}{\sqrt{T}}\;(\mathrm{mA})$** |
| 심실세동 위험한계 에너지 W | **$W = I^2 \times R \times T\;(\mathrm{J})$** |
| W\,[J] | **$W\,[\mathrm{J}] = \frac{I_k^2}{1{,}000{,}000} \times R \times T$** |
| 인체저항 500Ω·1초 | **$W = 0.165^2 \times 500 \times 1 \approx 13.61\ \mathrm{J}$** |
| `I_k` 단위 | **심실세동 위험한계 전류** · 식의 mA를 A로 환산 |
| 인체저항 800Ω·1초 | 약 **22J** |
| 인체저항 1,000Ω·1초 | 약 **27.23J** |
| 인체저항 5,000Ω·1초 | 약 **136J** |
| T | **통전시간(s)** |
| 500Ω·1초를 cal로 환산 | 약 13.61J ÷ 4.186 → **3.27cal** |

## 자주 틀리는 포인트

> ⚠️ **함정 주의**: `mA²`를 그대로 사용하면 에너지가 1,000,000배 달라짐 · 전류를 A로 변환한 뒤 `I²RT`를 계산함

- `T`가 1초가 아니면 먼저 `Ik = 165/√T`를 계산함
- 인체저항은 Ω로 맞추고, mA는 A로 변환함
- 답이 J인지 cal인지 확인하고 단위 변환을 마지막에 적용함
- 같은 유형이라도 저항값과 통전시간이 달라지므로 선택지의 숫자를 암기해 대입하지 않음
