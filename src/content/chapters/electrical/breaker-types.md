## 핵심 개념

차단기는 전로의 개폐와 사고전류 차단을 담당함 · 약호만 외우기보다 차단 대상과 동작 환경을 함께 비교함

| **약호** | 구분 포인트 |
|---|---|
| **OS** | 개폐 기능을 중심으로 사용하는 장치 |
| **VCB** | 진공 중에서 차단하는 차단기 |
| **MCCB** | 배선용 차단기 · 과부하·단락 사고 때 전로를 자동 차단 |
| **ACB** | 공기 중에서 차단하는 차단기 |
| **DS** | 회로를 분리·격리하는 단로기 계열 장치 |

## 판별 기준

‘절연물 용기 안에 개폐기구를 일체로 조립하고 과부하 및 단락 시 자동으로 전로를 차단한다’는 설명은 MCCB의 정의임 · 자동 사고전류 차단인지, 무부하 격리·개폐인지 구별함

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| OS | **개폐 기능을 중심으로 사용하는 장치** |
| VCB | **진공 중에서 차단하는 차단기** |
| MCCB | **배선용 차단기** · 과부하·단락 사고 때 전로를 자동 차단 |
| ACB | **공기 중에서 차단하는 차단기** |
| DS | **회로를 분리·격리하는 단로기 계열 장치** |
| MCCB 설명 | 정답은 **배선용 차단기(MCCB)** |

## 자주 틀리는 포인트

VCB와 ACB는 차단 매질이 핵심이고, DS는 보호용 자동 차단기와 기능이 다름 · 장치의 약호가 비슷해도 자동 차단 조건이 제시되면 MCCB 여부를 먼저 확인함
