## 핵심 개념

감전사고 예방은 전류가 인체를 통과할 수 있는 경로를 만들지 않는 것에서 시작함 · 이를 위해 충전부와 사람을 **절연·격리**하고, 절연이 실패해 외함에 전압이 나타나는 경우에는 **접지와 자동 차단**으로 위험 지속시간을 줄임 · 작업 단계에서는 전원을 차단하고 충전 여부를 확인하며, 보호구와 접근 통제를 마지막 방어선으로 사용함

따라서 감전 방지는 하나의 장치가 아니라 `직접 접촉 방지 → 고장 시 보호 → 작업 통제 → 개인보호`가 겹쳐진 구조임 · 명판의 정격 표시나 사고 후 처리 절차처럼 정보 제공 또는 사후 대응에 가까운 조치는 그 자체로 인체 전류 경로를 차단하지 못하므로 직접적인 방지대책과 구분함

## 절차 및 판별 기준

| 방어 단계 | 대표 조치 | 막으려는 상황 |
|---|---|---|
| 직접 접촉 방지 | 충전부 절연, 방호물·울타리, 접근 제한 | 사람이 정상 충전부에 닿는 상황 |
| 고장 시 보호 | 보호접지, 누전차단, 외함의 안전한 처리 | 절연 고장으로 금속 외함에 전압이 생기는 상황 |
| 작업 통제 | 전원 차단, 검전, 잠금·표시, 작업구역 관리 | 정비 중 재통전 또는 충전부 접근 |
| 개인보호 | 절연용 보호구·방호구, 절연 공구 | 남아 있는 접촉 가능성 |

누전차단기와 과전류 보호장치는 검출하려는 이상 상태가 같지 않음 · 또한 접지는 고장전류가 흐를 수 있는 경로를 만들고 보호장치가 동작하도록 돕는 조치이지, 불량 절연을 그대로 사용해도 된다는 뜻이 아님

### 문제 판별 순서

1. 직접 접촉인지, 외함 누전과 같은 간접 접촉인지 구분함
2. 문제의 조치가 전류 경로 차단·고장전류 처리·전원 차단 중 무엇을 하는지 확인함
3. 단순 표시, 사후 처리, 위험한 위치에 충전부를 두는 선택지는 직접 방지대책에서 제외함
4. 활선 근접작업이면 전압 조건과 작업 위치에 맞는 절연용 보호구인지 확인함

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 직접 접촉 방지 | **충전부 절연** · 방호물·울타리, 접근 제한 · 사람이 정상 충전부에 닿는 상황 |
| 고장 시 보호 | **보호접지** · 누전차단, 외함의 안전한 처리 · 절연 고장으로 금속 외함에 전압이 생기는 상황 |
| 작업 통제 | **전원 차단** · 검전, 잠금·표시, 작업구역 관리 · 정비 중 재통전 또는 충전부 접근 |
| 개인보호 | **절연용 보호구·방호구** · 절연 공구 · 남아 있는 접촉 가능성 |
| 직접 접촉 vs 외함 누전 | **충전부 직접 접촉과 간접 접촉을 구분** |
| 단순 표시·사후 처리·위험 위치의 충전부 | **직접 접촉 방지대책에 해당하지 않음** |
| 7,000V 이하 활선 근접작업 | **절연안전모** |
| 이동식 전기기기 | **접지설비** |
| 감전 방지대책이 아닌 것 | **정격표시·사고처리 프로세스 작성** |
| 노출 충전부 | 통전망을 두는 것이 아니라 **절연·방호·접근 제한** |

## 자주 틀리는 포인트

- `정격이 표시되어 있다`는 사실을 안전장치가 설치된 것으로 읽지 않음
- 절연이 불량한 기기는 접지저항만 측정하고 계속 사용하는 대상이 아님 · 절연 상태 자체를 바로잡아야 함
- 사고 발생 후 처리 절차는 필요한 관리 활동이지만 사고가 일어나기 전 전류 경로를 차단하는 예방조치와는 다름
- 정전작업의 구체적인 순서는 정전작업 절차 6단계 챕터, 접지 종류와 기준은 접지 챕터, 인체 전류의 생리 영향은 별도 챕터에서 확인함
