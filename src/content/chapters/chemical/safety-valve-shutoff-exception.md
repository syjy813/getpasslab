## 핵심 개념

안전밸브 등의 전단·후단에는 배출 경로 확보를 위해 원칙적으로 차단밸브를 설치할 수 없음

예외 — 자물쇠형 또는 이에 준하는 형식의 차단밸브 설치가 가능한 경우는 다음과 같음

| # | 예외 사유 |
|---|-----------|
| 1 | 인접한 화학설비·부속설비에 안전밸브 등이 각각 설치되어 있고, 연결배관에 차단밸브가 없는 경우 |
| 2 | 안전밸브 등의 배출용량의 1/2 이상인 자동압력조절밸브(구동용 동력원 차단 시 열리는 구조)와 안전밸브 등이 <strong>병렬</strong>로 연결된 경우 |
| 3 | 화학설비·부속설비에 안전밸브 등이 복수방식으로 설치된 경우 |
| 4 | 예비용 설비를 설치하고 각각의 설비에 안전밸브 등이 설치된 경우 |
| 5 | 열팽창에 의하여 상승된 압력을 낮추기 위한 목적으로 안전밸브가 설치된 경우 |
| 6 | 하나의 플레어 스택에 둘 이상의 단위공정의 플레어 헤더를 연결하고, 각 헤더 차단밸브의 열림·닫힘 상태를 중앙제어실에서 알 수 있도록 조치한 경우 |

안전밸브 설치 대상은 압력용기, 정변위 압축기, 정변위 펌프(토출측 차단밸브 설치분), 열팽창 파열 우려 배관 등임

**원심펌프는 대상 아님**

검사주기(현행 기준)는 다음과 같음

| 구분 | 주기 |
|------|------|
| 화학공정 유체와 디스크·시트가 직접 접촉 | 2년마다 1회 이상 |
| 안전밸브 전단에 파열판 설치 | 3년마다 1회 이상 |
| 공정안전보고서 이행상태 평가 우수 사업장 | 4년마다 1회 이상 |

## 적용 기준

| 용어 | 의미 | 주의점 |
|------|------|--------|
| 자물쇠형 차단밸브 | 임의 조작 방지 잠금 구조 | 상시 개방 상태 관리 |
| 정변위 펌프·압축기 | 토출 차단 시 압력 급상승 구조 | 원심식과 구분 |
| 파열판 | 1회용 파열 방출 장치 | 안전밸브와 직렬 조합 가능 |

## 시험 포인트

| 문제에서 보이는 표현 | 정답으로 연결 |
|---|---|
| 전단·후단 차단밸브 | 원칙적으로 **설치 금지** |
| 자동압력조절밸브와 안전밸브의 연결 | **병렬**이면 예외, **직렬**은 해당하지 않음 |
| 안전밸브 설치 대상이 아닌 것 | **원심펌프** |
| 정변위 펌프 | 토출측에 차단밸브가 설치된 경우 **설치 대상** |
| 2021년 기출의 직접 접촉 검사주기 | 당시 기준 **매년 1회 이상** |
| 현행 직접 접촉 검사주기 | **2년마다 1회 이상** |
| 현행 전단 파열판 | **3년마다 1회 이상** |
| 현행 이행상태 평가 우수 사업장 | **4년마다 1회 이상** |

> **기준일 주의**  이 페이지는 연결 기출의 출제 기준을 학습용으로 정리함
> 현행 실무 적용 전에는 최신 「산업안전보건기준에 관한 규칙」을 확인해야 함

## 자주 틀리는 포인트

> ⚠️ **함정 주의**: 차단밸브 예외는 **병렬**이며 직렬이 아님
> 검사주기는 개정됐으므로 **2021년 기출은 매년 1회**, 현행 학습은 **2년마다 1회**로 분리해야 함
