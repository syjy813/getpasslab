## 핵심 개념

<strong>자연발화</strong>는 외부 불꽃이나 전기 스파크가 직접 가열하지 않아도 물질 내부에서 발생한 열이 빠져나가지 못해 온도가 계속 올라가고, 결국 발화에 이르는 현상임 · 판단의 중심은 `열 발생량`과 `방열량`의 균형임

물질 내부에서 열을 만드는 대표적인 원인은 산화열, 분해열, 흡착열, 발효열, 중합열 등임 · 반대로 열이 쉽게 빠져나가면 축열이 어려워 자연발화 가능성이 낮아짐

## 판별 기준

- 주위 온도가 높고, 발열량이 크며, 열이 많이 축적될수록 자연발화가 쉬워짐
- 표면적이 넓으면 공기와 접촉하는 면적과 반응 면적이 커져 발열이 커질 수 있음 · 따라서 `표면적이 작을수록 쉽다`는 문장은 틀린 조건임
- 적당한 수분은 산화·분해·발효와 열 이동에 영향을 줄 수 있으므로, 수분이 항상 자연발화를 막는다고 단정하지 않음
- 통풍이 지나치게 크면 열을 빼앗아 축열을 줄일 수 있지만, 물질의 반응 조건에 따라 공기 공급이 발열을 키울 수도 있음 · 문제에서 제시한 조건을 함께 비교함
- 자연발화 방지에서는 통풍, 온도 상승 방지, 퇴적량과 표면적 관리, 공기 접촉 제한처럼 열이 쌓이지 않도록 하는 방향을 찾음

외부 점화원이 필요한 일반적인 점화와 달리, 자연발화는 내부 발열과 방열 불균형이 먼저 발생함 · 따라서 선택지에서 `증발열`처럼 자연발화 원인과 직접 거리가 먼 항목을 구분함

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 주위 온도·발열량·축열 | **클수록 자연발화 용이** |
| 표면적 | **넓을수록 반응·발열 증가 가능** · 작을수록 쉽다는 설명은 오답 |
| 적당한 수분 | **산화·분해·발효에 영향** · 항상 발화를 막는 것은 아님 |
| 통풍 과다 | **열 방출 증가 → 축열 감소** · 물질에 따라 공기 공급으로 발열 증가 가능 |
| 자연발화 방지 | **통풍·온도·퇴적량·표면적·공기 접촉 관리** |
| 산화열·분해열·흡착열·중합열 | **물질과 저장 조건에 맞는 축열 원인 구분** |
| 자연발화 원인과 거리가 먼 것 | **증발열** |
| 자연발화성 물질이 아닌 것 | **과염소산** |
| 열전도율 | 클수록 방열되므로 **자연발화 촉진과 거리가 멂** |
| 자연발화가 쉬운 환경 | **고온·다습** |

## 자주 틀리는 포인트

- 자연발화는 한 가지 원인으로 결정되지 않음 · 발열 원인과 방열 조건을 함께 봄
- `표면적이 넓다`와 `표면적이 작다`를 뒤집지 않음
- 자연발화 원인과 물질의 일반적인 점화원을 혼동하지 않음
- 이 챕터는 위험물 보관 법정 수치나 특정 물질의 상세 반응식을 다루지 않음
