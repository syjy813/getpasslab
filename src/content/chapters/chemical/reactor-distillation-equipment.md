## 핵심 개념

### 화학설비의 기능 구분

| 구분 | 대표 설비 | 기능 |
|---|---|---|
| 분리장치 | 결정조·유동탑·건조기 | 혼합물에서 성분 또는 수분을 분리 |
| 취급장치 | 분쇄기·분쇄분리기·압출기 | 분체를 분쇄·분리·성형하거나 이동 가능한 상태로 취급 |
| 분진처리 부속설비 | 사이클론·백필터·전기집진기 | 공정에서 발생한 분진을 포집·분리 |
| 운전·안전 부속설비 | 이송·자동제어·비상조치·감지경보·폐가스·전기안전 설비 | 공정의 연속 운전과 이상상태 대응을 지원 |

건조설비는 크게 **구조부분·가열장치·부속설비**로 나눔 · 구조부분에는 철골부와 보온판, 가열장치에는 열원장치, 부속설비에는 소화장치 등이 포함됨 · 설비 이름을 기능 구분과 바꾸어 읽지 않음

반응기의 분류 — 두 기준을 혼동시키는 것이 출제 핵심

| 기준 | 종류 |
|------|------|
| 조작방식 | 회분식, 반회분식, 연속식 |
| 구조방식 | 탑형, 관형(튜브형), 교반조형, 유동층형 |

반응기 설계 시 고려 요인 — 부식성, 상(相)의 형태, 온도 범위, 운전압력, 체류시간(공간속도) · ("중간생성물의 유무"는 해당 없음 — 기출 정답)

열교환기 점검 구분

| 구분 | 항목 |
|------|------|
| 일상점검 | 보온재·보냉재 파손 여부, 도장의 노후 상황, 플랜지부·용접부 누출 여부, 기초볼트 체결 정도 |
| 정기 개방점검 | 생성물·부착물에 의한 오염, 내부 부식·균열, 튜브 상태 |

열교환 능률 향상 — 유체 유속 적절 조절, **향류(대향류)** 흐름, 입출구 온도차 크게, 열전도율 높은 재료

## 구분 기준

| 용어 | 의미 | 주의점 |
|------|------|--------|
| 회분식 | 원료 일괄 투입·배출 | 조작방식 |
| 유동층형 | 촉매 입자를 유동 상태로 유지 | 구조방식 |
| 향류 | 두 유체가 반대 방향 흐름 | 평균 온도차 최대화 |

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 조작방식 | **회분식** · 반회분식, 연속식 |
| 구조방식 | **탑형** · 관형(튜브형), 교반조형, 유동층형 |
| 일상점검 | **보온재·보냉재 파손 여부** · 도장의 노후 상황, 플랜지부·용접부 누출 여부, 기초볼트 체결 정도 |
| 정기 개방점검 | **생성물·부착물에 의한 오염** · 내부 부식·균열, 튜브 상태 |
| 회분식 | **원료 일괄 투입·배출** · 조작방식 |
| 유동층형 | **촉매 입자를 유동 상태로 유지** · 구조방식 |
| 결정조·유동탑·건조기 | **분리장치** |
| 분쇄기·분쇄분리기·압출기 | **취급장치** |
| 사이클론·백필터·전기집진기 | **분진처리 부속설비** |
| 건조설비의 큰 구성 | **구조부분·가열장치·부속설비** |

## 자주 틀리는 포인트

> ⚠️ **함정 주의**: "탑형"을 조작방식에, "연속식"을 구조방식에 끼우는 교차 배치가 표준 함정 · 열교환기 흐름은 병류가 아니라 향류가 능률 유리 — "병류로 한다"가 틀린 것 정답 · 부착물 오염은 개방해야 보이므로 개방점검 항목
