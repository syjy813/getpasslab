## 핵심 개념

건조설비 문제는 `설비 구성`, `독립된 단층건물 기준`, `설비 구조`, `사용 중 예방조치`를 구분해서 판단함

| 학습자료의 구성 구분 | 해당 요소 |
|---|---|
| **구조부분** | 철골부·보온판 |
| **가열장치** | 열원장치 |
| **부속설비** | 소화장치 |

따라서 소화장치는 부속설비에 해당함 · 이 구성 분류와 산업안전보건기준에 관한 규칙 제280조부터 제284조까지의 설치·구조·사용 기준은 서로 다른 분류이므로 섞지 않음

## 법령 기준 및 판별

### 독립된 단층건물 기준

현행 확인 기준인 안전보건규칙 제280조(시행 2025년 9월 1일)는 다음 위험물 건조설비 중 건조실을 설치하는 건축물을 **독립된 단층건물**로 하도록 규정함

| 가열·건조 대상 또는 열원 | 기준 |
|---|---:|
| 위험물 또는 위험물이 발생하는 물질 | 내용적 **1m³ 이상** |
| 위험물이 아닌 물질 + 고체·액체연료 | 최대사용량 **10kg/h 이상** |
| 위험물이 아닌 물질 + 기체연료 | 최대사용량 **1m³/h 이상** |
| 위험물이 아닌 물질 + 전기 | 정격용량 **10kW 이상** |

건조실을 건축물의 최상층에 설치하거나 건축물이 내화구조인 경우는 독립된 단층건물 원칙의 예외임 · 2021년 5월 기출에서는 액체연료 `5kg/h`만 기준인 `10kg/h 이상`에 미달함

### 설비 구조

- 바깥 면은 **불연성 재료**로 만듦
- 위험물 건조설비의 측벽과 바닥은 **견고한 구조**로 함
- 상부는 **가벼운 재료**로 만들고 주위 상황을 고려해 **폭발구**를 설치함
- 발생하는 가스·증기·분진을 안전한 장소로 배출할 수 있게 함
- 위험물 건조설비의 열원으로 **직화**를 사용하지 않음

### 사용 중 폭발·화재 예방

1. 사용 전에 내부를 청소하거나 환기함
2. 발생한 가스·증기·분진 중 폭발·화재 위험 물질을 안전한 장소로 배출함
3. 가열건조하는 건조물이 **쉽게 이탈되지 않도록** 함
4. 고온으로 가열건조한 인화성 액체는 발화 위험이 없는 온도로 냉각한 뒤 격납함
5. 바깥 면이 현저히 고온인 건조설비 가까이에 인화성 액체를 두지 않음

## 시험 포인트

| 문제에서 보이는 키워드 | 정답으로 연결 |
|---|---|
| 부속설비 | **소화장치** |
| 위험물·위험물 발생 물질 | 내용적 **1m³ 이상**이면 독립된 단층건물 기준 |
| 액체연료 5kg/h | **10kg/h 미만**이므로 독립 단층건물 기준 대상이 아님 |
| 기체연료 2m³/h | **1m³/h 이상**이므로 기준 대상 |
| 전기 20kW | **10kW 이상**이므로 기준 대상 |
| 상부·폭발구 | 상부는 **가벼운 재료** · 주위 상황을 고려해 폭발구 설치 |
| 가열건조하는 건조물 | 쉽게 **이탈되지 않도록** 함 |
| 고온의 인화성 액체 | 발화 위험이 없는 온도로 **냉각 후 격납** |

## 자주 틀리는 포인트

- 위험물 건조설비의 상부를 무거운 재료로 만든다는 선택지는 반대로 된 표현임
- 고체·액체연료, 기체연료, 전기의 기준값과 단위를 서로 바꾸지 않음
- `쉽게 이탈되도록`이 아니라 **쉽게 이탈되지 않도록** 해야 함
- 독립 단층건물 기준에는 최상층 설치 또는 내화구조 예외가 있음
