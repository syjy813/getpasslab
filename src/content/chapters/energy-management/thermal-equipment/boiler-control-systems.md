## 자동제어의 구성

자동제어는 **측정 → 비교 → 판단 → 조작 → 공정 변화 → 피드백**의 흐름으로 봄

- **검출부**: 온도, 압력, 수위, 유량, 산소농도 등을 측정함
- **조절부**: 측정값과 설정값의 편차를 계산해 제어신호를 만듦
- **조작부**: 제어밸브, 댐퍼, 버너, 펌프 등을 움직임
- **제어대상**: 보일러 압력, 수위, 연소상태와 같은 공정량임

폐루프 제어는 결과를 다시 측정해 오차를 줄임 · 개루프 제어는 결과를 되먹임하지 않으므로 외란에 스스로 보정하지 못함

## 제어 동작

- **2위치 제어**: 설정값을 기준으로 켜짐·꺼짐 두 상태를 전환함 · 구조가 단순하지만 변동폭이 생김
- **비례(P) 제어**: 편차에 비례해 조작량을 바꿈 · 반응은 빠르지만 정상상태 편차가 남을 수 있음
- **적분(I) 제어**: 편차를 시간에 따라 누적해 정상상태 편차를 없앰 · 지나치면 응답이 느려지거나 진동함
- **미분(D) 제어**: 편차의 변화속도에 반응해 급격한 변화를 억제함 · 측정 잡음에 민감할 수 있음

PID 제어는 세 동작의 장점을 조합함 · 시험에서는 각 동작의 역할과 결과를 연결해 판별함

## 보일러 주요 제어

### 수위제어

- **1요소 제어**: 드럼 수위만 사용함 · 부하 변화가 작은 소형 설비에 단순함
- **2요소 제어**: 드럼 수위와 증기유량을 사용해 부하 변화를 미리 보정함
- **3요소 제어**: 드럼 수위, 증기유량, 급수유량을 사용해 큰 부하 변화에 대응함

급격한 증기부하 증가 때 압력이 떨어지며 기포가 팽창해 수위가 일시적으로 높아 보이는 **스웰**, 반대 상황에서 수위가 낮아 보이는 **슈링크**를 고려함

### 압력·온도제어

증기압력은 부하에 맞춰 연료와 공기량을 조절해 유지함 · 온수보일러는 출구 온도나 환수 온도를 기준으로 버너를 제어할 수 있음 · 과열증기 온도는 감온수 분사나 연소가스 분배 등으로 조절함

### 연소제어

연료와 공기를 부하에 맞춰 함께 조절함 · 부하를 올릴 때 공기를 먼저 늘리고 연료를 뒤따르게 하며, 부하를 내릴 때 연료를 먼저 줄이는 교차제한 방식은 연료 과다로 인한 불완전연소를 줄임 · 산소 트림은 배기가스 산소농도를 피드백해 공기량을 미세 조정함

## 시퀀스와 인터록

정상적인 기동 시퀀스는 대체로 운전조건 확인, 통풍 확인, 프리퍼지, 점화원 확인, 주연료 투입, 화염 확인, 부하 상승 순임 · 각 단계 조건이 만족되지 않으면 다음 단계로 넘어가지 않는 것이 인터록임

비상정지는 먼저 연료를 안전하게 차단함 · 트립 원인을 확인하지 않은 자동 재기동은 미연소 가스 축적과 재점화 위험을 만들 수 있음

## 시험 포인트

### 우선 암기

| 문제에서 보이는 표현 | 정답으로 연결 |
|---|---|
| 조절부 | 측정값과 설정값의 **편차 계산 → 제어신호 생성** |
| 비례(P) | **편차에 비례 · 정상상태 편차가 남을 수 있음** |
| 적분(I) | 편차 누적 · **정상상태 편차 제거** |
| 미분(D) | **편차 변화속도에 반응 · 급격한 변화 억제** |
| 1요소 수위제어 | **드럼 수위** |
| 2요소 수위제어 | **드럼 수위 + 증기유량** |
| 3요소 수위제어 | **드럼 수위 + 증기유량 + 급수유량** |
| 인터록 | 필수 조건 불충족 시 **다음 시퀀스 차단** |
| 송풍기 미작동 시 점화 차단 | **프리퍼지 인터록** |

### 추가 확인

| 문제에서 보이는 표현 | 정답으로 연결 |
|---|---|
| 정해진 순서대로 단계 진행 | **시퀀스 제어** |
| 공기압 신호 전달 | 전송거리 약 100~150m · **시간지연 발생** |
| 자동연소제어 / 급수제어 | **A.C.C / F.W.C** |
| 보일러 패널 내부 온도 | **60℃ 이하** |
| 교차제한 | 부하 상승 시 **공기 먼저**, 부하 하강 시 **연료 먼저** 조절 |

## 자주 틀리는 포인트

- 조절제어는 정상 운전값을 유지하고, 인터록은 위험한 순서나 조건에서 운전을 막음
- 3요소 수위제어의 세 신호는 수위·증기유량·급수유량임
- 산소 트림은 기본 연료·공기비 제어를 대체하는 장치가 아니라 미세 보정하는 제어임
