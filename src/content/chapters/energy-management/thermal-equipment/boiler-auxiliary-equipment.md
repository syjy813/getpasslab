## 급수 계통

급수 계통은 보일러에 필요한 물을 안정적으로 공급하고 수질을 유지하는 설비임 · 일반적으로 보충수와 환수는 급수탱크 또는 탈기 계통에서 모이고, 급수펌프가 절탄기를 거쳐 보일러로 보냄

- **급수펌프**: 보일러 압력보다 높은 토출압을 만들어 물을 공급함 · 흡입측 공기 유입, 부족한 흡입수두, 지나치게 높은 수온은 캐비테이션의 원인이 됨
- **급수밸브·체크밸브**: 유량을 조절하고 보일러수가 급수관으로 역류하는 것을 막음
- **급수탱크·탈기기**: 급수를 저장하고 용존 산소와 이산화탄소를 줄여 부식을 억제함
- **응축수 회수**: 고온 응축수의 현열과 처리수를 재사용해 연료와 보충수 사용을 줄임

급수 부족은 전열면 과열로 이어지고, 과다 급수는 증기 공간을 줄여 수분 동반을 일으킬 수 있음 · 수위제어기만 믿지 말고 수면계와 급수 상태를 함께 확인함

### 급수내관

급수내관은 보일러 내부로 들어온 급수를 한 지점에 집중시키지 않고 분산 공급하는 구멍이 뚫린 관임 · 차가운 급수가 고온의 동체나 수관에 국부적으로 직접 닿는 것을 줄여 열충격과 급격한 수위 변동을 완화함

과거 기출에서는 급수내관의 설치 위치를 **안전저수위보다 약 50mm 아래**로 반복해서 물었음

> 쉽게 이해하면: 뜨거운 용기에 찬물을 한 곳에 붓는 대신 샤워기처럼 여러 곳으로 나누어 공급하는 구조임

### 급수펌프 형식과 축동력

| 형식 | 작동 원리 | 시험 판별 |
|---|---|---|
| 원심펌프 | 임펠러 회전으로 유체에 속도와 압력을 부여 | 연속 유량에 적합하고 맥동이 작음 |
| 볼류트펌프 | 원심펌프의 한 형식 | 과거 기출에서 비교적 저압용으로 구분 |
| 터빈펌프 | 원심계 펌프 | 과거 기출에서 고압용으로 구분 |
| 왕복펌프 | 피스톤·플런저 왕복운동 | 고압에 유리하나 맥동이 큼 |

왕복식 펌프가 아닌 것을 묻는 과거 기출에서는 **터빈펌프**가 정답으로 출제됨

비중량 `γ`, 유량 `Q`, 전양정 `H`, 펌프효율 `η`가 주어진 구 공학단위 문제에서 펌프의 소요마력은 다음 관계로 계산함

$$
P(PS)=\frac{\gamma QH}{4500\eta}
$$

`γ`의 단위가 `kgf/m³`, `Q`가 `m³/min`, `H`가 `m`일 때 적용함 · 2015년 10월 기출의 `Q=10m³/min`, `H=8m`, `η=0.75`, 물의 `γ≈1000kgf/m³` 조건에서는 약 `23.7PS`가 됨

SI 동력으로 환산할 때 `1kW ≈ 102kgf·m/s`임

> 쉽게 이해하면: 원심펌프는 선풍기처럼 계속 돌면서 물에 에너지를 주고, 왕복펌프는 주사기 피스톤처럼 일정량의 물을 직접 밀어냄

### 인젝터

인젝터는 별도의 전동기 없이 **보일러 증기의 에너지로 급수하는 장치**임 · 고속 증기제트가 급수를 끌어들인 뒤 증기와 물이 혼합되고, 혼합류의 속도에너지가 토출부에서 압력으로 변환되어 보일러로 급수됨

- 구조가 간단하고 설치공간이 작음
- 별도의 전동기가 필요하지 않음
- 증기와 물이 혼합되며 급수가 예열됨
- 급수온도가 너무 높거나 인젝터 자체가 과열되면 급수가 곤란할 수 있음
- 노즐 마모·이물질·흡입측 공기 유입·체크밸브 이상 등이 작동불량 원인이 될 수 있음

> 쉽게 이해하면: 빠르게 분사되는 제트가 주변 물을 끌어당겨 함께 밀어내는 제트펌프와 비슷함

기동·정지 밸브 순서는 기출 또는 신뢰할 수 있는 원문에서 직접 확인하지 않은 상태에서는 임의로 외우지 않음

### 기수분리기와 비수방지관

- **기수분리기**: 증기 속에 동반된 물방울을 분리해 증기의 건도를 높임 · 과거 기출에서는 스크러버형·사이클론형·배플형 등이 출제됨
- **비수방지관**: 드럼 내 증기 취출구 부근에서 물방울이 증기와 함께 딸려 나가는 것을 억제함

두 장치는 모두 증기 속 수분을 줄이는 데 관련되지만, 기수분리기는 **이미 혼입된 수분을 분리**하고 비수방지관은 **물방울의 동반 취출을 억제**하는 장치로 구분함

## 압력용기와 열교환기

- **증기헤더**: 여러 보일러의 증기를 모으거나 사용처별로 분배함
- **증기축열기**: 부하가 낮을 때 열을 저장하고 순간 부하가 커질 때 증기를 보충함
- **플래시탱크**: 고압 응축수나 배출수가 낮은 압력으로 떨어질 때 생기는 재증발증기를 분리함
- **열교환기**: 두 유체를 섞지 않고 전열면을 통해 열을 교환함 · 향류는 같은 조건에서 병류보다 평균 온도차를 크게 확보하기 쉬움

## 폐열회수 설비

| 설비 | 가열 대상 | 목적 |
|---|---|---|
| 과열기 | 포화증기 | 증기 온도를 포화온도 이상으로 높임 |
| 재열기 | 터빈에서 일부 팽창한 증기 | 다시 가열해 습분을 줄이고 효율을 높임 |
| 절탄기 | 보일러 급수 | 배기가스 열로 급수를 예열함 |
| 공기예열기 | 연소용 공기 | 배기가스 열로 공기를 예열해 연소를 돕음 |
| 연료유 예열기 | 중유 등 액체연료 | 점도를 낮춰 이송과 무화를 돕음 |

배기가스 열을 지나치게 회수해 온도가 산성 이슬점 아래로 내려가면 저온부식 위험이 커질 수 있음 · 효율 향상과 부식 방지를 함께 고려함

## 시험 포인트

| 문제에서 보이는 표현 | 정답으로 연결 |
|---|---|
| 급수펌프 | 보일러 압력과 배관손실을 이기는 **토출압 필요** |
| 왕복식 펌프가 아닌 것 | **터빈 펌프** |
| 급수 체크밸브 | 보일러수의 급수관 **역류 방지** |
| 급수탱크 | 급수 저장 · 오염·동결 방지 · 필요 시 **가열·탈기로 공기 용입 억제** |
| 급수내관 | 급수를 **분산 공급**해 열충격·수위변동 완화 |
| 급수내관 설치 위치 | 과거 기출에서 안전저수위보다 약 **50mm 아래** |
| 펌프 소요마력 | `P(PS)=γQH/(4500η)` |
| 인젝터 | **증기를 이용한 급수장치** · 별도 전동기 불필요 |
| 기수분리기 | 증기 속 **혼입 수분 분리** |
| 비수방지관 | 증기취출구 부근의 **물방울 동반취출 억제** |
| 과열기 | **포화증기** 가열 |
| 고온부식이 잘 생기는 장치 | **과열기** |
| 절탄기 | 배기가스 열로 **보일러 급수** 예열 |
| 절탄기 효과 | 급수와 보일러수의 온도차 감소 → **열응력 감소** |
| 공기예열기 | 배기가스 열로 **연소용 공기** 예열 |
| 저온부식 | 배기가스가 산성 이슬점 이하가 되는 **저온 전열면·공기예열기** 주의 |
| 연료유 예열기 | **점도를 낮춰 이송·무화 보조** |
| 플래시탱크 | 감압 때 생기는 **재증발증기 분리·회수** |
| 향류 열교환 | **같은 조건에서 병류보다 평균온도차 확보에 유리** |

## 자주 틀리는 포인트

- 절탄기와 공기예열기는 모두 폐열회수 장치지만 가열하는 유체가 다름
- 응축수 회수는 절수만을 위한 것이 아니라 급수 보유열과 수처리 비용도 회수하는 운전임
- 기수분리기와 비수방지관은 모두 증기 품질과 관련되지만 작동 위치와 역할이 다름
- 펌프 축동력 공식은 `Q`의 시간 단위와 사용하는 상수 `4500`, `6120`의 조합을 섞지 않음
