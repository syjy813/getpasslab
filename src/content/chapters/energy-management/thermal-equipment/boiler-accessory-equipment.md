## 주요 계측장치

- **수면계**: 보일러 동체의 실제 수위를 운전자가 확인함 · 표시 수위가 의심되면 정해진 통수 절차로 증기측·수측 연결 상태를 확인함
- **압력계**: 보일러 내부 압력을 표시함 · 보일러와 압력계 사이의 사이폰관은 고온 증기가 계기에 직접 닿는 것을 막음
- **온도계**: 급수, 증기, 배기가스와 연료 온도를 감시해 연소·열교환 상태를 판단함
- **유량계**: 연료, 급수, 증기량을 측정해 열정산과 부하 관리를 돕음

계측기는 안전장치와 역할이 다름 · 계측기는 상태를 보여 주고, 경보·차단장치는 설정값을 벗어났을 때 운전자에게 알리거나 연료를 차단함

## 배출·청소 장치

**블로다운**은 보일러수 일부를 배출해 농축된 용해고형물과 슬러지를 제거하는 운전임 · 하부 블로다운은 침전물을 배출하는 데 유리하고, 연속 블로다운은 보일러수 농도를 일정하게 관리하는 데 유리함 · 과도한 블로다운은 열과 처리수 손실을 늘리므로 수질시험에 근거해 조절함

**수트블로어**는 전열면에 붙은 그을음과 회분을 증기나 공기로 제거함 · 전열면 오염은 배기가스 온도 상승, 통풍 저항 증가, 효율 저하를 일으킴 · 수트블로잉 중에는 화염과 노내압 변화를 감시함

## 시험 포인트

| 문제에서 보이는 표현 | 정답으로 연결 |
|---|---|
| 수면계 | 보일러 동체의 **실제 수위 표시** |
| 압력계 사이폰관 | 고온 증기의 직접 접촉을 막아 **압력계 보호** |
| 압력계 사이폰관 치수 | 물을 채운 관의 안지름 **6.5mm 이상** |
| 수면계 점검 시작 | **물콕·증기콕 닫기 → 드레인콕 열기** |
| 블로다운 | **보일러수의 농축 고형물·슬러지 배출** |
| 하부 블로다운 | 바닥의 **침전물 배출**에 유리 |
| 연속 블로다운 | 보일러수 **농도 일정 관리**에 유리 |
| 수트블로어 | 가스측 전열면의 **그을음·회분 제거** |
| 계측기 | **상태 표시** |
| 경보·차단장치 | **설정값 이탈 시 경보 또는 연료 차단** |

## 자주 틀리는 포인트

- 수면계의 표시가 움직인다고 항상 정상인 것은 아님 · 연결관 막힘 여부를 확인해야 함
- 블로다운을 늘리면 수질 농도는 낮아지지만 보일러 효율은 무조건 좋아지는 것이 아님
- 계측값을 표시하는 장치와 설정값에서 연료를 차단하는 안전장치를 혼동하지 않음
