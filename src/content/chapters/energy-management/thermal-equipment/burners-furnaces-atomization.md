## 연료별 연소장치

연소장치는 연료를 공기와 혼합하고 안정적으로 점화·연소시키며 필요한 열방출률을 유지함

- **고체연료**: 고정·이동·체인 화격자 등에서 연료 공급, 공기 분배와 회분 배출방식을 구분함
- **액체연료**: 버너에서 연료를 작은 방울로 무화해 증발과 공기 혼합을 빠르게 함
- **기체연료**: 공기와의 혼합 위치에 따라 확산연소와 예혼합연소로 나눔

미분탄 연소는 고체연료를 미세하게 분쇄해 공기와 함께 분사함 · 화격자 연소와 비교할 때 연료 입도, 연소속도, 비산회와 분쇄동력을 함께 봄

## 액체연료의 무화

| 방식 | 무화 에너지원 | 확인 항목 |
|---|---|---|
| 압력분무식 | 연료 자체 압력 | 유압·노즐 형상·점도 |
| 증기·공기분무식 | 무화용 증기 또는 공기 | 무화매체 압력과 사용량 |
| 회전식 | 회전컵의 원심력 | 회전속도·연료막·공기흐름 |

점도가 너무 높으면 큰 액적과 불완전연소가 생기기 쉬움 · 예열온도가 지나치게 높아도 기화·탄화와 분무 불량이 생길 수 있으므로 연료 성상과 버너 기준에 맞춤

## 연소실과 연소부하

연소실은 연료가 혼합·착화·연소할 공간과 체류시간을 제공함 · 연소실 열부하는 단위 체적당 투입열량, 화격자 연소율은 단위 화격자면적당 연료량처럼 분모와 단위가 다름

내화물은 고온을 견디고 열손실을 줄이며 화염 형상을 유지함 · 손상·박리는 국부 과열, 화염 편류와 본체 손상으로 이어질 수 있음

## 화염 안정

역화는 혼합기체 유출속도보다 화염전파속도가 커 화염이 버너 안쪽으로 전파하는 현상임 · 유출속도가 지나치게 크면 화염이 버너에서 떨어지는 리프팅이 생기고, 더 커지면 블로오프로 소화될 수 있음

점화 실패나 실화가 발생하면 연료를 차단하고 원인을 확인한 뒤 다시 퍼지함 · 연료를 추가 공급해 화염을 억지로 유지하지 않음

## 시험 포인트

| 문제에서 보이는 표현 | 정답으로 연결 |
|---|---|
| 압력분무식 버너 | **연료 자체 압력**으로 무화 |
| 증기·공기분무식 버너 | **증기 또는 공기**를 무화 에너지원으로 사용 |
| 회전식 버너 | 회전컵의 **원심력**으로 무화 |
| 2유체버너·수 기압 분무매체 | **고압기류식 버너** |
| 역화 | **화염전파속도 > 혼합기체 유출속도** |
| 리프팅·블로오프 | **혼합기체 유출속도가 화염전파속도보다 지나치게 큼** |
| 점화 실패·실화 | **연료 차단 → 원인 확인 → 재퍼지** |
| 수동점화·버너 2대 이상 | **한 대씩 순차 점화** |
| 응답이 느린 소용량 화염검출기 | **스택 스위치** |
| 연소실 열부하 | 단위 **연소실 체적**당 투입열량 |
| 화격자 연소율 | 단위 **화격자 면적**당 연료량 |

## 자주 틀리는 포인트

- 무화방식은 연료를 잘게 만드는 에너지원으로 구분함
- 역화와 리프팅은 혼합기체 유출속도와 화염전파속도의 관계가 반대임
- 화격자 연소율과 연소실 열부하의 분모를 혼동하지 않음
