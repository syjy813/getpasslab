## 배관도와 기호 읽기

배관계통도에서는 유체의 흐름 방향, 관경, 재질, 밸브·트랩·계기의 위치를 먼저 확인함 · 평면도는 실제 배치, 입면도는 높이 관계, 등각투상도는 배관의 3차원 형상을 파악하는 데 유리함

현장에서 기호를 읽을 때는 범례를 우선함 · 같은 모양이라도 도면 작성기준에 따라 의미가 달라질 수 있으므로 임의 추정하지 않음

## 관 이음과 시공

- **나사 이음**: 비교적 작은 관경과 분해가 필요한 곳에 사용함 · 나사산 손상과 밀봉 불량을 주의함
- **플랜지 이음**: 분해·점검이 쉬우며 밸브와 장비 연결에 많이 씀 · 볼트는 대각선 순서로 균등하게 조임
- **용접 이음**: 기밀성과 강도가 좋지만 품질관리와 검사, 작업 안전이 중요함
- **소켓·기계식 이음**: 재질과 압력·온도 범위에 적합한 제품과 시공법을 적용함

절단 뒤 버를 제거하고 관 중심을 맞춤 · 배관을 억지로 당겨 장비 노즐에 연결하면 열팽창과 진동이 노즐에 집중될 수 있음

## 열팽창과 지지

배관은 가열되면 늘어남 · 직관의 열팽창량은 개념적으로 `ΔL = αLΔT`로 계산함 · `α`는 선팽창계수, `L`은 길이, `ΔT`는 온도차임

팽창 루프, 벨로즈형 신축이음, 슬립형 신축이음 등으로 변위를 흡수함 · 고정점은 기준 위치를 잡고, 가이드와 행거는 배관이 의도한 방향으로 움직이게 함 · 신축이음만 설치하고 고정점·가이드를 잘못 배치하면 추력이 장비에 전달될 수 있음

## 밸브와 밀봉

| 장치 | 주 기능 |
|---|---|
| 게이트밸브 | 전개·전폐에 적합하고 완전 개방 시 저항이 작음 |
| 글로브밸브 | 유량 조절에 적합하나 압력손실이 비교적 큼 |
| 체크밸브 | 역류를 방지함 |
| 감압밸브 | 1차측의 높은 압력을 낮춰 2차측 압력을 유지함 |
| 안전밸브 | 설정압력 초과 시 유체를 방출함 |

감압밸브는 단순히 압력을 한 번 낮추는 장치가 아니라 1차측 압력과 사용량이 변해도 **2차측 압력을 설정값 부근으로 유지**하는 자동제어밸브임 · 설정압력 초과 시 유체를 외부로 방출하는 안전밸브와 역할을 구분함

강관의 호칭지름과 스케줄 번호는 실제 외경·두께의 관계를 문제 조건에서 확인함 · 절단·나사내기·확관 공구는 작업 대상과 기능을 연결함

패킹은 밸브 스템처럼 운동하는 부분의 누설을 막고, 개스킷은 플랜지처럼 고정된 접합면을 밀봉함 · 재질은 유체·온도·압력에 맞춰 선택함

## 바이패스 배관

바이패스관은 트랩·스트레이너·감압밸브·계기 등 주요 장치를 점검·수리·교체할 때 유체를 우회시키기 위한 배관임 · 정상운전 중 계속 열어 두는 주 유로로 이해하지 않음

> 쉽게 이해하면: 본선 도로를 공사할 때만 여는 임시 우회도로와 같음

과거 기출에서는 트랩이나 스트레이너 등의 고장·수리·교환에 대비한 바이패스관의 목적을 직접 물었음 · 연료차단밸브처럼 안전상 우회해서는 안 되는 장치와 구분함

## 시험 포인트

### 우선 암기

| 문제에서 보이는 표현 | 정답으로 연결 |
|---|---|
| 플랜지 이음 | **분해·점검이 쉬운 장비·밸브 연결부** |
| 용접 이음 | **기밀성·강도 우수 · 품질검사 필요** |
| 열팽창량 | **`ΔL = αLΔT`** |
| 신축이음 목적 | 열팽창에 의한 **배관 파열 방지** |
| 고정점·앵커 | **배관의 기준 위치 고정** |
| 진동 억제 지지장치 | **브레이스** |
| 가이드·행거 | **배관을 지지하고 의도한 방향의 이동 허용** |
| 게이트밸브 | **전개·전폐 · 완전 개방 시 저항 작음** |
| 글로브밸브 | **유량 조절 · 압력손실 비교적 큼** |
| 체크밸브 | **역류 방지** |
| 감압밸브 | 고압을 낮추고 **2차측 압력을 설정값 부근으로 유지** |
| 바이패스관 | 주요 장치의 **고장·수리·교체 시 우회 유로** |

| 패킹 / 개스킷 | **운동부 밀봉 / 고정 접합면 밀봉** |
| 바이패스에 두면 안 되는 장치 | **연료차단밸브** 등 안전상 우회 금지 장치 |

## 자주 틀리는 포인트

- 게이트밸브를 장시간 미세 유량조절에 쓰면 디스크와 시트가 손상될 수 있음
- 체크밸브는 유량을 조절하는 장치가 아니라 역류 방지 장치임
- 감압밸브와 안전밸브는 모두 압력과 관련되지만 제어 목적과 작동 방식이 다름
- 바이패스는 평상시 계속 사용하는 주 배관이 아니라 점검·수리·교체 시 우회시키기 위한 배관임
- 신축이음만 설치하고 고정점·가이드를 잘못 배치하면 배관 추력이 장비에 전달될 수 있음
