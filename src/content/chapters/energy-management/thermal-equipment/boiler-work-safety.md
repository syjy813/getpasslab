## 위험요인별 기본 대책

보일러 작업은 연료, 화염, 압력, 고온 유체, 전기와 회전체가 함께 존재함 · 작업 전에는 위험원을 확인하고 가능하면 에너지를 차단·격리한 뒤 잔류에너지를 제거함

- **압력**: 완전히 감압하고 압력계뿐 아니라 배출부로 잔압이 없는지 확인함
- **고온**: 충분히 냉각하고 증기·온수의 역류 가능성을 차단함
- **연료**: 주밸브를 차단하고 누설을 확인하며 환기함
- **전기·회전체**: 전원을 차단하고 잠금·표지해 오조작을 막음
- **밀폐공간**: 산소와 유해·가연성 가스를 측정하고 환기·감시·구조계획을 마련함

## 화재와 폭발

연료가 누설되어 공기와 가연범위의 혼합물을 만들고 점화원이 있으면 화재·폭발이 발생할 수 있음 · 점화 실패, 불완전연소, 버너 정지 뒤 연료밸브 누설과 부족한 퍼지가 대표 원인임

예방 순서는 누설 차단, 충분한 환기·퍼지, 점화 시퀀스 준수, 화염 확인, 실화 때 즉시 연료 차단임 · 가스 냄새나 검지기 경보가 있으면 전기 스위치를 함부로 조작하지 않고 점화원을 제거한 뒤 비상 절차를 따름

## 이상연소

- **역화**: 화염이 버너 쪽으로 거꾸로 전파함 · 연료·공기 속도와 혼합비, 버너 막힘을 확인함
- **리프팅**: 혼합기체 유출속도가 화염전파속도보다 지나치게 커져 화염이 버너에서 떨어짐 · 더 커지면 블로오프로 소화될 수 있음
- **맥동연소**: 연소와 압력변동이 반복돼 진동·소음을 만듦 · 연료공급, 통풍, 연소실 특성을 점검함
- **불완전연소**: 산소 부족이나 혼합 불량으로 일산화탄소와 그을음이 증가함

현상을 확인하지 않고 연료나 공기만 임의로 늘리면 위험이 커질 수 있음

## 화상·수격·파열

증기 누설부는 눈에 잘 보이지 않을 수 있고 고온 분류가 피부를 깊게 손상시킴 · 손으로 직접 누설 여부를 확인하지 않고 안전거리를 둔 점검방법을 사용함

응축수가 고속 증기에 밀리거나 밸브를 급히 열면 수격이 생김 · 배관 구배, 드레인과 트랩을 관리하고 밸브를 천천히 조작함 · 전열면의 과열·스케일·부식과 과압은 파열 위험을 높이므로 수질관리와 안전장치 기능시험이 필요함

## 공구·정비 작업

적합한 규격의 공구와 보호구를 사용하고, 회전체 방호덮개를 제거한 상태로 운전하지 않음 · 용접·용단은 주변 가연물을 제거하고 화재감시와 소화설비를 준비함 · 보일러 내부 작업은 연결 배관을 확실히 격리하고 다른 설비에서 증기·물·가스가 유입되지 않게 함

파이프렌치는 배관을 물어 회전시키는 전용 공구이므로 충격 공구처럼 사용하지 않음 · 나사절삭부의 날카로운 버나 절삭칩은 맨손으로 만지지 않고, 해머작업에서는 비산물에 대비한 보호안경을 착용함

## 소화 원칙

화재는 연료 종류와 전기 충전 여부에 맞는 소화방법을 선택함 · 연료공급을 안전하게 차단할 수 있다면 먼저 차단하되, 무리한 접근으로 인명 위험을 키우지 않음 · 전기설비가 충전된 상태에서 물을 사용하는 등 부적합한 소화방법을 쓰지 않음

## 시험 포인트

| 문제에서 보이는 표현 | 정답으로 연결 |
|---|---|
| 정비 전 기본조치 | **감압·냉각·연료 및 전원 차단·잔류에너지 제거** |
| 노내 폭발 예방 | 연료 누설 차단·환기·**충분한 퍼지**·점화순서 준수 |
| 역화 | **화염이 버너 안쪽으로 전파** |
| 리프팅 | **유출속도 과다로 화염이 버너에서 이탈** |
| 수격 예방 | **배관 구배·드레인·트랩 관리·밸브 천천히 조작** |
| 보일러 파열 위험 | **과압·저수위 과열·스케일·부식** |
| 보일러 수리·파이프렌치 | **망치 대용 사용 금지** |
| 취급상 원인이 아닌 것 | **재료·설계불량 또는 부속장치 미비** |
| 제작상 원인이 아닌 것 | **압력초과** |
| 기름보일러 화염 점멸 원인이 아닌 것 | **노내 부압 상태 자체** |
| 가스화재 | 불꽃만 끄지 말고 가능한 경우 **연료공급 차단** |
| 밀폐공간 작업 | **산소·유해가스 측정·환기·감시인·구조계획** |

## 자주 틀리는 포인트

- 가스화재는 불꽃만 끄고 누설을 계속 방치하면 미연소 가스가 축적될 수 있음
- 감압·냉각되지 않은 보일러의 맨홀이나 밸브를 분해하지 않음
- 사고 후 재가동은 안전장치 리셋만으로 끝나지 않으며 원인 제거와 기능 확인이 먼저임
