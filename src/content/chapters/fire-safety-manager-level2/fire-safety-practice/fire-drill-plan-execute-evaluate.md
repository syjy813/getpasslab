## 훈련은 평가까지 연결
계획 → 사전 안내·안전 확인 → 실행 → 평가 → 개선·재확인

계획에서는 화재 장소·시각·가용 인원, 역할, 통신 방법, 대피 경로·집결지를 정함 · 실제 화재와 혼동하지 않도록 필요한 사전 조치 실시

## 실행 중 확인
- 신고 내용과 내부 상황 전파
- 소화·피난 임무의 동시 수행
- 출입자·피난약자의 안전 이동
- 집결지 인원 확인과 미확인자 정보 전달
- 소방대 도착 시 위치·위험·설비 정보 인계

## 평가를 개선으로 바꾸는 예
‘피난이 느렸음’에서 끝내지 않고 어느 출입구에서 왜 지연됐는지 확인 → 적치물 제거·유도자 배치·연락 방법 수정 → 후속 훈련에서 개선 확인

훈련 시간을 줄이는 것만이 성과는 아님 · 무리한 뛰기·밀집·연기 구역 진입으로 시간을 단축한 결과는 안전한 훈련으로 평가하지 않음
