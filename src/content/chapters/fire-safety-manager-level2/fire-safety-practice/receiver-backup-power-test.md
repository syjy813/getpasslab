## 예비전원 시험의 목적
정전 때도 수신기·감지기·경보 기능이 유지되는지 확인 · 단순히 상용전원 표시등이 켜져 있는지 보는 시험과 다름

예비전원은 **감시 60분 후 경보 10분 이상** 작동할 수 있는 축전지 등의 조건 확인

## 판독 순서
예비전원 시험 조작 → 예비전원으로 전환·전압 및 표시 확인 → 음향·화재 감시 기능 확인 → 시험 해제·상용전원과 충전 상태 확인

시험 버튼으로 잠깐 표시가 정상이라고 법정 지속시간까지 검증된 것은 아님 · 표시 시험·용량 시험을 구분

수신기 복구 후에도 전원·충전 이상이 남으면 원인을 확인 · 전압 수치는 해당 기기의 정격·정상 범위로 판단



24V 계통의 대표 학습 예에서는 예비전원시험 **19~29V** 범위 확인 · 회로도통시험의 4~8V와 구별 · 예비전원감시 이상 표시는 연결 커넥터·배선·축전지·충전 상태를 확인하고, 수치를 모든 제품의 공통 법정 전압으로 일반화하지 않음
