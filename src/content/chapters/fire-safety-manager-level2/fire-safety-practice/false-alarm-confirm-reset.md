## 먼저 화재 여부 확인
비화재보는 화재가 아닌 열·연기·수증기·먼지 등에 의해 화재 신호가 발생한 상태 · 경보가 울리면 **실제 화재 확인이 우선**

수신기 지구 표시로 위치 확인 → 현장 확인·안전 조치 → 실제 화재이면 신고·대피·초기대응 → 비화재 원인이 확인되면 원인 제거·복구

## 발생 원인과 조치

원인을 제거하지 않고 복구버튼만 누르면 다시 신호가 발생할 수 있음 · 반복 경보를 피하려고 감지기를 떼거나 회로를 차단해 방치하지 않음

## 정상 복구
현장 원인 제거 → 해당 감지기·발신기 복구 → 수신기 복구 → 경종·연동·시험 스위치 정상 위치 확인 · 임시 정지 상태가 남지 않았는지 마지막으로 확인



축적기능은 짧게 발생한 열·연기 등에 따른 비화재보를 줄이는 방식 · 축적형감지기가 설치된 장소에는 감시전류를 단속 차단해 화재를 판단하는 수신기 방식 외의 것을 적용하는 조건 확인 · 감지기·수신기의 축적을 무조건 중복 적용하지 않음

## 축적기능 적용 장소의 조건
일시적인 열·연기·먼지로 비화재 신호 우려가 있을 때 **환기 불량 지하층·무창층, 실내면적 40㎡ 미만, 부착면 높이 2.3m 이하 장소** 등의 축적기능 조건 확인 · NFTC 203에서 정한 적응성 있는 감지기 설치 시 예외 적용
