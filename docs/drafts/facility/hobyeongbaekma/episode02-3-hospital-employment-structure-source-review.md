# 호병백마 병원 변외편 — 대학병원 시설직 고용구조 검토

- 작성: 2026-11-12 KST
- 대상: `[호병백마 ep.2-3 변외편] 병원도 다 같은 병원이 아니다｜대학병원 시설직은 왜 좋은 자리로 불릴까?`
- 상태: 집필용 내부 검토
- 원칙: 대학병원·정규직·시설직을 하나의 근무조건으로 일반화하지 않음
- 공개 본문에는 외부 커뮤니티 링크를 연결하지 않음
- 디시인사이드 글은 이번 변외편의 근거에서 제외

## 결론

이번 변외편의 핵심은 **“대학병원이라서 좋은 자리가 아니라, 병원이 직접 고용하는 일반/기술직 정규직처럼 고용구조와 보수체계가 좋은 자리가 대학병원 안에 따로 존재할 수 있다”**는 점이다.

같은 병원 건물 안에서 시설 관련 업무를 하더라도 다음은 서로 다를 수 있다.

- 채용 직군
- 고용주
- 정규직 여부
- 보수표
- 복리후생 적용 범위
- 승진·평가 체계
- 장기 고용 안정성
- 실제 담당 설비와 업무범위

따라서 “대학병원 시설관리”라는 한 문장으로 처우를 추정하면 안 된다.

## 2026년 현재 확인되는 구조 차이

### 1. 서울대학교병원 2026년 하반기 신규 직원 공고

서울대학교병원 2026년 하반기 신규 직원 채용 공고에서는 같은 병원 안에서 시설 관련 인력을 서로 다른 직군으로 모집했다.

- 일반 **기술직 기계 J1**: 1명
  - 공조냉동기계기사, 건축설비기사, 건설기계설비기사, 일반기계기사, 에너지관리기사, 가스기사 중 1개 이상 요구
  - 필기과목: 냉동 및 공기조화설비
- **시설지원직 기계 SA1**: 5명
  - 공조냉동기계 기능사·산업기사·기사, 에너지관리 기능사·산업기사·기사, 가스 기능사·산업기사·기사, 용접 관련 자격 중 1개 이상 요구

같은 서울대학교병원 시설 관련 채용이라도 채용 직급과 직군, 요구자격이 별도다.

이 사례로 확인할 수 있는 것은 “대학병원 시설직”이 하나의 동일한 채용 트랙이 아니라는 사실이다. 이 공고만으로 두 직군의 실제 연봉·승진·복리후생 차이를 단정하지 않는다.

공식 확인:
- 서울대학교병원 채용사이트 · 2026년도 하반기 신규 직원 채용 공고
- 게시일 2026-08-18

### 2. 강원대학교병원 업무협력직 시설관리 사례

강원대학교병원 업무협력직 채용 공고는 시설관리 직종을 **정규직**으로 모집하면서도 다음을 명시한다.

> 업무협력직은 용역업체가 수행하던 시설관리 등 업무를 담당하는 정규직 전환 직종이며, 직무 및 보수는 일반직(원무직)과 차이가 있음

2025-26 업무협력직 공고에서도 같은 구조가 확인된다.

이 사례는 “정규직”이라는 이름만으로 일반 기술직·일반직과 같은 보수체계를 기대하면 안 된다는 점을 보여준다.

공식 확인:
- 강원대학교병원 업무협력직 블라인드 채용공고
- 시설관리 포함 정규직 전환 직종
- 일반직과 직무·보수 차이 명시

### 3. 서울아산병원 현재 시설팀 채용

서울아산병원 채용사이트에는 2026-11-09 기준 다음 시설팀 공고가 확인된다.

- 시설팀(자동화/통신) 기술직
- 시설팀(설비) 기술직

병원 채용사이트는 별도 복리후생 페이지에서 통근버스, 직원주차장, 기숙사, 어린이집, 콘도·휴양소, 직원라운지, 스포츠센터 등을 안내한다.

다만 **병원 전체 복리후생 소개가 특정 시설팀 채용자에게 동일하게 적용된다고 단정하지 않는다.** 고용형태와 직군별 적용 범위는 개별 공고·근로계약·인사규정을 별도로 확인해야 한다.

## 집필에서 강조할 판단 기준

### “대학병원 정규직”이라는 말부터 쪼갠다

독자가 확인할 순서는 다음으로 정리한다.

1. 병원이 직접 고용하는가, 위탁업체가 고용하는가
2. 병원 내부에서 어느 직군으로 채용되는가
3. 기간의 정함이 없는 정규직인지, 계약직인지
4. 정규직이라면 일반 기술직인지 별도 지원직·업무협력직인지
5. 어떤 보수표·수당·복리후생 규정이 적용되는가
6. 승진·평가·정년 체계가 있는가
7. 실제 시설업무와 경력증빙이 원하는 커리어와 맞는가

## 본문에 쓰지 않을 주장

다음은 현재 확보된 공식 근거만으로 일반화하지 않는다.

- 대학병원 시설직은 모두 사학연금 대상이다
- 대학병원 시설직은 모두 교직원공제회 가입이 가능하다
- 대학병원 정규직 시설직의 초봉은 세전 월 300만원 이상이다
- 대학병원 정규직은 모두 호봉제다
- 대학병원 시설직은 용역보다 항상 급여가 높다
- 대학병원 시설직은 정년이 자동 보장된다
- 대학병원 일반 기술직과 시설지원직의 복리후생이 항상 다르다

이 중 개별 병원·직군 공고에서 직접 확인되는 내용이 생기면 **해당 사례**로만 반영한다.

## 본문 구성

1. **대학병원이라서 좋은 게 아니다**
   - “대학병원 시설직 = 좋은 자리”라는 문장을 먼저 해체
2. **같은 병원 안에도 서로 다른 시설직이 있다**
   - 2026 서울대학교병원 기술직 J1 / 시설지원직 SA1 사례
3. **정규직이라는 단어 하나로도 부족하다**
   - 강원대학교병원 업무협력직: 정규직이지만 일반직과 직무·보수 차이
4. **좋은 자리로 불리는 조건은 고용구조에 있다**
   - 직접고용, 명확한 직군, 보수체계, 복리후생, 장기 근속 구조, 승진·평가 체계
5. **대형 병원의 설비 경험은 별도의 장점**
   - 기존 ep.2-2와 중복하지 않도록 짧게만 연결
6. **지원 전 확인표**
   - 고용주 / 직군 / 정규·계약 / 보수표 / 복리후생 / 승진·정년 / 실제 업무

## 기존 병원편과의 경계

- ep.2-1 절망편: 민원, 업무분장, 당직, 신입교육
- ep.2-2 희망편: 다양한 설비, 교육, 점검·외주 협업, 경력증빙
- ep.2-3 변외편: **같은 병원 안에서도 고용구조·직군에 따라 자리가 달라지는 이유**

설비 종류와 의료법상 시설규격은 ep.2-2에서 이미 충분히 설명했으므로 변외편에서 반복하지 않는다.
