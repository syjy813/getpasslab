시설별 파일에는 두 편의 본문과 발행에서 제외할 내부 편집 메모를 담았다. 편집 메모의 작업 상태는 집필·교정 당시의 기록이다. 현재 Git 보관·발행 상태는 이 문서와 실제 제품 소스를 구분해 확인한다.

## 교정 및 검증 범위

- 9편의 오타·띄어쓰기·문장 호응·가독성·문단 흐름·불필요한 표현을 검토했다.
- 반복 설명과 부사를 줄이고 연속된 면접 질문을 목록으로 정리했다. 본문 분량은 원고별 약 6~10% 줄었다.
- 검토한 교정본의 제목·본문·출처 메모를 보관했다. Git 업로드 단계에서 새 사실이나 원고 내용을 추가하지 않았다.
- 각 파일의 본문 수(총 9편), Markdown 구조, 원본과의 일치, 기존 출처 URL과 메모 보존을 확인했다.
- 이번 변경은 원고 문서만이다. 제품 소스·이미지·slug·공개 URL·카테고리·발행 설정은 바꾸지 않았다. 문서 변경 범위상 별도 사이트 Build·브라우저 QA는 실행하지 않았다.

## 근거와 발행 경계

- 수집 범위와 미확인 사항은 기존 [source-index.md](source-index.md) 및 시설별 source review를 유지한다. 자료 수집의 미달 항목을 완료한 것으로 바꾸지 않는다.
- 후기의 개인 진술, 채용 공고의 조건, 집필 판단을 구분한다. 내부 메모를 발행 본문에 복사하지 않는다.
- ep.0은 이미 공개된 글이지만 이번 교정은 원고 파일에만 반영했다. 나머지 8편은 아직 공개하지 않았다.
- 사용자 요청은 교정 원고의 Git 업로드다. main 병합과 Production 배포는 이번에 수행하지 않는다.
