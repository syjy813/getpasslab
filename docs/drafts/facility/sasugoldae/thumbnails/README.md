# 사수골대 확정 썸네일 · 2026-11-18

- ep.0은 인물·문구 없이 4개 시설과 먹구름을 담은 에디토리얼 전경이다.
- 시설별 절망·희망 8종은 입체 캐리커처 화풍을 유지하고 작업 공간·동선·설비 표현을 보완했다. 골프장 절망편은 예초 지원 장면이다.
- 희망편은 작은 검은 타원형 눈과 완만한 곡선 눈썹, 절망편은 같은 계열의 눈과 지친 표정을 공통 적용했다.
- 이 디렉터리는 확정 이미지 원본 자산이다. 후속 8편은 PR #297에서 공개했으며 게시글 식별자·경로는 통합 출시 manifest와 공개 정본에서 관리한다.
- 2026-11-18 사용자 추가 승인으로 ep.0 목록 썸네일·교정 원고, 후속 8편의 대표 이미지/목록 카드, 마트 희망편 수정본을 함께 출시했다. ep.0의 기존 본문 대표 이미지와 OG는 유지했다.
- PNG 원본은 제작 대화의 생성 이미지에 보존하고, 이곳에는 리사이즈·크롭 없는 1448×1086 WebP를 보관한다. 최종 파일·원본 PNG 지문·용량·상태는 [manifest](../../../../audits/2026-11-18-series-thumbnails/manifest.json)가 이미지 제작·보관 당시의 기록이다. 현재 발행 상태는 [통합 출시 기록](../../../../audits/2026-11-18-pending-release/README.md)을 따른다.
