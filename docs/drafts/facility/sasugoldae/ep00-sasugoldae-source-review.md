# 사수골대 ep.0 source review

조사일: **2026-11-13** · 내부 집필 근거 문서 · 공개 원고 아님

상태: **부분 완료 — 핵심 자료 수는 확보했으나 후기 구성·접근·현행 수치 검증에 공백이 있음.**

개인 경험은 작성자가 그렇게 진술했다는 증거다. 실제 재직·급여·사고·인원은 독립 인증하지 않았다. 채용은 게시된 조건의 증거이며 실제 이행·현재 구인 상태·업계 평균을 보장하지 않는다. ‘확인하지 못함’은 해당 조건이 없다는 뜻이 아니다. 댓글은 본문과 구별하며, 댓글 수 표시만 보인 경우 내용 확인으로 세지 않았다.

집계·접근 한계·중복 원칙은 [전체 출처 색인](source-index.md) 참조. 대괄호의 소스 ID는 아래 소스 목록에 연결된다. 다른 시설 소스는 색인에서 찾을 수 있다.

## 1. 조사 범위

사우나·수영장·야외 골프장·대학교 시설관리의 경험·채용·공식 근거를 분리 수집했다. 학교와 대학병원·코스관리·소비자 이용 후기는 구별했다. 핵심 63건, 보조 6건, 기존 수집 중 제외 3건이다. 접근 불가·미확인 후보는 색인 별도 표에 보존한다.

## 2. 핵심 결론 후보

시설명만으로 평가를 예측하기보다 고용주·직군·담당범위·설비 노후도·팀 인원·교대·외주·예산을 함께 비교할 근거가 모였다. 시설 간 강도 순위나 업계 평균을 산출할 표본은 아니다.

용어 설명은 C01, 실제 조건 분석은 각 시설 검토문서가 근거다. 인터넷에서 같은 분류가 반복된다는 사실은 네 시설의 객관적 기피 순위를 입증하지 않는다.

## 3. 반복적으로 등장한 실제 업무

| 시설 | 자료에서 나온 연결 | 근거 성격 |
|---|---|---|
| 사우나 | 급탕·보일러·배관 ↔ 복합시설 영선·마감·새벽 운전 | 후기6건 + 공고 |
| 수영장 | 수질·여과·펌프·열원 ↔ 개장·마감·미화와 분장 | 복합시설 후기·긍정 단문 + 공고·업무표 |
| 골프장 | 클럽하우스·부속동 설비 ↔ 조출·숙박 병행·타팀 지원 | 후기3건 + 운영사/용역 공고 |
| 대학교 | 직접수리·전기·기계 ↔ 공사·예산·외주 감독·임용구조 | 직접/재게시 후기 + 대학 공식 자료 |

초기 요청서의 키워드를 조사 결론으로 복사하지 않았다. 제습·결로·제설·방학 강도 등 실제 반복 근거가 부족한 항목은 해당 시설 검토문서에서 미확인으로 남겼다.

## 4. 주요 단점

후기에서 확인된 부담은 노후 복합설비, 업무 범위 확대, 새벽·야간과 휴게 단절, 팀 간 결원 지원, 업무 기대와 현실의 차이다. 전 시설의 공통 필수업무나 발생률로 일반화하지 않는다.

## 5. 주요 장점

고정 근무·분장·기존 직원 교육·숙식·장기근속·직접고용 복지 등 평가를 바꿀 조건 후보가 있다. 실제 긍정 근무경험과 공고의 긍정 조건을 구분해야 한다. 골프장 장기근속 긍정 후기와 대학 직접 경험에 더해, PC Chrome에서 수영장 부담이 낮다는 단문도 확인했다. 사우나 장기 긍정·공공 수영장 상세 경험은 부족하다.

## 6. 직영·용역·고용형태 차이

운영주체와 근로계약 고용주, 정규/기간/무기계약, 직군·직급은 별도 축이다. 외부 업체 정규직을 현장 운영사 정규직으로 바꾸어 부르면 안 된다. 공공시설·대학 이름이 공무원 신분이나 연금 적용을 보장하지 않는다. 자회사라고 확정할 대학 시설 채용 사례는 미확보다.

## 7. 근무형태

격일·주야비·주주야야비휴·야간 전담·조중후 교대·일근·계절 기간제 등이 공존한다. 제목·요약과 상세 조건의 차이는 오류를 임의 수정하지 않고 면접 확인사항으로 기록했다. 휴게시간 표기가 실제 연속 휴게를 보장한다는 추론은 하지 않는다.

## 8. 설비·기술 경험

운전·일상점검, 직접 보수, 고장 진단, 외주 감독, 공사·예산 관리는 서로 다른 경험이다. 자격 우대·채용 필수·법정 선임·경력 인정도 구분한다. 설비 목록만으로 배우는 깊이·이직 성공·법정 경력 인정이 확정되지는 않는다.

## 9. 지원·면접 시 확인할 조건

고용주와 직군 → 담당 건물·설비 → 조당 인원·결원 → 실제 교대표·호출 → 정비·외주 범위 → 수당 포함 임금 → 연금·정년·교육 → 경력증명 내용 순서로 확인한다. 각 시설 문서 9절에 구체 질문을 정리했다.

## 10. 반대 사례

골프장 G04의 장기근속·낮은 체감 부담, G01의 숙식 장점, 대학 U02의 조직·공사관리 경험을 보존했다. SJ05의 고정시간·교육과 PJ08의 역할 분리는 채용 조건 반례다. 동일 시설의 긍정 후기가 부족하다고 다른 직무의 만족을 대체하지 않는다.

## 11. 상충하는 주장

| 상충 항목 | 처리 |
|---|---|
| 골프장 바쁨/편함 | 단기·장기·인원·담당범위·숙박 병행 확인 |
| 코스팀 분리/시설팀 예초 | 조직도와 결원 시 실제 지원을 구분 |
| 대학 직영이면 편함/더 넓게 담당 | 직군·인원·공사/보수·외주 경계 확인 |
| 공공시설이면 안정적·관리 우수 | 고용계약과 실제 검사·감독 자료를 각각 확인 |
| 오래된 공식 수질표/후속 조사표 | 개정·시행·시설 구분 확인 전 현행 수치 확정 보류 |

## 12. 공식 자료로 추가 검증한 내용

목욕장·체육시설 영업자의 관리 기준, 수영장 역할 분리와 위탁 감독, 대학 채용 직군·대학회계·용역 구조, 사학연금 법 적용 범위의 확인 필요성을 정리했다. 공고·업무표·과거 감사·과거 연구·현행 법률을 같은 종류의 근거로 취급하지 않는다. 법률 확인과 개별 현장의 법 준수 판정은 별개다.

## 13. 아직 검증되지 않은 주장

범수방의 시설별 후기·댓글 추가 확보, 네 시설 Google 조사 확대, 시설별 목표 후기 수, 사우나 장기 긍정·공공 수영장 상세 후기, 대학 자회사 사례, 현행 수질 별표 전체 수치, 자격별 선임·경력 인정, 평균 급여·강도·이직률이 남아 있다. 후기 표본이 치우쳐 네 시설 간 정량 비교는 불가하다.

## 14. 향후 집필에 사용할 수 있는 논지

ep.0은 용어 소개보다 평가를 가르는 조건 질문을 중심으로 설계할 수 있다. 다만 공개 원고는 이번 범위 밖이며 충분한 후기와 반대 사례를 보강한 뒤 작성한다. 대학 고용구조 별도편은 우선 검토 가치가 높다.

다음 수집 순위: 범수방 공개 열람 가능한 원문 → 단독 사우나·공공 수영장 긍정/부정 직접후기 → 대학 직군별 후기·자회사 근거 → 현행 법령 별표·공고 첨부. 모델 변경보다 접근 가능한 원문과 문서 판본을 확보하는 것이 현재 공백 해결에 직접적이다.

PC Chrome 추가 조사로 Google 직접 검색과 범수방 공개글 열람의 가능성은 확인했다. 디시 신규3건은 본문과 댓글까지 읽고 핵심에 추가했다. 범수방 대학 안전관리 U10은 건물 시설직과 다른 직무로 보조에 남겼다. 전체 과정과 변경 집계는 색인의 PC Chrome 절을 참조한다.
