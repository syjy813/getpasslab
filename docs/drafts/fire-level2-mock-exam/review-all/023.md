## 일반 기본문항

### FSM2-MOCK-023-01

위험물 지정수량과 배수 계산에 관한 설명으로 옳은 것은?

1. 배수는 저장량을 해당 물질 지정수량으로 나눈 값이다
2. 제1석유류는 수용성 여부와 무관하게 모두 200L다
3. 서로 다른 물질의 부피를 합해 가장 큰 지정수량으로만 나눈다
4. 지정수량 1,000L인 등유 650L의 배수는 6.5배다

**정답: 1번**

해설: 옳은 판단은 ‘배수는 저장량을 해당 물질 지정수량으로 나눈 값이다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 서로 다른 물질은 각각의 배수를 구한 뒤 합한다 / 제1석유류는 비수용성 200L·수용성 400L를 구별한다 / 지정수량 1,000L인 등유 650L의 배수는 0.65배다

### FSM2-MOCK-023-02

위험물 지정수량과 배수 계산의 기준을 적용한 판단 중 옳은 것은?

3. 알코올류의 지정수량은 4,000L다
4. 지정수량이 각각 200L·1,000L인 휘발유 160L와 등유 650L의 합산 배수는 0.81배다

**정답: 2번**

해설: 옳은 판단은 ‘서로 다른 물질은 각각의 배수를 구한 뒤 합한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 특수인화물의 지정수량은 50L다 / 알코올류의 지정수량은 400L다 / 휘발유 160L와 등유 650L의 지정수량이 각각 200L·1,000L이면 합계 1.45배다

### FSM2-MOCK-023-06

휘발유 160L를 저장한다. 지정수량이 200L일 때 지정수량의 배수는?

2. 0.8배
3. 1.25배

### FSM2-MOCK-023-11

[위험물 지정수량과 배수 계산 · 복합 사례]
같은 장소의 배수는 물질별로 나눠 합산한다. 표기한 지정수량을 적용하며 다른 혼재 제외 조건은 없다.

가. 휘발유 180L(S=200L)·등유 250L(S=1,000L)

나. 휘발유 0.12㎥(S=200L)·등유 450L(S=1,000L)

가와 나의 판단을 모두 옳게 연결한 것은?

1. 가: 1.15배 / 나: 0.4506배
2. 가: 1.15배 / 나: 1.05배
3. 가: 0.43배 / 나: 0.4506배
4. 가: 0.43배 / 나: 1.05배

**정답: 2번**

해설: 가: 1.15배. 근거: 각 배수를 합산. 계산: 180÷200+250÷1000 → 1.15배.

나: 1.05배. 근거: ㎥를 L로 먼저 환산. 계산: 0.12×1000÷200+450÷1000 → 1.05배.
