## 일반 기본문항

### FSM2-MOCK-017-01

연소범위와 폭발 위험 판단에 관한 설명으로 옳은 것은?

1. 하한계 미만은 연료가 부족한 희박 혼합이다
2. 상한계를 넘은 공간은 환기 중에도 영구히 안전하다
3. 메탄의 대표 연소범위는 약 50~95%다
4. 상한계 초과는 연료가 전혀 없는 상태다

**정답: 1번**

해설: 옳은 판단은 ‘하한계 미만은 연료가 부족한 희박 혼합이다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 상한계 초과는 산소가 부족한 과농 혼합이다 / 과농 혼합도 공기가 들어와 희석되면 연소범위에 진입할 수 있다 / 메탄의 대표 연소범위는 약 5~15%다

2. 아세틸렌은 연소범위가 약 2.5~81%로 프로판(약 2.1~9.5%)보다 훨씬 넓다.
