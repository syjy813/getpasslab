기기 범례가 도통시험 4~8V 정상인 P형 수신기다. 7회로를 선택해 측정한 값은 7V이다. 이 결과의 해석으로 맞는 것은?

1. 배터리의 법정 지속시간까지 합격
2. 감지기 열 감지 성능까지 무조건 합격
3. 해당 회로의 표시 전압은 정상 범위
4. 해당 회로 값과 무관하게 모든 회로 정상

**정답: 3번**

해설: 제시된 회로별 정상범위를 적용. 0V는 단선·종단저항 등 이상 확인이 필요하며 도통 정상도 감지 성능 전체 합격을 뜻하지 않음
