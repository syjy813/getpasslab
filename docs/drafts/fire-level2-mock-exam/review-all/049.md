### FSM2-MOCK-049-01

수신기 예비전원 시험과 이상 표시에 관한 설명으로 옳은 것은?

1. 감시와 경보를 합쳐 총 10분만 작동하면 된다
2. 예비전원 이상은 원인 확인 없이 항상 감지기 위치 문제로 확정한다
3. 정상 19~29V인 예비전원시험의 23V는 4~8V를 넘으므로 도통 불량이다
4. 정전 때 감시·경보 기능이 유지되는지 확인한다

**정답: 4번**

해설: 옳은 판단은 ‘정전 때 감시·경보 기능이 유지되는지 확인한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 감시 60분 후 경보 10분 이상 작동 조건을 확인한다 / 정상 19~29V로 준 24V 계통 시험에서 23V는 범위 안이다 / 예비전원 이상은 커넥터·배선·축전지·충전을 함께 확인한다
