### FSM2-MOCK-008-01

화재안전조사와 조치명령에 관한 설명으로 옳은 것은?

1. 원칙적인 조사계획 공개기간은 1시간이면 충분하다
2. 화재안전조사는 소화기 개수만 확인할 수 있다
3. 조사자는 신분 확인 요구를 받으면 증표를 감춰야 한다
4. 화재안전조사는 소방관서가 실시하는 행정 조사다

**정답: 4번**

해설: 옳은 판단은 ‘화재안전조사는 소방관서가 실시하는 행정 조사다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 피난시설·방화구획과 관리 업무도 조사할 수 있다 / 원칙적으로 조사계획을 홈페이지 등으로 7일 이상 공개한다 / 조사자는 권한을 나타내는 증표를 제시한다
