## 일반 기본문항

### FSM2-MOCK-045-01

경계구역 설정과 우선경보에 관한 설명으로 옳은 것은?

1. 지하층 계단에는 경계구역을 설정하지 않는다
2. 면적이 600㎡ 이하면 한 변이 100m여도 항상 적합하다
3. 일반 경계구역은 600㎡ 이하 조건을 확인한다
4. 모든 건물은 층수와 무관하게 한 경계구역으로 묶는다

**정답: 3번**

해설: 옳은 판단은 ‘일반 경계구역은 600㎡ 이하 조건을 확인한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 일반 구역은 면적 외에 한 변 50m 이하도 충족해야 한다 / 원칙적으로 하나의 경계구역은 두 층에 걸치지 않는다 / 지하 2개 층 이상 계단은 지하 부분 별도 구역을 확인한다

### FSM2-MOCK-045-02

2. 우선경보 적용 대상의 7층 화재는 7·8층만 경보하면 현행 범위를 충족한다
3. 전체가 보이면 구역 면적과 변 길이 제한이 모두 사라진다
4. 일반 구역은 면적 외에 한 변 50m 이하도 충족해야 한다

**정답: 4번**

해설: 옳은 판단은 ‘일반 구역은 면적 외에 한 변 50m 이하도 충족해야 한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 출입구에서 전체가 보이는 예외도 1,000㎡·한 변 50m 조건을 함께 본다 / 두 층 합계 500㎡ 이하인 경우의 예외를 확인한다 / 우선경보 적용 대상의 7층 발화는 7~11층 경보가 기본이다
