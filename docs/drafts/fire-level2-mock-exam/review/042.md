1. 분리 부품은 어디서 뗐는지 기록할 필요가 없다
2. 사람만 대피시키면 실제 방출 차단은 생략해도 된다
3. 실제 방출 차단을 확인한 뒤 자동 기동 조건을 시험한다
4. 다른 회사 장비의 안전핀 번호를 모든 설비에 그대로 적용한다

**정답: 3번**

해설: 옳은 판단은 ‘실제 방출 차단을 확인한 뒤 자동 기동 조건을 시험한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 사람 대피와 실제 오방출 방지조치는 각각 필요하다 / 차단 지점은 해당 설비 회로도와 승인 점검 절차로 정한다 / 분리 장치의 위치·상태를 기록해 복구 누락을 막는다

### FSM2-MOCK-042-02

### FSM2-CORE-027

승인 절차대로 실제 방출을 차단하고 가스계 교차회로 두 회로를 시험했다. 판단으로 맞는 것은?

1. 두 회로를 동작시키면 차단 상태와 무관하게 반드시 약제가 방출된다
2. 점검이므로 방출 안전조치는 필요 없다
3. 경보·기동 신호 확인과 실제 약제 방출 여부를 구분한다
4. 방호구역에 사람이 있으면 냄새로 약제 방출을 확인한다

**정답: 3번**

해설: 오방출 방지 상태에서 회로·경보·연동을 확인하며 신호 발생과 실제 방출을 동일시하지 않음

### FSM2-CORE-031

기동용기에 부착된 솔레노이드의 작동시험을 계획했다. 안전핀 제거 등 작동 조작 전에 우선할 것은?

1. 사람에게만 알리고 바로 작동시킨다
2. 먼저 격발해 약제가 나오는지 확인한다
3. 승인된 절차로 실제 약제 방출 경로를 차단·분리하고 그 상태를 확인한다
4. 방출 후에 환기할 창만 확보한다

**정답: 3번**

해설: 실제 방출 차단이 먼저. 안전핀 또는 전기 정지 하나만으로 모든 기동 경로가 차단된다고 일반화하지 않음
