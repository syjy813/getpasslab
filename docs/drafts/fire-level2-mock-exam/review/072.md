## 일반 실전문항

### FSM2-MOCK-072-01

소방훈련의 계획·실행·평가에 관한 설명으로 옳은 것은?

1. 집결지에 사람이 보이면 명부 대조 없이 전원 대피 완료로 기록한다
2. 신고 연결이 실패해도 대피가 빨랐으면 통신 평가는 생략한다
3. 야간 훈련에 실제 없는 주간 인원만 배치해도 현실성이 같다
4. 계획·안전 확인·실행·평가·개선과 재확인으로 연결한다

**정답: 4번**

해설: 옳은 판단은 ‘계획·안전 확인·실행·평가·개선과 재확인으로 연결한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 장소·시각·가용 인원과 역할을 계획에 반영한다 / 신고 내용과 내부 상황 전파가 정확한지 관찰한다 / 집결지 인원을 확인하고 미확인자 정보를 전달한다

### FSM2-MOCK-072-02

소방훈련의 계획·실행·평가의 기준을 적용한 판단 중 옳은 것은?

1. 소방대가 도착하면 건물 정보는 알리지 않고 모두 자리를 떠난다
2. 훈련은 모든 관계자를 속여야만 효과가 있다
3. 장소·시각·가용 인원과 역할을 계획에 반영한다
4. 한 임무가 모두 끝날 때까지 다른 담당자는 반드시 대기한다

**정답: 3번**

해설: 옳은 판단은 ‘장소·시각·가용 인원과 역할을 계획에 반영한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 실제 화재와 혼동하지 않도록 필요한 안내와 안전조치를 한다 / 가용 인원이 있으면 통보·소화·피난 임무 협조를 확인한다 / 도착 소방대에 위치·위험·인원·설비 정보를 전달하는지 확인한다

### FSM2-MOCK-072-03

다음 중 소방훈련의 계획·실행·평가의 개념과 조건을 정확히 설명한 것은?

1. 평가에는 느렸음 한 마디만 적고 원인과 조치는 쓰지 않는다
2. 신고 연결이 실패해도 대피가 빨랐으면 통신 평가는 생략한다
3. 훈련 시간을 줄이려면 이동이 느린 사람은 평가에서 제외한다
4. 실제 화재와 혼동하지 않도록 필요한 안내와 안전조치를 한다

**정답: 4번**

해설: 옳은 판단은 ‘실제 화재와 혼동하지 않도록 필요한 안내와 안전조치를 한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 신고 내용과 내부 상황 전파가 정확한지 관찰한다 / 피난약자의 실제 지원 방법과 이동 안전을 확인한다 / 출입구 지연 원인을 찾아 유도자·연락·적치물 개선으로 연결한다

### FSM2-MOCK-072-04

「소방훈련의 계획·실행·평가」 학습 내용을 정리했다. 옳게 정리한 것은?

1. 신고 내용과 내부 상황 전파가 정확한지 관찰한다
2. 한 임무가 모두 끝날 때까지 다른 담당자는 반드시 대기한다
3. 집결지에 사람이 보이면 명부 대조 없이 전원 대피 완료로 기록한다
4. 밀거나 뛰어 사고 위험이 커져도 시간만 짧으면 성공이다

**정답: 1번**

해설: 옳은 판단은 ‘신고 내용과 내부 상황 전파가 정확한지 관찰한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 가용 인원이 있으면 통보·소화·피난 임무 협조를 확인한다 / 집결지 인원을 확인하고 미확인자 정보를 전달한다 / 시간 단축만이 아니라 안전·정확성·협조와 개선 효과를 평가한다

### FSM2-MOCK-072-05

소방훈련의 계획·실행·평가 관련 사례를 판별할 때 타당한 판단은?

1. 훈련은 실행 인원 사진만 찍으면 평가 없이 종료한다
2. 훈련 시간을 줄이려면 이동이 느린 사람은 평가에서 제외한다
3. 소방대가 도착하면 건물 정보는 알리지 않고 모두 자리를 떠난다
4. 가용 인원이 있으면 통보·소화·피난 임무 협조를 확인한다

**정답: 4번**

해설: 옳은 판단은 ‘가용 인원이 있으면 통보·소화·피난 임무 협조를 확인한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 피난약자의 실제 지원 방법과 이동 안전을 확인한다 / 도착 소방대에 위치·위험·인원·설비 정보를 전달하는지 확인한다 / 계획·안전 확인·실행·평가·개선과 재확인으로 연결한다

### FSM2-MOCK-072-06

소방훈련의 계획·실행·평가에 대한 검토 의견 중 적절한 것은?

2. 피난약자의 실제 지원 방법과 이동 안전을 확인한다
3. 집결지에 사람이 보이면 명부 대조 없이 전원 대피 완료로 기록한다

### FSM2-MOCK-072-07
