# FSM2-001 · 소방안전관리대상물의 등급

일반 10개 · 핵심 5개 · 내용 검수 대기 초안

[전체 검토 목록](../review-index.md)

근거 챕터: [소방안전관리대상물의 등급](../../../../src/content/chapters/fire-safety-manager-level2/fire-safety-theory/management-target-grades.md)

일반문항은 현재 챕터의 이론·조건을 바탕으로 작성했다. 교재 쪽수별 직접 대조·현행 근거·정답과 오답의 유일성은 두 풀을 합친 후 검토한다.

## 일반 실전문항

### FSM2-MOCK-001-01

아파트가 지상 51층, 높이 180m이다. 다른 조건은 없다. 대상물 등급은?

1. 특급
2. 1급
3. 2급
4. 3급

**정답: 1번**

해설: 아파트는 지상 50층 이상 또는 높이 200m 이상이면 특급. 두 조건을 모두 충족할 필요 없음

### FSM2-MOCK-001-02

아파트가 지상 32층, 높이 110m이며 특급 조건은 없다. 대상물 등급은?

1. 1급
2. 특급
3. 2급
4. 3급

**정답: 1번**

해설: 특급이 아닌 아파트는 지상 30층 이상 또는 높이 120m 이상이면 1급

### FSM2-MOCK-001-03

아파트가 아닌 업무시설이 지상 12층, 연면적 8,400㎡이며 특급 조건은 없다. 등급은?

1. 특급
2. 1급
3. 2급
4. 3급

**정답: 2번**

해설: 아파트 외 지상 11층 이상 조건을 적용. 면적 1만5천㎡ 조건을 동시에 요구하지 않음

### FSM2-MOCK-001-04

판매시설이 지상 8층·연면적 12,000㎡이고 옥내소화전 설치 대상이다. 상위 등급 조건이 없다면 등급은?

1. 특급
2. 1급
3. 3급
4. 2급

**정답: 4번**

해설: 상위 등급을 제외하고 옥내소화전 설치 대상은 2급 조건에 해당

### FSM2-MOCK-001-05

아파트 외 대상물이 지상 9층·지하 21층으로 합계 30층이다. 특급 제외 용도는 아니다. 층수 조건상 등급은?

1. 1급
2. 2급
3. 특급
4. 3급

**정답: 3번**

해설: 특급의 아파트 외 30층 조건은 지하층을 포함. 1급 지상 11층과 구별

### FSM2-MOCK-001-06

아파트가 아닌 업무시설의 연면적이 105,000㎡이다. 특급 제외 용도가 아니면 등급은?

1. 특급
2. 1급
3. 2급
4. 3급

**정답: 1번**

해설: 아파트 외 연면적 10만㎡ 이상인 특급 조건을 먼저 적용

### FSM2-MOCK-001-07

물분무등소화설비는 호스릴 방식만 설치할 수 있는 대상물이다. 자동화재탐지설비 설치 대상이며 다른 2급 이상 조건은 없다. 등급은?

1. 특급
2. 1급
3. 2급
4. 3급

**정답: 4번**

해설: 호스릴 방식만 설치할 수 있는 물분무등 대상의 2급 제외 조건과 자동화재탐지설비의 3급 조건을 함께 적용

### FSM2-MOCK-001-08

가스 제조설비를 갖추고 도시가스사업 허가를 받아야 하는 시설이다. 가연성가스 저장량은 60t이고 상위 등급 조건은 없다. 등급은?

1. 특급
2. 2급
3. 1급
4. 3급

**정답: 2번**

해설: 도시가스사업 허가 대상 가스 제조설비는 100t 이상 1천t 미만 조건과 별개의 2급 해당 조건

### FSM2-MOCK-001-09

국보로 지정된 목조건축물로 상위 등급 조건은 없다. 소방안전관리대상물 등급은?

1. 특급
2. 2급
3. 1급
4. 3급

**정답: 2번**

해설: 국보·보물로 지정된 목조건축물은 2급 대상 조건에 포함

### FSM2-MOCK-001-10

간이스프링클러설비 설치 대상이지만 주택전용 간이스프링클러는 아니다. 상위 등급 조건이 없다면 등급은?

1. 특급
2. 1급
3. 3급
4. 2급

**정답: 3번**

해설: 간이스프링클러는 3급 판정 조건이며 주택전용의 제외 여부를 구별

## 핵심 변형문항

### FSM2-CORE-003

다른 특급 조건이 없는 아파트가 지상 52층, 높이 185m이다. 소방안전관리대상물 등급은?

1. 1급
2. 2급
3. 특급
4. 3급

**정답: 3번**

해설: 아파트는 지상 50층 이상 또는 높이 200m 이상이면 특급. 두 조건을 모두 요구하지 않음

### FSM2-CORE-201

제시된 조건을 갖춘 특정소방대상물이 해당하는 소방안전관리대상물의 등급으로 맞게 설명한 것은? • 용도: 판매시설 • 규모: 지상 9층, 지하 2층 / 연면적 12,800㎡ • 설치된 소방시설: 옥내소화전설비·스프링클러설비·자동화재탐지설비·유도등 • 가연성 가스는 저장·취급하지 않으며, 그 밖의 조건은 고려하지 않는다.

1. 2급 소방안전관리대상물
2. 특급 소방안전관리대상물
3. 1급 소방안전관리대상물
4. 3급 소방안전관리대상물

**정답: 1번**

해설: 이 특정소방대상물은 2급 소방안전관리대상물에 해당한다. 1급이 되려면 30층 이상(지하층 포함)이거나 높이 120m 이상이거나 연면적 1만5천㎡ 이상이거나 지상층의 층 수가 11층 이상이어야 하는데, 지하층 2개 층을 제외한 지상 9층·연면적 12,800㎡인 이 건물은 어느 기준에도 해당하지 않는다. 다만 스프링클러설비를 설치해야 하는 특정소방대상물이므로 2급으로 분류된다.

### FSM2-CORE-302

아래 특정소방대상물 가운데 2급 소방안전관리대상물이 아닌 것은? (모두 특급·1급 소방안전관리대상물에는 해당 하지 않는다고 본다)

1. 가연성 가스를 400톤 저장·취급하는 시설
2. 지하구
3. 옥내소화전설비와 스프링클러설비는 설치대상이 아니고 자동화재탐지설비만 설치해야 하는 판매시설
4. 「문화유산의 보존 및 활용에 관한 법률」에 따라 보물로 지정된 목조건축물

**정답: 3번**

해설: 자동화재탐지설비만 설치하면 되는 판매시설은 3급 소방안전관리대상물 범위이므로 2급이 아니다. 2급 소방안전관리대상물은 옥내소화전설비·스프링클러설비 또는 물분무등소화설비를 설치해야 하는 대상물, 가 연성 가스를 100톤 이상 1천톤 미만 저장·취급하는 시설, 지하구, 옥내소화전설비 또는 스프링클러설비가 설치된 공동주택, 보물·국보로 지정된 목조건축물이며, 이런 시설들은 모두 2급에 해당한다. 간이스프링클러설비(주택전 용 제외) 설치대상도 자동화재탐지설비만 설치하는 대상과 마찬가지로 3급이다.

### FSM2-CORE-353

제시된 조건의 특정소방대상물에 대한 설명 중 옳은 것은? 용도: 판매시설 규모: 지상 9층, 지하 2층 / 높이 38m 연면적: 12,000㎡ 설치된 소방시설: 옥내소화전설비·스프링클러설비·자동화재탐지설비·유도등

1. 스프링클러설비 설치대상에 해당하므로 2급 소방안전관리대상물이다.
2. 연면적이 1만제곱미터를 넘으므로 특급 소방안전관리대상물이다.
3. 지상층의 층수가 9층이므로 1급 소방안전관리대상물이다.
4. 자동화재탐지설비를 설치해야 하는 특정소방대상물이므로 3급 소방안전관리대상물이다.

**정답: 1번**

해설: 스프링클러설비 설치대상이라는 이유로 이 건물을 2급 소방안전관리대상물로 본 설명이 옳다. • 특급은 지하층을 포함한 30층 이상이거나 높이 120m 이상(아파트 제외), 또는 연면적 10만제곱미터 이상인 것이어서 해당하 지 않는다. • 1급은 연면적 1만5천제곱미터 이상이거나 지상층 11층 이상인 것이어서, 연면적 12,000㎡·지상 9층인 이 건물은 해당하지 않 는다. • 3급은 특급·1급·2급에 해당하지 않는 것 중 간이스프링클러설비 또는 자동화재탐지설비 설치대상이므로, 이미 2급인 이 건물에 는 적용되지 않는다.

### FSM2-CORE-452

소방안전관리대상물의 등급별 범위에 대한 설명 중 옳은 것은?

1. 지하층을 포함한 층수가 50층 이상인 아파트는 특급 소방안전관리대상물이다.
2. 지상층의 층수가 11층 이상인 아파트는 1급 소방안전관리대상물이다.
3. 연면적이 10만㎡ 이상인 특정소방대상물(아파트는 제외)은 특급 소방안전관리대상물이다.
4. 가연성 가스를 500톤 저장·취급하는 시설은 1급 소방안전관리대상물이다.

**정답: 3번**

해설: 30층 이상이거나 높이 120m 이상인 특정소방대상물(아파트 제외)에 해당하지 않으면서 연면적이 10만㎡ 이상 인 특정소방대상물(아파트 제외)도 특급 소방안전관리대상물에 포함된다는 설명이 옳다. • 아파트의 특급 기준은 지하층을 제외한 50층 이상 또는 높이 200m 이상이라고 한 설명이 틀렸다. • 지상층 11층 이상 기준은 아파트를 제외한 특정소방대상물에만 적용되는데 아파트에 적용된다고 한 설명이 틀렸다. • 가연성 가스는 1천톤 이상이어야 1급이고 100톤 이상 1천톤 미만은 2급 대상물인데 500톤 저장을 1급으로 본 설명이 틀렸다.
