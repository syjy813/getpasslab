## 일반 실전문항

### FSM2-MOCK-052-01

객석유도등 설치와 개수 계산에 관한 설명으로 옳은 것은?

1. 실내 객석 통로는 제시 조건에서 L÷4−1의 최종값을 올림한다
2. 면제 없는 실내 객석 18m·24m·31m 세 통로의 합계 최소 개수는 13개다
3. 면제 없는 실내 객석 24m 통로의 최소 개수는 6개다
4. 통로를 모두 이은 하나의 길이로 계산하면 언제나 같은 결과다

**정답: 1번**

해설: 옳은 판단은 ‘실내 객석 통로는 제시 조건에서 L÷4−1의 최종값을 올림한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 여러 객석 통로는 각각 계산한 다음 합산한다 / 해당 실내 객석 통로 24m의 최소 개수는 5개다 / 해당 실내 객석 18m·24m·31m 통로는 합계 최소 16개다

### FSM2-MOCK-052-02

객석유도등 설치와 개수 계산의 기준을 적용한 판단 중 옳은 것은?

1. 면제 없는 실내 객석 18m 통로는 최종값을 버려 최소 3개다
2. 면제 없는 실내 객석 31m 통로는 최종값을 내림해 최소 6개다
3. 여러 객석 통로는 각각 계산한 다음 합산한다
4. 객석유도등은 출입구 바로 위 천장에만 설치하는 등이다

**정답: 3번**

해설: 옳은 판단은 ‘여러 객석 통로는 각각 계산한 다음 합산한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 해당 실내 객석 통로 18m의 면제 없는 최소 개수는 4개다 / 해당 실내 객석 통로 31m의 최소 개수는 7개다 / 객석유도등은 객석 통로의 바닥 또는 벽에 설치한다

### FSM2-MOCK-052-03

실내 공연장 객석의 한 통로 길이는 18m다. 설치개수는 (L÷4−1)의 소수점 이하 올림이며 면제 조건이 없다. 필요한 최소 객석유도등 수는?

1. 3개
2. 5개
3. 4개
4. 6개

**정답: 3번**

해설: 해당 실내 객석 통로 18m의 면제 없는 최소 개수는 4개다. 계산: 올림(18÷4-1) = 4 개.

### FSM2-MOCK-052-04

실내 객석 통로 길이 24m에 (L÷4−1)의 소수점 이하 올림을 적용한다. 면제 조건이 없을 때 최소 객석유도등 수는?

1. 5개
2. 7개
3. 4개
4. 6개

**정답: 1번**

해설: 해당 실내 객석 통로 24m의 최소 개수는 5개다. 계산: 올림(24÷4-1) = 5 개.

### FSM2-MOCK-052-05

실내 객석 통로 길이 31m에 (L÷4−1)의 소수점 이하 올림을 적용한다. 면제 조건이 없을 때 최소 객석유도등 수는?

1. 9개
2. 8개
3. 7개
4. 6개

**정답: 3번**

해설: 해당 실내 객석 통로 31m의 최소 개수는 7개다. 계산: 올림(31÷4-1) = 7 개.

### FSM2-MOCK-052-06

실내 객석 통로가 18m와 24m로 두 개다. 각 통로에 (L÷4−1)의 소수점 이하 올림을 적용한 뒤 합산하며 면제 조건은 없다. 합계 최소 수는?

1. 8개
2. 9개
3. 10개
4. 11개

**정답: 2번**

해설: 해당 실내 객석의 18m·24m 두 통로는 합계 최소 9개다. 계산: 올림(18÷4-1)+올림(24÷4-1) = 9 개.

### FSM2-MOCK-052-07

실내 객석의 세 통로 길이가 18m·24m·31m다. 각 통로에 (L÷4−1)의 소수점 이하 올림을 적용한 뒤 더한다. 면제 조건이 없을 때 합계 최소 수는?

1. 19개
2. 16개
3. 17개
4. 13개

**정답: 2번**

해설: 해당 실내 객석 18m·24m·31m 통로는 합계 최소 16개다. 계산: 올림(18÷4-1)+올림(24÷4-1)+올림(31÷4-1) = 16 개.

### FSM2-MOCK-052-08

객석유도등 설치와 개수 계산의 적용을 검토한 내용 중 잘못된 것은?

1. 실내 객석 통로는 제시 조건에서 L÷4−1의 최종값을 올림한다
2. 객석이 있는 문화집회·종교·운동시설 등의 적용 조건을 확인한다
3. 객석유도등은 출입구 바로 위 천장에만 설치하는 등이다
4. 해당 실내 객석 통로 24m의 최소 개수는 5개다

**정답: 3번**

해설: 잘못된 판단은 ‘객석유도등은 출입구 바로 위 천장에만 설치하는 등이다’이다. 올바른 내용은 ‘객석유도등은 객석 통로의 바닥 또는 벽에 설치한다’이다. 나머지 보기는 각 조건에 맞는 설명이다.

### FSM2-MOCK-052-09

「객석유도등 설치와 개수 계산」에 관한 다음 진술을 판단한 것으로 옳은 것은?

ㄱ. 객석이 있는 문화집회·종교·운동시설 등의 적용 조건을 확인한다

ㄴ. 여러 객석 통로는 각각 계산한 다음 합산한다

1. ㄱ만 옳다
2. ㄴ만 옳다
3. ㄱ, ㄴ 모두 틀리다
4. ㄱ, ㄴ 모두 옳다

**정답: 4번**

해설: ㄱ은 옳다. 객석이 있는 문화집회·종교·운동시설 등의 적용 조건을 확인한다. ㄴ은 옳다. 여러 객석 통로는 각각 계산한 다음 합산한다.

### FSM2-MOCK-052-10

「객석유도등 설치와 개수 계산」에 관한 다음 진술을 판단한 것으로 옳은 것은?

ㄱ. 모든 실외 객석도 예외 없이 실내의 같은 개수 공식만 적용한다

ㄴ. 해당 실내 객석 통로 24m의 최소 개수는 5개다

ㄷ. 면제 없는 실내 객석 18m·24m·31m 세 통로의 합계 최소 개수는 13개다

1. ㄱ, ㄷ만 옳다
2. ㄱ, ㄴ, ㄷ 모두 틀리다
3. ㄴ만 옳다
4. ㄴ, ㄷ만 옳다

**정답: 3번**

해설: ㄱ은 틀리다. 실외 공연장·관람장의 별도 조명 기준은 실내 계산과 구별한다. ㄴ은 옳다. 해당 실내 객석 통로 24m의 최소 개수는 5개다. ㄷ은 틀리다. 해당 실내 객석 18m·24m·31m 통로는 합계 최소 16개다.
