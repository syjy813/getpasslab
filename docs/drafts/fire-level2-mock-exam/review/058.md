## 일반 실전문항

### FSM2-MOCK-058-01

응급처치의 일반원칙과 환자 상태 판단에 관한 설명으로 옳은 것은?

1. 반응 확인 전에 물을 먹여 의식을 깨우는 것이 기본이다
2. 일반인은 맥박을 5분간 확인한 뒤 압박 여부를 결정한다
3. 효과적으로 기침하는 사람은 즉시 입안을 보지 않고 손으로 훑는다
4. 구조자의 안전을 먼저 확보한 뒤 환자에게 접근한다

**정답: 4번**

해설: 옳은 판단은 ‘구조자의 안전을 먼저 확보한 뒤 환자에게 접근한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 어깨를 두드려 반응을 확인하고 119·AED 요청을 연결한다 / 일반인은 맥박을 오래 찾느라 압박을 지연하지 않는다 / 반응 있는 기도폐쇄 환자가 효과적으로 기침하면 기침을 유도한다
