## 일반 실전문항

### FSM2-MOCK-049-01

수신기 예비전원 시험과 이상 표시에 관한 설명으로 옳은 것은?

1. 감시와 경보를 합쳐 총 10분만 작동하면 된다
2. 예비전원 이상은 원인 확인 없이 항상 감지기 위치 문제로 확정한다
3. 정상 19~29V인 예비전원시험의 23V는 4~8V를 넘으므로 도통 불량이다
4. 정전 때 감시·경보 기능이 유지되는지 확인한다

**정답: 4번**

해설: 옳은 판단은 ‘정전 때 감시·경보 기능이 유지되는지 확인한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 감시 60분 후 경보 10분 이상 작동 조건을 확인한다 / 정상 19~29V로 준 24V 계통 시험에서 23V는 범위 안이다 / 예비전원 이상은 커넥터·배선·축전지·충전을 함께 확인한다

### FSM2-MOCK-049-02

수신기 예비전원 시험과 이상 표시의 기준을 적용한 판단 중 옳은 것은?

1. 교류전원등만 보면 예비전원으로의 전환이 확인된다
2. 정상 19~29V인 예비전원시험의 17V는 무조건 정상이다
3. 정전 시 정지하는 수신기는 예비전원의 정상 작동 상태다
4. 감시 60분 후 경보 10분 이상 작동 조건을 확인한다

**정답: 4번**

해설: 옳은 판단은 ‘감시 60분 후 경보 10분 이상 작동 조건을 확인한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 시험 조작 후 예비전원 전환·전압·표시를 확인한다 / 정상 19~29V로 준 기기의 17V는 범위 밖이다 / 정전 시 기능이 사라지면 자동 전환·예비전원 계통을 확인한다

### FSM2-CORE-026

예비전원시험을 누르는 동안 전압이 22V였다. 이 기기의 제시된 정상범위는 19~29V이다. 이 결과만으로 확정할 수 있는 것은?

1. 표시 전압은 제시 범위에 들지만 지속시간과 자동 절환은 별도 확인한다
2. 법정 지속시간 시험까지 모두 합격했다
3. 29V보다 낮으므로 반드시 단선이다
4. 상용전원 고장 여부와 무관하게 모든 기능이 정상이다

**정답: 1번**
