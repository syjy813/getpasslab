## 일반 실전문항

### FSM2-MOCK-023-01

위험물 지정수량과 배수 계산에 관한 설명으로 옳은 것은?

1. 배수는 저장량을 해당 물질 지정수량으로 나눈 값이다
2. 제1석유류는 수용성 여부와 무관하게 모두 200L다
3. 서로 다른 물질의 부피를 합해 가장 큰 지정수량으로만 나눈다
4. 지정수량 1,000L인 등유 650L의 배수는 6.5배다

**정답: 1번**

해설: 옳은 판단은 ‘배수는 저장량을 해당 물질 지정수량으로 나눈 값이다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 서로 다른 물질은 각각의 배수를 구한 뒤 합한다 / 제1석유류는 비수용성 200L·수용성 400L를 구별한다 / 지정수량 1,000L인 등유 650L의 배수는 0.65배다

### FSM2-MOCK-023-02

위험물 지정수량과 배수 계산의 기준을 적용한 판단 중 옳은 것은?

1. 특수인화물의 지정수량은 5,000L다
2. 서로 다른 물질은 각각의 배수를 구한 뒤 합한다
3. 알코올류의 지정수량은 4,000L다
4. 지정수량이 각각 200L·1,000L인 휘발유 160L와 등유 650L의 합산 배수는 0.81배다

**정답: 2번**

해설: 옳은 판단은 ‘서로 다른 물질은 각각의 배수를 구한 뒤 합한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 특수인화물의 지정수량은 50L다 / 알코올류의 지정수량은 400L다 / 휘발유 160L와 등유 650L의 지정수량이 각각 200L·1,000L이면 합계 1.45배다

### FSM2-MOCK-023-03

다음 중 위험물 지정수량과 배수 계산의 개념과 조건을 정확히 설명한 것은?

1. 지정수량 200L인 휘발유 160L의 배수는 1.25배다
2. 0.75㎥는 75L다
3. 특수인화물의 지정수량은 50L다
4. 제1석유류는 수용성 여부와 무관하게 모두 200L다

**정답: 3번**

해설: 옳은 판단은 ‘특수인화물의 지정수량은 50L다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 제1석유류는 비수용성 200L·수용성 400L를 구별한다 / 지정수량 200L인 휘발유 160L의 배수는 0.8배다 / 0.75㎥는 750L다

### FSM2-MOCK-023-04

「위험물 지정수량과 배수 계산」 학습 내용을 정리했다. 옳게 정리한 것은?

1. 알코올류의 지정수량은 4,000L다
2. 제1석유류는 비수용성 200L·수용성 400L를 구별한다
3. 지정수량 1,000L인 등유 650L의 배수는 6.5배다
4. 모든 위험물은 밀도와 무관하게 kg를 L로 바꿔 계산한다

**정답: 2번**

해설: 옳은 판단은 ‘제1석유류는 비수용성 200L·수용성 400L를 구별한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 알코올류의 지정수량은 400L다 / 지정수량 1,000L인 등유 650L의 배수는 0.65배다 / 지정수량이 kg인 물질은 같은 질량 단위로 배수를 계산한다

### FSM2-MOCK-023-05

위험물 지정수량과 배수 계산 관련 사례를 판별할 때 타당한 판단은?

1. 배수는 지정수량을 저장량으로 나눈 값이다
2. 지정수량 200L인 휘발유 160L의 배수는 1.25배다
3. 알코올류의 지정수량은 400L다
4. 지정수량이 각각 200L·1,000L인 휘발유 160L와 등유 650L의 합산 배수는 0.81배다

**정답: 3번**

해설: 옳은 판단은 ‘알코올류의 지정수량은 400L다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 지정수량 200L인 휘발유 160L의 배수는 0.8배다 / 휘발유 160L와 등유 650L의 지정수량이 각각 200L·1,000L이면 합계 1.45배다 / 배수는 저장량을 해당 물질 지정수량으로 나눈 값이다

### FSM2-MOCK-023-06

휘발유 160L를 저장한다. 지정수량이 200L일 때 지정수량의 배수는?

1. 8배
2. 0.8배
3. 1.25배
4. 0.08배

**정답: 2번**

해설: 지정수량 200L인 휘발유 160L의 배수는 0.8배다. 계산: 160÷200 = 0.8 배.

### FSM2-MOCK-023-07

등유 650L의 지정수량을 1,000L로 제시했다. 지정수량의 배수는?

1. 0.065배
2. 1.54배
3. 6.5배
4. 0.65배

**정답: 4번**

해설: 지정수량 1,000L인 등유 650L의 배수는 0.65배다. 계산: 650÷1000 = 0.65 배.

### FSM2-MOCK-023-08

같은 장소에 휘발유 160L와 등유 650L가 있다. 지정수량은 각각 200L·1,000L다. 합산 배수는?

1. 1.45배
2. 6.58배
3. 0.675배
4. 0.81배

**정답: 1번**

해설: 휘발유 160L와 등유 650L의 지정수량이 각각 200L·1,000L이면 합계 1.45배다. 계산: 160÷200+650÷1000 = 1.45 배.

### FSM2-MOCK-023-09

인화성 액체의 저장량이 0.75㎥다. 리터로 환산한 값은?

1. 75L
2. 7,500L
3. 7.5L
4. 750L

**정답: 4번**

해설: 0.75㎥는 750L다. 계산: 0.75×1000 = 750 L.

### FSM2-MOCK-023-10

「위험물 지정수량과 배수 계산」에 관한 다음 진술을 판단한 것으로 옳은 것은?

ㄱ. 모든 위험물은 밀도와 무관하게 kg를 L로 바꿔 계산한다

ㄴ. 제1석유류는 비수용성 200L·수용성 400L를 구별한다

ㄷ. 지정수량 1,000L인 등유 650L의 배수는 0.65배다

1. ㄴ, ㄷ만 옳다
2. ㄱ, ㄷ만 옳다
3. ㄱ, ㄴ만 옳다
4. ㄴ만 옳다

**정답: 1번**

해설: ㄱ은 틀리다. 지정수량이 kg인 물질은 같은 질량 단위로 배수를 계산한다. ㄴ은 옳다. 제1석유류는 비수용성 200L·수용성 400L를 구별한다. ㄷ은 옳다. 지정수량 1,000L인 등유 650L의 배수는 0.65배다.

## 핵심 변형문항

### FSM2-CORE-114

아래 위험물을 같은 장소에 저장할 때 지정수량 배수의 합은? • 휘발유(제1석유류, 비수용성 액체) 600L • 아세톤(제1석유류, 수용성 액체) 800L • 중유(제3석유류, 비수용성 액체) 4,000L

1. 7배
2. 5배
3. 9배
4. 12배

**정답: 1번**

해설: 지정수량 배수의 합은 7배이다. 지정수량 배수의 합은 각 위험물의 저장량을 그 품명의 지정수량으로 나눈 값을 모두 더해 구하며, 제1석유류의 지 정수량은 비수용성 200L·수용성 400L, 제3석유류는 비수용성 2,000L이다. 600÷200 = 3배 800÷400 = 2배 4,000÷2,000 = 2배 합계 = 3+2+2 = 7배 아세톤을 비수용성으로 잘못 보아 200L로 나누면 9배가 나오므로 수용성 여부를 반드시 확인해야 한다.

### FSM2-CORE-414

「위험물안전관리법」 및 같은 법 시행령상 위험물에 대한 설명 중 옳은 것은?

1. 제4류 위험물 중 제3석유류(비수용성 액체)의 지정수량은 1,000리터이다
2. 등유와 경유는 제4류 위험물 중 제1석유류에 해당한다
3. 제4류 위험물 중 알코올류의 지정수량은 400리터이다
4. 지정수량이란 제조소등의 설치허가 등에 있어서 최고의 기준이 되는 수량을 말한다

**정답: 3번**

해설: 알코올류의 지정수량은 400리터다. • 제3석유류는 비수용성 액체가 2,000리터, 수용성 액체가 4,000리터이며 1,000리터는 제2석유류(비수용성)의 지정수량이다. • 등유·경유는 인화점 21℃ 이상 70℃ 미만인 제2석유류이고, 인화점 21℃ 미만인 아세톤·휘발유가 제1석유류다. • 지정수량은 제조소등의 설치허가 등에서 최고가 아니라 최저의 기준이 되는 수량이다.

### FSM2-CORE-464

위험물과 지정수량에 대한 설명 중 틀린 것은?

1. 위험물은 인화성이나 발화성 등의 성질을 지닌 물품 가운데 대통령령으로 정해 놓은 것을 가리킨다.
2. 제4류 위험물 중 알코올류의 지정수량은 400L이다.
3. 제2류 위험물 중 마그네슘의 지정수량은 500kg이다.
4. 지정수량은 위험물의 위험성을 고려해 대통령령으로 정하는 수량으로, 제조소등 설치허가에서 최고의 기준이 되는 수량이다.

**정답: 4번**

해설: 지정수량은 제조소등 설치허가 등에서 최저의 기준이 되는 수량이라는 점에서, 최고의 기준이라고 한 설명이 옳지 않다. 그 수량 이상을 저장·취급하면 허가 대상이 된다는 뜻이며, 위험물은 인화성이나 발화성 등의 성질을 지닌 물품 가 운데 대통령령으로 정한 것을 말한다. 제4류 위험물 중 알코올류의 지정수량 400L와 제2류 위험물 중 마그네슘의 지정수량 500kg은 옳다. 참고로 제 1석유류 비수용성 액체(휘발유 등)의 지정수량은 200L이다.
