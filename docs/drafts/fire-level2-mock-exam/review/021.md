## 일반 실전문항

### FSM2-MOCK-021-01

화기작업 허가와 화재감시자에 관한 설명으로 옳은 것은?

1. 허가·위험 확인·방호 준비 뒤 작업과 감시를 진행한다
2. 11m와 10m는 같은 조항의 동일한 수치이므로 바꿔 써도 된다
3. 작업자가 보안경을 쓰면 감시자 배치 검토가 면제된다
4. 작업점이 깨끗하면 벽 반대쪽 가연물은 볼 필요가 없다

**정답: 1번**

해설: 옳은 판단은 ‘허가·위험 확인·방호 준비 뒤 작업과 감시를 진행한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 바닥 틈과 벽 반대편·아래층의 불티 위험도 확인한다 / 작업자 보호구 착용은 별도 감시자 역할을 대신하지 않는다 / 산업안전 기준의 감시자 배치 11m와 적치 금지 10m를 구별한다

### FSM2-MOCK-021-02

화기작업 허가와 화재감시자의 기준을 적용한 판단 중 옳은 것은?

1. 감시자는 용접 품질만 확인하고 화재 징후는 보지 않는다
2. 바닥 틈과 벽 반대편·아래층의 불티 위험도 확인한다
3. 해당 기준의 소화기는 작업장에서 50m 이상 멀리 두어야 한다
4. 허가서에는 공사 대금만 쓰고 위험요인은 생략한다

**정답: 2번**

해설: 옳은 판단은 ‘바닥 틈과 벽 반대편·아래층의 불티 위험도 확인한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 감시자는 화재 징후를 확인하고 경보·중지·초기대응을 한다 / 장소·시간·작업자·감시자·예방조치·연락 방법을 기록한다 / 해당 화재예방 기준의 작업장 주변 소화기는 반경 5m 이내 조건을 본다

### FSM2-MOCK-021-03

다음 중 화기작업 허가와 화재감시자의 개념과 조건을 정확히 설명한 것은?

4. 해당 화재예방 기준의 화기작업 소화기는 작업장 반경 50m 이상 멀리 두어야 한다

**정답: 1번**

해설: 옳은 판단은 ‘감시자는 화재 징후를 확인하고 경보·중지·초기대응을 한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 작업자 보호구 착용은 별도 감시자 역할을 대신하지 않는다 / 가연물 제거가 곤란하면 불티 차단 등 적절한 방호를 한다 / 교재 절차는 30분 이상 상주 확인 뒤 추가 3시간 이상 관찰로 연결한다

2. 15:00
3. 15:15
4. 15:45

**정답: 3번**

해설: 14:45+30분=15:15. 이후 추가 3시간 이상 현장 관찰·최종 확인이 연결됨. 일률적인 법정 최소시간으로 단정하지 않음
