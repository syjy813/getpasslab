## 일반 실전문항

### FSM2-MOCK-036-01

방수압력 측정과 피토게이지에 관한 설명으로 옳은 것은?

1. 호스 속 공기가 남은 최초 순간 수치만 기록한다
2. 노즐에서 D의 20배 떨어진 지점만이 정해진 측정 위치다
3. 옥내소화전 노즐선단 0.24MPa만 확인하면 방수량 130L/min까지 합격이다
4. 노즐선단 압력 측정에는 직사형 관창과 피토게이지를 사용한다

**정답: 4번**

해설: 옳은 판단은 ‘노즐선단 압력 측정에는 직사형 관창과 피토게이지를 사용한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 노즐 구경 D의 절반인 D/2 부근에서 중심 흐름을 측정한다 / 초기에 공기·이물질을 뺀 뒤 안정된 흐름에서 판독한다 / 노즐선단 0.24MPa는 최소 압력 조건을 충족하나 방수량은 별도 확인한다

### FSM2-MOCK-036-02

### FSM2-MOCK-036-09

ㄴ. 노즐에서 D의 20배 떨어진 지점만이 정해진 측정 위치다

1. ㄱ, ㄴ 모두 틀리다

### FSM2-MOCK-036-10

직사형 관창 구경 D는 16mm다. 노즐선단에서 D/2 부근에 피토관을 댈 때 계산되는 거리는?

1. 8mm
2. 4mm
3. 16mm
4. 32mm

**정답: 1번**

해설: 노즐 구경 16mm라면 D/2는 8mm다. 계산: 16÷2 = 8 mm.

### FSM2-CORE-036

직사형 관창과 피토게이지로 방수압력을 측정할 때 맞는 방법은?

1. 분무형 관창의 외곽 물방울만 측정
2. 펌프 압력계 값을 노즐선단 압력으로 대신
3. 노즐에서 멀리 떨어진 물줄기 끝에서 측정
4. 초기 공기·이물질을 배출하고 노즐선단 D/2 부근에서 흐름을 마주 보게 측정

**정답: 4번**

해설: 안정된 봉상주수의 중심에서 피토관 입구가 물 흐름을 받아야 함. D는 노즐 구경
