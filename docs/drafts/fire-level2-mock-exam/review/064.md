## 일반 실전문항

### FSM2-MOCK-064-01

화재 시 피난 행동과 대피 판단에 관한 설명으로 옳은 것은?

1. 내 집 화재에서 안전한 경로가 있으면 계단 등으로 대피하고 문을 닫는다
2. 경로가 연기로 막혀도 앞이 안 보이는 계단으로 무조건 진입한다
3. 뜨거운 문은 환기를 위해 즉시 활짝 열어야 한다
4. 불·연기가 유입돼도 모든 경우 대피 판단을 하지 않는다

**정답: 1번**

해설: 옳은 판단은 ‘내 집 화재에서 안전한 경로가 있으면 계단 등으로 대피하고 문을 닫는다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 경로가 막히면 대피공간 등 안전한 곳에서 문을 닫고 구조 요청한다 / 불·연기가 유입되면 안전한 경로로 대피하되 불가능하면 구조 요청한다 / 문을 열기 전 열·연기를 확인하고 뜨거운 문을 무리하게 열지 않는다

### FSM2-MOCK-064-02

화재 시 피난 행동과 대피 판단의 기준을 적용한 판단 중 옳은 것은?

1. 다른 집 화재도 유입·경로와 무관하게 반드시 문을 열고 나간다
2. 지나온 방화문은 뒤 사람을 위해 모두 쐐기로 고정 개방한다
3. 일반 승강기는 정전과 무관하게 항상 가장 안전한 피난 수단이다
4. 경로가 막히면 대피공간 등 안전한 곳에서 문을 닫고 구조 요청한다

**정답: 4번**

해설: 옳은 판단은 ‘경로가 막히면 대피공간 등 안전한 곳에서 문을 닫고 구조 요청한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 다른 집 화재로 불·연기 유입이 없으면 실내 대기와 상황 확인을 판단한다 / 화재 대피에 일반 승강기를 이용하지 않는다 / 대피하며 지나온 문을 닫아 확산을 늦춘다

화재 시 피난 행동과 대피 판단 관련 사례를 판별할 때 타당한 판단은?

### FSM2-MOCK-064-07

### FSM2-MOCK-064-09

「화재 시 피난 행동과 대피 판단」에 관한 다음 진술을 판단한 것으로 옳은 것은?

1. ㄱ, ㄷ만 옳다
2. ㄱ, ㄴ, ㄷ 모두 틀리다
3. ㄱ, ㄴ만 옳다
4. ㄴ, ㄷ만 옳다

### FSM2-CORE-050

피난하려는 문 손잡이가 뜨겁고 틈으로 연기가 나온다. 적절한 행동은?

1. 연기를 빼기 위해 문을 활짝 열어 둠
2. 상용 승강기를 무조건 사용
3. 무리하게 열지 말고 안전한 다른 경로 또는 대피공간을 판단하고 구조 요청
4. 귀중품을 챙기러 화재실에 재진입

**정답: 3번**

해설: 뜨거운 문을 무리하게 열거나 연기로 가득한 통로에 진입하지 않으며 현장 조건에 맞춰 피난·대기·구조 요청

### FSM2-CORE-100

지상 20층 오피스텔의 12층 복도에서 연기가 나 화재경보가 울렸다. 이때 재실자가 취해야 할 피난행동으로 잘못 설명한 것은?

1. 엘리베이터를 이용하지 않고 피난계단으로 내려간다.
2. 연기가 많은 구간에서는 자세를 낮추고 젖은 수건 등으로 코와 입을 막는다.
3. 아래층으로 내려갈 수 없으면 옥상으로 대피한다.
4. 대피하면서 지나온 방화문은 연기가 잘 빠져나가도록 열어 둔다.

**정답: 4번**

해설: 지나온 방화문을 연기가 잘 빠지도록 열어 두는 것은 옳지 않다. 방화문은 화염과 연기가 다른 구역으로 번지는 것 을 막는 시설이므로 대피하면서 지나온 뒤에는 반드시 닫아 두어야 한다. 열어 두면 계단실로 연기가 밀려들어 다른 층 재실자의 피난로가 막힌다. 화재 시에는 엘리베이터를 쓰지 않고 계단으로 옥외까지 대피하며, 연기 속에서는 자세를 낮추고 젖은 수건으로 코 와 입을 막고, 아래층으로 내려갈 수 없을 때에만 옥상으로 대피한다.

### FSM2-CORE-150

지상 20층 아파트의 12층 세대에서 화재가 발생하여 현관을 통한 대피가 어려운 상황이다. 화재 시의 일반적인 피 난행동으로 잘못 설명한 것은?

1. 발코니의 경량칸막이를 부수어 이웃 세대 쪽으로 피하거나, 세대 안에 마련된 대피공간으로 들어간다.
2. 대피 도중 출입문 손잡이가 뜨겁더라도 그 문이 가장 가까운 경로라면 열고 빠르게 통과한다.
3. 계단으로 대피할 때 연기가 차 있으면 자세를 최대한 낮추고 코와 입을 젖은 수건으로 막는다.
4. 아래층으로 내려가기 어려우면 옥상으로 대피한다.

**정답: 2번**

해설: 출입문 손잡이가 뜨거우면 문을 열지 말고 다른 대피로를 찾아야 하므로, 가장 가까운 경로라는 이유로 뜨거운 문 을 열고 통과한다는 설명이 옳지 않다. 손잡이가 뜨겁다는 것은 문 너머에 화염과 고온의 연기가 차 있다는 뜻이므로, 문을 열면 화염과 열기가 한꺼번에 밀려들어 매우 위험하다. 아파트에서 현관으로 나가기 어려우면 세대 사이의 경량칸막이를 파괴해 옆 세대로 가거나 세대 내 대피공간을 이 용하고, 아래층으로 내려갈 수 없을 때에만 옥상으로 대피한다. 엘리베이터는 이용하지 않고 계단을 이용하며, 연 기 속에서는 자세를 낮추고 젖은 수건으로 코와 입을 막아 연기를 마시지 않도록 한다.

### FSM2-CORE-200

아래는 화재 시 피난행동 요령을 정리한 것이다. ㉠~㉢에 들어갈 내용으로 맞게 설명한 것은? • 이동할 때에는 ( ㉠ )을(를) 이용하지 않고 계단으로 옥외까지 내려간다. • 아래층으로 내려갈 수 없으면 ( ㉡ )(으)로 대피한다. • 지나온 방화문은 ( ㉢ ) 뒤따르는 사람의 피난로를 지킨다.

1. ㉠ 계단참, ㉡ 지하층, ㉢ 열어 두어
2. ㉠ 승강기, ㉡ 지하층, ㉢ 열어 두어
3. ㉠ 승강기, ㉡ 옥상, ㉢ 닫아
4. ㉠ 비상구, ㉡ 옥상, ㉢ 닫아
