## 일반 실전문항

### FSM2-MOCK-034-01

감시제어반·동력제어반의 상태와 조작에 관한 설명으로 옳은 것은?

1. 수동 선택은 어떠한 직접 기동도 불가능하다는 뜻이다
2. 감시제어반은 펌프·전원·수위·밸브 등의 상태를 감시·제어한다
3. 동력제어반은 전동기 전원과 무관한 단순 안내 표지다
4. 수동 명령 정지면 선택이 자동이어도 모든 자동기동이 반드시 차단된다

**정답: 2번**

해설: 옳은 판단은 ‘감시제어반은 펌프·전원·수위·밸브 등의 상태를 감시·제어한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 동력제어반은 펌프 전동기에 실제 전원을 공급·제어한다 / 수동 기동 명령 정지와 자동기동 차단은 같은 뜻이 아니다 / 승인된 시험에서 수동 선택 후 기동버튼으로 직접 기동을 확인한다

### FSM2-MOCK-034-02

감시제어반·동력제어반의 상태와 조작의 기준을 적용한 판단 중 옳은 것은?

1. 동력제어반은 펌프 전동기에 실제 전원을 공급·제어한다
2. POWER 점등만으로 펌프 회전까지 확정한다
3. 평상시 두 제어반을 모두 수동 정지로 두는 것이 자동기동 상태다
