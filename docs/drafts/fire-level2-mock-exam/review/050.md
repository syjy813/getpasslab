## 일반 실전문항

### FSM2-MOCK-050-01

비화재보의 원인과 확인·복구에 관한 설명으로 옳은 것은?

1. 발화 위치를 모를 때 지구 표시를 지우는 것이 첫 단계다
2. 증기 경보를 막으려면 모든 감지기를 영구 철거한다
3. 비화재보가 잦아도 실제 화재 여부 확인을 우선한다
4. 복구버튼은 남아 있는 연기와 눌린 발신기를 자동 제거한다

**정답: 3번**

해설: 옳은 판단은 ‘비화재보가 잦아도 실제 화재 여부 확인을 우선한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 수신기 지구 표시로 위치를 파악하고 현장을 확인한다 / 조리 증기와 반복 경보는 감지기 적응성·설치 환경을 확인한다 / 원인 신호를 제거하지 않으면 복구 후 재경보가 날 수 있다

### FSM2-MOCK-050-02

비화재보의 원인과 확인·복구의 기준을 적용한 판단 중 옳은 것은?

1. 수신기 지구 표시로 위치를 파악하고 현장을 확인한다
2. 먼지가 원인이면 수신기 소리를 영구히 차단하면 해결된다
3. 오경보 이력이 있으면 실제 불꽃이 보여도 비화재보로 처리한다
4. 수신기 복구만 끝나면 현장 발신기 상태는 확인할 필요가 없다

**정답: 1번**

해설: 옳은 판단은 ‘수신기 지구 표시로 위치를 파악하고 현장을 확인한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 현장에서 실제 불·연기를 확인하면 신고·대피·초기대응으로 전환한다 / 먼지·곤충에 의한 경보는 오염과 관리 상태를 확인한다 / 현장 기기 원인과 상태를 복구한 뒤 수신기를 복구한다

### FSM2-MOCK-050-03

다음 중 비화재보의 원인과 확인·복구의 개념과 조건을 정확히 설명한 것은?

1. 온도 변화는 어떤 열감지기의 비화재보와도 관련이 없다
2. 경보가 안 들리도록 지구경종 정지를 계속 유지한다
3. 현장에서 실제 불·연기를 확인하면 신고·대피·초기대응으로 전환한다
4. 증기 경보를 막으려면 모든 감지기를 영구 철거한다

**정답: 3번**

해설: 옳은 판단은 ‘현장에서 실제 불·연기를 확인하면 신고·대피·초기대응으로 전환한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 조리 증기와 반복 경보는 감지기 적응성·설치 환경을 확인한다 / 급격한 온도 변화는 열감지기 종류·위치를 검토할 단서다 / 최종적으로 경종·연동·시험 스위치의 정상 위치를 확인한다

### FSM2-MOCK-050-04

「비화재보의 원인과 확인·복구」 학습 내용을 정리했다. 옳게 정리한 것은?

1. 감지기와 수신기의 축적은 조건 없이 무조건 중복 적용한다

4. 복구버튼은 남아 있는 연기와 눌린 발신기를 자동 제거한다

**정답: 2번**

해설: 옳은 판단은 ‘조리 증기와 반복 경보는 감지기 적응성·설치 환경을 확인한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 먼지·곤충에 의한 경보는 오염과 관리 상태를 확인한다 / 원인 신호를 제거하지 않으면 복구 후 재경보가 날 수 있다 / 축적기능은 비화재보 저감 목적과 적용 조건을 확인한다

### FSM2-MOCK-050-05

비화재보의 원인과 확인·복구 관련 사례를 판별할 때 타당한 판단은?

1. 수신기 복구만 끝나면 현장 발신기 상태는 확인할 필요가 없다
2. 이전에도 오경보였으면 이번 경보는 현장 확인 없이 끈다
3. 온도 변화는 어떤 열감지기의 비화재보와도 관련이 없다
4. 먼지·곤충에 의한 경보는 오염과 관리 상태를 확인한다

**정답: 4번**

해설: 옳은 판단은 ‘먼지·곤충에 의한 경보는 오염과 관리 상태를 확인한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 급격한 온도 변화는 열감지기 종류·위치를 검토할 단서다 / 현장 기기 원인과 상태를 복구한 뒤 수신기를 복구한다 / 비화재보가 잦아도 실제 화재 여부 확인을 우선한다

### FSM2-MOCK-050-06

비화재보의 원인과 확인·복구에 대한 검토 의견 중 적절한 것은?

1. 경보가 안 들리도록 지구경종 정지를 계속 유지한다
2. 복구버튼은 남아 있는 연기와 눌린 발신기를 자동 제거한다
3. 급격한 온도 변화는 열감지기 종류·위치를 검토할 단서다
4. 발화 위치를 모를 때 지구 표시를 지우는 것이 첫 단계다

**정답: 3번**

해설: 옳은 판단은 ‘급격한 온도 변화는 열감지기 종류·위치를 검토할 단서다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 원인 신호를 제거하지 않으면 복구 후 재경보가 날 수 있다 / 최종적으로 경종·연동·시험 스위치의 정상 위치를 확인한다 / 수신기 지구 표시로 위치를 파악하고 현장을 확인한다

### FSM2-MOCK-050-07

비화재보의 원인과 확인·복구에 관한 설명으로 옳지 않은 것은?

1. 현장 기기 원인과 상태를 복구한 뒤 수신기를 복구한다
2. 현장에서 실제 불·연기를 확인하면 신고·대피·초기대응으로 전환한다
3. 축적기능은 비화재보 저감 목적과 적용 조건을 확인한다
4. 복구버튼은 남아 있는 연기와 눌린 발신기를 자동 제거한다

**정답: 4번**

해설: 잘못된 판단은 ‘복구버튼은 남아 있는 연기와 눌린 발신기를 자동 제거한다’이다. 올바른 내용은 ‘원인 신호를 제거하지 않으면 복구 후 재경보가 날 수 있다’이다. 나머지 보기는 각 조건에 맞는 설명이다.

## 핵심 변형문항

### FSM2-CORE-023

습한 기계실에서 반복 경보가 발생했다. 화재가 아님을 현장에서 확인한 뒤 할 적절한 조치는?

1. 감지기 회로를 끊어 놓고 계속 운영
2. 확인 없이 경종만 영구 정지
3. 습기·누수·오염과 감지기 적응성을 확인하고 원인 제거 후 복구
4. 수신기를 철거하고 화재 확인을 생략

**정답: 3번**

해설: 비화재보도 실제 화재 확인이 먼저. 원인 제거·기기 복구·수신기 복구·정상 감시 상태 확인이 필요

### FSM2-CORE-037

발신기 버튼이 눌린 원인을 그대로 둔 채 수신기 복구만 반복했다. 예상되는 문제는?

1. 발신기 원인도 자동으로 반드시 제거된다
2. 감지기 감도가 자동으로 영구 조정된다
3. 소화기 압력이 자동으로 높아진다
4. 발신기 신호가 계속되어 정상 감시상태 복귀가 어려울 수 있다

**정답: 4번**

해설: 현장 감지기·발신기의 원인 제거와 복구 후 수신기를 복구해야 함

### FSM2-CORE-073

자동화재탐지설비에서 비화재보가 반복될 때 그 원인에 따른 대책으로 잘못 설명한 것은?

1. 주방에 비적응성 감지기가 설치된 경우 — 정온식 감지기 등 그 장소에 적응성이 있는 감지기로 교체한다.
2. 건축물 누수로 감지기가 오동작하는 경우 — 해당 감지기의 배선을 잘라 회로에서 분리해 둔다.
3. 천장형 온풍기에 밀접하게 설치된 경우 — 기류가 흐르는 방향에서 벗어나도록 이격하여 설치한다.
4. 흡연구역의 담배연기로 연기감지기가 동작하는 경우 — 해당 구역에 환풍기 등을 설치한다.

**정답: 2번**

해설: 배선을 잘라 감지기를 회로에서 분리해 두는 대책은 옳지 않다. 그 구역은 화재를 감지하지 못하게 되어 설비를 사 실상 무력화하는 조치가 된다. 누수로 인한 오동작은 누수 부분을 방수 처리하고 젖은 감지기를 교체하는 것이 올바른 대책이다. 주방처럼 평상시 열이 많은 곳에는 차동식이 아니라 정온식 감지기를 써야 하며, 온풍기 기류나 담배연기처럼 환경이 원인인 경우에 는 설치 위치를 옮기거나 환기 설비를 보강한다.

### FSM2-CORE-084

건물 2층 휴게실에서 조리 중 발생한 연기 때문에 감지기가 동작하여 경보가 울렸다. 현장을 확인해 실제 화재가 아님을 확인한 소방안전관리 담당자가 취한 조치 중 잘못 설명한 것은?

1. 먼저 수신기로 가서 화재표시등과 지구표시등으로 신호가 들어온 경계구역을 점검하였다.
2. 현장에서 실제 화재가 아님을 확인한 뒤 주경종·지구경종 스위치를 눌러 음향장치를 일시 정지시켰다.
3. 수신기가 정상 감시상태로 돌아온 것을 확인한 뒤, 다시 울릴 것에 대비하여 주경종·지구경종 스위치는 정지 위치에 그대로 두 었다.
4. 창문을 열어 연기를 배출하는 등 비화재보의 원인을 없앤 뒤 수신기의 복구스위치를 눌러 감시상태로 되돌렸다.

**정답: 3번**

4. ㉠ → ㉢ → ㉡ → ㉤ → ㉣

**정답: 3번**

해설: 비화재보 대응은 수신기 확인(㉡) → 현장 확인(㉢) → 음향장치 정지(㉠) → 원인 제거(㉣) → 수신기 복구(㉤) 순서로 진행한다. 먼저 수신기에서 어느 경계구역이 표시되는지 확인해야 어디로 가야 할지 알 수 있으므로 수신기 확인이 가장 앞이 며, 그아래 반드시 현장에 가서 실제 화재 여부와 발신기 상태를 눈으로 확인한 뒤 비화재보임이 확인되고 나서야 음향장치를 정지시킨다. 현장 확인 전에 경종부터 끄면 실제 화재일 때 대피가 늦어진다. 원인인 발신기 누름버튼을 복구한 뒤에야 수신기 가 정상으로 복구되므로 원인 제거·수신기 복구가 마지막이며, 여기에는 정지시켰던 스위치를 정상 위치로 되돌리 는 조치가 포함되어야 한다.
