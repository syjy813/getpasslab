## 일반 실전문항

### FSM2-MOCK-029-01

소화기 배치와 필요한 개수 계산에 관한 설명으로 옳은 것은?

1. 벽을 통과하는 직선거리만 짧으면 소형 보행거리 기준을 충족한다
2. 위락시설은 업무시설과 동일한 100㎡ 기준만 적용한다
3. 감소·배치 추가 조건 없이 100㎡마다 1단위인 업무시설 1,050㎡에 A급 3단위 제품은 최소 3개다
4. 면적별 능력단위 계산 뒤 제품 능력으로 나누고 배치를 확인한다

**정답: 4번**

해설: 옳은 판단은 ‘면적별 능력단위 계산 뒤 제품 능력으로 나누고 배치를 확인한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 감소·배치 추가 조건 없이 업무시설 1,050㎡에 A급 3단위 제품이면 면적상 최소 4개다 / 위락시설은 대표적으로 30㎡마다 1단위를 적용한다 / 소형 20m·대형 30m 이내의 실제 보행거리를 확인한다

### FSM2-MOCK-029-02

**정답: 2번**

### FSM2-MOCK-029-03

다음 중 소화기 배치와 필요한 개수 계산의 개념과 조건을 정확히 설명한 것은?

2. 의료시설 등은 대표적으로 50㎡마다 1단위를 적용한다
3. 각 층에 1개만 있으면 모든 33㎡ 이상 거실의 조건도 자동 충족한다
4. 위락시설은 업무시설과 동일한 100㎡ 기준만 적용한다

**정답: 2번**

해설: 옳은 판단은 ‘의료시설 등은 대표적으로 50㎡마다 1단위를 적용한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 위락시설은 대표적으로 30㎡마다 1단위를 적용한다 / 각 층 외에 구획된 33㎡ 이상 거실의 배치 조건도 본다 / 적법한 2/3 감소 조건의 18개는 6개를 남긴다는 뜻이다

4. 벽을 통과하는 직선거리만 짧으면 소형 보행거리 기준을 충족한다

**정답: 2번**

해설: 옳은 판단은 ‘위락시설은 대표적으로 30㎡마다 1단위를 적용한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 주요구조부 내화와 정해진 실내 마감 요건을 모두 충족하면 기준면적 2배 조건을 본다 / 소형 20m·대형 30m 이내의 실제 보행거리를 확인한다 / 아파트등의 특별기준과 감소 제외 용도·층을 먼저 확인한다

### FSM2-MOCK-029-09

소형소화기 기본 필요 수가 18개인 공장이다. 감소 제외 용도·층이 아니며 전부 옥내소화전 유효범위에 있어 2/3 감소가 허용된다. 다른 추가 배치 조건은 없다. 남겨야 할 최소 수는?

1. 18개
2. 9개
3. 12개
4. 6개

**정답: 4번**

해설: 적법한 2/3 감소 조건의 18개는 6개를 남긴다는 뜻이다. 계산: 18×(1-2÷3) = 6 개.

### FSM2-MOCK-029-10

「소화기 배치와 필요한 개수 계산」에 관한 다음 진술을 판단한 것으로 옳은 것은?

ㄱ. 스프링클러가 있으면 아파트 소화기도 모두 2/3 줄일 수 있다

ㄴ. 위락시설은 대표적으로 30㎡마다 1단위를 적용한다

ㄷ. 소형 20m·대형 30m 이내의 실제 보행거리를 확인한다

1. ㄱ, ㄴ, ㄷ 모두 옳다
2. ㄴ, ㄷ만 옳다
3. ㄱ만 옳다
4. ㄱ, ㄷ만 옳다

**정답: 2번**

해설: ㄱ은 틀리다. 아파트등의 특별기준과 감소 제외 용도·층을 먼저 확인한다. ㄴ은 옳다. 위락시설은 대표적으로 30㎡마다 1단위를 적용한다. ㄷ은 옳다. 소형 20m·대형 30m 이내의 실제 보행거리를 확인한다.
