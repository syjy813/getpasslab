### FSM2-MOCK-057-01

점검표의 결과 표기와 불량 내용에 관한 설명으로 옳은 것은?

1. 확인 불가 항목은 기록에서 조용히 삭제한다
2. 범례가 ○ 양호이면 실제 확인한 정상 항목에 ○를 쓴다
3. 실측값은 기준값과 같게 바꿔 기록한다
4. ×가 불량인 범례에서 적치물 때문에 사용 불가한 항목도 ○로 쓴다

**정답: 2번**

해설: 옳은 판단은 ‘범례가 ○ 양호이면 실제 확인한 정상 항목에 ○를 쓴다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 범례가 × 불량이면 사용을 방해하는 적치물 항목은 ×다 / 확인 불가·미실시는 사유를 별도로 남긴다 / 측정값과 판정 기준을 구별해 남긴다

### FSM2-MOCK-057-02
