## 일반 실전문항

### FSM2-MOCK-040-01

준비작동식 스프링클러와 교차회로 점검에 관한 설명으로 옳은 것은?

1. 밸브만 열리면 감열체가 온전한 폐쇄형 헤드에서도 반드시 방수한다
2. 2차측이 차단되어도 개방 표시만 켜지면 헤드측 통수가 확정된다
3. 준비작동식의 2차측은 평상시 대기압·저압이며 폐쇄형 헤드를 쓴다
4. 같은 회로의 감지기 두 개는 항상 두 독립 회로와 같다

**정답: 3번**

해설: 옳은 판단은 ‘준비작동식의 2차측은 평상시 대기압·저압이며 폐쇄형 헤드를 쓴다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 서로 다른 두 감지기 회로의 작동 조건을 확인한다 / 밸브 물 공급과 폐쇄형 헤드 열 개방이 모두 충족되어야 방수한다 / 헤드측 차단 시험의 밸브 개방 신호와 실제 헤드측 물 공급을 구별한다

### FSM2-MOCK-040-02

준비작동식 스프링클러와 교차회로 점검의 기준을 적용한 판단 중 옳은 것은?

1. 한 회로의 경보만으로 두 회로 동작 시험을 완료했다고 기록한다
2. 서로 다른 두 감지기 회로의 작동 조건을 확인한다
3. 오인 신고를 유도하기 위해 시험 사실을 관계자에게 숨긴다
4. 자동 회로를 시험했으면 수동 기동 경로는 존재할 수 없다

**정답: 2번**

해설: 옳은 판단은 ‘서로 다른 두 감지기 회로의 작동 조건을 확인한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 한 회로 신호의 화재 경보와 두 회로의 밸브 기동 조건을 구별한다 / 관계자에게 경보·연동 시험 영향을 사전 안내한다 / 수동 기동은 자동 교차 조건과 별도의 경로로 확인한다

### FSM2-MOCK-040-03

다음 중 준비작동식 스프링클러와 교차회로 점검의 개념과 조건을 정확히 설명한 것은?

1. 헤드측 오방수를 막으려면 2차측 개폐밸브를 무조건 열어 둔다
2. 수신기 복구버튼 하나면 모든 밸브가 반드시 자동 폐쇄된다
3. 밸브만 열리면 감열체가 온전한 폐쇄형 헤드에서도 반드시 방수한다
4. 한 회로 신호의 화재 경보와 두 회로의 밸브 기동 조건을 구별한다

**정답: 4번**

해설: 옳은 판단은 ‘한 회로 신호의 화재 경보와 두 회로의 밸브 기동 조건을 구별한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 밸브 물 공급과 폐쇄형 헤드 열 개방이 모두 충족되어야 방수한다 / 교재 시험은 2차측 개폐밸브 차단 후 배수밸브 개방을 연결한다 / 수신기 복구와 밸브의 기계적 재설정은 별개로 확인한다

### FSM2-MOCK-040-04

「준비작동식 스프링클러와 교차회로 점검」 학습 내용을 정리했다. 옳게 정리한 것은?

### FSM2-MOCK-040-05

준비작동식 스프링클러와 교차회로 점검 관련 사례를 판별할 때 타당한 판단은?
