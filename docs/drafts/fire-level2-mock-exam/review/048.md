1. 한 회로만 정상이면 선택하지 않은 전 회로도 합격이다
2. 도통 정상 하나로 감지기 오염과 감도까지 모두 합격이다
3. 정상 4~8V로 제시한 도통시험의 6V는 반드시 단선이다
4. 회로도통시험은 배선·종단저항의 경로 상태를 확인한다

**정답: 4번**

해설: 옳은 판단은 ‘회로도통시험은 배선·종단저항의 경로 상태를 확인한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 도통이 정상이더라도 감지기의 실제 화재 감지 성능은 별도 확인한다 / 정상 4~8V로 제시한 도통시험의 6V는 제시 범위에 든다 / 해당 회로를 선택해 결과를 보고 다른 회로도 차례로 확인한다

### FSM2-CORE-033

1. 단선·종단저항 접속 등 회로 상태를 확인한다
2. 감시 60분·경보 10분 용량 합격으로 기록
