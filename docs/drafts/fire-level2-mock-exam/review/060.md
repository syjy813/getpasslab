## 일반 실전문항

### FSM2-MOCK-060-01

자동심장충격기의 패드와 사용 순서에 관한 설명으로 옳은 것은?

1. 젖은 옷 위에 패드를 붙이면 전극이 반드시 정상 접촉한다
2. AED가 도착하면 전원을 켜고 음성 안내를 따른다
3. 다른 패드는 신발 밑창에 붙이는 것이 기본이다
4. 일반인 구조자가 피부색만 보고 임의로 충격을 결정한다

**정답: 2번**

해설: 옳은 판단은 ‘AED가 도착하면 전원을 켜고 음성 안내를 따른다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 패드를 붙일 가슴을 노출하고 젖어 있으면 닦는다 / 다른 패드는 왼쪽 겨드랑이 아래 옆가슴에 붙인다 / 충격 필요 여부는 AED의 분석·안내에 따른다

### FSM2-MOCK-060-02

자동심장충격기의 패드와 사용 순서의 기준을 적용한 판단 중 옳은 것은?

1. 충격 후에는 맥박을 수분간 찾아본 뒤 압박한다
2. 패드를 붙일 가슴을 노출하고 젖어 있으면 닦는다
3. 분석 중에는 환자를 계속 흔들어야 판독이 정확하다
4. 성인 일반 패드는 둘 다 오른쪽 팔 위에 붙인다

**정답: 2번**

해설: 옳은 판단은 ‘패드를 붙일 가슴을 노출하고 젖어 있으면 닦는다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 성인 일반 패드 하나는 오른쪽 쇄골 아래 가슴에 붙인다 / 심장리듬 분석 중에는 환자에게 접촉하지 않는다 / 충격 후에는 즉시 가슴압박을 재개한다

### FSM2-MOCK-060-09

「자동심장충격기의 패드와 사용 순서」에 관한 다음 진술을 판단한 것으로 옳은 것은?

ㄱ. 충격 불필요는 심정지가 완전히 해결되었다는 뜻이다

ㄴ. 젖은 옷 위에 패드를 붙이면 전극이 반드시 정상 접촉한다

1. ㄴ만 옳다
2. ㄱ만 옳다
