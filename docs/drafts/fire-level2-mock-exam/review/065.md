일반문항은 현재 챕터의 이론·조건을 바탕으로 작성했다. 교재 쪽수별 직접 대조·현행 근거·정답과 오답의 유일성은 두 풀을 합친 후 검토한다.

## 일반 실전문항

### FSM2-MOCK-065-01

전기화재와 정전기의 예방에 관한 설명으로 옳은 것은?

1. 허용 전류를 넘게 여러 기기를 쓰는 것은 과부하의 단서다
2. 단락은 두 물체 사이 정전기 전위차를 줄이는 예방 작업이다
3. 차단기가 안 떨어지면 어떤 단자 과열도 존재할 수 없다
4. 느슨한 단자는 저항이 줄어 항상 냉각 효과가 있다

**정답: 1번**

해설: 옳은 판단은 ‘허용 전류를 넘게 여러 기기를 쓰는 것은 과부하의 단서다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 서로 다른 전위 도체가 접촉해 큰 전류가 흐르면 단락의 단서다 / 느슨한 접속부는 저항 증가와 국부 발열을 일으킬 수 있다 / 차단기 설치가 모든 접촉 불량 검출을 보장하지 않는다

### FSM2-MOCK-065-02

전기화재와 정전기의 예방의 기준을 적용한 판단 중 옳은 것은?

1. 정전기 불꽃은 에너지가 작아 어떤 가연성 혼합물도 점화하지 못한다
2. 트래킹은 연소범위의 상한 농도만을 뜻한다
3. 서로 다른 전위 도체가 접촉해 큰 전류가 흐르면 단락의 단서다
4. 누전은 정상 전류가 정상 경로로만 흐르는 상태다

**정답: 3번**

해설: 옳은 판단은 ‘서로 다른 전위 도체가 접촉해 큰 전류가 흐르면 단락의 단서다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 절연 손상으로 전류가 본래 경로 밖으로 흐르면 누전을 의심한다 / 오염·습기로 절연물 표면에 탄화 도전 경로가 생기는 현상이다 / 전하 축적 뒤 방전 불꽃이 증기·분진의 점화원이 될 수 있다

### FSM2-MOCK-065-03

3. 차단기만 있으면 멀티탭 정격을 초과해도 화재 위험이 없다
4. 느슨한 단자는 저항이 줄어 항상 냉각 효과가 있다

**정답: 1번**

해설: 옳은 판단은 ‘절연 손상으로 전류가 본래 경로 밖으로 흐르면 누전을 의심한다’이다. 나머지 보기의 기준은 다음과 같이 바로잡는다: 느슨한 접속부는 저항 증가와 국부 발열을 일으킬 수 있다 / 문어발 연결·허용 용량 초과를 피한다 / 접지는 땅으로 전하를 보내고 본딩은 물체 사이 전위차를 줄인다

## 핵심 변형문항

### FSM2-CORE-214

전기화재와 정전기로 인한 화재를 막기 위한 조치로 잘못 설명한 것은?

1. 하나의 콘센트에 여러 개의 전기기구를 문어발식으로 꽂아 사용하지 않는다.
2. 정전기가 축적되지 않도록 전기저항이 큰 절연성 재료를 골라 사용한다.
3. 정전기 발생이 우려되는 장소는 공기를 이온화하고 상대습도를 70퍼센트 이상으로 유지한다.
4. 누전차단기를 설치하고 월 1~2회 시험버튼을 눌러 정상 동작 여부를 확인한다.

**정답: 2번**

해설: 정전기 축적을 막으려면 전기저항이 큰 절연성 재료가 아니라 도전성(전도체) 재료를 쓰고 접지를 해야 한다는 점 에서, 절연성 재료를 쓰라고 본 설명은 옳지 않다. 전기저항이 큰 물질일수록 전하가 흘러 나가지 못해 대전되기 쉽기 때문이다. 정전기는 건조할 때 잘 발생하므로 습도를 70퍼센트 이상으로 유지하고 실내 공기를 이온화하는 것이 예방책이 되 며, 문어발식 콘센트 사용을 피하고 누전차단기 시험버튼을 눌러 정상 동작을 확인하는 것은 과부하·누전에 의한 전기화재를 막는 기본 조치이다. 전선은 묶거나 꼬이지 않게 하고 비닐장판·카펫 밑으로 지나가지 않도록 한다.
