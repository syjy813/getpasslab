감지기를 차례로 시험할 때 원인 신호가 사라지면 수신기도 따라 복구되게 하는 시험용 기능은?

2. 주경종 정지 기능

4. 예비전원 감시 기능

### FSM2-CORE-085

〈제시문〉는 P형 수신기에 있는 어떤 조작스위치의 기능을 설명한 것이다. 이 기능을 하는 스위치의 명칭은? • 감지기를 하나씩 차례로 시험할 때, 감지기가 원래 상태로 돌아가면 수신기도 따라서 원래 상태로 돌아가게 한다. • 이 스위치를 쓰면 감지기 하나를 시험할 때마다 복구스위치를 따로 누르지 않아도 된다.

1. 도통시험스위치
2. 주경종 정지스위치
3. 자동복구스위치
4. 예비전원시험스위치

**정답: 3번**

해설: 자동복구스위치는 감지기가 복구되면 수신기도 따라서 복구되도록 하는 스위치로, 감지기를 하나씩 차례로 시험 하는 동작시험에서 매번 복구스위치를 누르는 수고를 덜어 준다. 도통시험스위치는 수신기와 감지기 사이 회로가 끊겼는지 확인할 때 쓰고, 주경종 정지스위치는 수신기 안이나 그 가까이에 설치된 주음향장치를 잠시 멈출 때 쓴다. 예비전원시험스위치는 축전지의 전압이 정상 범위인지 확인할 때 사용한다.

### FSM2-CORE-089

각 층과 같은 번호의 회로가 대응하는 P형 수신기다. 화재등·4회로 지구표시등은 켜져 있고 발신기등은 켜져 있다. 다른 이상·시험 조작은 없다. 표시를 맞게 해석한 것은?

1. 교류전원등만으로 화재 위치를 확정한다
2. 지구표시등과 층의 대응은 의미가 없다
3. 발신기 복구와 무관하게 복구버튼만 누르면 원인이 반드시 제거된다
4. 4층에서 화재신호가 수신됐으며 발신기 조작 신호가 확인된다

**정답: 4번**

해설: 화재등은 화재신호, 지구표시등은 해당 경계구역, 발신기등은 발신기 조작 신호를 구분하는 표시. 실제 화재 여부는 현장 확인

### FSM2-CORE-128

P형 수신기의 스위치·표시등과 그 기능을 정확하게 연결한 것은?

1. 주경종정지스위치 — 각 경계구역에 설치된 지구경종의 울림을 멈추는 데 사용한다.
2. 회로도통시험스위치 — 경보음이 규정 음량으로 울리는지 음향장치의 성능을 확인하는 데 사용한다.
3. 자동복구스위치 — 동작한 감지기가 원상태로 돌아가면 수신기의 화재표시도 저절로 복구되게 하여 감지기 동작시험에 사용 한다.
4. 스위치주의등 — 모든 조작스위치가 정상위치에 놓여 있을 때 점멸하여 정상임을 알린다.

**정답: 3번**

해설: 자동복구스위치는 동작한 감지기가 복구되면 수신기의 화재표시도 자동으로 복구되도록 하는 스위치로, 감지기를 하나씩 동작시켜 보는 시험에서 사용한다. • 주경종정지스위치는 수신기에 내장되거나 인접 설치된 주경종을 멈추는 것이고, 각 경계구역의 지구경종은 지구경종정지스위 치로 멈춘다. • 회로도통시험스위치는 경보음이 아니라 감지기회로의 단선 유무와 기기 접속 상태를 확인하기 위한 것이며, 이를 위해 감지기회 로 끝부분에는 종단저항을 설치한다. • 스위치주의등은 조작스위치가 정상위치에 있지 않을 때 점멸하여 복구를 알리는 표시등이다.
