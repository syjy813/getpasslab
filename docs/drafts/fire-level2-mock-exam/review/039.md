1. 시험밸브함은 헤드 1개 개방에 해당하는 흐름으로 기능을 확인한다

1. 시험밸브를 연 채 장기간 방치
2. 경보만 끄고 밸브 상태 확인 생략
3. 시험밸브 닫힘·누수와 압력 회복·수신기 및 자동기동 상태 확인
4. 헤드를 모두 파괴해 복구

**정답: 3번**

해설: 헤드 1개 개방에 해당하는 흐름을 시험한 뒤 원상복구. 실제 헤드를 열로 파괴하는 시험과 다름
