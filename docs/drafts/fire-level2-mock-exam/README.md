# 소방안전관리자 2급 실전 모의고사 — 통합 검토 초안

작성 기준: 교재 대조 후 정정한 현재 챕터 · main `e1a5cdc35dd51005c78b8ed30d53eda37db535e1` · 2026-10-19

## 최신 문항 관리 기준

**[통합 관리표](question-table.md)** · [필터 가능한 검토 파일](question-table.html) · [단일 데이터 테이블](question-table.json)

사용자가 제공한 복원 **원본 500개에만 핵심 표시**를 적용한다. 기존 변형 500개는 핵심 변형, 나머지는 일반 기본·심화로 구분한다. 모든 행에 1과목·2과목을 배정했다. 현재 관리표는 원본 참조 500행과 기존 작성 1,980개를 합친 **2,480행**이다. 원본을 새로 집필한 문항 수에 합산하지 않는다.

`question-table.json`의 `isCore`, `questionType`, `subjectId`, `reviewStatus`가 현재 관리·필터 기준이다. 이전 core500.json의 핵심 태그는 변형 풀의 초기 제작 이력이며 원본 여부를 뜻하지 않는다. 기존 파일은 보존하고 통합표에서 의미를 명확히 구분했다. 검수·공개 상태와 핵심 여부는 서로 별도 컬럼이다.

원본 OCR 50개와 나머지 원문은 모두 내용 대조 전이다. 선택지를 안전하게 분리하지 못한 47행은 `choices=null`로 두고 원문과 상태를 보존했다. 선택지 분리 453개도 정답 검증 완료를 의미하지 않는다.

## 기존 기본 740문항 작성 방식

현재 챕터의 이론·경계값·예외·현장 대응을 바탕으로 챕터별 10개 판단 주제를 구성했다. 001 샘플을 유지하고, 002~074는 직접 작성한 올바른 진술과 오개념을 이용해 정오 판별·복수 진술·계산 문항을 만들었다. 동일한 문항에 번호나 숫자만 붙여 수를 늘리는 방식으로 구성하지 않았다.

| 형식 | 수 |
|---|---:|
| 기존 등급 판정 사례형 | 10 |
| 옳은 설명 선택 | 418 |
| 옳지 않은 설명 선택 | 139 |
| 복수 진술 조합 | 139 |
| 수치 계산 사례 | 34 |

법정 기준값은 임의 변형하지 않는다. 계산 사례는 입력·단위·완화 제외·올림 조건을 제시했다. 도식이 필요한 조건은 텍스트로 자족하도록 제시하며 보이지 않는 그림을 전제하지 않는다. 기본문항의 정답 위치는 각 번호에 185개씩 배분했다. 심화도 각 위치에 185개씩이어서 전체 1,980개의 정답 위치는 각 495개다.

직접 작성한 진술의 참·거짓과 오답의 타당성은 **최종 검수에서 독립적으로 재도출할 대상**이다. 현재 챕터는 교재 대조 정정 결과를 반영하지만, 일반문항별 교재 쪽수 직접 대조는 완료로 표시하지 않았다. 출제 주제의 중복·난이도·정오 판별형 비중·오답의 설득력도 통합 검토 때 조정한다.

재현 가능한 작성 원본:

- `scripts/fire-mock-authoring/chapter-facts.txt`: 73개 챕터 × 10개 판단 주제의 진술·오개념
- `scripts/fire-mock-authoring/numerical-items.json`: 계산 사례 34개의 문제·정답·오답
- `scripts/build-fire-general-mock740.py`: 고유 ID·선택지 배치·해설·검토본 생성

## 추가 심화 740문항 작성 방식

챕터별로 새 적용 사례 10개를 작성하고 서로 다른 사례를 2~3개 묶어 10문항씩 구성했다. 새 사례를 복합 결론·기록 수정·세 사례 평가에 재사용하므로, 모든 문항이 서로 무관한 지식을 묻는다는 주장은 하지 않는다. 각 문항은 최소 두 사례의 판단이 필요하며 일부만 맞춘 결론을 오답으로 넣었다.

| 형식 | 수 | 판단 요구 |
|---|---:|---|
| 두 사례 결론 연결 | 296 | 두 조건의 결론이 모두 맞는 선택지 |
| 최소 수정 대상 선택 | 296 | 맞는 기록은 유지하고 잘못된 기록을 빠짐없이 수정 |
| 세 사례 평가 | 148 | 세 의견의 타당성을 각각 판단한 뒤 합산 |

- 경계값·용도별 제외·여러 기산점·복합 단위·구획별 올림·압력과 유량·신호와 실제 작동·조건별 피난과 응급처치를 사례에 적용
- 물리적 기준값을 임의 변경하지 않고 새로운 사례 입력값과 잘못된 적용을 대비
- 89개 사례의 **계산식 95개 독립 재계산**, 이 사례가 들어가는 심화문항은 **135개**
- 사례 하나가 서로 다른 묶음에서 2~3회 쓰이므로 같은 개념의 반복 정도는 통합 검토에서 조정
- `심화`는 작성 시 난도 목표이며 실제 수험생 정답률·변별력은 미측정
- 교재 범위를 넘어선 생소한 지식이나 모호한 조건을 난도 근거로 사용하지 않음

작성 원본은 `scripts/fire-mock-authoring/hard-cases.txt`다. 생성 데이터와 검토본은 이 원본에서 파생하며 원문 복원자료 500개와의 새 1:1 관계를 만들지 않는다. `hard-editorial.json`의 문항별 사례·챕터 해시와 함께 검토한다. 법령·기술기준·2025 CPR의 관련 공식 자료를 확인했지만 새 740문항의 내용 전수 검수를 완료했다고 표시하지 않는다.

## 핵심 500개 범위와 보존 사항

복원자료는 50개씩 10묶음, 총 500개다. 공식 인증 기출이 아니며 원본 표시답도 독립 검증된 정답으로 취급하지 않는다. `핵심`은 변형 풀 식별 태그이며 공식 출제빈도·적중률·실제 시험일을 인증하지 않는다.

- OCR 첫 세트 50개는 깨진 문장을 재사용하지 않고 관련 개념으로 다시 작성했다
- 212개는 정정한 챕터에 따른 사례·조건 재구성이다. 그림 의존 사례는 텍스트로 바꿨다
- 238개는 원본 조건·보기 의미를 유지한 표현 변형·선택지 재배열 초안이다. 모두 새로운 수치 사례라고 주장하지 않는다
- 원본 고유 ID 500개와 1:1 연결하며 정답 위치는 원본 표시 위치와 다르다. 각 위치는 125개씩이다
- 그림을 텍스트로 바꾼 문항이 원본의 정확한 추론 단계·난이도를 보존했는지는 검토가 필요하다

원본 제공처의 묶음명·연도는 새 실전 회차의 공식 기출 연도로 노출하지 않는다. 일반 740개 추가 과정에서는 핵심 500개를 다시 생성하거나 수정하지 않았다.

## 근거와 검사 결과

교재 대조·정정 이력은 `docs/audits/2026-10-18-fire-level2-textbook-corrections/`에 있다. 법령·기술기준·의학 내용의 적용 시점은 통합 검토에서 문항별로 재확인한다. 주요 확인 자료:

- [화재예방법 시행령 — 2026-07-01 시행판](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=287389)
- [자체점검 결과 조치 — 시행규칙 제23조](https://law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1033855839)
- [2025 한국 심폐소생술 가이드라인 — 질병관리청](https://www.kdca.go.kr/bbs/kdca/49/305205/download.do)
- 응급처치 챕터의 질병관리청·WHO 화상 안내 등 기존 근거

기존 기본·핵심 검사 완료 항목:

- 일반 740개·핵심 500개·통합 1,240개, 고유 ID와 지문 완전 일치 중복 없음
- 74개 챕터 각각 일반 10개, 과목·태그·정답 인덱스·보기 4개·해설 연결
- 일반 편집 메모와 챕터 해시 연결, 기존 핵심·편집 메모·001 샘플 보존
- 일반 계산 진술 **35개 독립 재계산**, 그중 직접 계산 문제 **34개는 실제 정답 보기의 값까지 확인**
- 기존 핵심 계산 **51개 독립 재계산** 및 원본 1:1 연결 유지
- 읽기용 74개 파일에 통합 1,240개가 한 번씩 포함되는지 확인, 내부 링크 확인

추가 심화 검사: 챕터별 10개·ID 11~20·4개 보기·정답 연결·2~3개 사례 연결·수정 대상과 합산 정답·95개 계산식·전체 1,980개 수록·기존 파일 보존을 확인했다.

**이전 집필 파일은 `reviewStatus: draft`, `publicationApproved: false`다. 최신 통합표에서는 이를 `reviewStatus: pending`, `publicationStatus: unpublished`, `examEligible: false`로 구분한다.** 구조·계산 검사와 문항 내용의 진위 인증을 구별한다. 교재 쪽수·정답 유일성·오답 근거·현행 기준·유사도·난이도 전수 검수와 서비스 탑재는 대기 중이다.

## 통합 검토와 이후 연결

1. 교재 쪽수·문맥과 현행 법령·기술기준·응급처치 지침을 문항별 대조
2. 정답을 독립적으로 도출하고 나머지 세 보기의 오답 근거 확인
3. 기본·심화·핵심 간 유사도, 중복 학습 주제·난이도·문항 형식 조정
4. 최종 승인 문항 목록을 확정한 뒤 서비스 연결과 모바일·PC QA

서비스 연결 시 전체 / 핵심만 / 일반만과 챕터 필터를 구분하고, 일반 안에서 기본·심화를 구분할 수 있다. 실전 회차는 과목별 25개·총 50개를 별도로 조합한다. source ID·편집 메모는 학습 화면에 노출하지 않는다.

## 재생성·검사

최신 통합 관리표는 사용자 원본 index를 입력해 생성한다.

```bash
python3 scripts/build-fire-question-table.py --source /path/to/outline-data.json
node scripts/verify-fire-question-table.mjs
```

현재 추가분과 전체 1,980개 검토본:

```bash
python3 scripts/build-fire-hard-mock740.py
python3 scripts/verify-fire-hard-mock740.py
```
