## 사용자 정책과 현재 산출물

| 풀 | 정책 | 이번 산출물 | 공개 상태 |
|---|---|---|---|
| 챕터별 일반문항 | 74개 챕터에 약 10개씩, 본문과 교재 이론을 적용 | 001 챕터 샘플 10개. 나머지 730개는 미작성 | 초안·미공개 |
| 핵심 변형문항 | 사용자 제공 복원문제 500개와 각 1:1로 연결하는 별도 500개 | `core500.json` 500개 | 초안·미공개 |

직전 제안의 첫 챕터 10개 샘플과 별도로, 사용자가 추가 요청한 복원자료 기반 핵심 500개를 준비했다. 기본문항 약 740개와 핵심 500개는 합쳐 약 1,240개를 목표로 하되, **현재 1,240개가 작성되었다고 보고하지 않는다.**

공식 기출을 뜻하는 이름 대신 **실전 모의고사**를 사용한다. `핵심`은 이 자료 기반 변형 풀을 식별하는 태그이며 공식 출제빈도·적중률·실제 시험일을 인증하는 표시가 아니다.

## 파일

- `core500.json`: 핵심 초안 500개. 4지선다·단일 정답·해설·챕터·과목·`핵심` 태그
- `chapter001-sample.json`: 등급 판정 일반문항 10개. 핵심 태그 없음
- `sample-review.md`: 일반 10개와 핵심 10개의 읽기용 샘플
- `editorial-review.json`: 원본 ID·PDF 페이지·제공처 묶음명·변형 방법·챕터 해시·계산 검산식·검수 상태
- `validation.json`: 실제 구조·계산 검사의 결과. **정답 전수 검수와 구별**

학습용 데이터와 제작·검수 메모는 별개 파일이다. 원본 PDF·원문 전체·교재 파일은 저장소에 추가하지 않았다. 기존 정본 기출 3,621개와 공개 본문·UI·CSS는 바꾸지 않았다.

## 문항 제작 범위

복원자료는 50개씩 10묶음, 총 500개다. 내부 source index의 고유 ID를 하나도 빼거나 중복 배정하지 않았다. 이 자료는 공식 정본이 아니며 표시 정답도 전수 인증된 답안이 아니다.

- 첫 OCR 세트 50개는 깨진 문장을 재사용하지 않고 관련 개념으로 다시 작성했다
- 추가 212개는 교재 대조 후 정정한 챕터를 근거로 사례·조건을 다시 구성했다. 그림 의존 문항은 조건을 글로 제시했다
- 나머지 238개는 원본의 출제 조건과 보기 의미를 유지한 표현 변형·선택지 재배열 초안이다. 이들을 모두 새로운 수치 사례로 재작성했다고 주장하지 않는다
- 모든 핵심 문항의 정답 **위치**는 원본 표시 위치와 다르며, 각 위치는 125개씩 무작위 순서로 배분했다. 정답 위치 변경과 정답 내용의 변경·검증은 별개다
- 법정 기준값·단위는 임의로 바꾸지 않는다. 새 계산 사례는 입력·정답·보기·해설을 함께 구성했다
- 단순한 유사 표현 변경과 새로운 사례 생성은 `method`로 구분했다. 500개가 500개의 서로 다른 개념이라는 주장은 하지 않는다

그림을 텍스트 사례로 바꾼 문항은 원본과 같은 챕터의 판단 원리를 다루지만, **원본 그림의 정확한 추론 단계·난이도까지 보존한 것으로 인증하지 않았다.** 검수 시 원본과 직접 다시 대조해야 한다.

## 근거와 검수 상태

작성 시 사용자 제공 복원자료의 지문·보기·표시답·해설과 현재 공개 챕터를 참조했다. 관련 교재 대조·정정 근거는 `docs/audits/2026-10-18-fire-level2-textbook-corrections/`에 있다. 다음 공식 자료를 추가 대조했다.

- [화재예방법 시행령 — 2026-07-01 시행판](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=287389)
- [자체점검 결과의 조치 — 시행규칙 제23조](https://law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1033855839)
- 응급처치의 근거 판본은 기존 챕터의 2025 한국 심폐소생술 지침, 질병관리청 화상 안내 및 WHO 화상 지침을 유지

현재 완료된 검사는 총수·고유 ID·원본 1:1 연결·보기 4개·유일한 보기 문자열·정답 인덱스·태그·해설 존재·누락된 그림 참조·문항 지문 완전 중복·챕터 해시 및 **51개 계산식의 독립 재계산**이다.

**500개 전체의 정답·오답 유일성·현행 근거·교재 이론 적용에 대한 문항별 내용 검수는 미완료다.** 구조 검사 통과나 원본 표시답 추적을 그 검수의 완료로 바꾸어 말하지 않는다. 모든 편집 기록은 `reviewStatus: draft`, `publicationApproved: false`이며 실제 서비스의 문제 데이터나 실전 모의고사에 연결하지 않았다.

공개 전 필요한 문항별 확인:

1. 원본이 묻는 판단과 새 문항의 판단 범위·난이도 비교
2. 정답을 원본 표시답과 독립적으로 도출하고 나머지 세 보기의 오답 근거 확인
3. 관련 챕터와 교재 쪽수·공식 근거를 구체적으로 연결하고 오래된 조건·수치 제외
4. 표현만 변형된 238개를 포함한 전체 중복·유사도와 학습 가치 재검토
5. 검수가 끝난 문항만 별도 승인 목록에 올리고 UI 연결·모바일·PC QA 진행

## 이후 실전 모의고사 연결 정책

- 전체 / 핵심만 / 일반만을 태그로 선택하고, 챕터별로 학습 범위를 제한
- 핵심 500개를 챕터당 10개 수량에 합산하지 않음
- 실전 회차 구성은 과목별 25개·총 50개를 별도로 조합. 원본 제공처의 묶음명을 새 시험 회차나 공식 기출 연도로 노출하지 않음
- 점수·정답·해설·연결 챕터를 학습에 사용하고 source ID·검수 메모는 사용자 화면에 노출하지 않음
- 검수 승인 전 전체 500개를 자동으로 문제풀이 대상에 넣지 않음
