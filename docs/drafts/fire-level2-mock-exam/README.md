## 일반문항 작성 방식

현재 챕터의 이론·경계값·예외·현장 대응을 바탕으로 챕터별 10개 판단 주제를 구성했다. 001 샘플을 유지하고, 002~074는 직접 작성한 올바른 진술과 오개념을 이용해 정오 판별·복수 진술·계산 문항을 만들었다. 동일한 문항에 번호나 숫자만 붙여 수를 늘리는 방식으로 구성하지 않았다.

| 형식 | 수 |
|---|---:|
| 기존 등급 판정 사례형 | 10 |
| 옳은 설명 선택 | 418 |
| 옳지 않은 설명 선택 | 139 |
| 복수 진술 조합 | 139 |
| 수치 계산 사례 | 34 |

법정 기준값은 임의 변형하지 않는다. 계산 사례는 입력·단위·완화 제외·올림 조건을 제시했다. 도식이 필요한 조건은 텍스트로 자족하도록 제시하며 보이지 않는 그림을 전제하지 않는다. 일반문항의 정답 위치는 각 번호에 185개씩 배분했다.

직접 작성한 진술의 참·거짓과 오답의 타당성은 **최종 검수에서 독립적으로 재도출할 대상**이다. 현재 챕터는 교재 대조 정정 결과를 반영하지만, 일반문항별 교재 쪽수 직접 대조는 완료로 표시하지 않았다. 출제 주제의 중복·난이도·정오 판별형 비중·오답의 설득력도 통합 검토 때 조정한다.

재현 가능한 작성 원본:

- `scripts/fire-mock-authoring/chapter-facts.txt`: 73개 챕터 × 10개 판단 주제의 진술·오개념
- `scripts/fire-mock-authoring/numerical-items.json`: 계산 사례 34개의 문제·정답·오답
- `scripts/build-fire-general-mock740.py`: 고유 ID·선택지 배치·해설·검토본 생성

## 핵심 500개 범위와 보존 사항

복원자료는 50개씩 10묶음, 총 500개다. 공식 인증 기출이 아니며 원본 표시답도 독립 검증된 정답으로 취급하지 않는다. `핵심`은 변형 풀 식별 태그이며 공식 출제빈도·적중률·실제 시험일을 인증하지 않는다.

- OCR 첫 세트 50개는 깨진 문장을 재사용하지 않고 관련 개념으로 다시 작성했다
- 212개는 정정한 챕터에 따른 사례·조건 재구성이다. 그림 의존 사례는 텍스트로 바꿨다
- 238개는 원본 조건·보기 의미를 유지한 표현 변형·선택지 재배열 초안이다. 모두 새로운 수치 사례라고 주장하지 않는다
- 원본 고유 ID 500개와 1:1 연결하며 정답 위치는 원본 표시 위치와 다르다. 각 위치는 125개씩이다
- 그림을 텍스트로 바꾼 문항이 원본의 정확한 추론 단계·난이도를 보존했는지는 검토가 필요하다

원본 제공처의 묶음명·연도는 새 실전 회차의 공식 기출 연도로 노출하지 않는다. 일반 740개 추가 과정에서는 핵심 500개를 다시 생성하거나 수정하지 않았다.

- 일반 편집 메모와 챕터 해시 연결, 기존 핵심·편집 메모·001 샘플 보존
- 일반 계산 진술 **35개 독립 재계산**, 그중 직접 계산 문제 **34개는 실제 정답 보기의 값까지 확인**

- 읽기용 74개 파일에 통합 1,240개가 한 번씩 포함되는지 확인, 내부 링크 확인

**모든 문항은 `reviewStatus: draft`, `publicationApproved: false`다.** 구조·계산 검사와 문항 내용의 진위 인증을 구별한다. 교재 쪽수·정답 유일성·오답 근거·현행 기준·유사도·난이도 전수 검수와 서비스 탑재는 대기 중이다.

## 통합 검토와 이후 연결

1. 교재 쪽수·문맥과 현행 법령·기술기준·응급처치 지침을 문항별 대조
2. 정답을 독립적으로 도출하고 나머지 세 보기의 오답 근거 확인
3. 일반·핵심 간 유사도, 중복 학습 주제·난이도·문항 형식 조정
4. 최종 승인 문항 목록을 확정한 뒤 서비스 연결과 모바일·PC QA

서비스 연결 시 전체 / 핵심만 / 일반만과 챕터 필터를 구분한다. 실전 회차는 과목별 25개·총 50개를 별도로 조합한다. source ID·편집 메모는 학습 화면에 노출하지 않는다.
