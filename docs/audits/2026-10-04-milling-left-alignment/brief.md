# 좌측 정렬 브리프

- 적용: milling-safety 카드 하나. 사용자가 현재 그림의 좌측 정렬을 제안하여 본문 시작선에 맞춤
- 실제 읽고 적용한 정본: docs/standards/learning-image-design-system-v1.md v1.2 §§5–6,9; 직전 제작 브리프의 L2 유형/질문/기술 범위 유지
- 학습 질문: 무엇이 회전하고 일감은 어디에 고정되며 컬럼은 어디인가? 기존6문항과 본문·캡션·alt 동일
- 원본 재사용: milling-motion-illustrated-v1.webp 그대로, 래스터/SVG/화살표·부품·글자 수정 없음
- 카드의 바깥 정렬만 center→left. 폭424px, 이미지최대390px, 상단24px·좌우16px 내부 여백과 종횡비 유지
- 모바일320/390px에서는 카드가 본문 가용 폭을 채우므로 표시 폭·라벨 크기 그대로; PC에서는 카드 왼쪽과 본문 시작선을 일치시킴
- 범위: 밀링 scoped selector만 변경. 선반/다른 챕터 카드 정렬 그대로
- 검증: 빌드와 기존 CI 회귀+320/390/1440px에서 카드 시작점 실측; 이미지 응답 바이트·가독성·기출 연결 동일 검사. 캡처에서 고정 헤더와 캡션이 겹치지 않도록 스크롤 위치만 조정
- 배포 승인: 기존 실서버 수정·재배포 지시가 이어지는 작업
- CI/배포/Production 결과는 PR 본문에 최종 증거로 갱신하며, 이 파일은 변경 전 브리프임
