# 흙막이 지보공 구조 그림 브리프

캡션: 흙막이 지보공의 부재 배치 / 학습용 재구성 · 버팀대식 예시, 앵커·접합 상세 생략

- 대상: construction/earth-retaining-components, 주 기출 20220424_112 · 20190804_118 · 20200606_120 · 20200926_113 · 20190303_119 · 20180304_102
- 학습 질문: 흙막이판, 엄지말뚝, 띠장, 버팀대는 어디에 있고 어떻게 연결되는가?
- 표현: L1 구조 도식, 입체 투영으로 수직재·벽면 평행 수평재·굴착부 횡단 수평재 구별
- 검증: 6개 정본 지문·보기·수록 답안 직접 대조. 문제 원본 도판 없음(해당 6개 manifest 미등록)
- 근거: OSHA OTM Section V Chapter2 VI/Fig V:2-7 (posts, wales, sheeting, crossbrace strut 연결); 1926.650 cross braces/wales 정의; FHWA-IF-99-015 §2.3.2.3 p15(문서 PDF34) lagging과 soldier-beam flange 관계
- 직접 라벨: 흙막이판, 엄지말뚝, 띠장, 버팀대. 색뿐 아니라 명칭과 지시선으로 구분
- 구조: 양쪽 흙막이벽; 흙막이판은 수직 말뚝 사이, 띠장은 굴착면에 평행하게 말뚝 안쪽, 버팀대는 양쪽 띠장 사이에 접촉
- 그림 범위: 부재 배치 예시, 설계도·설치 순서·하중 계산 그림이 아님
- 생략: 앵커식, 접합부·치수·단수·기초 상세. 토압 화살표는 생략하고 본문 부재 역할 표 유지
- 미확인: 20190804_118 수록 답안 ②버팀대와 본문의 띠장 설명 불일치. 공식 원문/정정 미확인; 원본 답안 변경 없이 문항 확인 전에 읽을 수 있도록 본문에 주의 안내
- 본문 중복: 그림은 위치 관계만, 기존 표는 역할 설명. 시험 포인트 전면 재정리 없음
- 에셋: 기존 정확한 원본 없음, 공개 SVG 신규 작성. PC/모바일 동일 파일, 390단위 폭,24px 라벨(320px에서 최소14px 목표)
- 표시: 기존 좌측 정렬·최대424px 카드·위 여백24px 유지, 가로폭에 억지 확대하지 않음
- alt: 흙막이판이 엄지말뚝 사이에 설치되고, 두 벽의 안쪽 띠장을 버팀대가 가로질러 연결하는 입체 구조 그림
