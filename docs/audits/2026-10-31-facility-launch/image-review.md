## 검수 절차와 잔여 사항

- 최초 원고 24개 파일은 4:3 WebP와 텍스트 alt가 연결되어 있었다. 05-03은 연도 오인을 막기 위해 초안 본문에서 제외해 현재 23개를 표시하며, 원본과 웹용 파일은 모두 보존한다. 해당 채용 사례는 본문에서 확인할 수 있다.
- 320·390px 실제 브라우저 이미지 캡처를 CI QA에 추가했다. 표시 중인 23개가 대상이다. 결과 파일과 브라우저에서 글자가 읽히는지는 수동 확인해야 하며, 캡처 생성만으로 가독성을 보증하지 않는다.
- 01-04는 원본에 화살표가 있지만 사용자가 승인한 그림이고 시설 가이드에 본문·캡션에서 순서가 아님을 명시하기로 한 기준이 있어 해당 보완을 유지한다. 05-03은 원본 교정 전 본문에서 제외했다. 원본 재제작·변경에는 기존 패키지의 별도 승인 경계를 적용한다. 03-02·03-03 및 다중 카드 그림은 실제 표시 크기에서 검토 후 처리한다.
- 이 기록은 법령·채용 정보 전체의 사실 검증이나 1~5번 발행 승인이 아니다.

## 320·390px 브라우저 캡처 확인

- GitHub Actions `facility-draft-qa` 실행 41445765425에서 실제 브라우저가 당시 표시한 이미지 24장을 320px·390px 화면에서 각각 캡처했다. 화면의 이미지 표시 폭은 화면 여백을 뺀 너비다. 이후 05-03은 본문 표시에서 제외됐으며 나머지 23장은 동일한 이미지 파일이다.
- 01-02·01-03·01-05, 02-03, 03-02·03-03, 04-02~05, 05-02·05-04·05-05의 보조 문구는 특히 320px에서 작다. 각 글의 인접 본문·표·목록에 핵심 판단 항목이 존재하는지 대조했다. 03-03은 계약·고용승계·변경 후 조건을 본문 목록으로 보완했다.
- 캡처는 Chromium의 자동화 화면이다. 실물 기기, Safari, 시스템 글꼴 확대 및 보조기기 확인은 하지 않았으며 작은 그림 글씨 자체가 읽기 좋다는 판정은 아니다. 그림 교체 여부는 별도 검토한다.
- 시설 본문 이미지는 로딩 전 4:3 비율로 공간을 예약하고, 로딩 후에는 이미지 고유 비율을 따른다. 이는 레이아웃 이동을 줄이기 위한 조치이며 실제 LCP·CLS 수치를 측정한 것은 아니다. 자격증 영역의 이미지 스타일은 변경하지 않았다.

## 2026-11-03 표시 정리 판정

- [최신 검수](factcheck-and-images-20261103.md)의 기준과 이미지 판정표를 따른다. bbee729의 실제390px 이미지23개 캡처 전체,작은 문구가 많은320px6개와 주요 원본 문구를 대조했다.
- 01-04는 법적 요건을 순서로 오해할 화살표 때문에 **원본을 보존하고 본문에서 제외**한다. 별도 재제작 없이 HTML의 세 개념 설명 목록으로 전달한다. 이전 기록의 캡션 보완으로 표시 유지하던 방침을 대체한다.
- 05-03 제외를 유지하여 본문 이미지는22개(4/4/5/5/4). 나머지는 핵심 내용이 인접 HTML에도 있어 작은 보조 글씨만으로 판단하지 않도록 유지한다. 이미지 자체의 작은 글씨가 전부 읽기 좋다는 판정은 아니다.
- 재게시 공고 원문과 이미지 숫자·용어·가상 표시를 대조했으며 기존24개 WebP의 내용과 바이트를 변경하지 않았다. 이번 신규 이미지 생성·재제작·확대 기능·CSS 변경 없음.
