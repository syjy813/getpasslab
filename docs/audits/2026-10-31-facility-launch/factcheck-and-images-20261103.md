# 초기 1~5 콘텐츠 사실관계·이미지 정리

확인일: 2026-11-03(KST). 기준: PR #222의 bbee729 이후 사용자 승인 작업. 대상은 현재 다섯 원고에 **실제로 남긴 설명과 수치**다. 새로운 선임 자격표나 다른 회차의 채용조건을 추가하지 않았다.

## 결론과 범위

- 다섯 원고의 주요 법령·서류 요건·채용 사례를 아래 근거와 대조하고, 필요한 표현과 출처를 보완했다. 체크리스트·진로 조언은 편집상의 권고이고, 가상 상황과 가상 급여는 사실 자료와 구분한다.
- 한전FMS는 회사 명의 공고 PDF를 대학 재게시 첨부에서 확보해 1·3쪽을 렌더링하고 모집표·근무조건표를 대조했다. 회사 채용시스템에서 직접 받은 파일이라고 표시하지 않는다.
- 01-04의 법적 요건 간 화살표 그림은 파일을 보존하고 본문에서 제외한다. 05-03의 연도 혼동 그림도 앞선 제외를 유지한다. 24개 원본 WebP는 바이트 그대로이며 본문 표시는 **22개(4/4/5/5/4)**다.
- 검수상 다섯 편 모두 공개 후보로 유지한다. `status: draft`와 기존 경로·발행일은 보존하며 `reviewedAt`만 이번 확인일로 갱신했다. 발행 승인, 티스토리 대표 URL 정책, 공개 상태 QA, main 병합·Production 배포는 별도다.
