# 초기 1~5 콘텐츠 사용자 관점 첨삭

2026-11-03. 사용자 승인에 따라 2026-11-02 독자 관점 검토안을 원고에 반영했다. 시설 콘텐츠 통합 가이드 v1.4의 한 문단 한 주장, 초보자 용어 풀이, 글별 다음 행동, 제목과 본문 일치를 적용했다.

| 글 | 실제 변경 |
|---|---|
| 01 | 도입과 비유를 줄이고 수변전설비·공조기 설명을 풀었다. 관심 업무 표시 후 고용주 확인 글로 연결한다. |
| 02 | 담당 업무·급여와 근무표·교육·선임과 책임·경력증빙의 다섯 기준으로 재구성했다. 겹치는 설비 설명을 합치고 면접 질문표도 맞췄다. 기존 이미지의 다섯 질문은 별도 예시로 설명하며 급여 질문을 본문에 보완했다. |
| 03 | 고용주 비교표를 세 열로 줄이고 고용승계·계속근로기간을 일상적인 질문으로 먼저 풀었다. 근무형태·급여 글로 이어 읽도록 했다. |
| 04 | 반복되는 일반론과 가상 예시 안내를 정리했다. 가상 수치 표시는 도입과 표·이미지 부근에 남기고 법령 적용 조건은 본문에 유지했다. 실제 근무표와 급여 구성표를 나란히 비교하도록 마무리했다. |
| 05 | 제목을 ‘공공부문 시설관리 채용공고 읽는 법｜실제 사례로 보는 6가지 기준’으로 변경했다. 서로 다른 기관 자료가 우열 비교표로 읽히지 않게 목적을 설명하고 수치의 반복 해설을 줄였다. |

## 보호 범위

- 공개 URL·slug·카테고리·자료 출처·확인일·초안 상태를 유지했다. `updatedAt`만 실제 편집일로 갱신했다.
- 원고의 이미지 참조 파일과 이미지 원본은 유지했다. 05-03은 앞선 조치대로 표시하지 않는다.
- 05의 모집·급여·경쟁률·평균보수·채용 시점 수치를 보존했다. 이번 첨삭은 새 법률 판단이나 채용정보 재검증이 아니다.
- 고용승계의 개별 사정, 경력심사, 법정수당의 사업장 규모·감시단속 승인 등 적용 조건은 보존했다.

## 검증

원고별 출처·보호 메타데이터·이미지 참조 목록을 변경 전후 대조하고 02의 1~5 소제목과 05의 주요 수치를 확인했다. 일반·미리보기 빌드, 초안 제외·내부 링크·SEO 결과 및 GitHub CI는 해당 최종 커밋 기준으로 구분해 확인한다. main 병합·Production 배포는 이번 범위가 아니다.
