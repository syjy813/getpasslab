# FSM2-001 학습 콘텐츠 위계 시범 적용

사용자 승인 범위: 소방안전관리대상물의 등급 챕터 한 곳에 코드 적용 및 실서버 배포.

- 대제목 아래 첫 콘텐츠 16px, 설명문과 표 16px, 표와 참고문 8px
- 큰 섹션 전환은 1px 회색 구분선과 PC 48px / 모바일 32px의 전체 간격으로 구분함. 선의 앞·뒤 간격을 포함한 값이며 중복 여백을 더하지 않음
- 기존 파란 제목 바·제목 앵커·문구·수치·예외·기출 근거는 유지함
- 시험 포인트 핵심 문구와 설명은 8px, 항목 사이는 구분선을 포함해 32px, 박스 안쪽은 PC 24px / 모바일 16px
- 표 글자는 PC·모바일 모두 14px. 본문·대제목·참고문 크기는 기존 반응형 토큰 사용
- 스타일은 `.fire-grade-lesson` 아래에만 적용. 공유 CSS 파일은 배포하되 다른 챕터에는 이 클래스가 없으므로 새 규칙이 적용되지 않음
- 챕터의 스타일 URL 버전을 갱신해 이전 공개 CSS 캐시와 구분함

본문·문제의 내용 변경 없음. 빌드 전후 본문 텍스트 및 다른 HTML의 해시를 대조하고, 네 화면 폭에서 실제 요소 간 거리와 구분선을 검사함. 과거 릴리스 기준은 유지하며 이번 4개 파일의 원본·현재 전체 바이트를 검증한 뒤 이전 상태로 복원함.
