# 41. P1-24-02 — 점프 목록의 최근 항목과 고정

## 학습 본문

### 한 줄 핵심

점프 목록은 **작업 표시줄의 프로그램 아이콘에서 최근·고정 항목을 빠르게 열기 위한 목록**이며, 열기·실행·고정·제거 조작을 구별함

### 점프 목록 열기

연결 기출에서는 작업 표시줄에 있는 **프로그램 아이콘을 마우스 오른쪽 단추로 클릭**하여 점프 목록을 여는 방식으로 출제됨

따라서 문제의 첫 단서는

**작업 표시줄 프로그램 아이콘 → 마우스 오른쪽 클릭 → 점프 목록**

으로 연결함

### 항목 실행

점프 목록에 표시된 항목을 클릭하면 해당 항목을 열 수 있음

즉,

**목록에서 항목 선택 → 항목 실행**

으로 판단함

### 항목 고정

자주 사용하는 항목은 점프 목록에서 해당 항목을 가리킨 뒤 **압정 아이콘**을 이용해 고정하는 방식으로 출제됨

핵심은

**최근 사용 항목과 고정 항목은 다름**

이라는 점임

고정하면 최근 사용 여부와 관계없이 목록에 유지하도록 지정하는 의미임

### 항목 제거

연결 기출의 함정은

`항목을 가리킨 다음 Delete 키를 누르면 점프 목록에서 제거된다`

라는 설명임

해당 기출에서는 이 조작을 **잘못된 설명**으로 판단함

따라서 점프 목록에서 항목을 없애는 조작을 일반 파일 삭제와 같은 `Delete 키` 동작으로 외우지 않음

### Aero Peek와 구별

점프 목록은 **최근·고정 항목을 빠르게 여는 기능**이고, Aero Peek는 **창을 최소화하지 않고 바탕화면이나 열린 창을 미리 보는 기능**임

두 기능 모두 작업 표시줄과 연결될 수 있으므로 목적을 기준으로 구별함

## 주 기출 적용 검토

| question_id | 단서 | 본문 적용 | 판단 |
|---|---|---|---|
| `20190831_016` | 프로그램 아이콘 우클릭·항목 실행·압정·Delete | 열기·실행·고정은 점프 목록 조작, Delete 키 제거 설명은 틀림 | **④** |

## 보조 기출 활용

`20160625_016`, `20200704_011`은 Aero Peek 보기에서 `작업 표시줄 프로그램 아이콘을 오른쪽 클릭해 최근 파일 목록을 확인`하는 설명이 점프 목록임을 구별하는 보조 사례로만 사용함

## 시각 자료

별도 이미지 불필요

`아이콘 우클릭 → 목록 열기 → 항목 클릭 / 고정`의 짧은 세로 흐름으로 충분함

## 편집 메모

- 주 1문항·보조 2문항 유지

- 현재 Windows의 메뉴 위치를 새로 확정하지 않음
- Aero Peek 설명은 다음 `P1-24-03`으로 넘김

# 42. P1-24-03 — Aero Peek으로 바탕화면·창 미리보기

## 학습 본문

### 한 줄 핵심

Aero Peek는 과거 Windows 기출에서 **열린 창을 최소화하지 않고 바탕화면이나 열린 창을 잠깐 미리 보는 기능**으로 출제됨

### 문제에서 찾을 핵심 단서

다음 표현이 나오면 Aero Peek와 연결함

- 모든 창을 최소화하지 않음
- 바탕화면을 빠르게 미리 봄
- 작업 표시줄의 프로그램 아이콘을 가리켜 열린 창을 미리 봄

따라서 핵심 흐름은

**창을 그대로 둠 → 잠깐 미리 봄 → Aero Peek**

임

### 비슷한 기능과 구별

| 보기의 설명 | 해당 기능 |
|---|---|
| 저장 위치와 관계없이 종류별로 파일을 모아 접근 | 라이브러리 |
| 창을 최소화하지 않고 바탕화면·열린 창 미리보기 | Aero Peek |
| 여러 배경 사진을 번갈아 표시 | 바탕화면 슬라이드 쇼 |
| 프로그램 아이콘 우클릭 후 최근 항목 확인 | 점프 목록 |

문제는 기능 이름보다 **무엇을 하려는 기능인가**를 먼저 보면 쉽게 구별됨

### 작업 표시줄 미리보기 단축키

보조 기출에서는 작업 표시줄에 열려 있는 프로그램의 미리보기를 차례대로 표시하는 바로 가기 키를 **Windows 로고 키 + T**로 출제함

이 단축키는 Aero Peek의 정의 자체라기보다 작업 표시줄의 열린 프로그램 미리보기를 다루는 보조 판단으로 사용함

### 버전 주의

Aero Peek라는 용어와 Windows 7/10의 세부 조작은 과거 기출 문맥으로 유지함

2027 기준 Windows 11에서 같은 이름·같은 위치·같은 동작으로 제공된다고 이 챕터에서 단정하지 않음

| `20200704_011` | 최소화 없이 바탕화면·열린 창 미리보기 | Aero Peek → **②** |

별도 이미지 불필요

Aero Peek / 라이브러리 / 슬라이드 쇼 / 점프 목록의 목적 비교표가 가장 효율적임

# 44. P1-32b-01 — 해상도와 텍스트 표시 설정

## 학습 본문

### 한 줄 핵심

화면 설정 문제는 **화면에 어떻게 표시할지 바꾸는 디스플레이 설정**과 **Windows의 외형을 꾸미는 개인 설정**을 구별함

### 디스플레이 쪽에서 판단할 항목

연결된 Windows 7 기출에서는 [디스플레이]와 다음 항목을 연결함

- 연결된 모니터 감지
- 모니터 방향 설정
- 화면 해상도 설정
- 사용자 지정 텍스트 크기(DPI)
- ClearType을 이용한 텍스트 가독성 조정

시험에서는 이 항목들을 **화면 표시 방법을 조정하는 기능**으로 묶어 판단함

### 테마는 다른 목적

테마는 바탕 화면 배경·창 색·소리·화면 보호기처럼 Windows의 외형을 한꺼번에 바꾸는 **개인 설정** 성격임

따라서 Windows 7 기출에서

`[디스플레이]에서 테마 기능을 이용해 배경·창 색·소리·화면 보호기를 변경할 수 있다`

는 설명은 설정 범위가 다르므로 틀림

### 현재 Windows와 연결할 때

현재 Windows 11에서도 해상도·배율 같은 화면 배치 관련 설정은 **시스템의 디스플레이 영역**, 테마는 **개인 설정의 테마 영역**으로 목적이 구분됨

다만 Windows 7의 `DPI`, `ClearType`, 제어판 경로를 현재 Windows 11의 화면과 똑같다고 표현하지 않음

### 문제 판단표

| 바꾸려는 것 | 우선 판단 |
|---|---|
| 해상도·모니터 방향 | 디스플레이 |
| 화면 요소 크기·배율 | 디스플레이 |
| 텍스트 가독성 | 표시·접근성 관련 설정 |
| 배경·색·테마 | 개인 설정 |

## 주 기출 적용 검토

| question_id | 선택지 판단 | 근거 |
|---|---|---|
| `20160305_005` | ① 틀림 | 테마는 기출의 [디스플레이] 담당 범위가 아님 |
|  | ② 맞음 | 모니터 감지·방향·해상도 |
|  | ③ 맞음 | 텍스트 크기(DPI) |
|  | ④ 맞음 | ClearType 텍스트 조정 |
|  | 정답 | **①** | |

## 시각 자료

별도 이미지 불필요

`디스플레이 설정 ↔ 개인 설정`의 목적 비교표가 가장 직접적임

## 편집 메모

- Windows 7 기출의 제어판 경로는 당시 버전 문맥으로 유지
- 현재 Windows 11 공식 문서에서도 해상도·배율은 디스플레이, 테마는 개인 설정으로 구분됨
- ClearType의 현행 메뉴 경로를 이 챕터에서 새로 확정하지 않음
- 테마 자체 설명은 `ADD-08`에서 보완

# 45. ADD-05 — 소리의 입력·출력 장치와 음량

## 학습 본문

### 한 줄 핵심

소리 문제는 먼저 **녹음은 입력, 재생은 출력**으로 구별하고 장치 선택·사용 여부·음소거 상태를 확인함

### 입력과 출력부터 구별

| 작업 | 장치 방향 |
|---|---|
| 마이크로 음성을 녹음 | 입력 |
| 스피커·헤드폰으로 소리를 재생 | 출력 |

스피커에서 소리가 정상적으로 난다는 사실은 **마이크 입력도 정상이라는 뜻이 아님**

입력과 출력은 각각 다른 장치와 상태를 확인해야 함

### 출력 소리가 안 날 때

학습 판단 순서

1. 올바른 출력 장치를 선택했는지 확인
2. 장치가 사용 가능한 상태인지 확인
3. 음소거 여부와 음량 확인

여러 출력 장치가 연결된 경우 소리가 다른 장치로 출력되고 있을 수도 있음

### 녹음이 안 될 때

스피커 음량만 올리는 것으로 해결하지 않고

1. 올바른 입력 장치가 선택됐는지
2. 입력 장치가 사용 가능한지
3. 필요한 경우 마이크 접근 권한 조건이 있는지

를 구별함

다만 앱별 마이크 권한의 자세한 설정은 별도 개인정보·권한 범위로 넘김

### 핵심 오답

`소리가 안 난다 = 무조건 볼륨만 올린다`

`스피커가 정상 = 마이크도 정상`

처럼 입력·출력을 하나의 상태로 판단하지 않음

## 직접 연결 기출

주 기출·보조 기출 **없음**

2026·2027 출제기준의 시스템 설정·멀티미디어 하드웨어 설정 범위를 보완하기 위한 기초 챕터임

실제 기출이나 출제 빈도를 새로 만들어 붙이지 않음

## 학습 예시

스피커에서는 동영상 소리가 정상적으로 들리지만 음성 녹음이 되지 않는 경우

→ 출력 장치보다 **녹음 입력 장치와 사용 상태**를 먼저 확인함

이 예시는 학습용이며 실제 기출이 아님

## 시각 자료

별도 이미지 불필요

`마이크 → 입력 / 스피커·헤드폰 → 출력`의 2행 표로 충분함

## 편집 메모

- 직접 배정 기출 없음
- 현재 Microsoft 공식 문서도 입력 장치와 출력 장치를 별도로 선택·활성화하고 음소거 여부를 확인하도록 안내함
- 드라이버 재설치·서비스 재시작 같은 고급 장애 조치는 범위 밖
- 앱 마이크 접근 권한은 별도 권한 챕터로 넘김

# 46. ADD-08 — 배경·테마와 해상도 설정 구별하기

## 학습 본문

### 한 줄 핵심

**배경·색·테마는 화면의 외형을 꾸미는 개인 설정**, **해상도·배율은 화면에 표시되는 크기와 배치를 조정하는 디스플레이 설정**으로 구별함

### 개인 설정

테마는 Windows의 외형을 한꺼번에 꾸미는 설정임

현재 Windows 공식 문서에서도 테마에는 다음과 같은 요소가 포함될 수 있음

- 바탕 화면 배경
- 창 색
- 소리
- 기타 개인 설정 요소

따라서

`배경 사진을 바꾸고 싶다`
`Windows의 전체적인 외형을 바꾸고 싶다`

라는 목적이면 개인 설정·테마 쪽으로 판단함

### 디스플레이 설정

해상도와 배율은 **화면에 내용을 어떤 크기와 배치로 표시할지**와 관련됨

- 해상도 변경
- 텍스트·앱 등 화면 요소의 배율 조정
- 여러 디스플레이의 배치·선택

등은 테마와 목적이 다름

### 시험에서의 핵심 구별

| 변경 목적 | 판단 |
|---|---|
| 배경 그림·창 색·테마 변경 | 개인 설정 |
| 화면 해상도 변경 | 디스플레이 설정 |
| 화면 요소가 너무 작아 크게 표시 | 배율·텍스트 크기 등 표시 설정 검토 |
| 글자를 더 읽기 쉽게 표시 | 표시·접근성 관련 설정 검토 |

테마를 바꾼다고 해상도 자체가 바뀌는 것은 아님

## 직접 연결 기출

# 47. ADD-42 — 절전·최대 절전·종료의 차이

## 학습 본문

### 한 줄 핵심

전원 상태는 **얼마나 빨리 작업을 다시 이어야 하는가, 전력을 얼마나 사용해야 하는가, 해당 PC가 기능을 지원하는가**를 기준으로 구별함

### 절전

절전은 PC를 완전히 종료하지 않고 **적은 전력을 사용하면서 빠르게 작업을 재개**하기 위한 상태임

짧게 자리를 비웠다가 다시 작업할 상황과 연결하기 쉬움

현재 Microsoft 공식 문서도 절전을 `적은 전력 사용 + 빠른 재개`로 설명함

### 최대 절전

최대 절전은 절전보다 전력 사용을 더 줄이면서 나중에 이전 작업 상태로 돌아가기 위한 기능으로 설명됨

현재 공식 문서에서 중요한 조건은

**모든 PC에서 최대 절전을 사용할 수 있는 것은 아님**

이라는 점임

따라서 문제에서 최대 절전을 무조건 모든 PC의 기본 지원 기능으로 단정하지 않음

### 종료

종료는 PC를 **완전히 끄는 상태**임

절전·최대 절전처럼 빠른 작업 재개를 목적으로 하는 상태와 구별함

### 비교

| 상태 | 전력 사용 | 작업 재개 | 주의 |
|---|---|---|---|
| 절전 | 매우 적게 사용 | 빠름 | PC·전원 설정에 따라 동작 차이 |
| 최대 절전 | 절전보다 더 적게 사용 | 절전보다는 느릴 수 있음 | 모든 PC에서 지원되지 않을 수 있음 |
| 종료 | PC를 완전히 끔 | 새로 시작 | 절전 상태와 같지 않음 |

### 덮개·전원 버튼 주의

노트북 덮개를 닫거나 전원 버튼을 눌렀을 때 어떤 상태로 들어가는지는 **설정에 따라 달라질 수 있음**

`덮개를 닫으면 언제나 최대 절전`
`전원 버튼을 누르면 항상 종료`

처럼 고정된 동작으로 외우지 않음

## 직접 연결 기출

주 기출·보조 기출 **없음**

시스템 설정 범위를 보완하기 위한 기초 챕터임

## 학습 예시

잠깐 자리를 비운 뒤 곧바로 이어서 작업해야 함

→ 절전을 우선 비교

오랫동안 사용하지 않고 전력 사용을 더 줄이면서 작업 상태 복귀가 필요함

→ 해당 PC가 지원한다면 최대 절전을 비교

실제 기출이 아닌 학습 예시임

## 시각 자료

별도 이미지 불필요

절전 / 최대 절전 / 종료의 3행 비교표가 가장 효율적임

## 편집 메모

- 직접 배정 기출 없음
- 현재 Microsoft 공식 문서 기준으로도 최대 절전은 일부 PC에서 제공되지 않을 수 있음
- 미저장 데이터가 어떤 상황에서도 반드시 보존된다고 단정하지 않음
- 전원 버튼·덮개 동작은 설정 가능성을 함께 명시함

# 49. ADD-06 — Bluetooth 장치의 검색·페어링·연결

## 학습 본문

### 한 줄 핵심

Bluetooth 장치는 **PC가 Bluetooth를 지원하는지 → 상대 장치가 검색 가능한 상태인지 → 페어링 → 연결 완료** 순서로 판단함

### 1. PC의 Bluetooth 지원 확인

먼저 PC에 Bluetooth 기능이 있는지와 사용할 수 있는 상태인지 확인함

현재 Windows 공식 문서에서도 Bluetooth 설정 항목이 보이지 않는 경우 Bluetooth 어댑터나 드라이버가 없는 상황을 확인하도록 안내함

### 2. 장치를 검색 가능한 상태로 만들기

Bluetooth를 PC에서 켰다고 해서 주변 장치가 자동으로 모두 나타나는 것은 아님

연결하려는 마우스·키보드·헤드폰 등의 장치가 **전원이 켜져 있고 검색 가능한 페어링 상태**여야 함

장치를 검색 가능하게 만드는 구체적인 방법은 기기마다 다를 수 있음

### 3. 페어링

검색된 장치를 선택하고 필요한 확인 절차를 거쳐 두 장치가 서로를 등록하도록 하는 과정임

**Bluetooth ON = 페어링 완료**

가 아님

### 4. 연결 상태

페어링을 완료한 뒤 실제 연결 상태를 확인함

지원되는 장치는 이후 범위 안에 들어오면 자동 연결될 수 있지만 이를 모든 Bluetooth 장치의 절대 동작으로 확대하지 않음

### 유선 장치와 구별

이 챕터에서는 유선·무선의 모든 설치 절차를 비교하지 않고

**Bluetooth는 검색 가능 상태와 페어링 과정이 필요**

하다는 차이에만 집중함

2026·2027 출제기준의 장치 설정·Bluetooth 설정 범위를 보완하는 챕터임

# 50. ADD-07 — 휴대전화와 PC 연결의 목적과 조건

## 학습 본문

### 한 줄 핵심

휴대전화와 PC를 연결하면 **메시지·알림 등 일부 기능을 PC에서 연동해 사용할 수 있지만, 지원 기기·기능·권한 조건에 따라 사용할 수 있는 범위가 달라짐**

### 연결의 목적

현재 Microsoft의 Phone Link 계열 기능은 휴대전화와 Windows PC를 연결하여 기기별 지원 범위 안에서 다음과 같은 기능을 제공할 수 있음

- 메시지
- 알림
- 통화
- 일부 사진·파일·앱 관련 연동

핵심은 **휴대전화의 모든 기능을 PC에서 그대로 복제하는 기능이 아니라 기기 간 연동 기능**이라는 점임

### 연결만 했다고 모든 기능이 열리는 것은 아님

사용 가능한 기능은 다음 조건에 따라 달라질 수 있음

- 연결한 휴대전화 종류와 지원 여부
- PC와 휴대전화의 연결 상태
- 기능별 필요한 권한 허용 여부
- 해당 기능 자체의 지원 범위

따라서

`PC와 휴대전화를 연결했으므로 어느 휴대전화에서도 모든 앱·사진·통화 기능을 동일하게 사용할 수 있다`

라고 판단하면 안 됨

### 권한 조건

알림·메시지·연락처 등 일부 기능은 휴대전화에서 필요한 권한을 허용해야 사용할 수 있음

즉,

**연결 완료 ≠ 모든 기능 사용 가능**

임

### 2026 출제기준과 현재 제품의 구별

이 챕터는 2026 출제기준의 `전화 설정` 공백을 보완하기 위해 설계됨

현재 Microsoft 문서는 Phone Link를 기준으로 설명하지만, 이를 2026 시험용 과거 전화 설정 화면과 동일한 메뉴라고 표현하지 않음

특정 과거 메뉴 이름이나 최소 OS 버전 숫자를 시험 필수 암기로 새로 추가하지 않음

## 직접 연결 기출

주 기출·보조 기출 **없음**

2026 출제기준의 전화 설정 범위를 보완하는 챕터임

2027 기준에는 같은 직접 항목이 없다는 기존 검토 상태를 유지함

## 학습 예시

→ `연결 실패`만 확인할 것이 아니라 **알림 기능 지원 여부와 권한 조건**도 구별해서 확인함

실제 기출이 아닌 학습 예시임

## 시각 자료

## 편집 메모

- 직접 배정 기출 없음
- 현재 Phone Link 공식 문서는 기능별 지원 기기와 권한 차이가 있음을 명시함
- 현재 Phone Link의 기능 목록을 2026 시험 화면의 기능 목록으로 그대로 옮기지 않음

# 51. P1-33 — Windows 접근성 기능의 도움 대상

## 학습 본문

### 한 줄 핵심

접근성 기능은 **사용자가 어떤 어려움을 줄이려는 기능인지**를 기준으로 돋보기·내레이터·대비·화상 키보드·토글 키·마우스 키를 구별함

### 화면을 크게 보기 — 돋보기

돋보기는 화면의 내용을 확대하여 보기 쉽게 만드는 접근성 기능임

연결된 Windows 7 기출에서는

- `Windows 로고 키 + +`로 실행·확대
- `Windows 로고 키 + -`로 축소
- `Windows 로고 키 + Esc`로 종료

를 묻고 있음

이 단축키 가운데 확대·축소·종료는 현재 Microsoft 문서에서도 확인되는 조작임

### 도킹 모드와 렌즈 모드 구별

기출의 핵심 함정은

`도킹 모드를 실행하면 마우스 포인터 주위의 영역이 확대된다`

라는 설명임

마우스 포인터 주위를 따라 확대하는 설명은 **렌즈 모드**에 해당하고, 도킹 모드는 확대 영역을 화면의 일정 위치에 두는 방식으로 구별함

따라서 연결 기출의 해당 설명은 틀림

### 화면 내용을 읽어 주기 — 내레이터

내레이터는 화면의 텍스트와 인터페이스 정보를 음성으로 읽어 주는 화면 읽기 기능임

시각적 정보 확인이 어려운 사용자를 돕는 기능으로 판단함

### 대비를 높여 보기 쉽게 — 고대비·대비 테마

과거 Windows 7/10 기출에서는 `고대비`라는 표현을 사용함

현재 Windows에서는 **대비 테마**라는 명칭이 사용되며 텍스트와 UI 요소의 가시성을 높이는 목적은 이어짐

시험에서는 버전별 명칭을 섞기보다

**색 대비를 크게 하여 화면 요소를 더 쉽게 구별**

하는 목적을 기억함

### 실제 키보드 없이 입력 — 화상 키보드

화상 키보드는 화면에 표시되는 키보드를 마우스·포인팅 장치 등으로 선택하여 입력할 수 있게 하는 접근성 기능임

현재 Windows에서도 접근성 기능으로 제공됨

### 토글 키

Caps Lock·Num Lock·Scroll Lock 같은 토글 키를 누를 때 소리로 상태 변화를 알 수 있도록 하는 기능임

따라서 키 상태를 청각적으로 확인하는 도움 기능으로 판단함

### 마우스 키

숫자 키패드를 이용해 마우스 포인터를 움직일 수 있게 하는 접근성 기능임

`마우스를 움직이기 어렵다 → 숫자 키패드로 포인터 제어`

라는 단서와 연결함

### 자녀 보호와 구별

자녀 보호는 자녀의 사용 시간·게임·프로그램 등을 제한하는 **이용 제한 기능**임

돋보기·고대비·토글 키·마우스 키처럼 사용상의 어려움을 줄이기 위한 접근성 기능과 목적이 다름

### 다중 디스플레이와 구별

모니터를 두 대로 확장해 표시하는 다중 디스플레이 설정은 화면 구성·디스플레이 기능이지 접근성 센터의 대표적인 접근성 기능으로 보는 항목이 아님

별도 이미지 불필요

기능명과 `누구에게 어떤 도움을 주는가`를 연결한 비교표가 가장 적합함

## 편집 메모

- 주 5문항·보조 0문항 유지
- 과거 기출의 `고대비`와 현재 Windows의 `대비 테마` 명칭을 구별함
- 현재 공식 Microsoft 문서에서 돋보기·내레이터·화상 키보드·토글 키가 접근성 기능으로 제공됨을 재확인함
