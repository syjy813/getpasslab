# 62. ADD-04 — 작업에 맞는 Windows 보조 도구 고르기

## 학습 본문

### 한 줄 핵심

Windows 보조 도구 문제는 **만들려는 결과가 계산값인지, 텍스트인지, 화면 캡처 이미지인지**를 먼저 확인함

### 작업 결과로 도구 구별

| 작업 | 우선 선택할 도구 |
|---|---|
| 기본 산술 계산 | 계산기 |
| 간단한 텍스트 작성·저장 | 메모장 |
| 화면 전체·창·일부 영역을 이미지로 캡처 | 캡처 도구 |

도구 이름보다 **최종 결과물의 종류**를 보면 빠르게 구별 가능함

### 계산기

Windows 계산기는 기본 산술 계산을 수행하는 도구임

현재 버전에는 공학·그래프·프로그래머·날짜 계산·단위 변환 등 기능이 더 있지만 이 챕터의 판단에는 **기본 수치 계산**만 사용함

예

`18 × 7 계산`

→ 계산기

### 캡처 도구

캡처 도구는 화면 전체·창·일부 영역을 이미지로 남기는 기능임

현재 Snipping Tool에는 동영상·AI 등 추가 기능도 존재하지만 **과거 Windows 보조 도구의 일반 기능으로 확대하지 않음**

예

`화면 일부를 이미지로 저장`

→ 캡처 도구

### 메모장

간단한 텍스트 작성·저장은 메모장 범위임

메모장의 세부 기능·버전 차이는 다음 `P1-32c`에서 다룸

## 직접 연결 기출

주 기출·보조 기출 **없음**

공식 출제기준의 Windows 보조프로그램 범위를 보완하기 위한 챕터임

대표 상황은 학습 예시이며 실제 기출이 아님

## 시각 자료

별도 이미지 불필요

`계산값 / 텍스트 / 화면 이미지 → 계산기 / 메모장 / 캡처 도구`의 3행 표가 적합함

## 편집 메모

- 직접 배정 기출 없음
- 계산기의 고급 모드·Snipping Tool의 최신 AI/동영상 기능은 핵심 범위 밖
- 메모장 상세는 `P1-32c`
- 현재 Microsoft 문서로 계산기와 캡처 도구의 기본 기능을 재확인함

# 63. P1-32c — 메모장에서 할 수 있는 작업

## 학습 본문

### 한 줄 핵심

2019년 기출의 메모장은 **텍스트 저장·문자열 찾기·현재 날짜/시간 삽입은 가능하지만 그림·차트 같은 OLE 개체 삽입은 지원하지 않는 텍스트 편집기**로 판단함

### 텍스트 저장

연결 기출에서는 메모장에서 작성한 문서를 저장할 때 기본 확장자를 `.txt`로 판단함

핵심

**메모장 → 텍스트 문서 → `.txt`**

### 문자열 찾기

문서 안에서 특정 문자열을 찾는 기능을 사용할 수 있음

따라서 `특정 문자열 검색이 불가능하다`는 방향으로 판단하지 않음

### 날짜·시간 삽입

연결 기출에서는 현재 날짜와 시간을 삽입하는 기능이 있는 것으로 출제됨

현재 Microsoft 문서에도 메모장의 로그 기능과 날짜·시간 관련 기능이 남아 있음

### OLE 개체는 구별

연결 기출의 핵심 오답은

`그림, 차트 등의 OLE 개체를 삽입할 수 있다`

라는 설명임

해당 기출 시점의 메모장은 Word 같은 복합 문서 편집기가 아니므로 **OLE 개체 삽입 기능으로 보지 않음**

### 현재 버전 주의

현재 Windows 11 메모장은 과거 버전보다 기능이 확장되어 Markdown 기반의 가벼운 서식 기능도 도입됨

따라서

`메모장은 현재도 아무 서식도 지원하지 않는다`

라고 일반화하지 않음

다만 **가벼운 텍스트 서식 지원과 OLE 개체 삽입은 다른 기능**이므로 연결 기출의 정답은 그대로 유지함

# 64. ADD-43 — 저장 공간 확인과 자동 정리

## 학습 본문

### 한 줄 핵심

저장 공간 관리는 **현재 무엇이 공간을 차지하는지 확인 → 삭제 가능한 임시 항목 정리 → 클라우드 파일의 로컬 보관 여부 조정** 순서로 판단함

### 저장 공간 확인

Windows의 저장소 설정에서는 시스템 드라이브의 사용량과 저장 항목을 확인할 수 있음

현재 Windows에서는 다른 드라이브의 저장 사용량도 별도로 확인 가능함

### Storage Sense

Storage Sense는 임시 파일·휴지통 등의 불필요한 항목을 조건에 따라 자동 정리하여 공간을 확보하는 기능임

중요한 조건

- 기본적으로 시스템 드라이브를 대상으로 동작
- 다운로드 폴더·클라우드 콘텐츠는 사용자가 조건을 설정하지 않으면 자동 정리 범위가 다를 수 있음
- 모든 드라이브의 모든 파일을 같은 규칙으로 지우는 기능이 아님

### 온라인 전용과 영구 삭제 구별

OneDrive 등의 클라우드 파일을 **온라인 전용**으로 바꾸면 로컬 디스크 공간은 확보할 수 있음

하지만 클라우드 원본이 영구 삭제되는 것은 아님

즉

**로컬 사본 제거 ≠ 클라우드 원본 삭제**

임

네트워크 연결과 계정 상태가 갖춰지면 다시 파일에 접근하거나 로컬로 내려받을 수 있음

## 직접 연결 기출

주 기출·보조 기출 **없음**

시스템 설정과 디스크 관리 사이의 범위를 보완하는 기초 챕터임

대표 상황은 학습 예시이며 실제 기출이 아님

## 시각 자료

별도 이미지 불필요

`공간 확인 → 임시 파일 정리 → 클라우드 파일 온라인 전용`의 3단계 흐름이 적합함

## 편집 메모

- 직접 배정 기출 없음
- Storage Sense가 모든 드라이브를 동일하게 정리한다고 쓰지 않음
- 온라인 전용 파일 전환을 클라우드 삭제로 설명하지 않음
- 디스크 정리의 구체 대상은 `P1-26-01`

# 65. P1-26-01 — 디스크 정리로 지울 수 있는 항목

## 학습 본문

### 한 줄 핵심

과거 Windows의 디스크 정리 문제는 **임시 파일·휴지통 같은 정리 대상**과 **글꼴 파일·사용자 파일처럼 임의로 정리 대상으로 보지 않는 항목**을 구별함

### 기출의 대표 정리 대상

연결 기출에서는 다음을 디스크 정리 대상으로 제시함

- 임시 인터넷 파일
- 휴지통의 파일
- 다운로드한 프로그램 파일

반면

`사용하지 않은 폰트(*.TTF) 파일`

은 해당 기출의 디스크 정리 대상이 아님

### 디스크 정리와 RAM 부족은 다른 문제

휴지통 파일을 지우면 저장장치 공간은 확보할 수 있음

하지만 **RAM 용량 자체가 늘어나는 것은 아님**

따라서 RAM 부족 해결 방법을 묻는 문제에서 `휴지통 비우기`는 직접적인 해결책이 아님

### 디스크 정리와 바이러스 예방은 다른 목적

디스크 정리는 불필요한 저장 파일을 정리하는 기능임

방화벽·의심 메일 삭제·백신 업데이트와 같은 **바이러스 예방 기능**과 목적이 다름

따라서 정기적인 디스크 정리를 바이러스 감염 예방법으로 판단하지 않음

### 현재 Windows와 연결할 때

현재 Windows에서는 저장소 설정·Storage Sense·정리 권장 사항 등으로 공간 정리 기능이 확대됨

과거 `디스크 정리` 창의 모든 항목을 현재 UI와 동일하게 외우지 않음

# 66. P1-26-02 — 디스크 오류 검사의 대상과 역할

## 학습 본문

### 한 줄 핵심

디스크 오류 검사는 **파일 시스템 오류와 디스크 오류를 확인·복구하는 기능**이며 네트워크로 연결된 드라이브를 로컬 디스크처럼 검사하는 기능이 아님

### 무엇을 검사하는가

연결 기출에서는 오류 검사의 역할로 다음을 제시함

- 폴더·파일 관련 오류 검사 및 복구
- 디스크의 불량 섹터 검출

따라서 **손상된 파일 시스템·디스크 오류 확인**이 핵심 목적임

### 네트워크 드라이브와 구별

연결 기출의 오답은

`네트워크 드라이브를 선택하여 오류 검사를 할 수 있다`

라는 설명임

현재 Microsoft의 `chkdsk` 문서도 검사 대상을 **로컬 디스크**로 제한하며 네트워크로 리디렉션한 드라이브에는 사용할 수 없다고 명시함

### 조각 모음과 역할 구별

파일이 손상된 상황에서 `디스크 조각 모음`을 실행하는 것은 오류 복구 기능과 목적이 다름

- 오류 검사 → 파일 시스템·디스크 오류 확인·복구
- 조각 모음/최적화 → 저장된 파일 배치를 정리하여 읽기·쓰기 성능을 개선

따라서 `파일 손상 → 조각 모음`으로 바로 연결하지 않음

### 정기 실행 표현 주의

2018년 기출은 `시스템 성능 향상을 위해 정기적으로 수행하는 것이 좋다`는 선택지를 맞는 설명으로 취급함

이를 현재 모든 PC에 정기 검사를 의무적으로 수행해야 한다는 운영 원칙으로 확대하지 않음

# 67. P1-26-03 — 디스크 조각 모음과 최적화의 목적

## 학습 본문

### 한 줄 핵심

드라이브 최적화는 **파일 배치·저장장치 특성에 맞게 접근 효율을 개선하는 작업**이며 디스크 용량을 늘리거나 손상된 파일을 복구하는 기능이 아님

### 과거 HDD 조각 모음

Windows 7 기출에서는 하드 디스크에 흩어진 파일 조각을 재정렬하여 파일 읽기·쓰기 성능을 향상시키는 기능을 **디스크 조각 모음**으로 출제함

단서

- SSD → TRIM을 이용한 최적화

따라서 최신 SSD를 HDD와 똑같이 조각 모음한다고 설명하지 않음

# 68. P1-26-04 — 디스크 포맷과 파일 시스템

## 학습 본문

### 한 줄 핵심

### 파일 시스템의 역할

파일 시스템은 파일·폴더를 저장하고 이름·위치·공간 사용 등을 관리하는 구조임

따라서 연결 기출의

`파일 시스템은 문자 파일, 영상 파일, 데이터 파일 등을 관리하기 위한 기능`

처럼 파일 **내용 종류를 분류하는 기능**으로 설명하면 부정확함

### 포맷과 데이터

과거 기출에서는 포맷을 실행하면 디스크의 데이터가 지워진다고 판단함

**새 파일 테이블을 만들지만 볼륨 전체를 완전히 덮어쓰지는 않음**

`포맷 = 모든 비트를 완전 소거`

### 빠른 포맷

빠른 포맷

- 새 파일 테이블 생성
- 전체 볼륨을 완전히 덮어쓰지 않음
- 일반 포맷보다 빠름

이라는 차이를 기억함

연결 기출에서 포맷 창에서 설정 가능한 항목

- 볼륨 레이블
- 파일 시스템
- 빠른 포맷

## 현행 Microsoft 문서 검증 반영

- Calculator: 기본 산술 계산 및 여러 계산 모드 지원
- Snipping Tool: 화면 전체·창·영역 캡처 지원
- Storage Sense: 임시 파일·휴지통 정리, 시스템 드라이브 중심 동작
- OneDrive 온라인 전용: 로컬 공간만 확보하며 클라우드 원본 영구 삭제 아님
- `chkdsk`: 로컬 디스크 대상, 네트워크 리디렉션 드라이브에는 사용할 수 없음
- 드라이브 최적화: HDD는 조각 모음, SSD는 TRIM
- 빠른 포맷: 새 파일 테이블 생성, 전체 볼륨 완전 덮어쓰기는 아님
- Windows 현재 기본 정보: 설정 > 시스템 > 정보에서 CPU·RAM·시스템 종류·Windows 버전 등 확인
- `msinfo32`: 하드웨어·시스템 구성 요소·소프트웨어 환경 정보 제공
- Device Manager Code 28: 장치 드라이버 미설치 상태
