# 28. P1-21 — 시스템·응용·유틸리티 구별하기

## 학습 본문

### 한 줄 핵심

소프트웨어는 **컴퓨터 시스템을 관리·중계하는가, 사용자의 목적을 직접 수행하는가, 관리 작업을 보조하는가**를 기준으로 구별함

### 시스템 소프트웨어

시스템 소프트웨어는 컴퓨터 하드웨어와 응용 소프트웨어 사이에서 시스템을 효율적으로 운영하도록 돕는 소프트웨어임

기출에서 다음 단서와 연결함

- 컴퓨터와 사용자 사이의 중계
- 하드웨어의 효율적인 사용 지원
- 시스템 운영·관리
- 운영체제 포함

과거 컴활 기출의 분류에서는 시스템 소프트웨어를 **제어 프로그램과 처리 프로그램**으로 나누며, 언어 번역 프로그램은 처리 프로그램 쪽에 포함하는 방식으로 출제됨

따라서 `시스템 소프트웨어는 제어 프로그램과 번역 프로그램으로 구분한다`는 설명은 해당 기출 분류와 맞지 않음

### 응용 소프트웨어

응용 소프트웨어는 사용자가 문서 작성·그래픽 작업·데이터 관리처럼 **특정 목적의 작업을 수행하기 위해 사용하는 프로그램**임

원본 그림 `20151017_010`에서

- Windows → 시스템 소프트웨어
- Photoshop → 응용 소프트웨어
- Linux → 시스템 소프트웨어
- 한컴오피스 → 응용 소프트웨어
- Unix → 시스템 소프트웨어

로 구별됨

따라서 응용 소프트웨어만 고르면 **Photoshop + 한컴오피스**임

### 유틸리티 프로그램

유틸리티는 컴퓨터·운영체제·응용 프로그램의 사용과 관리를 보조하는 서비스 프로그램으로 출제됨

핵심은 **사용자의 주 목적을 직접 수행하는 프로그램이라기보다 시스템 사용·관리의 편의를 돕는 프로그램**이라는 점임

다만 과거 기출에서 유틸리티의 구체적 예로 든 Windows 프로그램은 당시 시험 분류를 따르며, 현재 Windows의 제품 구성이나 앱 분류까지 같은 방식이라고 일반화하지 않음

### 세 분류를 한 번에 구별

| 구분 | 판단 질문 |
|---|---|
| 시스템 소프트웨어 | 컴퓨터 시스템을 관리·중계하는가 |
| 응용 소프트웨어 | 사용자의 특정 작업 목적을 직접 수행하는가 |
| 유틸리티 | 시스템 사용·관리 작업을 보조하는가 |

# 29. P1-23-01 — 운영체제가 관리하는 자원과 작업

## 학습 본문

### 한 줄 핵심

운영체제는 **CPU·기억장치·입출력장치·파일 같은 자원을 관리하고 사용자와 컴퓨터 사이의 인터페이스를 제공**함

### 운영체제가 관리하는 대상

기출에서 운영체제의 주요 기능으로 묶는 항목

- 프로세스 관리
- 기억장치 관리
- 주변장치 관리
- 파일 관리
- 자원 스케줄링
- 자원 공유
- 사용자 인터페이스 제공

따라서 `프로세스·기억장치·주변장치·파일 관리`라는 표현이 나오면 운영체제의 핵심 기능으로 판단함

### 실행 위치 주의

운영체제 파일은 저장장치에 보관될 수 있지만 컴퓨터가 작동하는 동안 필요한 운영체제 구성 요소는 주기억장치에 적재되어 실행됨

따라서

`운영체제는 컴퓨터가 작동하는 동안 하드 디스크에 위치하여 실행된다`

라는 설명은 틀림

### 제어 프로그램과 처리 프로그램

과거 기출의 시스템 소프트웨어 분류에서는 제어 프로그램의 예로 다음을 구별함

- 감시 프로그램
- 작업 관리 프로그램
- 데이터 관리 프로그램

언어 번역 프로그램은 제어 프로그램이 아니라 **처리 프로그램**으로 구별함

### 바이러스 방지는 핵심 운영체제 기능과 구별

현대 운영체제에는 보안 기능이 포함될 수 있지만 해당 기출이 묻는 **운영체제의 전통적인 핵심 기능 분류**에서는 실시간 바이러스 침입 방지를 주요 기능으로 보지 않음

따라서 기출에서는 자원 관리·스케줄링·인터페이스·공유와 바이러스 방지를 구별함

### 채널·인터럽트와 장치 자동 인식 구별

채널과 인터럽트는 입출력 처리나 CPU의 작업 흐름과 관련된 개념임

장치를 자동으로 인식·설정하는 PnP, 전원을 켠 채 장치를 연결·분리하는 Hot swapping과는 다른 개념임

# 30. ADD-16 — 운영체제의 종류와 사용 환경

## 학습 본문

### 한 줄 핵심

운영체제는 **하드웨어 자원을 관리하고 응용 프로그램이 동작할 기반을 제공하는 시스템 소프트웨어**이며 사용 환경에 따라 여러 종류가 존재함

### 운영체제와 응용 프로그램 구별

| 예 | 구분 | 핵심 역할 |
|---|---|---|
| Windows | 운영체제 | PC 자원 관리와 응용 프로그램 실행 기반 제공 |
| Linux | 운영체제 | 다양한 PC·서버 등에서 시스템 자원 관리 |
| Android | 운영체제 | 모바일 기기 등의 자원 관리와 앱 실행 기반 제공 |
| 문서 작성·그래픽 앱 | 응용 프로그램 | 사용자의 특정 작업 수행 |

운영체제와 응용 프로그램을 구별할 때 제품 이름보다 **역할**을 먼저 확인함

- 하드웨어·메모리·파일·프로세스를 관리 → 운영체제
- 운영체제 위에서 문서 작성·편집·그래픽 작업 등을 수행 → 응용 프로그램

### 사용 환경

운영체제는 데스크톱·서버·모바일 등 서로 다른 사용 환경에서 사용될 수 있음

그러나 한 운영체제를 하나의 환경에만 고정하여 외우지 않음

예를 들어 Linux는 서버에서 널리 사용되지만 데스크톱 환경에서도 사용할 수 있음

따라서 이 챕터에서는

**운영체제의 사례와 역할을 연결**

하는 수준으로 학습함

## 직접 연결 기출

주 기출·보조 기출 **없음**

공식 출제기준의 운영체제 종류·사용 환경 범위를 보완하기 위한 기초 챕터임

직접 기출이나 출제 빈도를 새로 만들어 붙이지 않음

# 31. P1-23-02 — 운영체제의 성능 평가 지표

## 학습 본문

### 한 줄 핵심

운영체제 성능 평가는 **얼마나 많이 처리하는가, 얼마나 빨리 응답하는가, 얼마나 믿을 수 있는가, 얼마나 즉시 사용할 수 있는가**를 구별함

### 주요 평가 지표

| 평가 항목 | 판단 기준 |
|---|---|
| 처리 능력(Throughput) | 일정 시간 동안 얼마나 많은 작업을 처리하는가 |
| 응답 시간(Response Time) | 요청한 뒤 응답을 받기까지 얼마나 걸리는가 |
| 신뢰도(Reliability) | 오류 없이 정확하고 안정적으로 동작하는 정도 |
| 사용 가능도(Availability) | 필요할 때 시스템을 사용할 수 있는 정도 |

### 처리 방식과 평가 지표는 다름

`데이터를 일정 시간 모아 한꺼번에 처리한다`

는 설명은 운영체제의 성능 평가 항목이 아니라 **일괄 처리 방식**의 특징임

따라서 문제에서

- 처리 능력
- 신뢰도
- 사용 가능도
- 일괄 처리 능력

이 함께 나오면 `일괄 처리`만 다른 분류로 제거함

# 32. P1-22b — 컴파일러와 인터프리터의 번역·실행 방식

## 학습 본문

### 한 줄 핵심

기출의 전형적 비교에서는 **컴파일러는 전체 프로그램을 번역해 목적 프로그램을 만들고, 인터프리터는 한 문장씩 번역·실행**함

### 컴파일러

기출 기준 특징

- 프로그램 전체를 한꺼번에 번역
- 목적 프로그램 생성
- 번역 과정은 상대적으로 시간이 더 걸릴 수 있음
- 번역된 목적 프로그램을 실행할 때는 빠른 편

### 인터프리터

기출 기준 특징

- 한 줄 또는 한 문장씩 번역하며 실행
