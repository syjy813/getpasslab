# 시설 05번 이미지 타이포그래피·브랜드 표준 적용 기록

- 기준: `docs/standards/facility-content-guide-v1.4.md` §5.13, 신규 §5.13.6 (검토용 PR #244)
- 대상 문서: `src/content/facility/public-sector-comparison.md` (공개 URL, 본문 문구, 출처, 메타데이터 유지)
- 범위: `05/01-public-sector-hero.webp`, `05/02-employer-types.webp`, `05/04-pay-data-comparison.webp`의 **출력 이미지 교체**. 원본 `facility-assets/05/*.webp` 5장은 손대지 않음.
- 방식: `facility-asset-edits/05/*.svg` 3장을 편집 가능한 벡터 마스터로 보존하고 Astro 빌드 완료 후 Sharp로 1440×1080 WebP를 생성. 공개 이미지 URL 3개와 기존 공개 이미지 URL 22개 전체 유지.
- 색상: 포레스트 그린 `#114935`, 짙은 그린 `#0B4632`, 아이보리·연한 그린.
- 글꼴: 기존 한글 글꼴 우선, `NanumSquare, Noto Sans KR, Apple SD Gothic Neo, Malgun Gothic, sans-serif` 폴백 사용. 폰트 파일을 별도 첨부·배포하지 않음.

## 공통 타이포그래피 결정

- SVG 마스터: 1440×1080, 4:3
- 제목: 64px Bold, **x=80 / y=198(텍스트 기준선; 실제 글자 상단 약 140px)**, 좌측 정렬
- 부제: 30px Regular, x=80 / y=274, 좌측 정렬. 제목에서 시각적으로 약 16px 아래
- 브랜드: 기존 경로형 심벌 + GetPassLab 1개, 우측 상단 녹색. 장식 회차 배지·하단 중복 브랜드 없음
- 핵심 설명/카드는 본문과 모순되지 않도록 비교 구조만 표현. 공고 수치·기관 로고·재직 증명 같은 사실 주장 추가하지 않음
- 모든 새 마스터는 제목 및 부제의 정확한 SVG text 속성을 사용하며, WebP 변환 과정에서 임의 글꼴 축소 없음

## 검증 게이트

1. source SVG 3개의 Git blob SHA를 `scripts/check-facility-launch.mjs`에서 고정
2. 빌드 결과 WebP가 동일 마스터로 독립 재렌더링한 바이트와 일치하는지 확인
3. 시설 원본 24개 SHA·기존 published 이미지 URL 22개 목록 및 기존 공개 문서 목록을 그대로 유지
4. PC 1440px, 태블릿 768px, 모바일 390px·320px의 이미지 가로 넘침·비율·본문/캡션 배치를 기존 시설 QA에서 검증
5. 생성형 이미지가 기출·법령·수치의 출처를 대체하지 않음. 웹 이미지와 본문 내용이 어긋나면 문서 원본을 우선

실제 GitHub Actions 통과, PR 병합, 배포 및 실서버 QA는 실행 결과가 있을 때만 완료로 기록한다.
