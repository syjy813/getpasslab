| 위치 | 이전 | 수정 |
|---|---|---|
| 기출 안내 | 연결 기출로 개념의 출제 방식 확인 | 문제 버튼을 눌러 배운 개념을 적용해 보기 |

| 보조 기출 제목 | 기초 개념을 적용할 기출 | 함께 연습할 기출문제 |

| 입력 장치 | 긴 문장에서 세 가지 키보드 설정 나열 | 재입력 시간·반복 속도·커서 깜박임 속도를 세 줄로 대응 |

본문의 바탕 화면·바로 가기·일정 시간·우선순위 표기를 통일함. 고정 제목·slug와 원본 기출 표기는 변경하지 않음. 단독 접속어·강조문·문장 어미로 쪼개진 문단을 통합하고, 서로 붙을 수 있는 독립 안내는 목록으로 표시함.

보조 기출 안내에 회차·문항 번호를 붙여 어떤 문제에 대한 설명인지 구별함. 모바일 화면을 읽으며 남은 단독 조사·문장 어미를 추가 통합하고, 목록 뒤에 떨어진 설명은 목록 앞에 배치함. 키보드 설정의 중복 목록을 제거함.
