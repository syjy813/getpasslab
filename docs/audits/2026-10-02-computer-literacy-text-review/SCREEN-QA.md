검토 대상은 컴퓨터일반 1~81 본문·요약 및 기출 안내임. 81개 전체를 검토해 57개 수정하고 24개 유지함. 확인한 소스 커밋은 `2cec8b9ab00ce22c4b5bf876c9515b9195008276`임.

## 수정으로 해결한 문제

| 문제 | 수정 결과 |
|---|---|
| 편집자 관점의 ‘보존함·검수 보류’ 문구 | 학습자가 구별할 조건과 선택지 판단 안내로 변경 |
| ‘즉·임·라는 설명임’이 독립 문단으로 분리됨 | 앞뒤 문장을 연결하고 목록 설명을 목록 앞에 배치 |
| 바탕화면·바로가기 등 본문 표기 혼재 | 바탕 화면·바로 가기·일정 시간·우선순위로 통일 |
| 기출 영역에서 다음 행동이 불명확함 | 문제 버튼을 눌러 개념을 적용해 보도록 안내 |
| 보조 설명이 어느 문제에 대한 것인지 불명확함 | 각 설명 앞에 시험 회차·문항 번호 표시 |
| 키보드 설정 설명의 반복 | 목적별 세 줄로 정리하고 중복 목록 제거 |

제목·URL·챕터 순서·기출 배정·원본 문제·선택지·정답·이미지는 유지함. Unicode·SATA·포맷 및 과거 Windows 조건은 삭제하지 않고 수록 답안과 해석 주의를 함께 제공함.

## 후속 UI 검토 항목

스크린샷에서 광고 영역의 예약 공백이 본문과 기출 사이의 읽기 흐름을 끊고, 하단 관련 챕터 카드 6개가 짧은 챕터에서는 본문보다 길게 느껴짐. 광고 로딩 전후의 높이와 관련 챕터 노출 수는 별도 UI 개선 후보임. 이번 텍스트 수정에서는 CSS와 광고 동작을 변경하지 않음.

화면 QA는 Chromium의 viewport 에뮬레이션이며 실물 스마트폰·Safari 검증과 실제 수험생 사용자 테스트는 수행하지 않음. 광고·추적 요청은 차단된 미리보기 화면이므로 실제 광고가 로드된 상태의 가독성은 별도 확인이 필요함.
