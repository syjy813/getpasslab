# 시설 게시 이미지 일괄 개선

> 후속 사용자 승인으로 카드 73장의 하단 여백을 줄였다. 현재 `manifest.json`은 후속본을 가리키며 아래의 최초 4:3 제작 이력과 구별한다. 이전 manifest·마스터·파생은 보존되어 있다. 최신 규격·검증은 `../2026-11-06-facility-card-spacing/README.md` 참조.

## 범위와 기준

사용자 승인: 공개 시설 글 카드형 이미지를 공통 템플릿으로 재제작하고, 제목과 픽토그램의 연관성·깨짐·하단 문구 정렬을 검수한다. 대표/썸네일에서 사람을 제외하고 사람 표현이 필요한 글은 별도 보고한다. 새 범위의 Production 배포 승인은 아직 없다.

기준 main `ddcaecf638bf42c57651776336caea134daa4319` (PR254), 전용 브랜치 `codex/facility-image-bulk-refresh-20261106`. 중단 전 남은 미커밋 파일과 생성 원본을 그대로 이어 검수·보완했다.

적용 가이드: `facility-content-guide-v1.4.md` §5.13.1–8, §5.14; `learning-image-design-system-v1.md` §1, §5–7, §9의 브리프·원본보존·최종 표시 검수·기술 관계 왜곡 금지. 이번 그림은 시설 에디토리얼 비교·자료 확인 이미지이며 실제 배관 시공도·법정 서식 원본이 아니다.

## 결과물

- 공개13편: 총90장 = 대표13 + 카드77. 공공부문 비교 글의 최근 승인5장(대표1+카드4)은 유지·회귀검증한다.
- 나머지12편: 대표12 + 카드73 = 85장을 교체/추가한다. 각 글의 비교항목은 읽기 쉽게 2~3카드 묶음으로 분할한다. 원본64장과 과거 파생·승인 마스터는 보존한다.
- `hero-masters/`: 중단 전 생성된 사람 없는 대표 PNG12장. `masters/`, `specs/`: 정본 템플릿의 편집가능 SVG와 이미지별 제목·부제·아이콘·조건·행동문구 브리프. `facility-image-refresh/`: 검토한1440×1080 WebP85장.
- `manifest.json`: 글·이미지 URL·원본 매핑·마스터/파생 해시·렌더러 의존성. `inventory-before.json`, `previous-articles/`, `baseline-output.json`은 이전 상태 증거다.
- 본문 비교표·서술·출처·날짜·slug·공개 글 URL·자격증 콘텐츠·광고·CSS를 유지하고 이미지 태그·alt·치수만 변경한다. 기존 이미지 URL은 유지하며 분할한 추가 이미지 URL만 더한다.

## 그림 브리프·검수 방법

독자 질문: 글의 주제와 실제 확인할 자료/조건을 어떻게 구분할까?
캡션: 기존 본문 캡션을 유지한다. 카드에 담긴 수치·조건은 인접 HTML 표·목록과 대조한다.
표현: 대표는 글별 건물·설비·공고·서류 일러스트, 카드는 동등한 비교 또는 체크항목. 비교 대상 사이의 순서·우열 화살표는 추가하지 않는다.
색·라벨: 기존 포레스트 그린·아이보리, 정본64px/30px 제목·부제, 우상단 카드 로고. 대표에는 로고를 추가하지 않는다.
모바일 목표: 320/390px의 본문 전체 폭에서 비율·핵심 제목·윤곽·이미지 로딩을 확인한다. 상세 조건은 HTML에도 유지한다.

픽토그램 의미와 최종 래스터를12편 모두 육안 대조했다. 새28종은 24/26/30/31/104/140px에서 가시성과 프레임 밖 잘림을 검사하며, 기존 근무표·사업소의 도형간 간격 검사를 유지한다. 하단 행동문구·한줄은 각 글자 잉크를 측정하여 보정하고 최종 WebP에서 차이2px 이내를 검사한다.

## 검증 상태

최종 수행 결과는 `validation.json`과 PR Checks를 확인한다. 컨테이너 Chromium은 소켓 생성 제한으로 실행 실패하여 로컬 브라우저 검증 완료로 간주하지 않는다. 원격 CI의320/390/768/1440px 공개/검토모드 화면 검사를 사용한다. 실제 휴대폰·Safari·실광고·Production·검색 색인은 이 작업에서 확인하지 않는다.
