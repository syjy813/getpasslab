# 소방 2급 전체 패널 중심 챕터 개편

기준 main: `c308c4f728a661837b0b9c5f785bdc63fa383748`

사용자가 승인한 전체 패널 이미지 3장을 기준으로 기존 4개 챕터를 개편했다. 새 챕터를 늘리지 않고 기존 ID, URL, 학습 순서, 문제 배정과 정답을 유지한다.

| 챕터 | 개편한 학습 흐름 | 문제 연결 |
|---|---|---|
| FSM2-048 회로도통시험 | 전체 판 → ① 도통시험 선택 → ② 회로 선택 → ③ 도통 결과 → 표시등/전압계 비교 → 시험 종료 | 기존 FSM2-048 |

## 이미지와 본문 일치

- 승인한 PNG 3장을 무손실 WebP로 인코딩했다. `image-validation.json`에 원본과 픽셀 동일성 및 크기를 기록한다. 기존 SVG는 삭제하지 않는다.
- 전체 판과 부분 확대는 같은 WebP를 사용한다. CSS 창으로 해당 위치를 보여주므로 확대본의 스위치나 표시 상태가 전체 판과 달라지지 않는다.
- 수신기 두 그림은 동일한 부품 배치를 유지한다. 도통시험 정상, 예비전원시험 중 낮음의 서로 다른 표시 구역을 본문과 alt에서 명시한다.
- 펌프 그림은 주펌프가 **수동 선택이지만 정지 중**이다. 기존 FSM2-077의 ‘수동 기동해 운전 중’ 설명을 제거하고 두 펌프의 기동 꺼짐/정지 켜짐과 일치시켰다.
- 전체 판의 작은 라벨에만 의존하지 않게 11개 확대 영역과 HTML 설명을 제공한다. 전체 판 확대창은 1280px 이미지와 양방향 스크롤을 제공하고 닫을 때 원래 위치와 초점을 복원한다.
- CSS는 새 `fire-panel-lesson`, `fire-panel-dialog`에 한정한다. 다른 자격증과 기존 그림 확대 크기를 바꾸지 않는다.

## 적용한 작성·그림 기준

`CHAPTER_WRITING_GUIDE.md` 및 `docs/standards/learning-image-design-system-v1.md` v1.2 §§1–9를 확인했다.

- §§1–2: `figure-briefs.json`에 질문, 캡션, L2 범위, 판독 단서와 모바일 목표를 기록
- §§3–4: 선택 강조와 켜짐/꺼짐, 표시 이름을 병기. 배관·결선·압력 설정을 임의로 추가하지 않음
- §5: 승인한 원본 그림 제목을 보존하는 예외를 기록. HTML 캡션은 전체 판에서 찾을 위치를 안내하며 원본 제목을 그대로 반복하지 않음
- §6: 전체 판과 확대부는 PC/모바일에 동일한 에셋 사용. 실제 표시 폭과 가로 넘침은 브라우저에서 검사
- §§7–9: 승인 원본과 파생본 구분, 시각적 일치와 기술적 검증 범위 구분, build·브라우저·배포를 별도 상태로 기록

| moducbt-27775-q30, moducbt-27777-q33, moducbt-27778-q38 | 감시제어반과 MCC의 서로 다른 수동 기동 절차 |

수치와 기동 원칙은 기존 검수 본문 및 공개 문항의 제시 조건을 유지했다. 4~8V와 19~29V를 모든 기기의 공통 법정값으로 쓰지 않는다. 이번 작업은 제조사별 결선, 실제 제품의 표시 배치, 기동 설정값을 새로 확정한 검증이 아니다.

사용자 첨부 이미지의 상태와 승인한 파생 이미지에 맞춰 설명을 편집했다. 기존 출처 링크는 유지했다. 국가법령정보센터의 NFTC 102/203 링크를 다시 열었으나 동적 본문을 완전히 가져오지 못했으며, 이를 현행 전문 재검증으로 표시하지 않는다.

## 검사 구조

`check-fire-full-panels.mjs`는 현재 소스·에셋·공개 HTML을 직접 읽어 전체 목록과 바이트를 확인한다. 4개 챕터의 ID/URL/order/문제 공유, 이미지/확대부/alt, 기존 에셋 보존, 공개 문제 payload와 승인 문항 파일의 동일성을 검사한다.

이전 스냅샷을 현재 상태로 덮어쓰지 않는다. `review.json.gz`의 정확한 해시가 일치하는 변경만 `read-before-fire-full-panels.mjs`에서 이전 바이트로 되돌려 역사 검사를 수행한다. 모르는 변경은 그대로 노출된다. 이전 priority 검사는 그 릴리스의 계약을 검사하도록 이 계층을 통하고, 새 검사가 현재 상태를 담당한다. 격리 history guard에 필요한 helper와 메타데이터도 함께 복사하도록 갱신했다.

브라우저 검사는 `qa-fire-full-panels.cjs`에서 320/390/768/1440px × 4챕터를 검증한다. 기존 bulk/priority 브라우저 검사의 해당 챕터 이미지 경로·해상도도 갱신했다. PR QA와 향후 Production QA에 새 검사를 연결했다.

실행 결과는 `validation.json`, `browser-results.json`을 참조한다. 실제 단말과 Safari 검증, main 병합 및 배포는 별도 확인 대상이다.

## 후속 개정: 전체 판과 번호별 설명

사용자가 모바일 확대 이미지가 너무 크다고 피드백하고, 이어 부분 확대 대신 ①·②·③ 텍스트 안내를 제안했다. 추가 PC 화면에서도 확대 카드의 높이 차이와 빈 공간을 확인했다.

- 모바일과 PC 모두 부분 확대 영역을 숨기고 11개 번호별 설명을 한 열로 배치
- 확대 카드의 외곽선과 큰 여백을 제거. 제목 16px, 설명 14px 유지
- 전체 판 이미지와 전체 판 확대 버튼 유지. 원본 이미지·본문·문제·공개 URL은 변경하지 않음
- `text-steps-style.json`은 변경 전/후 CSS 해시와 이전 원문을 기록. 기존 `review.json.gz`는 그대로 보존
- 현재 네이티브 검사는 이 CSS의 승인된 개정을 검증하고, 역사 검사는 정확히 일치하는 CSS만 이전 바이트로 되돌림. 알 수 없는 변경은 숨기지 않음
- 브라우저 검사는 320/390/768/1440px에서 확대 영역 비표시, 번호별 설명의 세로 배치와 테두리 제거, 전체 판 확대와 원래 스크롤/초점 복원, 문제 연결을 확인

후속 개정 로컬 브라우저: 4챕터 × 320/390/768/1440px의 16조건 PASS. 모바일 도통시험과 PC 펌프 제어반의 번호별 텍스트 영역을 캡처해 육안 확인. 전체 판 확대, 스크롤/초점 복원, 기존 문제 연결 유지 확인.
