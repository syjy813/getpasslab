# GetPassLab 소방 설비 시각자료·챕터 세분화 초안 v1

작성: 2026-10-27 · 대상: 소방안전관리자 2급 · 상태: 구성·시각 초안, 사이트 미반영

## 1. 제안 요약

세 영상의 첨부 자막을 현재 챕터와 대조했다. 장치 이름, 작동 과정, 제어반 표시 판독, 점검·복구가 한 챕터에 섞인 부분을 나누는 안이다. 문제 하나나 버튼식/로터리식의 차이마다 새 챕터를 만들지는 않는다.

- 관련 기존 13개 챕터를 22개 학습 단위로 재구성하는 전체안: 기존 13개 유지·집중 보완 + 신규 9개
- 전체 74개 챕터는 전부 적용할 경우 83개가 된다. 신규 ID와 순서는 이 문서에서 확정하지 않는다.
- 1차 권장 범위: 수신기 동작시험, 감지기·발신기 신호 판독, 펌프 자동·수동 판독, 성능시험 배관, 준비작동식 제어반 판독의 신규 5개와 관련 기존 챕터 보완
- 2차: 릴리프밸브, 압력챔버, 수조 유효수량, 가스계 기동·방출 확인의 신규 4개
- 시각 초안 2장: 도통시험 상태 판독 / 감시제어반·동력제어반 상태 판독

현재 공개 주소와 기존 챕터 ID는 유지한다. 기존 본문에서 옮길 설명, 문제 연결, 관련 링크는 실제 구현 단계에서 함께 조정한다. 이 초안으로 사이트·문제 데이터·공개 URL을 변경하지 않았다.

## 4. 이번 시각 초안 2장

### 4.1 도통시험: 시험 선택·회로 선택·결과를 순서대로 읽기

- 연결: FSM2-048, 향후 챕터 3
- 학습 질문: 1구역을 선택한 도통시험에서 단선 표시가 켜져 있으면 무엇을 판단하는가?
- HTML 캡션 초안: ‘도통시험은 시험 종류·선택 회로·결과 표시를 순서대로 읽음’
- 유형/레벨: 비교·판독형 / L2 조작부를 알아볼 수 있는 학습 패널 재구성
- 근거: V1 11:15–19:25 및 28:39–30:29, 현재 FSM2-048
- 핵심 상태: 도통시험 선택, 1구역 선택, 단선 표시 점등. 화재·지구 표시와 분리
- 이번 시각 초안은 세 판독 영역만 남긴 개념 패널. 실제 수신기의 전체 조작부 배치나 표시 목록을 재현하지 않음
- 생략: 실제 배선도·감지기 연결 회로·전압 눈금. 영상의 ‘길’ 비유를 감지기 직렬 배선도로 그리지 않음
- 원본: 새로 만든 시각 초안. 기존 `end-of-line-resistor-circuit-v1.svg`는 변경하지 않음
- 색: 중립 회색/남색 패널, 선택은 파랑, 단선은 적색과 ‘단선 표시 켜짐’ 직접 라벨. 특정 제조사의 표준 색상이라는 뜻은 아님
- 예상 alt: ‘도통시험과 1번 회로가 선택되고 정상 표시가 꺼져 있으며 단선 표시가 켜진 개념 패널. 시험 종류, 선택 회로, 결과 표시의 순서로 읽음’

### 4.2 펌프 제어반: 모드와 실제 운전 상태를 따로 읽기

- 연결: FSM2-034, 향후 챕터 7·8
- 학습 질문: 감시제어반이 자동이고 MCC의 주펌프가 수동인 상황에서 운전 방식을 어떻게 읽는가?
- HTML 캡션 초안: ‘선택스위치로 운전 방식을, 운전 표시로 실제 상태를 확인’
- 유형/레벨: 상태 판독형 / L2 조작부를 알아볼 수 있는 학습 패널 재구성
- 근거: V2 15:51–18:29, V3 05:43–08:26, 현재 FSM2-034
- 핵심 사례: 감시제어반 자동·연동 / 동력제어반 주펌프 수동 기동 / 충압펌프 자동 선택·정지. 전원과 운전 표시 구분
- 모드별 허용 명령과 결선은 이 학습 예시의 조건이며 모든 제품의 우선순위를 확정하는 회로도로 쓰지 않음
- 생략: 실제 전력 결선·단자 번호·압력 설정값·전압값·자동 정지의 세부 회로
- 원본: 새 초안. 기존 `control-panel-normal-v1.svg`는 보존
- 예상 alt: ‘감시제어반은 자동·연동, MCC 주펌프는 수동 기동, 충압펌프는 자동 선택 상태인 학습용 제어반 비교. 전원 표시와 운전 표시를 구별’

두 이미지 모두 독립 검토용 인포그래픽이므로 이미지 안에 제목을 한 번 제공한다. 실제 챕터 삽입 때는 HTML 캡션과 중복 제목을 정리하고, 복잡한 내용은 한 장에 몰지 않고 상태별 카드·확대 이미지로 나눈다. 생성된 초안은 기술적 근거 자체가 아니며, 최종 글자·표시 상태·스위치 대응을 별도로 검수한다.

## 5. 디자인·제작 기준

GetPassLab `docs/standards/learning-image-design-system-v1.md` v1.2의 §§1–9를 적용한다. 캡션과 학습 질문을 먼저 확정하고, 장치 연결을 추측하지 않으며, 상태색과 유체색을 구분하고, 390px·320px 실제 표시 폭에서 글자를 확인한다.

- 밝은 배경, 남색 제목, 중립 회색 장치, 절제된 파랑 강조를 공통 사용
- 단순한 글자 상자 대신 버튼·선택 위치·표시등을 식별할 수 있는 장치 일러스트
- 색만으로 판단하지 않게 ‘켜짐/꺼짐/선택/점멸’ 병기
- 1장에는 핵심 사례 하나와 2–3개 판독 단서만 제공
- 원문 도판·제조사 제품 외관을 복제하지 않음
- 실제 배관·전기 결선, 성능 곡선·눈금처럼 정밀도가 필요한 정보는 생성 이미지로 확정하지 않음
- 시각 초안 생성: 내장 imagegen 사용. 4절의 제작 브리프를 바탕으로 밝은 배경·남색 제목·금속 질감의 개념 패널·큰 한글 라벨을 요청하고, 실제 결선·수치·제조사 표식을 제외. 생성 후 불필요한 시험 버튼을 제거하고 충압펌프의 정지 표시를 보정

## 6. 공개 반영 전 확인할 쟁점

1. 수신기 평상시 표시 목록·색상과 시험/복구 조작은 예시 기기별로 확인
2. 자막 마지막의 ‘모든 표시등 소등’을 교류전원 등 정상 표시까지 끄라는 뜻으로 쓰지 않음
3. 자동복구의 사용 조건과 누름·유지·해제 방식은 실제 예시 기기 자료로 확인
4. 주펌프와 충압펌프의 정지 조건을 동일하게 일반화하지 않음
5. 순환배관의 목적을 설명할 때 ‘압력이 무한정 상승’ 같은 과장된 비유는 빼고 기준에 맞춰 서술
6. 펌프 기동용 PS·유수검지장치 PS·가스계 방출 확인 PS의 감시 대상과 후속 표시를 구분
7. 준비작동식 밸브 개방·급수와 실제 헤드 방수를 구분
8. 가스계 방출 전후 안전 동작과 지연시간을 자막만으로 확정하지 않음
