## 범위 복원과 수량 정정

사용자의 요청은 도통시험 등 세 영상에서 제안한 원래 미완료 항목 전체의 제작이다. 작업 폴더의 `outputs/GetPassLab-fire-visuals-chapter-plan-v1.md`에서 원안을 찾았고, 이 폴더에 `original-proposal-v1.md`로 원문을 보존했다.

원안은 **기존 13개 보완 + 신규 9개 = 22개 학습 단위**다. 신규 22개를 뜻하지 않는다. 이전에 안내한 ‘신규 17개 잔여’와 별도 재선정 4개를 차감한 ‘13개 잔여’는 잘못된 집계였다. 원문 복원 사실과 정확한 범위를 사용자에게 알리고, 원안의 항목을 임의 대체하지 않고 완료했다.

- 이번 처리 10개: 남은 신규 4개 제작과 기존 6개 보완

- 원안과 다르게 재선정한 4개를 담았던 PR204는 병합하지 않고 종료. 소스 브랜치는 보존했으며 이 릴리스에 포함하지 않음. PR204의 임시 ID는 공개 배포되지 않았음

## 정확성과 근거

- 순환배관: 펌프와 체크밸브 사이에서 분기한 물의 경로와 과열 방지 역할. 주배관이 닫힌 체절운전 예시에서는 닫힌 밸브 너머에 흐름 화살표를 그리지 않음. 릴리프밸브는 스프링과 물의 압력을 비교하는 개념 단면이며 제조사 실물 포트/치수/스프링 사양/설정압력으로 주장하지 않음
- 압력챔버: 압력계/압력스위치/안전밸브/배수밸브를 각각 식별. 수원/물올림수조와 목적을 구별. 특정 포트 배치의 재현이 아니며 파란 점선 신호가 물 배관과 교차하지 않음
- 겸용수조: 일반급수와 소화용 흡수구 사이를 유효수량 범위로 판독. 유효높이 1.5m와 바닥면적 4㎡는 새 계산 예시이며 법정 고정 높이를 뜻하지 않음. 4×1.5=6㎥이며 5.2㎥ 기본 필요량 비교는 일반 기준 N=2 조건. 옥상수원 등 다른 의무까지 전체 적합이라고 결론내리지 않음
- 가스계: 제어반 기동 명령/솔레노이드/기동용기와 압력 검지/확인 표시를 구분. 무엇을 감시하는 PS인지는 제시 계통으로 판단. 기동 명령 또는 확인 표시만으로 모든 노즐의 실제 약제량까지 정상이라고 판단하지 않음. 전체 기동관 연결이나 공통 지연시간을 추정하지 않음
- 수신기: 예비전원감시가 이상 표시인 P형 수신기 예시. 모든 제품의 동일 표시/색/정상 조합을 주장하지 않음
- 그림은 소방학습용 자료이며 실제 작업의 차단/분리/방출 조작 매뉴얼을 임의로 생성하지 않음

확인한 1차 자료와 기존 승인 문항을 대조했다. 문제 원문/정답을 바꾸지 않았으며 새 출제 빈도나 실제 학습자 정답률을 주장하지 않는다.

1. [NFTC 102 현행 검색 본문](https://www.law.go.kr/admRulInfoP.do?admRulSeq=2100000281772): 2026-07-01 시행, 주/예비펌프 정의 및 수원 2.1.4/2.1.5 확인. 동적 뷰어에서 전문 전체를 읽었다고 주장하지 않음. 순환배관/압력챔버 기준은 기존 033/035 검수 본문과 승인 문항도 대조
2. [한국소방산업기술원 안내](https://hits.kfi.or.kr/portal/main/contents.do?menuNo=500265): 기동용수압개폐장치/압력챔버 역할과 구성 네 부품 확인
3. [기동용수압개폐장치 형식승인 기준](https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000215642): 압력챔버와 기동용압력스위치의 정의 확인. 과거 문서의 전체 조항을 현행으로 주장하지 않음
4. [공식 소방시설 점검표](https://www.law.go.kr/lbook/lbFileDownload.do?flExt=pdf&lbookConflSeq=104873&lbookSeq=105457): 기동장치와 방출 표시, 압력스위치 동작/표시 항목 대조
5. [가스계 소화설비 안전자료](https://www.seosan.go.kr/DATA/bbs/2964/20251111040826784no6IPy.pdf): 전기적 연동 정지만이 아닌 실제 기동/방출 경로의 안전조치 확인. 자료의 ‘30초’를 모든 설비의 공통 지연시간으로 쓰지 않음
6. 원안의 세 영상과 타임스탬프는 원안 문서에 보존. 이번 작업에서 원본 프레임을 재시청하거나 분실된 첨부 자막을 복원했다고 주장하지 않음

## 시각자료 기준

`docs/standards/learning-image-design-system-v1.md` v1.3 §§1–9를 실제로 읽고 적용했다. `figure-briefs.json` 작성 후 `render-fire-original-plan.py`로 새 기술 도식을 제작했다. 새 공개 SVG 8장(평상시 표시 포함), 공통 CSS 1개를 추가했다.

릴리프밸브/압력챔버/수조는 기능 부품을 알아보는 단면/구조 도식이며, 나머지는 역할 비교용 L1 도식이다. 특정 제조사의 실물 결선/포트 위치 또는 완전한 시공도가 아니다. 새 SVG 글자는 21단위 이상이며 380단위 공통 에셋을 사용한다. 물은 녹색 실선과 라벨, 기동 신호는 파란 점선과 라벨로 구별한다. HTML 제목은 한 번, `※ 학습을 위해 재구성된 이미지` 안내는 그림마다 13px 보통 굵기로 한 번 표시한다. 새 그림과 재사용 031 그림은 760px 확대, 037은 기존 600px 크롭 확대를 제공한다.
