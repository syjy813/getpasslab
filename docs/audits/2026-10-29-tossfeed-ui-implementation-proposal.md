- 상태: **구현 전 설계·완료 기준. 실제 제품 변경 없음**
- 근거: [실측·조작 QA 보고서](2026-10-29-tossfeed-cloud-browser-qa.md)
- 전제: 고정 Cloud 데스크톱 1363×936에서 확인. 지정 1440×900·390×844·320×700 및 실물 모바일은 미확인
- 원칙: 토스피드의 역할 분리·읽기 흐름을 참고하고 GetPassLab의 자격증 학습 구조·공개 URL·문제 데이터·광고를 보호

## 1. 구현 우선순위와 범위

| 순서 | 범위 | 시작 가능 조건 | 다음 단계 진입 기준 |
| --- | --- | --- | --- |
| 1차 / P0 | 공통 GNB·서비스 탐색 | 기존 공개 라우트 목록 확인, 시설 홈 목적지 확정 | 두 서비스 식별·기존 챕터 탐색·필수 폭·키보드 회귀 통과 |
| 2차 / P1 | 시설 홈·목록·카드 | 실제 시설관리 글·분류 데이터 확보 | 카드 상태별 탐색·빈 목록·긴 제목·뒤로가기 통과 |
| 3차 / P1 | 시설관리 정보 상세 | 공식 근거·기준일·정보형 글 1개 확보 | 결론·조건·예외·출처·관련 학습 연결 검수 |
| 4차 / P2 | 자격증 읽기 화면 제한 개선 | 4자격증 기준 캡처 및 기존 기능 회귀 목록 | 글자·여백·표·그림의 읽기 개선과 기존 기능 보존 |

시설 서비스 신규 URL은 이 문서에서 임의 확정하지 않는다. 기존 학습 공개 URL을 이동하거나 새 prefix로 바꾸지 않는다. **문제풀이·채점·모의고사 구조는 모든 단계에서 변경 제외**다.

## 7. 다음 UI 구현의 검증 가능한 완료 기준

1. GNB 시범 변경 전에 현행 4자격증의 대표 URL과 탐색/모달 기준선을 확보한다. 이번 1363px 근거는 재사용하되 **지정 폭 검증을 대신하지 않는다.**
2. 1440×900·390×844·320×700에서 두 서비스 표시·현재 위치·탐색을 실제 확인한다. 768×1024는 보조.
3. 로고·서비스 링크·자격증·과목·목차·카드→상세·뒤로가기·새로고침을 조작한다.
4. Tab·Enter/Space·Escape·Shift+Tab과 초점 복귀를 확인한다. 클릭 성공을 접근성 전수 PASS로 확대하지 않는다.
5. 기사 카드의 처음 로드·필터·뒤로가기·재로드·긴 제목·이미지 없음·빈 결과를 확인한다.
6. 기존 기출·정답·학습 그림·하단 탐색·광고·canonical 보존을 확인한다. 기사 UI 때문에 문제풀이 구조를 바꾸지 않는다.
7. 구현/Test/Build/Commit/Push/CI/Merge/Deploy/Production을 각 증거로 보고한다.
