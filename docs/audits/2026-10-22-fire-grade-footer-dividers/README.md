# FSM2-001 하단 섹션 경계 보완

본문 안 두 섹션에만 적용됐던 구분선을 문제 풀기·관련 챕터까지 확장함. FSM2-001에만 있는 `.fire-grade-lesson`을 포함한 article로 CSS 범위를 제한하므로 공유 레이아웃·문제풀이 스크립트·다른 챕터 구조는 수정하지 않음.

- 광고 다음 문제 풀기 제목 앞에 1px 회색 구분선. 광고 영역 끝에서 제목까지 PC 48px / 모바일 32px
- 문제 풀기 카드 영역 끝에서 관련 챕터 제목까지 같은 간격과 1px 선
- 두 제목 아래 카드/목록까지 16px
- 광고의 기존 하단 margin이 섹션 간격에 중복되지 않도록 이 챕터에서만 정리함. 광고의 높이·상단 간격·로딩·노출·위치는 유지함
- 기존 제목 바·본문·문제 링크·관련 챕터 링크는 유지함. 스타일 URL 버전을 갱신해 기존 CSS 캐시와 구분함

기존 본문 섹션 두 개뿐 아니라 하단 두 영역의 실제 간격과 선 표시를 네 화면 폭에서 측정하고 하단 경계 이미지를 저장함. 기존 릴리스 해시와 검수 자료는 수정하지 않으며 새 바이트만 정확히 역변환함.
