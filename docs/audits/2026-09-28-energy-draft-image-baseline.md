## 즉시 발견된 가독성 문제(소스 크기 기반, 브라우저 측정 아님)

- 현행 SVG 안의 보조 텍스트는 주로 `font-size=16`, 팬 라벨 `17`.
- 만약 `560` 폭 도식이 모바일에서 실제 `344 CSS px`로 표시되면 비율은 약 `0.614`. 내부 16은 **약 9.8 CSS px**, 17은 **약 10.4 CSS px**로 축소됨.
- 따라서 **SVG 선명도 자체와 읽기 쉬움은 별개**. 현재 운영 그림을 기준 시료로 삼되, 차기 개선 때 실제 화면의 글자 크기를 우선 보완해야 함.
- 실제 콘텐츠 너비와 글자 크기는 320/390px 브라우저 QA에서 확인 후 수치를 갱신.
