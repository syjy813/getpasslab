# 공통 기출 문제풀이 UI 정렬

기준 main: `4d8235fe86a1c39a04bde14d7f0c8764eee40149`

사용자가 첨부한 두 번째 화면의 팝업 소개 문장과 시험 연도/문항 번호를 제거하고, 닫기 버튼과 답안 선택을 소방안전관리자 2급 모의고사에 맞춤. 사용자 요청에는 수정 후 실서버 배포가 포함됨.

## 변경 범위

- 제품 소스 변경은 `InstantQuestionPractice.astro` 1개
- 닫기: 공통 `btn btn-secondary`, `창 닫기`, 44px 이상 터치 영역, 소방 모의고사와 같은 15px 글자/패딩/색/테두리/모서리
- 선택지: 눈에 보이는 원형 입력 표시를 숨기고 번호와 문장으로 표시. 카드 전체로 선택하며 색과 테두리로 상태 표시. 소방 모의고사의 패딩, 간격, 줄 높이, 모바일 16px/PC 17px 적용
- 네이티브 radio와 label을 유지해 단일 선택과 Tab/방향키/Space 및 보이는 키보드 초점 유지
- 일반 소개와 팝업의 시험 연도/원래 문항 번호만 제거. 문항별 주의와 채점 후 해설 상태는 유지
- 세 자격증의 실제 공통 팝업 406개에 적용. 공유 스타일의 빌드 경로 변경 때문에 챕터 HTML 530개에 새 CSS 참조 반영
- 문제 원문/선택지/정답/연결/해설 데이터, 기출 이력, 본문, 이미지와 공개 URL은 보존. 소방 모의고사 제품 소스도 유지

## 검증 방법

`review.json.gz`에 기준 파일 1,445개와 현재 파일 지문, 두 런타임 번들, 531개 파일의 정확한 역변환을 기록함. HTML은 소개/출처 삭제, 닫기 버튼, CSS/JS 참조의 다섯 가지 변환만 허용. 기존 감사 기록을 수정하지 않고 새 역변환 계층을 연결함. 알 수 없는 변경은 그대로 드러나도록 유지함.

소방 모의고사에서 실제 계산된 버튼 및 선택지 스타일을 읽어 3개 자격증 × 320/390/768/1440px의 12건과 직접 비교. 숨겨진 입력은 label 클릭으로 검사하고 키보드는 실제 Tab/방향키/Space로 별도 검사함. 기존 완료·재시작·오답/정답·이미지/주의 문항·네트워크 오류/재시도와 닫기/스크롤 복원 검사를 유지함.

PR CI에 참조 비교 검사를 추가하고 Pages 배포 후 같은 Production 비교 및 스크롤/채점 검사를 실행하는 워크플로를 추가함. 실행 결과와 배포 증거는 PR에 기록함. 물리 단말 및 Safari는 미검수.
