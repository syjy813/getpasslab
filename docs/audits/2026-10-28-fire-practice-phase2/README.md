# 소방 실무 2차 시각자료 보완

기준 main dac6daf77852e8dfe7d881b004ce414bf832607d(PR201 배포 완료). 사용자가 제안한 기존4개 챕터 보완과 실서버 배포까지 승인한 작업.

## 범위와 기준

- FSM2-039 습식 스프링클러 시험밸브함: 2차측 연결, 압력계용 콕밸브와 시험밸브의 시험/평상 상태, 방수구와 배수 경로
- FSM2-035 펌프 성능시험: 정격 대비 좌표를 계산한 예시 곡선, 체절 상한과 최대유량 하한, 실제 단위 환산과 판정
- FSM2-036 피토게이지: 직사형 관창, 물줄기를 마주 보는 입구와 D/2 위치, 0.20MPa 예시 눈금
- FSM2-040 준비작동식: 물 경로와 기동 신호 분리, 밸브 개방과 헤드 개방의 구별, 시험 상태 및 복구 조건

집필 정본과 학습 이미지 정본 v1.3 §§1–9를 적용. `figure-briefs.json`을 그림 전에 작성하고 공개 문항의 판단을 `question-review.json`에 연결했다. 원본 재사용을 검토한 뒤 기존 단순 SVG는 그대로 보존하고, 장치 식별성과 모바일 읽기를 위해 새 버전을 제작했다. 제목은 캡션, 안내는 `※ 학습을 위해 재구성된 이미지` 한 번만 표시한다. 내부에는 부품명/상태/값만 배치했다.

새 SVG4개는 `scripts/render-fire-practice-phase2.py`로 재생성 가능한 벡터 도식이다. 생성형 이미지를 기술 관계의 근거로 사용하지 않았다. 금속 음영은 외형 식별을 위한 표현이며 제조사 실물이나 시공도를 표방하지 않는다. 배관 접속, 닫힌 헤드 뒤 방수 없음, 피토관 방향, 44단위 노즐 구경과 22단위 거리, 0~1.0MPa 눈금의 0.20MPa 바늘 각도를 명시했다.

## 근거와 확인 범위

- 기존4개 본문, 원본 SVG와 공개 승인 문항을 우선 대조. 79챕터 및 메타데이터/ID/slug/order/related와 문항 배정/정답/승인 상태 보존
- 펌프 예시: 정격500L/min/0.60MPa, 체절0.81MPa, 최대유량750L/min에서0.37MPa. 0.84MPa 상한/0.39MPa 하한 계산. 정격점은100% 비교 기준이며 곡선을 제조사 인증곡선으로 표시하지 않음
- 피토게이지 D/2와 직각 측정 조건은 기존 본문 및 공개 문항 moducbt-27774-q33의 조건을 유지. 새 원본 사진이나 현행 점검 고시 전문을 확인했다고 주장하지 않음
- 준비작동식 그림은 밸브가 열리고 헤드가 닫힌 한 예시 상태. 차단/배수를 시행한 시험 상태와 물 공급 상태를 같은 그림에서 섞지 않음. 제품별 내부 트림/기동 압력/복구 방식은 생성하지 않음
- 공식 검색 본문의 NFPC102 제5조제1항제3호·7호로 압력/펌프 판정 수치를 대조. NFTC103 시험배관은 공식 기준집의 2.5.12.1~3 및 기존 검수 내용과 대조. 현행 NFTC 동적 뷰어는 전문 추출이 되지 않아 전체 현행 전문 재검증으로 표시하지 않음

## 검증과 배포

- 기존 소스/에셋과 공개 HTML의 현재1426파일 해시를 네이티브 검증. 새 에셋5개와 4본문/4HTML의 정확한 변경만 이전 검사에서 역복원. 과거 감사 스냅샷은 유지하고 미확인 변경은 숨기지 않음
- 320px에서 표의 본문 넘침을 찾아 표 내부 스크롤로 수정. 그림 라벨 겹침을 확인해 이동하고 피토관 거리/구경 비례를 교정
- 자동 검사와 브라우저 최종 결과는 `check-results.json`, `browser-results.json` 참조. SVG4개/4챕터×320/390/768/1440px, 확대/스크롤/포커스 복원/원래 문제 묶음과 문제 시작을 확인
- 최종 로컬 Build550페이지, 정적 검사56개 PASS. 새 브라우저16조건과 SVG4개 캔버스 경계/라벨 검사 PASS
- 기존 범용 이미지/탐색 회귀 검사에서도 대상4챕터×4폭16조건 PASS. 과거 검토 스냅샷은 보존하고 현재 이미지/확대 크기 및 통합된 절 제목만 런타임 기대값으로 연결
- 실물 제조사 검수, 물리 기기 및 Safari 검사는 미실행
- 원격 CI, 병합, Pages 배포와 실제 Production 검증은 각 실행 결과로 구별. 이 기록은 원격 업로드 전에 작성
