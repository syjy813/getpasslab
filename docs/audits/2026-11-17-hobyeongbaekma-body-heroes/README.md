# 호병백 본문 상단 대표 이미지 제거

사용자 승인: 이번에 목록 썸네일을 교체한 ep.0·호텔 2편·병원 3편·백화점 2편의 상단 대표 이미지를 제거하고, 최소 검증 후 실서버 배포한다.

제품 변경은 각 원고의 첫 figure 삭제뿐이다. 대학병원은 해당 figure에 딸린 캡션도 함께 제거한다. 다른 본문·메타·목록 썸네일·설명 이미지·공유 이미지·마트편은 유지한다.

`manifest.json`의 삭제 전후 SHA-256과 삭제 문자열/위치로 기존 원고를 정확히 복원할 수 있다. 기존 릴리스 보호 검사는 이 승인 차이만 복원하며, 출력 검사는 대표 이미지 부재와 기존 본문·내부 링크·메타·썸네일 유지를 확인한다.

검증은 기존 통합 이미지 검사, Production 빌드 1회와 대상 발행·공개 콘텐츠·SEO 검사로 한정한다. 광범위 로컬 브라우저 QA는 생략하며, 배포 후 대상 8편 HTML과 목록을 확인한다. 실제 성공/실패·배포 근거는 `deployment.json`에 기록한다.
