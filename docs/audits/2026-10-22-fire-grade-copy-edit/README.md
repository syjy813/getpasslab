# FSM2-001 문장·중복·표 편집

승인 범위: 앞선 검토안의 수정 및 실서버 배포. 적용은 소방안전관리대상물의 등급 챕터 하나로 제한함.

시험 포인트 5개를 3개로 정리하고 원 복원 문항 4개의 판단 근거를 새 항목에 연결함. 보류 문항은 계속 제외함. 1·2번의 층수 설명/사례를 통합하고, 5번의 중복 면적·별도 대상 정보는 표에 유지함. source-review.json에 현재 표의 모든 조건·공통 전제 및 3개 시험 포인트와 원문항 ID를 저장함.

예시에는 상위 등급 조건 배제와 법정 설치 대상이라는 전제를 유지함. 가연성 가스는 저장·취급량으로 표현함. 호스릴·주택전용 제외, 지하층 포함 여부, 면적별 제외 용도, 이상·미만 경계 등 정답을 바꾸는 조건은 유지함. 기존 법령 검수 자료의 한계(공개 PDF 구판)를 보존하며 현행 별표 전체 재검증으로 주장하지 않음.

기존 제목 앵커, 본문·하단 구분선과 간격, 문제풀기 링크, 기출 데이터는 유지함. 상위 등급 제외 문구는 불릿에서 별도 전제로 분리함. 표 행 제목을 상단 정렬하고 열/행 헤더 의미를 지정함. 스타일 URL 버전도 갱신함. 기존 검수 자료와 릴리스 해시는 바꾸지 않고 이번 편집만 정확히 복원함.
