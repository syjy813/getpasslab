# WEB 전달용 작업 결과서 — 시설 대표 이미지·썸네일 가운데 정렬

## 결론·변경 범위

- PR #246의 `a12572c1e9060c59ff05d33e8f3c6b4586a13d11` 기준으로 대표 이미지·썸네일 렌더러의 제목/부제를 가운데 정렬로 변경했다.
- 제목·부제와 모든 tspan을 x=720, text-anchor=middle에 배치한다. 캔버스·그래픽 외곽·안전영역의 가로 중심과 일치한다.
- 제목 64px/700·줄 높이 74px, 부제 30px/400·줄 높이 40px, 간격 16px과 각각 최대 2줄을 유지한다. 기존 자동 줄바꿈 폭 제한도 유지한다.
- 1줄 프리뷰를 재생성하고 각각 2줄인 JSON/SVG 예시를 추가했다. 두 요소가 모두 2줄이면 그래픽 시작 y가 114px 이동하며 하단 y=1000은 유지된다.
- 정본 시설 가이드 §5.13.8과 양쪽 README에 대표 이미지 가운데 정렬/카드형 헤더 좌측 정렬을 구분했다.
- 카드 렌더러와 카드 1~4장 SVG·JSON, 기존 콘텐츠·공개 URL·실서버 이미지·배포 설정은 변경하지 않았다. 로고의 우측 상단 위치와 1회 표시, 색상과 그래픽 슬롯 구조를 유지했다.

## 시작 상태·작업 환경

- 이 환경에는 사용자 PC의 로컬 체크아웃이 없다. 해당 PR 커밋의 관련 파일 22개만 GitHub에서 가져온 별도 작업 사본에서 검증했다. 사용자 로컬의 미커밋·미추적 상태를 확인했다고 주장하지 않는다.

- AGENTS.md에는 별도 WEB 전달용 결과서 서식이 없어 요청의 변경·검증·미완료 항목을 기준으로 이 문서를 작성했다.

## 적용 가이드·그림 브리프

- 정본 `docs/standards/facility-content-guide-v1.4.md` §5.13.6~8과 `docs/standards/learning-image-design-system-v1.md`를 확인했다. 학습 이미지의 §6~7·9에서 정한 기존 원본 보존·PC/모바일 구분·검증 상태 구분 원칙을 적용했다. 이번 대상은 학습 도식이 아닌 커버 템플릿이다.
- 목적/질문: 커버 제목·부제가 메인 그래픽과 같은 중심축에 놓이는가?
- 유형/표현: 기존 셸의 텍스트 정렬만 경미 수정. 메인 그래픽은 미리보기 슬롯이며 실제 기술 흐름·설비·수치·배관·화살표를 만들지 않는다.
- 문구/브랜드: 기존 샘플 문구 보존, 2줄 줄바꿈 예시 추가. 우측 상단 로고 1회. PNG/JPEG/WebP만 별도 슬롯에 삽입하는 원칙 유지.
- 기준 원본: PR #246의 기존 렌더러·공통 토큰·프리뷰. PC/모바일 공통 4:3 파일을 유지한다.
- 확인한 관계: text/tspan/캔버스/그래픽 슬롯 중심 및 줄 수별 세로 간격. 미확인: 실제 브라우저의 한글 자형·작은 표시 폭 가독성.
