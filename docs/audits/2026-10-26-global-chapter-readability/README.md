# 전체 공개 챕터 표·문장 가독성 적용

기준 커밋: `72b5f177e690f160a1184d1a90b5fbd6afcc36a1` · 2026-10-26

## 범위와 동작

4개 자격증의 521개 공개 챕터를 공통 `ReadableChapter`로 정적 렌더링한다. 산업안전 263개, 컴활 163개, 소방 74개, 에너지 21개이며 신규 본문에도 같은 표시 기준이 적용된다.

- 표 셀의 독립 항목을 작은 불릿과 줄바꿈으로 구분
- 본문에서 독립 문장을 이어 붙인 ` · `를 줄바꿈으로 표시
- 검토한 문맥 37개는 병렬·선택·공동 충족을 접속어로 명시
- 49개 유형의 긴 표 셀은 원래 조건과 순서를 보존하며 항목별로 분리
- 기호를 일괄적으로 `및` 또는 `또는`으로 바꾸지 않음. 짧은 분류명·수식·코드·단위·원래 숫자 나열은 보호

실제 본문이 달라진 챕터는 332개(산업안전 200, 컴활 39, 소방 72, 에너지 21)다. 나머지 189개도 공통 처리를 거치며 기존 줄바꿈 또는 보호할 기호를 유지한다. 새 목록으로 바뀐 표 셀은 577개이고 문장 구분 줄바꿈은 953개다.

## 보존과 구현

521개 Markdown 원문, frontmatter, 문항 연결 및 canonical 문항·선택지·정답은 변경하지 않는다. 정적 HTML에서 학습 본문 슬롯만 처리하여 광고·기출 팝업·모의고사·챕터 탐색은 유지한다. 브라우저 실행 스크립트나 추가 네트워크 요청은 없다.

parse5 7.3.0은 이미 잠긴 의존성이며 직접 의존성으로 명시했다. DOM 위치를 읽어 승인된 범위만 변경하고 전체 문서를 다시 직렬화하지 않는다. 기존 인라인 강조를 유지하고 표 항목 분리 시 열린 강조 태그를 닫고 다시 열어 잘못된 중첩을 방지한다.

`baseline.json`은 기준 커밋의 source/public 850개 파일, HTML 547개 및 521개 공개 경로를 고정한다. `review.json`은 네이티브 전체 SHA256, 승인된 역변환 조각 및 추가 파일을 기록한다. 과거 릴리스 검사는 이 정확한 변경만 되돌린 뒤 기존 고정 해시·문항·문자열 검증을 수행한다. 새 파일은 정확한 해시를 검사하고 새 검증에서 실제 존재와 전체 목록을 확인한다. 과거의 고정 증거 파일과 해시는 수정하지 않는다.

`check-global-chapter-readability.mjs`는 실제 네이티브 바이트, 전체 빌드 대조, 반복 적용 안정성, 숫자열, 수식·코드·이미지·링크·제목 및 본문 외 영역의 보존과 임의 변경 거부를 검사한다. 기존 4개 격리 mutation guard에도 새 역변환 의존성을 명시한다.

## 검토 근거

본문의 기존 의미와 연결 문항을 보존하는 편집이다. 과거 기출의 오답 조건은 틀림 표시와 수치를 유지하며 공동 조건임을 명시한다. 예: 접지공사 면제·생략 표의 `교류 대지전압 300V 이하·건조한 곳`은 **생략 가능 조건이라는 설명이 틀림**을 그대로 보존한다. 현행 면제 조건으로 새로 권장하지 않는다.

- 관계인의 대체 정의와 업무 병렬: 화재예방법 제24조·제27조 및 소방기본법 제2조의 기존 검토 근거 유지
- 특별피난계단의 `노대 또는 부속실`: 법제처 해석 [21-0432 등 인용 해석](https://opinion.lawmaking.go.kr/nl4li/lsItptEmp/443369)
- 제조물의 `제조되거나 가공된 동산`: [제조물 책임법 제2조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0002&lsiSeq=193381&urlMode=lsScJoRltInfoR)
- 상병보상연금의 공동 요건 및 간병급여의 `상시 또는 수시`: [법제처 생활법령정보](https://www.easylaw.go.kr/CSP/OnhunqueansInfoRetrieve.laf?onhunqnaAstSeq=82&onhunqueSeq=1793)
