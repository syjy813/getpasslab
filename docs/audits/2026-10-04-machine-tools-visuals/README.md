# 공작기계 움직임·핵심 부품 그림 4장 검토본

사용자 이미지 추가 요청에 따라 선반·수평형 밀링·드릴링 머신·플레이너를 새 SVG로 학습용 재구성함. 특정 제조사 기계 사진이나 실제 운전 수칙 도판이 아님. 그림 제작 전 brief.json에 캡션·적용 문항·핵심 관계·생략 범위·모바일 목표를 작성함.

학습 이미지 디자인 정본 v1.2 §§1–9 적용: L1 개념 도식, 중립색 구조·직접 라벨·회전/왕복 화살표, HTML figcaption과 SVG 제목 중복 방지, 360 viewBox/22 단위 라벨, PC·모바일 공통 에셋, alt/width/height, 방호·구동부 생략 표시. 이전 그림 복제나 외부 도판 복사 없음. 피트의 실제 구조·위치는 추정하여 그리지 않음.

원본 정본 24문항을 독해하고 CCOHS 및 NPTEL 자료와 기계 움직임·고정 관계를 대조함. 주 24문항/URL/frontmatter/기출 정본/원본 이미지는 불변. 이번 줄바꿈 배포 이후의 별도 검토용 PR이며 이미지 Production 배포는 미실행.
