# 소방안전관리자 2급 · 167문항 보완 및 재검수

기준: `8b4f765f2c3608d72e6e079347367339e61de424` · 2026-10-20 · PR #171 작업 브랜치

전수 1차 QA에서 답을 선택했으나 지적·주의사항이 있던 **167개 ID 전부**를 처리했다. **지문·선택지 82개**, **챕터 근거·해설 연결 85개**를 보완하고 연계 이론 **28개 챕터**를 수정했다. 167개 모두 수정된 조건으로 답을 다시 판단했으며 수록 정답과 일치했다. 정답 번호 변경은 0개다. 답안 일치 자체를 공개 승인으로 해석하지 않는다.

원본 500개의 추출문, 전체 2,480개의 ID·과목·핵심 표시·원본/변형 계열·정답 번호를 보존했다. 나머지 2,313문항은 행 전체가 동일하다. 편집한 원본의 표시문은 교정본이며 원본 화면의 정확한 복원으로 인증하지 않는다.

- 확인 후 유지: 별표 1은 실제 유도등 하위 항목으로 유도표지를 열거한다. 해당 보기를 오류로 바꾸지 않고 챕터에 근거를 보완

## 검증과 남은 범위

- Build: 545개 경로 생성 성공
- `node scripts/verify-fire-question-table.mjs`: 통합표·필터·HTML 동기화·공개 차단 검사
- `node scripts/check-fire-persona-corrections.mjs`: 현재 원본 파일·전체 행·167개 재풀이·28개 챕터·공개 상태·524개 학습 본문 해시 검사
- 과거 감사 기록의 golden hash와 최초 풀이 기록은 덮어쓰지 않음. 정확한 승인 변경과 보존한 이전 파일로 역사 검사를 재현
- 이번 실행의 전체 검사 결과는 validation.json 참조. 현재 수정본의 브라우저·실물 모바일 QA 실행 여부도 별도 표시

**기존 풀이 보류 152개는 이번 수정 대상 167개와 별개이며 보류 유지**다. 선택지 47개·도면/표시 60개·챕터 근거 45개의 원본 복구 및 재풀이가 남아 있다. 일부 챕터 추가가 이들에도 도움이 되지만 재검수 통과로 자동 전환하지 않았다. 변형 189개의 원본 선택지 반복과 심화 전체의 반복 구성 개선은 이번 범위 밖이다.

이 검수는 제공하는 챕터·표시 문항에 대한 모델 검수다. 같은 대화에서 저작·정답 정보를 이미 보았으므로 독립 블라인드 평가가 아니다. 모든 교재 쪽수·모든 해설 문장을 최신 외부 근거로 전수 감사한 작업은 아니다. 공식 보관 원문과 직접 연관된 기준을 대조했고 동적 사이트 일부의 현재 본문 재수집에는 제한이 있다.

모든 문항은 `pending / unpublished / examEligible:false` 유지. main 병합·Production 배포 미실행.

## CI 상태와 별도 화면 검증

PR 병합 미리보기의 기존 Fire QA #39401708662는 main에서 추가된 `AdFitFloating.astro`가 과거 파일 목록과 달라 실패했다. 소방 문항 보완과 별개의 통합 이슈이며 해당 검사를 제거하거나 통과 처리하지 않았다. 수정 28챕터의 새 절·모바일/PC 가로 넘침·문제 풀기 진입은 별도 `Fire persona content browser QA` 작업으로 검증한다.

학습 이미지 정본 v1.2의 §6·9를 읽고 390px/1440px 실제 렌더 기준을 적용했다. 이미지 파일·캡션·alt·연결은 수정하지 않았으며 그림 내용의 새 전수 시각 판독으로 주장하지 않는다.

main `991e9ad`의 기존 광고 컴포넌트·레이아웃 두 파일을 검토 브랜치에 통합했다. 광고 동작은 변경하지 않고 정확한 파일 해시·기존 레이아웃 보존본으로 역사 검사와 현재 소스850개 검사를 연결했다. 통합 후 로컬38개 검사 모두 다시 통과했다. 새 브라우저 검사에서 정상적인 `?chapter=` 링크를 경로 오류로 판단하던 조건도 URL pathname 기준으로 정정했다.
