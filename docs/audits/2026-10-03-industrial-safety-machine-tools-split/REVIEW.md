- 다섯 페이지를 `공작기계` 그룹으로 묶음 · 기존 자동 관련 챕터 링크를 활용해 비교 페이지 → 개별 기계 → 비교 페이지로 이동 가능
- 기존 비교 페이지에서 형삭기·금형 링크도 유지 · 페이지 공통 구성·스타일·기출 팝업 코드 수정 없음
- 과목 전체의 기존 정렬 로직은 유지 · 비교 페이지 관련 링크는 선반 → 밀링 → 드릴 → 플레이너 순서임 · 모바일 이전/다음은 현재 사이트의 그룹 탐색 순서에 따름
- 비전공자를 위해 각 기계의 움직임과 해당 본문에 필요한 용어를 도입부에서 정의함
- 반복되던 핵심 개념·시험 포인트·함정 요약을 기계별 설명으로 정리함 · 정해진 글자 수나 광고 심사 목적의 분량 확대 없음
- 이번 작업은 시범 분리임 · 나머지 분리 후보 및 학습 이미지 제작은 후속 작업임
