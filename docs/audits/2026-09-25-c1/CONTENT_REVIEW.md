# C1 이론→기출 적용 전수 검토

최종 검토일: 2026-09-26 · 대상: 현재 로컬 27개 챕터 · 원문·정답·배정 유지

## 결론

- 주 기출 63문항: 본문 근거 충분 54문항, 기출의 단위·용어 조건을 적용하면 풀이 가능한 문항 6개, 원문 타당성 주의 3문항
- 보조 연결 41건: 이 챕터에서 정답 판단 가능한 연결 15건, 일부 선택지·개념만 지원 23건, 원문 주의 승계 3건
- 중복 제외 70문항을 모두 읽고 검토 · 그림 2종은 실제 PNG의 내부 표기와 선택지를 직접 대조
- ADD-17은 배정 기출 없음 · 부품 목적·호환 조건의 개념 검토만 완료, 기출 풀이 검증 완료로 표시하지 않음
- 전수 검토 완료는 모든 기출 원문의 단일 정답 타당성 승인과 다름 · 주의 문항은 아래 보류 근거 유지

## 검토 방법과 한계

1. 현재 Markdown 본문과 canonical 문제의 전체 선택지를 읽고 정답을 고르는 최소 근거를 대응
2. 틀린 것을 묻는 문항은 본문으로 틀린 진술을 확정할 수 있는지, 맞는 것을 묻는 문항은 올바른 대응을 확정할 수 있는지 확인
3. 정답 판별에 충분한 근거가 있으면 나머지 선택지의 모든 용어를 본문에 추가하지 않음 · CPU 문제의 GIGO·ADPS 등은 불필요한 분량 확장 방지
4. 보조 문항은 해당 절에서 가능한 판단과 외부 챕터가 필요한 판단을 분리 · 주 기출 배정으로 승격하지 않음
5. 단위·인코딩·신호 방향·인터페이스·BIOS 등 버전과 표현에 민감한 부분을 아래 1차 자료와 교차 확인
6. 원문과 정답을 확인하면서 수행한 AI 검토이므로 블라인드 응시, 실제 수험생의 정답률, 모든 개별 문장의 독립 외부 검증을 뜻하지 않음

## 이번 수정

- 입출력장치: 입력장치가 아닌 것을 묻는 문제에서 펌웨어를 “제거”한다는 표현을 “선택”으로 수정
- 멀티미디어 보드: 그래픽 데이터는 디지털이며 아날로그 화면 변환은 디지털→아날로그라는 판단 근거 추가
- 문자 코드: 전자우편의 ASCII 기본 형식과 확장 지원을 구별하는 2줄 추가; Unicode 고정 16비트가 2019년에도 부정확했음을 명시
- 성능 수치: 보조 기출에 필요한 벤치마크와 패치를 2줄로 구별
- USB: 127을 물리 포트 보장 수로 오해하지 않도록 버스의 장치 주소와 구별
- SATA: 확인되지 않은 과거 호환 모드를 정답 합리화 근거로 사용하지 않음; ③도 일반 구조와 맞지 않음을 명시
- 컴퓨터 역사: 제시 정답 ①과 다른 보기의 “최초” 범위 생략을 명시
- 처리 방식: 보조 2문항의 안내를 본문이 실제 지원하는 판단 범위로 정정

## 계산·그림 점검

- 2⁸=256 · 1024³=1,073,741,824 · 2×1024²=2,097,152 재계산
- 1ps=10⁻¹²s < 1ns=10⁻⁹s < 1μs=10⁻⁶s < 1ms=10⁻³s 확인
- CPU 원본: ㄱ의 ALU·누산기→연산, ㄴ의 명령·번지 레지스터→제어
- 노트북 사양 원본: Core i5→CPU, UHD Graphics 620→GPU, 16GB DDR4 RAM→주기억, SSD 256GB→저장장치
- 문제 문장의 일반화와 이미지 자체의 판독을 구별 · 그림·선택지·정답 원본 변경 없음
