## 5. 유지해야 할 주의 조건

### `20150307_016`

- 과거 기출은 GB를 1024³ Byte 관례로 사용
- 현행 SI/IEC에서는 GB와 GiB를 구별
- 기출 원문·정답은 수정하지 않음

### `20190831_010`

- 과거 기출의 Unicode `1문자=16비트` 채점값은 보존
- 현재 Unicode의 일반 정의로 사용하지 않음
- UTF-16 코드 단위와 Unicode 코드 포인트를 혼동하지 않도록 현재 초안 유지

### `20190831_012`

- canonical 정답 ① 유지
- SATA가 병렬 방식이라는 ①은 핵심 오류
- ③ Master/Slave 문구는 기존 검수상 복수 쟁점이 남아 있음
- ③을 보편적 참 명제로 만들지 말 것
- 공식 복수정답이라고 새로 판정하지 말 것

### `20150307_019`

- 키보드 오류가 부팅과 무관하다고 일반화하지 않음
- BIOS 설정에 따라 부팅 중 주변장치 오류 처리 조건이 달라질 수 있다는 기존 사실검토 유지
- P1-46에서는 BIOS/펌웨어의 역할 보조 근거로만 제한

### `ADD-17`

- 직접 배정 주/보조 기출 없음
- 공식 출제기준 `PC 업그레이드` 범위를 보완하는 기초 챕터
- 본문 예시는 학습 예시이며 실제 기출이라고 표시하지 않음
- 출제 빈도를 새로 만들지 않음
