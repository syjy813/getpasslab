# FTA 기호 분리 그림 브리프

기준: 학습 이미지 디자인 시스템 v1.2 §§1–9. 기존 SVG 원본은 변경하지 않고 별도 파생본으로 구성. 생성 그림 없이 SVG의 검증 가능한 선화 사용.

| 항목 | 사상기호 | 게이트 기호 |
|---|---|---|
| 학습 질문 | 사각형·원·집·마름모가 어떤 사상인가? | AND·OR·조건 P를 가진 억제 게이트의 출력 조건은? |
| 캡션(제작 전) | 사각형·원·집 모양·마름모를 사상의 의미와 연결함 | AND·OR의 입력 관계와 억제 게이트 옆 조건 P를 비교함 |
| 유형/레벨 | 비교형 L1 | 비교형 L1 |
| 원본 | 기존 fta-symbols.svg 상단 + 20220424_030/20210814_033/20210515_032 PNG | 기존 fta-symbols.svg AND/OR/억제 부분 + 20190303_023 PNG |
| 근거 | 저장소 기출 5문항, NASA Handbook Table4-1 의미 확인 | 저장소 기출7문항, NASA Handbook Table4-1 출력 조건 의미 확인 |
| 변경 | 4개 도형 2×2 배치, 긴 의미 설명은 HTML로 이동 | 3개 검증 대상 도형만 재배치, 부정 게이트는 문장/조건 표로 설명 |
| 라벨 | 결함사상·기본사상·통상사상·생략사상 | AND·OR·억제, 조건 P |
| 의미색/선 | 중립 구조색/직접 이름, 기호의 기존 경계 형상 유지 | 중립 구조색, 입력·출력·P 직접 라벨 |
| 범위 | 사상의 형태 비교, 완성된 FT도 아님 | 연결된 전체 FT도 아님 |
| HTML/SVG 중복 | 이미지 내부에 카드 제목·긴 정의 반복 없음 | 이미지 내부에 카드 제목·긴 출력조건 반복 없음 |
| PC/모바일 | 공통360단위, 핵심20px→390px 실제 그림 약316px에서17.6px 목표 | 공통360단위, 핵심20px 및P18px |
| 접근성 | SVG title/desc와 HTML alt, width/height, 확대 링크 | SVG title/desc와 HTML alt, width/height, 확대 링크 |

원본·선택지·정답 변경 없음. 20180304_036은 선택지의 도형 원본이 현재 등록되어 있지 않아 해당 원본 그림 대조는 미확인(수록 답안3 통상사상 및 NASA의 house 정의만 확인). 부정 게이트는 기존 합본의 A 사각형 모형을 새 그림에 옮기지 않음. 공개 결과의 PC/390/320px 검사 상태는 PR 증거로 구분.
