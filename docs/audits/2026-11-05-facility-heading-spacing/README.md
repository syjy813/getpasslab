## 변경

- 시범 H2 `padding-top`을 기존 16px에서 기존 토큰 `--space-6`(24px)으로 변경.
- H2 위 마진48px·구분선1px·아래 마진16px, 짙은 그린·700 유지. H3와 본문 밖 제목, 다른 글의 화면은 유지.
- 정본 가이드 v1.4에 PR247의 미병합 색상·배경 기준을 통합하고 간격 표·체크리스트 추가. 기존 상단 여백 출발값은 구분선 위 마진/아래 패딩을 구분한 확정값으로 교체. 전체 확장 지침과 현재 한 편의 시범 적용 범위를 구분.
- 공통 CSS·콘텐츠·이미지·날짜·URL·데이터 구조 변경 없음. native guard의 레이아웃 blob 한 개만 갱신하며 기존 fingerprint는 보존.
- 기존 4폭 QA에 시범/비시범 H2 상단 패딩과 H2/H3 위·아래 마진 검증 추가.

## 검증 기록

실제 Build·보호 검사·출력 비교·공개/검토 모드 4폭 CI 및 배포·Production 결과는 해당 PR의 최종 기록으로 확인한다. 과거 감사기록은 수정하지 않는다. `output-delta.json`은 동일 환경의 변경 전후 clean 출력 비교 결과다.

시범 변경과 가이드 통합 완료 후 미병합 문서 PR247은 이 작업으로 대체 처리한다. 다른 글의 일괄 적용은 후속 작업으로 유지한다.
