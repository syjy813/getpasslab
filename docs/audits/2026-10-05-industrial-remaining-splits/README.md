- `originals/`: 분리 전 부모 7개 원문. 과거 감사 파일은 덮어쓰지 않는다.
- `question-source-review.json`: 54개 정본 지문·4지선다·답안과 새 배정. 기출 문구의 기존 오탈자·공백도 원문대로 보존한다.

## 외부 원자료 대조와 확인 범위
