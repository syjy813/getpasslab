## 가설통로의 경사와 안전난간

가설통로는 작업 중 이동할 수 있도록 임시로 설치한 통로임

| 항목 | 연결 기출의 기준 |
|---|---|
| 구조 | 견고하게 설치 |
| 경사 | 원칙적으로 30도 이하 |
| 미끄럼 방지 | 경사가 15도를 초과하면 미끄러지지 않는 구조 |
| 안전난간 | 추락 위험 장소에 설치 |

경사 상한은 계단을 설치하거나 **높이 2m 미만의 통로에 튼튼한 손잡이**를 설치한 경우 예외가 있음

작업상 부득이한 경우에는 필요한 부분에 한하여 안전난간을 임시로 해체할 수 있음

## 가설통로의 계단참

계단참은 이동 중 쉬거나 방향을 바꿀 수 있도록 마련하는 평평한 부분임

| 통로 | 적용 조건 | 설치 간격 |
|---|---|---|
| 수직갱에 가설된 통로 | 길이 15m 이상 | 10m 이내마다 |
| 건설공사의 비계다리 | 높이 8m 이상 | 7m 이내마다 |

계단·계단참 자체의 강도는 별도 챕터에서 확인함
