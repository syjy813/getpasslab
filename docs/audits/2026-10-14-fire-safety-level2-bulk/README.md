# 소방안전관리자 2급 나머지 73챕터 집필·검수

기준 main `4a00736b7ad4eb8f6e1acac189c44069167cc164`, 작업 브랜치 `codex/fire-level2-all-chapters-20261014`

사용자의 “남은 73개 챕터 일괄 집필·검수” 승인에 따라 정본 74챕터 중 기존 FSM2-037을 제외한 73개를 집필하고 사이트에 통합함. 배포·main 병합은 별도 승인 범위임. 자체 예상문제·모의고사는 이번 구현에 포함하지 않음

## 집필·근거

- 사용자 정본 목차 74개·500개 복원 모의고사 문항 연결 사용. 기존 챕터 번호·공개 URL과 원문 문제 데이터·정답·ID는 유지
- 1과목 49챕터, 2과목 25챕터. 목차의 그룹·학습 순서 적용. FSM2-037의 order만 37→40로 정렬하고 원래 본문·이미지·URL은 유지
- 최소 판별 개념 → 조건·계산·절차 → 오답 구별 방식으로 직접 집필. 명사형·~함과 문장 끝 마침표 생략 적용
- 법령·NFTC 수치 및 조건은 2026-10-14~15 조회한 공식 본문·별표와 대조. 법령의 미래 시행 별표와 현행 별표 구분. 응급처치는 2025 한국 CPR 지침·질병관리청·적십자 안내 대조
- `source-registry.json`에 URL·조회일·텍스트 해시, `editorial-decisions.json`에 불일치와 적용 판단 보존
- 복원 문항을 공식 기출·확정답안으로 취급하지 않음. `source-question-map.json`은 집필 범위 추적용이며 500문항 수록 정답을 공식 확정답안과 전수 대조했다는 증거가 아님
- `chapter-review.json`에 챕터별 범위·주/보조 문항·본문 소제목·공식 근거·이미지·검수 상태 기록
- 공개 본문에는 원문 복원문항·편집 메모·검수 판단·수록 기출 출제 이력 UI를 추가하지 않음. 적용 시점이 필요한 공식 기준 링크만 별도 표기

## 문항 적용 보완

최종 범위 대조에서 건축행위·옥탑 산정, 방화구획 면적, 보일러 연료별 이격, 소화기 감소, 옥외소화전 설치 대상, 열감지기 구조, 피난계획 세부 항목, 자위소방대 유형, 교육 원칙, 업무수행 기록 범위, 연기 속도 대표값과 소방계획 4단계를 보완함. 학습용 대표값은 법정 공통 수치로 단정하지 않음

## 이미지·화면

이미지 정본 `docs/standards/learning-image-design-system-v1.md` v1.2 §§1–9를 실제 열어 적용함. 제작 전 캡션·학습 질문·구조·범위·생략 관계·모바일 목표를 `image-briefs.json`에 작성함

- SVG 32개, 30개 챕터에 배치. 필수 이미지 목차 항목 모두 충족. 기존 스프링클러 PNG·4방식 확대는 보존
- 수치·회로·부품 연결·위치가 중요한 그림을 독자 SVG로 제작. 사용자 원본 PNG를 덮어쓰거나 편집하지 않음
- 기존 ChapterLayout·학습 카드·표·서체·2열/모바일1열 규격 사용. HTML 캡션과 SVG 부품·값 라벨의 역할 분리
- 320폭 SVG, 기본22px·최소20px 라벨, 의미색과 문자 병기, 연결과 흐름 화살표 구분. 임의 시공도·특정 제조사 회로로 인증하지 않음
- 같은 SVG를 PC·모바일 사용. 640px 확대·내부 스크롤, 닫기/ESC/배경 닫기, 본문 위치·inline style·포커스 복원
- 긴 표의 내부 스크롤 지원. 2과목 콘텐츠 추가로 나타난 과목 전환 메뉴의 모바일 화면 밖 열림을 소방 페이지 전용 스타일로 수정

## 보호 검사

`baseline.json`은 기존 src/public736개와 article451개의 해시. `release.json`은 정확한 추가·변경 경로/해시 및 원본 경로

기존 source 변경은 안내 문구, 기존 챕터 정렬값, 기존 소방 전용 CSS의 메뉴 위치뿐임. 기존450article은 바이트 동일. 기존 스프링클러 article은 원래 본문을 그대로 두고 공용 RelatedChapters가 새 관련 링크6개를 추가함. 해당 변화만 검증하고 과거 원문으로 투영하는 helper를 연결. 예전 audit JSON·해시는 덮어쓰지 않음
