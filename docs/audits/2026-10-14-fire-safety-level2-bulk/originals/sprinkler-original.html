스프링클러 방식과 작동 순서

습식·건식·준비작동식·일제살수식의 배관 상태와 방수 조건

핵심 개념

스프링클러 방식은 2차측 배관의 상태 → 헤드 형태 → 밸브 기동 조건으로 판별함

  • 1차측: 밸브로 물이 공급되는 쪽
  • 2차측: 밸브를 지나 헤드로 이어지는 쪽
  • 폐쇄형 헤드: 감열체로 닫혀 있다가 열을 받으면 개방
  • 개방형 헤드: 감열체 없이 방수구가 이미 열린 상태

스프링클러 4방식

아래 그림은 평상시 상태를 비교하는 학습용 재구성임 · 공급측은 가압수가 있는 것으로 가정하고 가압송수장치·상세 트림·시공 치수는 생략

작동 순서

방식작동을 시작하는 단서물 공급·방수 흐름
습식헤드가 열에 의해 개방준비된 물 방수 → 유수검지장치 작동
건식헤드 개방으로 기체 방출2차측 압력 저하 → 1차측 수압으로 밸브 개방 → 물 공급·방수
준비작동식감지기에 따른 밸브 개방2차측에 물 공급 + 헤드 열 개방이 모두 충족되면 방수
일제살수식자동감지 또는 수동식 기동일제개방밸브 개방 → 담당 구역의 개방형 헤드에서 일제 방수

준비작동식은 밸브 개방으로 물이 공급되는 조건과 헤드가 열에 의해 열리는 조건을 구분함 · 두 조건의 실제 선후는 화재 상황에 따라 달라질 수 있음

수동 기동도 가능하며 자동 기동 시 교차회로의 조건을 함께 확인

습식의 경보 신호와 펌프 기동

알람밸브·기동용수압개폐장치를 사용하는 경우의 작동 예시

  1. 열에 의해 폐쇄형 헤드 개방·방수
  2. 2차측 배관 압력 저하
  3. 1차측 압력에 밀려 알람밸브의 클래퍼 개방
  4. 시트링홀로 들어간 물이 경보용 압력스위치 작동 → 사이렌·밸브개방 표시
  5. 기동 설정압력까지 압력이 낮아지면 기동용수압개폐장치 작동 → 펌프 기동

클래퍼는 알람밸브의 내부 덮개임 · 경보용 압력스위치는 경보 신호를 전달하고, 기동용수압개폐장치는 배관 압력변동을 검지해 펌프를 기동함

현행 기준은 습식·건식의 펌프 기동을 유수검지장치 발신, 기동용수압개폐장치 또는 혼용으로 허용함 · ‘펌프가 항상 마지막’으로 일반화하지 않음

시험 포인트

문제에서 보이는 표현정답으로 연결
2차측까지 물 + 폐쇄형 헤드습식
2차측 압축공기·질소 + 공기압축기건식 · 공기 공급관의 2차측 연결 확인
감지기 작동 → 물 공급 + 폐쇄형 헤드준비작동식 · 헤드의 열 개방도 필요
개방형 헤드 + 일제개방밸브일제살수식 · 담당 구역에서 일제 방수
동결 우려가 있는 비난방 장소평상시 2차측의 물 유무로 방식 구별
습식 사이렌·밸브개방 표시의 직접 원인클래퍼 개방 후 경보용 압력스위치 작동
배관 압력변동에 따른 펌프 기동기동용수압개폐장치 · 경보 신호와 역할 구별

자주 틀리는 포인트

  • 준비작동식은 밸브가 열렸다는 사실만으로 방수된다고 단정하지 않음 · 물 공급과 헤드 열 개방을 모두 확인
  • 일제살수식의 평상시 2차측은 대기압 상태임 · 개방형 헤드라도 밸브가 물을 차단하므로 평상시에는 방수되지 않음
  • 습식 사이렌의 직접 원인을 감지기 교차회로나 펌프 기동으로 대체하지 않음 · 경보 신호와 펌프 기동의 역할 구별
