# 보일러 형식 그림의 구조감 개선 검토

- 대상: `boiler-types-construction` 챕터 첫 절의 원통형 3종·수관식 3종
- 기준: `docs/standards/learning-image-design-system-v1.md` v1.1의 L2 구조·단면형, 원본 정보 보존, 캡션/그림 분리, 모바일 390px 우선
- 사용자 원본: 「보일러 종류별 구조도 인포그래픽.png」 및 입형/횡형 보일러 비교 이미지. 원본 이미지는 이 PR에서 수정하거나 덮어쓰지 않음
- 공개 파생본: 각 형식별 생성 일러스트 6장을 1200×800 WebP로 최적화. AI 생성 그림이므로 실제 제품의 설계도나 특정 연소가스 왕복 경로로 해석하지 않음

## 그림 브리프

| 묶음 | 학습 질문 | HTML 캡션 | 그림이 구별할 구조 | 그림 밖 직접 기준 |
|---|---|---|---|---|
| 원통형 | 연소가스가 지나는 큰 노통, 여러 연관, 둘의 결합을 어떻게 구별하는가 | 원통형 보일러의 내부 구조 / 연소가스는 관 안, 물은 관 밖 | 한 동체 속 큰 노통 / 가는 연관 다발 / 노통+연관 | 각 구조에서 관 안 가스와 관 밖 물의 관계 |
| 수관식 | 밀도차 순환, 펌프 순환, 한 번 통과를 어떻게 구별하는가 | 수관식 보일러의 물길 / 물·증기는 관 안, 열은 관 밖 | 증기드럼·강수관·하부 헤더·가열 수관 / 순환펌프 / 드럼 없는 연속 가열관 | 드럼 ↓ 강수관 또는 펌프 → 헤더 → 수관 ↑ / 급수 → 관류 → 증기 |

- 유형/레벨: 비교형과 구조·단면형을 결합한 L2 학습용 재구성
- 색: 강재는 중립색, 관 안 가스·가열 영역은 주황색, 물은 파란색으로 표현. 색만으로 판단하지 않도록 HTML에 유체 이름과 방향을 병기
- alt: 6개 그림마다 다른 구조와 관내 유체를 서술. 그림 안에는 부정확한 AI 한글 라벨과 중복 제목을 넣지 않음
- 모바일/PC: 두 묶음은 PC 2열, 767px 이하 1열. 각 묶음 안의 3개 형식은 언제나 세로 순서. 각 이미지는 카드 안에서 최대 390px
- 원본 대비 보존: 버너, 금속 동체, 물 공간, 노통·연관의 실물 형태, 드럼·헤더·수관·펌프 및 관류식 연속관. 원본 하단의 광범위한 장단점·용도 표는 그림 안에 복제하지 않음
- 원본 대비 변경: 여섯 형식을 각각 분리하고, 이미지 안의 생성 텍스트 대신 검증 가능한 HTML 기준 문구를 사용. 첫 절의 기존 중복 요약 표는 제거하고 이후 시험 포인트 표는 유지
- 금지/주의: 실제 연소가스 다중 패스의 연결, 개별 노즐·안전밸브의 정확한 위치, 압력/용량 수치는 이 개념 그림에서 주장하지 않음. 빨간 가열 표현은 수관 안에 연소가스가 흐른다는 뜻이 아님
- 연결 기출: 기존 챕터의 143개 문항 및 공개 식별자는 변경하지 않음. 개별 그림이 143개 전체의 풀이를 직접 지원한다는 뜻은 아님

## 근거 및 검수

- 사용자 원본: 「보일러 종류별 구조도 인포그래픽.png」의 분류와 주요 부품 배치를 대조
- Spirax Sarco, [Shell Boilers](https://www.spiraxsarco.com/learn-about-steam/the-boiler-house/shell-boilers?sc_lang=en-GB): 연소 생성물이 관 안을 지나고 주변 보일러수에 열을 전달하는 관계
- Spirax Sarco, [Water-tube Boilers](https://www.spiraxsarco.com/learn-about-steam/the-boiler-house/water-tube-boilers?sc_lang=en-GB): 수관 안 물, 주위 열원, 강수관·상승관의 자연순환 및 강제순환 도입
- Spirax Sarco, [Water Levels in Steam Boilers](https://www.spiraxsarco.com/learn-about-steam/the-boiler-house/water-levels-in-steam-boilers): 관류/코일형의 증기드럼 부재
- Babcock & Wilcox, [Steam: Its Generation and Use (sample)](https://www.babcock.com/assets/PDF-Downloads/Steam-42-Sample.pdf): 관류식은 물이 관로를 한 번 지나 증기로 나가는 개념

## 검증 상태와 제한

- WebP 6개 파일은 각각 1200×800, 합계 약 535kB. 여섯 그림의 312×208 축소본에서 각 구조 형태를 확인함
- Astro Build 295페이지, SEO 0 경고/0 오류, 공개 콘텐츠 0 오류, 지연 기출 콘텐츠 0 오류 통과
- 실제 320px·390px 브라우저 화면 QA는 이 실행 환경에서 Chromium 다운로드가 실패하고 로컬 서버를 cloud browser가 열지 못해 미완료. 이미지 파일과 HTML의 치수·alt·경로는 빌드 산출물에서 확인함
- AI 생성 도안의 세부 볼트·노즐·화염 모양은 기술 근거로 사용하지 않음. 학습 판단은 인접 문구와 기존 상세 순환도에 기반함. 전문가 도면 검수가 아니라 개념 관계 대조임
- Main 병합·Production 배포는 이 PR 범위에서 진행하지 않음

## 디자인 가이드 개선 제안

v1.1의 L2 기준에 **원본과 후보 이미지를 나란히 보고 장치 형태만으로 분류 가능한지 평가**하는 검수 항목을 추가할 만함. 단순화로 원본의 구조감과 식별 정보가 사라지면 모바일 가독성이 좋아져도 재제작 또는 원본 활용으로 되돌리는 기준. 이번에는 제안만 기록하고 정본 가이드는 변경하지 않음.
