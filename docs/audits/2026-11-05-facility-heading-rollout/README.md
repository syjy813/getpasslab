# 시설 게시글 전체 소제목 스타일 적용

- 기준 main: `0b938c98b1a25b3f55cabc714bf1161c5f00e9a8` (PR249 시범 글24px 배포 완료).
- 사용자 승인 범위: 다른 시설 게시글에도 일괄 반영.
- 대상: 공개 시설 게시글13편의 본문 H2/H3. 미승인 초안 공개와 자격증 영역 변경은 포함하지 않음.

## 변경

- 시설 공통 CSS의 본문 H2에 기존 테마 `--primary-700`·700, 위 패딩24px 적용. 위 마진48px·구분선1px·아래16px 유지.
- H3는 기존 짙은 중성색·600과 위32px·아래12px을 유지. H1·요약·출처·관련 글 등 본문 밖 제목은 변경하지 않음.
- 공공부문 비교 글의 조건부 modifier·인라인 스타일을 제거. 모든 글이 공통 CSS를 사용하며 향후 같은 레이아웃을 사용하는 글에도 적용.
- 가이드 §5.11.1을 시범1편에서 전체13편 공통 적용 상태로 갱신.
- 기존4폭 QA에서 기존5편과 추가8편의 본문 제목 색·굵기·패딩·마진을 검증.

## 보호 검사

- 레이아웃·시설 CSS의 승인 blob2개만 갱신. 원본·이전 fingerprint는 보존.
- CSS 내용 변경으로 content-hash 파일명이 교체됨. 기존 공개 baseline을 수정하지 않고 `css-bundle.json`에 구/신 파일명과 SHA256을 고정. 공개 guard에서 정확히1개 번들 교체만 허용하고 새 바이트를 검증.
- 동일 환경 clean 출력 비교: 914개 유지, 시설 HTML18개는 번들 참조 변경(시범 글은 추가로 임시 클래스·스타일 제거), CSS1개 교체, 나머지895개 바이트 동일.
- 18개 HTML은 번들 참조와 시범 스타일 정리를 제외한 정규화 HTML이 동일함을 확인. 원고·날짜·이미지·공개URL·sitemap·자격증 결과물 유지. 상세 `output-delta.json`.
- 번들 검증 manifest 변경도 시설 QA를 실행하도록 workflow 경로 필터에 이 감사 디렉터리를 추가.
