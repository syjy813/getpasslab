# 사수골대·마트 목록 썸네일

## 승인 및 범위

2026-11-18 사용자가 기존 마트 희망편에도 부드러운 눈매를 적용하도록 요청했다. 이후 **배포하지 않고 Git까지만 업로드하며, 신규 사수골대 시리즈와 함께 출시**하도록 변경했다. 이 최종 지시가 이전 배포 요청보다 우선한다.

- 교체 준비 2종: 사수골대 ep.0 목록 이미지, 호병백마 마트 희망편 목록 이미지. 작업 브랜치에만 반영하며 main·Production에는 미적용이다.
- 사수골대 후속 8종: 현실성·눈매 수정 최종 WebP를 원고 폴더에 보관. 게시글·slug·URL을 만들거나 원고 PR #295를 병합하지 않는다.
- 희망편은 검은 타원형 눈과 완만한 눈썹, 절망편은 피로한 눈꺼풀·눈썹을 사용한다. 화풍과 업무 장면은 유지한다.
- 본문 원고·본문 대표 이미지·OG/canonical·공개 URL·레이아웃·의존성은 변경하지 않는다.
- main 병합·배포는 수행하지 않는다. 원고 공개와 이번 이미지 변경은 출시 시 함께 판단한다.

## 이미지 및 검증

- 원본 PNG는 생성 이미지로 보존한다. [manifest.json](manifest.json)에 최종 10종의 원본/파생 SHA-256·상태·치수·압축 정보를 기록한다.
- WebP는 1448×1086, 크롭·리사이즈 없음. 공개 ep.0은 278,588바이트, 마트 희망편은 185,386바이트다.
- 기존 불변 검사는 새 ep.0 목록 매핑 1행만 정확히 복원하도록 확장하고, 승인된 마트 이미지 지문만 변경한다. 본문과 OG 보호 검사는 유지한다.
- 로컬 Build 586페이지, 시설 발행·관련 링크·IA·불변 소스 보호·SEO·공개 콘텐츠 검사 PASS. SEO는 기존 경고 5개, 오류 0개다. 제품 소스 검사 이후 추가 변경은 인계/가이드/검증 문서뿐이다.
- 로컬 Chromium은 실행 환경의 socket/프로세스 제한으로 시작하지 못했다. 로컬 반응형 브라우저 QA는 미완료이며 PR의 기존 사수골대/시설 QA에서 320·390·768·1440px를 확인한다. 실제 CI 결과는 PR Checks가 정본이다.
- 최종 요청에 따라 Production 검증·배포는 수행하지 않았다.
