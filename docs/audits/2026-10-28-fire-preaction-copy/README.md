# 준비작동식 설명 문구 보완

- 대상: FSM2-040 `preaction-cross-zone-test`
- 사용자 피드백: 회로, 2차측, 기동 조건을 설명 없이 압축해 이해하기 어려움
- 변경: A와 B 감지 조건 → 밸브 개방과 헤드 쪽 배관 급수 → 화재열에 의한 헤드 개방의 세 단계로 설명
- 용어: A와 B는 감지기를 연결한 전기 회로이며, 2차측은 밸브를 지난 뒤 헤드로 이어지는 배관으로 정의
- 자동 교차회로 예시와 별도 수동 기동 경로를 분리하고, 같은 회로의 감지기 두 개는 A와 B 각각의 감지를 대신하지 못함을 유지
- 시험 시 2차측 차단 조건, 밸브 개방 확인, 복구 설명과 회로별 적용 조건은 유지
- 기존 그림, 캡션, alt, 재구성 안내, 챕터 메타데이터, 문제와 정답, 공개 URL 유지
- 근거 범위: 직전 배포의 검증된 기술 내용과 사용자에게 설명한 문장을 풀어 쓴 편집이며, 새 설비 요건이나 법정 수치를 추가하지 않음
- 이미지 정본 적용: `learning-image-design-system-v1.md` §5 본문과 그림 역할 분리, §6 모바일 검수, §9 웹 QA. SVG 수정 없음
- `review.json.gz`는 이 챕터 원문과 빌드 HTML의 두 변경만 SHA-256으로 식별. 과거 검수 기록은 수정하지 않고 정확히 일치하는 변경만 역변환
