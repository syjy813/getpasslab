# 모든 챕터 회색 수식 박스

사용자가 확인한 농도 환산 샘플을 모든 자격증의 챕터 수식 박스에 확대. 공통 global.css에 scoped 규칙을 두고 샘플 전용 CSS 및 article 클래스를 제거. 원문 수식·기출·본문은 변경하지 않음. 파란 h2, 표/일반 인라인 수식, 기출 팝업 유지. 기존 크기/여백/스크롤 동작 유지.

첨부 컴활 2급 제작 가이드의 원문·수식·숫자 보존 및 모바일 확인 기준 적용. 이번 작업은 표시 CSS 변경이며 새 콘텐츠 집필이나 사실 검수가 아님.

430개 기존 공개 챕터의 article HTML 및 질문 버튼 목록과 모든 미변경 src/public 지문을 기록. 3개 표시 파일의 정확한 변경을 역으로 적용하면 직전 배포 원문 지문과 일치. 과거 검증 기록은 수정하지 않고 후속 지문 chain에 연결.

Build/보호 검사/전체 챕터 320·390·1440px QA 및 최종 배포 결과는 PR 설명에 실제 결과로 기록. 실물 휴대폰 학습 효과 미검증.
