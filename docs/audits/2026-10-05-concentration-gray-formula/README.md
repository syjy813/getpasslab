# 농도 환산 수식 박스 회색 예시 — 2026-10-05

사용자 요청에 따라 농도 환산 한 챕터에서만 수식 카드 배경을 gray-100(#F2F4F6), 테두리를 gray-200(#E5E8EB), 수식 문자를 gray-800(#333D4B)로 변경. h2 파란 배경, 본문·기출·수식·크기·여백·다른 챕터 불변.

ChapterLayout의 조건부 클래스 1줄 및 기존 산업안전 스타일에 특정 클래스 색상 선언만 추가. 기존 스타일 원문은 삽입 부분을 제거해 정확히 복원 가능. 제공 HTML과 320/390/1440px 색상·페이지 넘침 및 기존 35개 기출 회귀 검사. 최종 Preview/Deploy/Production 증거는 PR 설명.
