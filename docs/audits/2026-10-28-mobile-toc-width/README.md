# 모바일 챕터 목차 너비와 말줄임

기준: 로컬 dac479b. 소방 이미지 문구 검토본 위에 이어서 구현. 원격 업로드, PR, Production 배포는 수행하지 않음.

## 구현

제품 변경은 `src/styles/global.css`의 767px 이하 규칙 6줄. 공통 GNB의 모든 자격증에 적용.

- 고정 360px 너비 대신 제목의 실제 너비에 따라 패널 크기 결정
- 기존 화면 양끝 24px 범위 안에서 최대 폭 제한
- 제목이 짧으면 패널을 줄이고, 최대 폭보다 긴 제목만 한 줄 말줄임
- 링크의 원래 전체 제목과 href 보존. 그룹 제목에도 같은 오버플로 처리
- 최소 44px 터치 높이, 현재 챕터 자동 스크롤, 하단 고정 바와 8px 간격 유지
- 768px 이상 목차와 일반 페이지의 자격증/과목 메뉴는 기존 규칙 사용

## 검증

- Astro build 550페이지 성공
- 산업안전/전기 `전력 공식` 390px: 기존 342px에서 약 211px로 축소. 목차의 모든 제목 표시
- Chromium 8대표 챕터 × 320/390/767/768/1440px, 총 40조건 PASS. 짧은 제목 전체 표시와 내용에 맞는 패널 폭, 실제 긴 제목의 말줄임, 가로 넘침 없음, 터치 높이, 기존 링크 및 마지막 항목 이동, 하단 바 간격 검사
- 컴활 컴퓨터 일반의 긴 제목 `형태를 만드는 모델링과 질감을 표현하는 렌더링`은 320px에서 말줄임 대상임을 실측
- 5개 화면 폭의 일반 페이지 자격증/과목 메뉴도 확인
- 물리 기기 및 Safari 검사는 수행하지 않음
- 현재 1421개 소스/에셋/HTML 검증. 챕터 본문, 그림, 문제 데이터 및 URL 불변. 생성 HTML은 전역 CSS 파일명만 변경됨
- 과거 감사 스냅샷을 유지하고 정확히 일치하는 이번 CSS/파일명 변경만 역사 검사에서 역복원. 미확인 변경은 숨기지 않음
- 자동 검사 54개 PASS. 감사 스냅샷은 전체 현재 해시와 정확한 CSS/파일명 패치만 저장해 중복 HTML 보관을 피함
- 자동 검사 최종 결과는 `check-results.json`, 브라우저 측정값은 `browser-results.json` 참조

관련 CI에 현재 파일 검사와 모바일 목차 브라우저 검사를 추가했으나 이 작업의 원격 CI는 미실행.
