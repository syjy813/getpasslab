# 소방 실무 세부 챕터 4개 제작

기준 main: `56a133d4406b57cda0b4c6311ca7255cf8e82e9a` (PR #203 배포 완료)

사용자는 기존 챕터 재보완보다 미제작 항목을 우선하고, 여러 항목을 일괄 제작하도록 요청했다. 원래 22개 제안의 전체 원문은 저장소와 PR에서 복원되지 않았고 Personal Context도 사용할 수 없었다. 현재 79개 챕터와 문항을 대조해 독립 챕터가 없는 세부 판독 주제 4개를 재선정한다고 알린 뒤 구현했다. **아래 4개가 원래 미제작 17개 목록의 확정 항목이라는 주장은 하지 않는다.**

| 신규 ID | 주제 | 기존 문제 묶음 | 순서 |
|---|---|---|---:|
| FSM2-080 | 수신기 평상시 표시와 스위치주의 | FSM2-047 | 56.05 |
| FSM2-081 | 주경종과 지구경종의 정지 대상 | FSM2-047 | 56.3 |
| FSM2-082 | 발신기 복구와 재경보 | FSM2-050 | 59.1 |
| FSM2-083 | 순환배관과 성능시험배관의 역할 구분 | FSM2-035 | 51.2 |

소방 챕터는 79개에서 83개, 전체 공개 챕터는 526개에서 530개가 된다. 기존 챕터 3개의 related 링크와 공개 개수 안내만 수정했다. 기존 79개 학습 본문, ID, URL, order, 이미지와 문제를 보존했다.

## 학습과 연결 문제

- 기존 승인 문제의 어떤 판단을 설명하는지 `figure-briefs.json`과 `question-review.json`에 기록
- 평상시 예시의 교류전원/전압지시 정상과 예비전원감시/스위치주의를 구별. 예비전원감시가 이상 표시인 수신기 예시로 범위를 명시하며 모든 제품의 표시 조합으로 일반화하지 않음
- 주경종 정지와 지구경종 정지는 대상이 다름. 화재 확인 전 경보부터 정지하도록 가르치지 않으며, 비화재 확인 후 원인 제거/수신기 복구/음향장치 정상 복귀를 구분
- 발신기 원위치가 수신기 복구보다 먼저. 수신기 복구가 발신기의 물리적인 누름 상태를 원위치로 바꾼다고 설명하지 않음
- 성능시험배관은 유량/압력 시험, 순환배관은 체절운전 수온 상승 방지. 그림은 역할 비교용 부분 도식이며 두 경로의 동시 운전이나 시공도를 뜻하지 않음. 생략 관계를 본문에 명시
- 원래 2,480행과 공개 승인 2,328문항, 보류 152문항 및 기존 74개 비어 있지 않은 문제 묶음을 변경하지 않음
- 새 문항을 배정하지 않고 `practiceChapter`로 기존 047/050/035 묶음에 연결. 버튼과 연결 챕터명으로 묶음을 알림

## 검증 근거

- 동방전자 [RP250 사용설명서](https://m.dbsy119.com/exec/front/Board/download/?filename=RP250_%EC%82%AC%EC%9A%A9%EC%9E%90%EC%84%A4%EB%AA%85%EC%84%9C_27-Nov-2017.pdf&no=10&realname=2019/08/16/0fa75a03f4a956c98d441b2efc29cd37.pdf) 3.2.5의 주경종/지구경종 정지 대상 확인. 이 제품의 모든 표시/연동 설정을 일반 P형 수신기에 이식하지 않음
- 한국소방안전원 [공동주택 소방계획서](https://cdn.kfsi.or.kr/kfsa/FILE/board/10045/2022/20220316110315213.pdf) p.53(파일 56쪽)의 비화재보 7단계와 현장 원인 제거/발신기 복구→수신기 복구→음향장치 복구 확인. 과거 자료의 관련 법령/선임 의무를 현행으로 인용하지 않음
- 국가법령정보센터 [2026 법령집 검색 본문](https://www.law.go.kr/lbook/lbFileDownload.do?flExt=pdf&lbookConflSeq=102659&lbookSeq=103701)의 NFTC 102 2.2.1.7/2.2.1.8 역할 구분과 기존 033/035 및 승인 문항 대조. 현행 기준 전문 전체를 읽었다고 주장하지 않으며 설치 치수나 릴리프 설정 압력은 새로 제시하지 않음
- 제공했던 영상 3개의 원본을 이번에 재시청하거나 분실된 자막을 복원했다고 주장하지 않음

## 시각자료와 가독성

`docs/standards/learning-image-design-system-v1.md` v1.3 §§1–9 적용. `figure-briefs.json`을 먼저 작성한 뒤 `render-fire-followup-chapters.py`로 380단위 SVG 4장을 독자 제작했다. 이전 그림은 전부 보존했다.

그림은 상태 및 대상 비교용 L1 도식이다. 기기 전체의 실제 외형/제조사 결선 또는 정밀한 시공도가 아니다. 상태색은 켜짐/꺼짐 문자, 두 경종은 정지 대상, 물은 녹색 경로와 부품명으로 함께 구별한다. 전기 결선과 유체 흐름을 같은 화살표로 혼동하지 않게 비교 범위를 본문에 설명한다.

제목은 HTML 1회, 안내는 `※ 학습을 위해 재구성된 이미지` 13px 보통 굵기로 1회 표기한다. 이미지 안에 제목이나 긴 안내를 반복하지 않는다. SVG 글자는 21~25단위이고 실제 모바일 표시 크기를 측정한다. 별도 모바일 그림 없이 공통 그림과 760px 확대를 제공한다.

## 보호 검사

새 네이티브 검사는 현재 1,441개 소스/에셋/HTML/사이트맵을 직접 검사한다. 추가 13개 파일과 기존 39개 변경을 해시로 확인하고, 기존 챕터 본문은 관련 링크 앞까지 동일함을 검증한다. 기존 소스의 변경은 관련 링크 3개와 안내 개수 1개로 제한한다.

과거 검수 기록을 덮어쓰지 않는다. 새 역변환 계층은 전체 파일 해시가 일치할 때만 정확한 이전 바이트를 복원하며 신규 파일도 해시가 일치할 때만 과거 목록에서 제외한다. 알 수 없는 변경은 그대로 드러난다. 기존 격리 변이 검사에 새 계층 의존성을 추가했다.
