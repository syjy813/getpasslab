## 그림 브리프와 수정 범위

| 대상 | 학습 질문 / 캡션 역할 | 원본에서 보존 | 수정한 판단·생략 범위 |
|---|---|---|---|
| 자연순환식 | 강수관의 물과 가열 수관의 물·증기 혼합물은 각각 어느 쪽으로 이동하는가 | 증기드럼·외부 강수관·하부 헤더·가열 수관 | 수관 안의 붉은색→파란색 오독 제거. 물은 아래, 혼합물은 위로 복귀. 노즐·화염은 설계도 근거 아님 |
| 강제순환식 | 자연순환 회로에 어떤 동력 장치가 추가되는가 | 같은 회로와 외부 물 순환펌프 | 수관 색의 상태 역행 표현 제거. 펌프는 강수관에서 헤더로 가는 물 경로에만 표시 |
| 관류식 | 급수는 드럼 없이 어떻게 증기로 나가는가 | 하부 급수·한 줄로 굽은 관·상부 증기 출구 | 관 안 색상 반복을 없애고 실버 관으로 통일. 물→증기는 HTML 문구로 직접 표기. 실제 증발 위치·세부 열설계는 주장하지 않음 |
| 상세 자연순환 | 실제 부품 위에서 복귀 회로를 추적할 수 있는가 | 기존 SVG의 드럼↓강수관→헤더→승수관↑드럼 | 교정된 실물형 그림에 별도 SVG 화살표 3개를 겹쳐 방향만 표시, 직접 경로 문구는 HTML로 표시. 이미지 내부 생성 글자 없음 |
| 원통형 3종 | 노통/연관의 형태를 구분할 수 있는가 | 큰 노통·작은 연관·동체의 물 공간 | 실물형 컷어웨이의 오른쪽 위 불명확한 굽은 관을 제거. 가스 반전·배출관 생략을 본문·alt에서 명시하고 상세 작동도라 주장하지 않음 |

- 유형/레벨: 수관식 비교는 L2 구조·단면형, 상세 자연순환은 실물형 단면 + 검증 가능한 코드 화살표
- 색: 파랑은 급수·보일러수, 흰 기포는 상승 수관의 혼합물, 주황은 관 밖 가열 공간, 실버 관은 내부 상태를 색만으로 단정하지 않음. 자연순환 경로는 녹색 단방향 화살표 3개 + HTML 라벨
- alt: 비교 그림 각각 다른 물길을 서술하고 상세 그림은 회로의 시작·복귀를 텍스트로 전달
- PC/모바일: 비교 그림 PC 2열/모바일 1열의 각 최대 390px 유지. 상세 그림 최대 800px, 모바일은 카드 너비에 비례해 축소, 경로 설명은 15px HTML 텍스트
- 확인하지 않은 디테일: 특정 기종의 노즐 위치·실제 연소가스 패스·증발 시작 위치·펌프 성능·압력 수치

## 기술 근거

- 사용자 원본: 자연순환 강수관 ↓ / 가열관 ↑, 강제순환 펌프, 관류식 한 번 통과 구조 대조
- Spirax Sarco, [Shell Boilers](https://www.spiraxsarco.com/learn-about-steam/the-boiler-house/shell-boilers?sc_lang=en-GB): 가스가 관 안, 물이 관 밖. 가스 패스 배치는 기종에 따라 다름
- Spirax Sarco, [Water Tube Boilers](https://www.spiraxsarco.com/learn-about-steam/the-boiler-house/water-tube-boilers?sc_lang=en-GB): 물이 관 안, 강수관 하강과 가열 수관 상승, 강제순환 도입
- Babcock & Wilcox, [Steam: Its Generation and Use (sample)](https://www.babcock.com/assets/PDF-Downloads/Steam-42-Sample.pdf): 자연순환의 밀도차·강제순환 펌프 및 관류의 단일 통과·드럼 부재
- Spirax Sarco, [Water Levels in Steam Boilers](https://www.spiraxsarco.com/learn-about-steam/the-boiler-house/water-levels-in-steam-boilers): 관류/코일형의 드럼 부재

## 검증 기록

- 신규 WebP 6장 각각 1200×800. 기존 v1 파일·원본·공개 챕터 URL·문항 ID는 유지
- 상세 경로 화살표의 세 위치는 왼쪽 강수관 ↓, 하부 헤더 →, 가운데 가열 수관 ↑로 수동 대조
- 그림 속 화염은 가열 영역의 시각화이고 수관 내부 연소가스나 실제 화염 접촉을 뜻하지 않음
- 로컬 Astro Build 295페이지 통과. 빌드 HTML에서 새 WebP 6장 참조(상세도에 자연순환 이미지 재사용)·실제 파일·1200×800 치수·alt, SVG 경로 화살표 3개 확인
- SEO 297 HTML/296 URL 경고·오류 0, 공개 콘텐츠 0 오류, 지연 기출 0 오류, 컴활 공개·C1 검증 통과. `git diff --check` 통과
- 여섯 그림의 312×208 축소본과 자연순환 상세도의 350px 합성 렌더를 시각 확인. 실제 320px·390px 브라우저 화면 QA는 이 실행 환경에서 접근 수단이 없어 미완료
- PR CI, Production 배포·공개 렌더는 아직 미실행. 각 단계는 실제 결과가 생긴 뒤 별도로 확인
