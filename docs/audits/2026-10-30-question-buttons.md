# 기출 이력 버튼 가독성 개선

- 기준 main `5dd17169258db92b68aa38d34dfa650cb82d1b98`. 모바일 타원 기출 버튼 글자 13→14px, 높이 최소 44px과 버튼 간격은 유지한다.
- `YYYY년 M월 시행` 형태의 버튼 표시만 `YYYY년 M월 · N번`으로 축약한다. 다른 표기는 그대로 유지하며 접근성 이름은 기존 `YYYY년 M월 시험 N번`을 제공한다. 문항 ID, 정답, 해설, 팝업 및 본문은 바꾸지 않는다.
- 기출 건수 메타는 파란 볼드에서 회색 세미볼드로 낮추고, 문제 풀이 안내는 최소 14px로 올린다. 파란 문제 풀기 버튼 크기와 문구는 유지한다.
- 소방 전용 문제풀이 화면은 별도 구성으로 이번 변경 대상이 아니다. 기출 이력 컴포넌트를 사용하는 챕터에 적용된다.
- 빌드·SEO·기존 콘텐츠 보존 검사를 진행하며, 320/390/1440px 버튼 가독성·레이어 및 회귀 결과는 CI에서 확인한다. 생산 서버 반영은 별도 승인 대상이다.
