# 소방 학습 그림 문구와 글자 위계 정리

기준: main 471b8e7. 현재 작업은 로컬 검토본이며 원격 업로드, PR, 배포는 수행하지 않음.

## 확인한 문제와 적용

- 카드 캡션보다 이미지 안 장식 제목이 커서 제목의 위계가 뒤집힘
- 카드 캡션의 안내와 래스터 이미지의 하단 안내가 중복됨
- 독립된 안내를 가운뎃점으로 연결해 기존 집필 규칙과 어긋남
- 대상과 상태를 직접 말하는 캡션으로 8개 챕터 정리. PC 17px, 모바일 16px, 700 굵기
- 안내는 `※ 학습을 위해 재구성된 이미지` 한 번만 표시. 13px, 400 굵기

## 이미지 처리와 보존

학습 이미지 정본 v1.3 §§1–9 중 원본 재사용, 캡션과 이미지 역할 분리, 중복 제거, 실제 표시 폭 검수와 확대 동작을 적용. `figure-briefs.json`에 각 그림의 캡션과 표시 범위 기록.

원본 WebP 7개를 그대로 재사용하고 HTML 표시 창에서 상단 장식 제목과 하단 중복 문구 영역만 제외. 기술 부품을 따로 잘라 만드는 상세 컷이 아님. 본문과 확대 보기에서 동일한 표시 범위 사용. 표시등, 스위치, 배관과 연결 경로의 원본 픽셀, alt, 번호별 설명, 시험 조건 및 기출 연결은 보존. 모바일의 작은 장치 라벨은 기존 1280px 확대 보기로 확인할 수 있음.

모든 src/public 및 생성 HTML의 현재 바이트를 `review.json.gz`로 검증. 이전 감사 스냅샷은 변경하지 않고 정확히 일치하는 이번 수정만 역사 검사에서 역복원. 미확인 추가 변경은 숨기지 않음.

## 검증

- Astro build: 550페이지 성공
- 현재 전체 파일 1421개 검증. 변경된 제품 파일은 8개 챕터와 공통 CSS. 기존 이미지와 문제 데이터 불변
- Chromium에서 8개 챕터 × 320/390/768/1440px, 32조건 검사. 가로 넘침, 이미지 로딩, 번호별 설명, 확대 및 스크롤/포커스 복원, 기존 문제 묶음과 390px 실제 문제 시작 확인
- 글자 크기와 안내 개수는 computed style로 검사. 원본/표시 창 경계 확인
- 물리 기기 및 Safari 검사는 수행하지 않음
- 자동 검사 53개 PASS. 브라우저 32조건 PASS
- 최종 자동 검사 결과: `check-results.json`, `browser-results.json` 참조
