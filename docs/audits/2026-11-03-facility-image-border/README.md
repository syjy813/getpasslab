# 시설 이미지 테두리·하단 브랜드 정리

기준 main `d58618c66f89a0968f60dda4167386ce274810b0`. 사용자 승인 범위는 시설 공개 이미지22장/목록 썸네일 수정·검증·Draft PR이며,main 병합·Production 배포는 별도 승인 대상이다.

## 결과와 보존

- 본문 이미지와 목록 커버에 기존 라운드를 유지하는 연한 회색1px solid 테두리 및 border-box를 적용했다. 자격증 이미지나 광고 이미지에 적용하지 않는다.
- 하단 한글 브랜드가 있는11장만 built-in imagegen `precise-object-edit`로 편집했다. 그림별 제목·부제·비교 항목·숫자·카드 순서·주요 인물/설비 배치를 원본과 육안 대조했다. 기존 그림 전체를 새 디자인으로 교체하는 작업은 아니다. 생성 결과의 모든 픽셀이 원본과 같다고 주장하지 않는다.
- 원본24장과 본문/alt/caption을 보존했다. 11장 파생은 `facility-asset-edits/{01,02,03}/`에 같은 파일명으로 저장,공개URL은 기존 `/images/facility-drafts/`를 유지한다. 나머지 공개11장은 원본 바이트를 그대로 사용한다. 제외된01-04/05-03도 계속 공개하지 않는다.
- 기존 상단 브랜드와 영문 GetPassLab은 이번 하단 한글 정리에서 유지한다. 신규 하단 한글 브랜드를 이미지 안에 생성하지 않도록 정본 시설가이드v1.4 §5.13을 수정했다.
- 파생11장 치수는 원본과 동일(10장1448×1086,1장1447×1087). 추가 크롭·리사이즈 없이 PNG 생성 마스터를 WebP quality90/method6으로 변환했다. 원본11장1,886,514바이트→파생11장2,267,994바이트로381,480바이트 증가했다. 글자 가독성을 우선했으며 LCP/CLS 수치는 측정하지 않았다.
