## 표시와 보호

홈의 기존 container 좌우24px을 광고 행에서만 상쇄하고 실제 document/부모 clientWidth 안에 고정 크기를 가운데 배치한다. 768px 이상에서는 신규 광고와 예약 영역을 숨기고 초기화하지 않는다. 작은 화면도 해당 단위 폭보다 실제 가용 폭이 작으면 전체 행을 숨긴다. 320px에15px 스크롤바가 생긴 client305 조건에서는300×250만 표시하고320×100은 초기화하지 않는다.

각 단위의 발급 ID·폭·높이는 그대로 사용한다. 기존 AdFit 비동기 SDK를 각 단위에1회만 로드하며, resize에서 이미 생성한 ins/script를 재사용한다. 요청 전 mount에 고정100/250px 높이와 광고 label 공간을 확보한다. 상단 카드/학습 안내와 광고 사이32px, 다음 section/푸터까지의 간격을 둔다. 관리자 설정(새로고침·소재 허용 등)은 코드에서 덮어쓰지 않는다.

PC 좌우 광고와 기존 목록/챕터 광고·기출/이미지·학습 탐색은 변경하지 않는다. 제품 수정은 `src/pages/index.astro`1개다. 콘텐츠/문항/이미지 원본·공개 경로·canonical·SEO는 유지한다.
