# 토스피드 참고 재검증 기록 — GetPassLab 가이드 v1.3

- 점검일: 2026-10-29
- 목적: 기존 v1.2의 '토스피드 참고' 표현 중 확인 사실·GetPassLab 해석·미검증을 분리
- 범위: 공개된 토스피드 메인/카테고리/정보형 아티클, 토스 기술 블로그 라이팅 글, GetPassLab main 소스
- **판정: 정보구조·텍스트/마크업 검증은 수행. 실제 연결된 PC Chrome의 클릭·스크롤·뷰포트 전환·픽셀 측정은 수행하지 못함.**

## 1. 어떤 방법으로 확인했는가

| 방법 | 실제 확인한 것 | 확인할 수 없는 것 |
| --- | --- | --- |
| 연결된 Chrome의 열린 토스피드 탭 **읽기 전용** | 메인, 기사 페이지의 링크·제목·버튼 이름 등 페이지 텍스트/마크업 | 사용자의 브라우저를 직접 클릭·스크롤·크기 변경한 결과, 화면 스크린샷 |
| 공개 URL 페이지 열람 | 토스피드 메인·카테고리·아티클 정보 구조, 날짜·필진·소제목, 공식 라이팅 문서 | 최신 렌더 CSS의 실제 적용값/모바일 UI 동작. 외부 페이지 텍스트 검색 결과는 수집 시점이 다를 수 있음 |
| GitHub 현재 `main` 파일 직접 확인 | `src/pages/index.astro`, `src/components/GNB.astro`, `src/styles/global.css` 등 구현 | 배포 시점의 Production 화면, 실제 모바일 브라우저에서의 동작 |

**주의:** 페이지에서 추출한 텍스트/DOM에는 화면에서 한 번만 보이는 요소의 중복 마크업 또는 숨김 메뉴가 포함될 수 있음. 텍스트 추출 순서·중복을 실제 시각적 배치나 결함으로 해석하지 않음.

## 3. 이 검증으로 수정한 기존 해석

1. **'토스피드의 서비스 스위치'라고 단정하지 않음:** 상단은 토스피드 내 콘텐츠 영역·도구의 메뉴. GetPassLab '시설의 모든 것/자격증의 모든 것'은 프로젝트가 정한 자체 서비스 구분
2. **'토스피드 전체가 결론 먼저·짧은 글'이라고 일반화하지 않음:** 정보형과 이야기형 아티클이 공존함. 정보형 기사에 한해 목적별 구성 참고
3. **'토스피드와 같은 카드·폰트·간격'이라고 쓰지 않음:** 픽셀 측정 근거 없음. 기존 GetPassLab CSS 토큰 우선
4. **'모바일 QA 완료'라고 쓰지 않음:** 버튼의 DOM 존재와 실제 탭·터치 작동은 별개
5. **'추천/인기'의 도입 조건 명시:** 실제 분류·콘텐츠와 추천 근거가 충분한 경우에만 노출. 근거 없는 인기·빈출 배지 생성 금지
