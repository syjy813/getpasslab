# 시설 카드 하단 여백 축소

사용자 승인 범위: 설명 마지막 줄과 하단 연두색 라벨 사이의 여백을 약 절반으로 축소하고, 좌우 라벨 정렬을 유지한 채 템플릿·카드73장·이미지만 나열한 HTML을 갱신한다. Production 배포는 포함하지 않는다.

기준 HEAD `4dd0775`, 작업 브랜치 `codex/facility-card-spacing-20261106`.

## 변경과 원본 보존

- 기본 렌더러를 재사용하는 `generate-facility-compact-infographic.mjs`에 축소 프로필 추가. 카드 행의 가장 긴 설명을 기준으로 라벨 앞 공백을 줄이고 카드 높이·푸터·프레임·캔버스를 같은 양만큼 조정한다. 본문과 아이콘의 크기·좌표는 그대로다.
- 73개 WebP를 `facility-card-spacing/`에 저장하고 SVG·JSON 브리프를 이 폴더의 `masters/`, `specs/`에 저장한다. 이미지 높이는 990/1010/1017/1036px, 가로1440px. 본문73개 이미지 태그의 예약 높이도 일치시켰다.
- 대표12장과 공공부문 비교 글5장은 바이트 동일. 이전85개 WebP·마스터·브리프를 유지하고 이전 매핑을 `before-manifest.json`으로 보존한다. 본문·표·날짜·출처·URL·alt·문구·픽토그램은 유지한다.
- 사용자 HTML은85장을 원래 순서로 포함한다. 외부 이미지 요청 없이 열리도록 WebP를 내장하고 실제 치수를 지정했다.
- 정본 가이드 §5.13.9와1~4카드 축소 프로필 예제를 추가한다. 기존4:3 샘플과 이미 짧은4카드2×2 배치는 보존한다.
