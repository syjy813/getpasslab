## 확인 방법

- 167문항을 조건·정답의 유일성·해설과 선택지의 대응·연계 챕터의 설명 범위로 재검토했다. 이미 정답을 본 같은 모델의 재검수이며 독립 블라인드 평가나 실제 수험생 정답률 측정은 아니다.
- NFTC 103 1.7.1.9·2.6.2.1, NFTC 102 2.2.1.3, 화재예방법 제24조·제50조·제52조 및 자체점검 고시의 보관 공식 원문을 관련 부분에 다시 대조했다. 자체점검 고시 제5조·제6조는 점검표와 성능시험조사표를 각각 별지 제4호·제5호서식으로 지칭한다. 최신 소방서 서식 안내의 검색 결과도 확인했으나 일부 동적 공식 사이트의 본문 재수집은 실패했다.
- 한국소방안전원 교재 전체를 새로 열어 쪽별 대조한 검수가 아니다. [기존 근거·수집 한계](../2026-10-20-fire-persona-corrections/sources.json)를 유지한다.
- 빌드 545경로, 통합표 재생성·동기화, 원본·정답 보존, 공개 차단, 현재·과거 데이터·SEO 등 전체 38개 검사를 실행해 통과했다. 해시 검사는 데이터 보존 검증이며 의미 정확성 검수를 대신하지 않는다.
- 새 브라우저 검사는 390px·1440px의 28챕터 56페이지 외에 **실제 보완 대상 167문항 × 2화면폭 = 334개 표시**를 비공개 검토표에서 확인한다. 파일은 테스트 요청에만 주입하며 공개 풀이 풀을 변경하지 않는다. 브라우저 실행 결과는 CI 완료 후 별도 기록한다.
- 학습 이미지 디자인 시스템 v1.2를 읽고 표시 폭·넘침 기준을 적용했다. 이미지 파일·기술 도판의 내용은 이번 후속 QA에서 새로 전수 판독하지 않았다. 실물 모바일 기기 검사는 미실행이다.

기존 풀이 보류 152문항은 별도이며 계속 보류한다. 모든 문항의 `pending / unpublished / examEligible:false` 상태를 유지했다. main 병합·실서버 배포는 하지 않았다.
