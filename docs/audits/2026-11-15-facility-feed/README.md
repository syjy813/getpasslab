# 모바일 커뮤니티 피드 레이아웃

사용자가 승인한 예시의 **왼쪽 썸네일·오른쪽 제목**을 홈·카테고리·관련 글의 모바일 일반 목록에 적용한다. 실서버 배포까지 승인된 작업이다.

- 기준 제품: `ea67d199ab0839a2fb569a66aff2df172da4194e` (PR #279).
- 640px 미만: 요약 숨김, 제목 전문 16px/600/1.5, 썸네일 원본 비율 유지. 폭 360px 미만 88px, 그 이상 96px. 제목과 간격 16px/20px.
- 항목 상하 28px·최소 높이 128px. 부모 행 간격 0, 두 번째부터 옅은 상단 구분선. 이미지 없는 항목도 같은 여백·구분선·요약 숨김.
- 기존에 제거된 목록 뱃지·날짜는 표시하지 않는다. PC·홈 대표 카드, 상세 원고/날짜/분류, SEO 데이터, URL, 원본 이미지와 공개 범위는 유지한다.
- `AGENTS.md`, `UI_UX_GUIDE.md` 타이포·반응형·접근성, 시설 통합 가이드 §4.4를 적용한다.

## 검증

- Node 24, 기존 lockfile·의존성 동일. Build 584페이지 PASS.
- SEO 오류 0·기존 경고 5, 공개 콘텐츠 오류 0, 시설 발행·관련 링크 163개·통합 이미지 보호 검사 PASS.
- [내용 비교](content-validation.json): 생성 HTML 586개가 시설 CSS 파일명만 정규화하면 기준 빌드와 모든 바이트가 같다. 목록 28페이지·134카드의 제목·이미지·링크·메타·상세 날짜가 보존된다. 모바일 요약은 CSS로만 숨긴다.
- `qa-facility-launch.cjs`의 기존 4폭 검사를 새 요구사항으로 갱신했다. 좌우 정렬·고정 썸네일 폭·중앙 정렬·요약 숨김·제목 잘림 없음·28px 여백·구분선·행 간격 0·PC 요약 유지와 기존 비율/탐색/넘침 검사를 수행한다.
- `delta.json`과 `read-facility-feed.mjs`는 이번 소스/CSS 변경만 정확히 복원한 뒤 이전 불변 검사를 실행한다. 과거 baseline이나 승인 원본 자산은 변경하지 않는다.
- 화면 CI, 병합, Pages 배포 및 Production 확인은 후속 검증 기록으로 연결한다. 로컬 브라우저 실행 제한은 이전 작업에서 확인되어 CI로 수행한다.
