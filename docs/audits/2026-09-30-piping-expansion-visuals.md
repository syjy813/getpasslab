- 그림 안 텍스트·유체색·화살표는 없음. 구분 단서는 HTML 카드 아래 14px 키로, 캡션 제목·한 줄 기능은 `figcaption`에만 둠
- 원본 에셋: 해당 챕터의 기존 그림 없음. imagegen 내장 도구로 만든 새 원본 PNG 4개에서 공개용 1254×1254 WebP 4개를 생성함
- PC·모바일 공통 에셋. PC 2열·767px 이하 1열. 이미지는 카드 폭 390px 이하, HTML 제목 18px·설명/키 14px. 390px·320px에서 실제 표시 확인은 별도 QA 항목
- 법령·시기 의존 수치 없음. 이 그림들은 형식의 대표적 외형을 비교하며 제작사별 제품 도면을 뜻하지 않음

## 기술 근거 및 경계

- Spirax Sarco, [Pipe Expansion and Support](https://www.spiraxsarco.com/learn-about-steam/steam-distribution/pipe-expansion-and-support): 가열에 따른 관 길이 증가, 고정점·슬라이딩 지지, 루프·슬리브·벨로즈의 구별 및 필요한 가이드
- STENFLEX, [Swivel joints](https://www.stenflex.com/en/products/swivel-joints.html): 회전 연결부와 벤드/엘보 조합 가능성. 이 자료는 특정 스위블 제품의 구조에 대한 근거이며, 그림의 나사·너트 형태 자체를 보증하지 않음
- **확인한 관계:** 네 유형을 식별하는 굽은 관, 동축 슬라이딩과 패킹, 금속 주름, 회전 이음/엘보 조합. 관련 기출의 형식과 설명도 대조
- **생략한 관계:** 유체 경로·운전 중 변위 단계, 지지점·가이드 배치, 실제 시공 방향/공차/설계 치수. 그림의 연결된 한 줄 관을 실제 증기 배관의 완전한 시공도로 읽지 않도록 본문에 범위 명시
- **미확인 디테일:** 생성 이미지의 용접 비드, 유니온·너트, 패킹 편조, 주름 수와 소재 마감은 임의 표현이며 제품별 사양의 증거가 아님
- 루프 그림의 상향 U자 형태는 형식 판별용 정면 투영. Spirax Sarco는 증기 배관 루프의 수평 설치 및 배수 주의를 설명하므로, 이를 수직 설치 권장으로 읽지 않도록 alt와 본문에 설치 방향 생략을 명시

## QA

- 이미지 품질: 네 그림 각각 1254×1254, 구조가 서로 구별되며 텍스트 중복·화살표·잘못된 물 상태색 없음. 슬리브의 내·외관 동축성, 루프와 스위블의 한 줄 연결, 벨로즈 양끝 연결을 눈으로 검토
- `npm run build`: 295페이지 성공, 대상 HTML에서 4개 이미지가 각 1회 참조되고 `dist/images`에 4개 파일 존재
- `npm run check:seo`: 경고·오류 0. `npm run check:public-content`, `npm run check:deferred-question-content`: 오류 0. `git diff --check`: 통과
- 320px·390px 실제 브라우저 캡처 및 Production 배포·확인은 아직 미실행
