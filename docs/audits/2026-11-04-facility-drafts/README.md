## 변경

- 한전FMS·우체국시설관리단·코레일테크·캠코FMC 4편과 법정선임·기계설비 등급·경력신고·보일러 선임 4편을 `status: draft`로 등록했다. 기존 공개 5편·경로·이미지 파생본은 보존한다.
- 기존 selective-assets 통합과 카드 커버 목록에 6~13번을 등록했다. 일반 빌드에서는 신규 원고·이미지 40장을 제공하지 않는다. `FACILITY_DRAFT_PREVIEW=1`은 로컬/CI 검토 전용이며 공개 배포하지 않는다. noindex는 접근 제어가 아니다.
- 검토 ZIP의 수정 원고·선정 이미지 40장을 그대로 사용한다. 한전FMS 붙임3 및 코레일테크 공개경쟁 공고 출처 문구 6곳의 `PDF`만 `문서`로 바꿨다. URL·쪽수·수치 보존. 다른 법령·채용 사실의 재검증은 이번 Git 반영 단계에서 수행하지 않았다. 발행 직전에 날짜·현행 근거를 다시 확인해야 한다.
- `draft-manifest.json`은 신규 8원고·40이미지의 해시다. 기존 공개 파일은 `public-baseline.json`으로 대조한다. Astro 내부 `.prerender` 임시 산출물은 공개 파일 집계에서 제외한다.
- 현재 native guard는 신규 원고·원본 에셋을 별도 해시로 검증하고, 기존 원본24장·파생12장·공개22장 및 나머지 소스/URL 검사를 유지한다. 카드의 추가 커버 목록만 새 blob으로 고정한다. 과거 snapshot과 역사 검증 도구는 수정하지 않았다.
- 시설 QA workflow는 공개/검토 모드 모두에서 새 정적 검사와 8편×4폭 브라우저 검사를 실행한다. 기존 홈/카테고리 QA도 검토 모드의 13편·채용5편·법정선임4편에 맞췄다. 일반 공개 모드의 5편 기대값은 유지한다.
