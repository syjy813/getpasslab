# 소방안전관리자 2급 문제 풀기

사용자 요청: 다른 자격증의 ‘기출 출제 이력’ 위치에 소방 전용 ‘문제 풀기’를 두고, 챕터별 풀이와 전체 모의고사를 제공함. 기준 커밋 `9140bf1685283f79d827ccc0ab933115f0c75b26`, 기존 초안 PR #171을 이어 작업함.

## 제공 기능

- 공개된 소방 챕터 74개에 ‘이 챕터 문제 풀기’, ‘전체 모의고사 풀기’ 링크 추가
- 챕터 풀이: 해당 chapterId의 공개 문항 전체를 무작위 순서로 풀고 문항별 정답·해설 확인, 시간 제한 없음
- 전체 모의고사: 1과목 25개와 2과목 25개, 60분. 원본과 그 변형을 같은 시험에 중복 출제하지 않음
- 모의고사 제출 전 답안 변경·문제 번호 이동, 미응답 수 확인 및 제출 취소, 시간 종료 시 자동 제출
- 과목당 문항 4점, 각 과목 40점 이상 및 평균 70점 이상 판정. 결과의 문항별 정답·해설과 해당 이론 챕터 링크 제공
- 새 문제로 다시 풀기. 로그인·서버 저장 없이 새로고침/페이지 이탈 시 기록 초기화
- 잘못된 챕터 ID는 오류 안내하고 시작 차단. 과목별 공개 문제 부족 시 짧은 시험으로 대체하지 않음

시험 형식 근거: [한국소방안전원 2급 시험 안내 Ver 26.1, 3쪽](https://safe.kfsi.or.kr/assets/downloadDoc/33.pdf), 2026-10-20 확인. 무작위 문항 구성은 자체 모의고사 기능이며 공식 기출 회차 재현이 아님.

## 공개 조건과 문항 정본

문항 정본은 기존 `docs/drafts/fire-level2-mock-exam/question-table.json` 하나를 유지함. 새 문항 저장소나 복사본을 만들지 않음. 현재 원본 복원 500개·변형 500개·기본 740개·심화 740개, 총 2,480행 모두 검수 대기 상태를 유지함.

빌드 타임에 다음 세 조건을 모두 충족한 행만 브라우저에 전달함:

1. `reviewStatus: approved`
2. `publicationStatus: published`
3. `examEligible: true`

공개 승인된 행은 추가로 고유 ID, 1/2과목, 챕터 연결, 같은 원본 계열의 과목 일치, 4개 비어 있지 않은 선택지, 1~4의 정답 번호, 해설, `contentStatus: draft_complete`를 검사함. 승인 행의 구조가 잘못되면 빌드를 실패시킴. 원본의 OCR·선택지·도표·답안 대조가 필요한 행을 임의 승인하지 않음.

현재 공개 승인 문항은 0개이므로 실제 빌드의 풀이 화면에는 ‘문제 준비 중’을 표시하고 시작을 차단함. 문항 본문·답안·원본 추출 텍스트는 공개 HTML/JS에 포함하지 않음. `핵심`은 원본, `핵심 변형`은 파생 문항이라는 기존 통합표 기준을 유지함.

## 검증 범위

- 로컬 `npm run build`
- `scripts/check-fire-practice-logic.mjs`: 공개 조건 8조합, 불완전/중복/과목 충돌 승인 데이터 차단, 과목별 25개 및 원본 계열 중복 없는 100회 표집, 원본 순서 보존, 문항 부족, 점수·합격 경계
- `scripts/check-fire-practice.mjs`: native src/public 전체 지문, 74개 진입 영역만 추가, 기존 524개 학습 본문 및 정본 기출 보존, 실제 빌드에서 초안 문항 제외
- `scripts/check-fire-practice-history-guard.mjs`: 격리된 임시 디렉터리에서 새 소스·이전 원본·article·추가 파일·삭제 변이 검사. 과거 골든해시는 유지하며 정확한 후속 변경만 역투영
- 기존 전체 `scripts/check-*.mjs` 검사
- `scripts/qa-fire-practice.cjs`: 자동 브라우저 QA 추가. 실제 빌드의 대기/잘못된 챕터, 74개 챕터 모바일·PC 진입 영역, 합성 문항으로 풀이·답안 복원·제출 취소·50문항·70점 경계·재시작·자동 제출·텍스트 주입 방어, 기존 3개 자격증 팝업을 검사하도록 구성

브라우저의 합성 문항은 테스트 요청 응답에만 주입함. 문항 정본이나 승인 상태, 실제 빌드 산출물은 변경하지 않음. 로컬 환경에서는 Chromium 다운로드가 유효한 설치 파일을 반환하지 않아 실제 브라우저 QA를 실행하지 못했음. 저장소의 Fire safety level 2 launch QA에 위 스크립트를 연결했으며 실제 CI 결과는 PR Checks가 기준임. 실물 Safari/iOS/Android 검증은 미실행.

학습 이미지·기존 챕터 MD·기출 정본은 변경하지 않았음. 전체 문항 내용 검수·main 병합·Production 배포는 미실행.
