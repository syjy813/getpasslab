## 변경 동작

1. 고정320/728px 광고가 실제 document clientWidth에 들어가지 않으면 광고 내용 표시/초기화를 보류한다. 기존 광고 단위·슬롯·예약 높이는 유지하며 자르거나 축소하지 않는다. 이미 로드한 광고도 resize·스크롤바 변화에 따라 숨김/복원하고 중복 생성하지 않는다.
2. GNB에 자격증 서비스 이름과 선택 메뉴를 표시한다. 챕터에서는 자격증 선택과 기존 챕터 목차를 함께 제공한다. 모바일은 짧은 표시명과 전체 접근성 이름을 구분한다. 한 메뉴만 열리고 Escape·외부 클릭·키보드 초점 이탈로 닫힌다. Escape는 해당 summary로 초점을 돌린다.
3. 홈을 짧은 소개→4자격증 선택으로 구성하고 모바일 제목의 한 글자 고립 줄을 피한다. 4개 카드의 실제 챕터/기출 집계를 유지한다.
4. 자격증 허브는 시험 선택을 통계보다 먼저, 시험 목록은 과목 선택을 빈출 챕터보다 먼저 배치한다. 과목 목록은 기존 그룹 ID로 바로가기를 제공하고 작은 화면의 전체 챕터를 간결한 행으로 표시한다.
5. `catalog.css`는 홈·허브·시험·과목의 catalog class에만 적용한다. 학습 본문 타이포그래피·표·도식·기출·모의고사 구조는 변경하지 않는다. 시설 메뉴·임시 시설 페이지는 추가하지 않는다.

## 환경과 남는 범위
