## 문제 연결

기존 문제 관리표 2,480행, 공개 승인 2,328문항, 보류 152문항과 챕터 배정은 변경하지 않음. 새 5개 챕터는 `practiceChapter`로 같은 과목의 기존 공개 문제 묶음에 연결하며 버튼을 **연결 챕터 문제 풀기**로 표시. 해당 묶음에 더 넓은 기존 범위의 문제가 포함될 수 있음을 연결 챕터명으로 알림.

없는 문제를 새로 배정한 것처럼 표시하지 않으며, 문제 페이지에는 기존 74개 비어 있지 않은 묶음만 전달. 연결 대상이 없거나 과목이 다르거나 공개 문제가 없으면 빌드 오류로 차단. 전역 문제 ID와 기존 해설·이론 링크는 유지.

- [NFTC 102](https://www.law.go.kr/admRulInfoP.do?admRulSeq=2100000281772) 2.3.7.1의 토출밸브 앞 분기·유량계 앞 개폐밸브·뒤 유량조절밸브를 국가법령정보센터 검색 본문과 기존 검수 본문으로 대조. 동적 뷰어에서 현행 전문 전체를 다시 읽은 것은 아님
- [소방관서 자동복구 기능 설명](https://jngjsobang.go.kr/yeosu/minwon/counsel/counsel_list/index.jsp?boardId=bbs_0000000000000151&cntId=213&mode=view): 시험위치에서 감지기 복구에 따른 수신기 복구 기능을 공개 검색 본문으로 확인
- 기존 FSM2-034·035·040·047과 공개 승인 문항을 대조. 연결 판단은 `figure-briefs.json`에 문항 ID별로 기록. 새로 출제 빈도나 실제 정답률을 주장하지 않음
- 감지기 신호와 발신기 신호 비교에는 ‘동작시험 해제·기타 이상 없음·해당 표시 기능 정상’ 조건을 명시. 경계구역과 층수의 대응도 조건이 있을 때만 적용

- 준비작동식은 입력·기동 명령·실제 개방 확인·폐쇄형 헤드 방수를 구분. A회로 2개 감지기를 두 독립 회로로 치환하지 않음
- 배관도는 시험 분기 부분만 표현. 흡입밸브·체크밸브·순환배관·계기 생략을 그림 바로 아래 밝힘. 닫힌 설비측에 흐름 화살표를 그리지 않음

## 이미지 기준과 확인

`docs/standards/learning-image-design-system-v1.md` v1.2 §§1–9 적용. 캡션·학습 질문을 먼저 작성한 `figure-briefs.json` 다음에 도식을 제작. 기존 생성형 인포그래픽과 공개 원본 에셋을 덮어쓰지 않음.

공통 380단위 SVG, 중립 금속 패널·남색 라벨·파랑 선택. 켜짐/꺼짐/입력/없음/운전/정지를 문자로 병기. 실제 제조사 배치·색상 표준으로 주장하지 않음. HTML 캡션을 그림 안에 중복하지 않으며 alt·크기·확대를 제공.

SVG를 한글 폰트로 PNG 렌더해 5장 육안 확인. 배관 라벨이 관로와 겹친 초기본을 수정. 320/390/768/1440px 실제 브라우저 검증은 `qa-fire-priority-chapters.cjs`와 CI artifact로 구분하여 기록.

## 보호와 검증

신규 네이티브 검사 `check-fire-priority-chapters.mjs`는 실제 현재 861개 소스·에셋과 552개 HTML, 529개 article을 직접 검사. 기존 모든 학습 본문·기출·그림 바이트를 관련 링크 앞까지 정확히 보존했는지 확인. 새 챕터의 연결 문제·학습 순서·이미지 경로·광고 슬롯도 검사.

이전 스냅샷의 해시는 수정하지 않음. `review.json.gz`에는 이번에 바뀐 소스 9개와 렌더링 결과의 정확한 역변경만 고정. 역사 검사 전용 파일 접근은 전체 현재 해시가 맞을 때만 이전 바이트로 투영하고 신규 5개 본문·5개 SVG·5개 HTML을 정확한 해시 확인 후 제외. 알 수 없는 변경은 그대로 남거나 실패. 격리 변이 검사의 helper·메타데이터 의존성을 함께 복사하도록 갱신.
