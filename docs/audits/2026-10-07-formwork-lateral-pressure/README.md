## 본문과 기출

공개 예정: https://getpasslab.co.kr/industrial-safety/written/construction/formwork-lateral-pressure/

거푸집/측압의 뜻, 슬럼프의 최소 의미, 증감 조건6행 표로 구성함. 온도↑ → 응결 빨라짐 → 유동 상태 유지시간 감소 → 측압↓를 통해 두 문제의 틀린 보기를 구별함. 기출에 없는 설계공식·특수 콘크리트 설계·수치 계산·마지막 반복 요약·시험 포인트 표·그림은 추가하지 않음

두 문항은 이전 공개 챕터 어디에도 주 기출로 배정되지 않았음을 확인함. 새 챕터에 단독 배정하며 기출 정본·선택지·정답·ID·과목·일자·검수상태는 수정하지 않음

20180428_111번은 일반적인 콘크리트 타설 안전(지보공 점검·슈트·편중 타설 포함)을 묻는 더 넓은 범위임. 이번 측압 전용 챕터에 억지로 배정하지 않음. 동바리 조립/침하 방지, 거푸집 해체는 기존 챕터로 연결함
