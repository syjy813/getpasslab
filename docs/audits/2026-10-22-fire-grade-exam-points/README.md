# FSM2-001 시험 포인트 근거 검토

복원 500문항을 대상으로 챕터 배정과 등급 관련 용어를 확인함. 직접 배정 5문항 중 검수 승인된 4문항만 사용했으며, 보류 1문항은 배제함. 파생 500문항·일반 1,480문항을 복원 원본의 증거로 사용하지 않음.

`source-review.json`에 각 포인트의 원문항 ID·현재 검수된 지문·선택지·답과 대응을 저장함. 빈도·출제 확률을 추정하지 않음. 원자료 `rawSourceText`에는 OCR 오류와 과거 해설 오류가 있어 원문을 그대로 정답 근거로 인용하지 않음. 기존 검수된 문항과 교재 수치·조건을 대조함.

- 27777-q01 / 27780-q03: 지상 9층과 지하 2층을 1급의 지상 11층으로 더하지 않음. 법정 설비 대상과 상위 등급 배제 조건을 유지함
- 27779-q02: 가연성가스 400t·지하구·보물 목조건축물과 자동화재탐지설비만 필요한 판매시설을 구별함
- 27782-q02: 아파트 층수의 지하층 제외, 비아파트 면적 조건과 용도별 제외, 가스 500t 오답을 구별함
- 보류 27773-q03: 숫자·선택지가 훼손되어 포인트의 근거에서 제외함

‘조건에 붙는 단서’ 제목을 삭제하되 답을 바꾸는 법적 예외는 없애지 않음. 층수·연립주택·주택전용 간이스프링클러·목조건축물 조건은 표에, 특급·1급 제외 용도는 표 아래 참고문에 통합함. 일반 740문항의 기존 판단 조건과 원본 500문항 데이터는 변경하지 않음.

법령 대조 범위: 국가법령정보센터의 현행 법령 메타데이터(시행 2026-07-01)와 별표 4 공개 PDF의 등급 수치·범위를 확인함. 공개 PDF는 구판 용어를 포함하므로 현행 별표 전체 재검증으로 보고하지 않음. 기존 법령 링크와 확인 일자는 유지함.

배포 후 공개 본문은 최신이나 기존 URL의 CSS가 브라우저에 남아 전용 규칙이 없는 사례를 확인함. FSM2-001의 스타일 링크에 버전 쿼리를 붙여 기존 캐시와 분리함. 다른 챕터의 스타일 링크와 본문은 변경하지 않음.
