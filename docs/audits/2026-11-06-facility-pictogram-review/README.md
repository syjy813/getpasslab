# 시설 픽토그램 전수 검수와 교정

사용자가 픽토그램 깨짐을 지적하여 전수 검수와 발견 문제 수정을 승인했다. 기준 HEAD `fd8329f`, 전용 브랜치 `codex/facility-pictogram-review-20261106`. Production 배포는 범위 밖이다.

## 확인·수정한 형태

전체39종의 원본104px/축소31px과 최종 WebP의57개 표시 변형을 나란히 대조했다. 다음4종은 작은 표시에서 연결부나 중복 선이 어색해 보일 수 있어 정리했다.

| 도형 키 | 이전 형태의 문제 | 교정 |
|---|---|---|
| mechanical | 열린 배관 끝·펌프와 모터 경계가 모호함 | 흡입구·토출구의 끝선과 펌프/모터 연결, 지지대를 명확히 구성 |
| gas | 십자형 윤곽의 여러 모서리가 뭉쳐 밸브가 잘 드러나지 않음 | 배관·밸브 본체·핸들을 구별 |
| submission | 화살표가 종이 하단과 트레이 윗테두리를 관통 | 종이/화살표를 이격하고 트레이 상단을 열린 형태로 변경 |
| rail | 가까운 이중 선이 작은 크기에서 합쳐짐 | 좌우 레일을 각각 한 선으로 정리하고 침목 간격 유지 |

다른35종(기존정본11종·추가24종)은 변경하지 않았다. SVG가 유효하다는 사실과 축소 시 읽히는 형태를 구분하여 검사했다. 이 도형은 편집용 주제 아이콘이며 실제 시공 도면이나 법정 기호가 아니다.

## 적용과 보존

- 영향받는28개 카드 이미지의30개 픽토그램을 재제작했다. 새 편집가능 마스터와 브리프는 `masters/`, `specs/`, 새 WebP는 `facility-pictogram-review/`에 저장했다.
- 기존85장 가운데57장(대표12장·카드45장)은 바이트 동일하다. 이전 compact 마스터·브리프·WebP·매핑과 추가도형 모듈을 보존한다.
- 공개 이미지 URL·alt·문구·레이아웃·축소한 하단 여백·예약 치수는 그대로다. 85장 이미지 나열 HTML의 내장 WebP만 교체한다.
- 재현 명령: `node scripts/repair-facility-pictograms.mjs`. 이전 일괄 생성 명령 대신 이 전용 명령을 사용하여 이전 검토 자산을 보존한다.

## 검증과 범위

- `check-facility-pictogram-review.mjs`:39종×10크기(24/26/28/31/35/38/104/118/128/140px), 총390개 잘림·가시성 검사. 서류제출 종이/화살표/트레이의 진한 선 사이에 최소1개 빈 픽셀이 있는지 검사. 수정4종 범위·이전 자산·나머지 바이트 보존 검사.
- 이전 근무표/사업소 복합도형 간격 검사, 템플릿11개 검사, 카드73장/182항목의 간격 보존 검사.
- 실제 최종 WebP 및320/390px 축소 래스터에서 도형을 시각 검수한다. SVG 파싱·픽셀 검사만으로 의미 적합성이나 브라우저 QA 완료를 주장하지 않는다.
- Build·최종85장 검증·255문구 중앙정렬·SEO 결과는 `validation.json`에 별도 기록한다. 브라우저 반응형QA·원격CI·Push·Production 배포는 미실행이다.

적용 가이드: 시설 콘텐츠 가이드 §5.13.7–9(도형 의미·복합도형·최종 래스터·하단여백) 및 학습이미지 가이드 §1/5–7/9(브리프·원본보존·최종표시·단계구분). 그림 브리프는 기존 카드 JSON을 유지하며 의미·문구·조건·수치를 바꾸지 않았다.
