# 공작기계 5개 챕터 의미 단위 줄바꿈

사용자 스크린샷의 한 줄로 이어진 정의와 설명을 빈 줄이 있는 Markdown 문단으로 분리함. 같은 패턴의 5개 챕터 본문도 검수하여 문단·목록 항목으로 분리함. 의미상 하나의 묶음인 장치명·제목·표·frontmatter의 가운뎃점은 유지함.

기존 문구·조건·강조·24문항·frontmatter 불변. 문장 중간에 고정 `<br>`를 넣지 않고 320/390/1440px에서 자연스럽게 줄을 감싸는 문단을 사용함. 사용자 `그건 수정해서 배포하자` 명시 배포 승인. 기계별 그림은 별도 후속 검토본에서 제작하며 이번 배포 범위에 포함하지 않음.

Test/Build/CI/Deploy는 실제 증거를 확인한 후 PR 및 인수인계에 기록함.
