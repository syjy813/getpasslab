# 기출문제 이미지 렌더러 및 모바일 표시 검증

## 결론

기출문제 모달에 선택적 로컬 이미지를 표시할 수 있는 렌더러와 모바일 레이아웃을 구현했다. 실제 이미지 등록부는 비워 두었고, 에너지관리기능사 32문항의 `review: "jpg 확필"`과 챕터 관계 0건을 유지했다. 따라서 이번 작업만으로 공개되는 에너지 기출문제나 이미지 자산은 없다.

대표 문항 1건은 원본 작업 트리와 분리한 일회용 복제본에서만 임시 연결해 화면을 검증했다. 임시 검수 해제, 챕터 관계, 이미지 등록은 복제본 삭제와 함께 모두 제거했다.

## 구현 범위

- `src/config/questionImages.ts`
  - `${cert_id}:${question_id}` 복합 키를 사용하는 명시적 이미지 등록부
  - 중복 키와 빈 대체 텍스트를 빌드 시 거부
  - 현재 정적 이미지 import와 등록 항목은 0개
- `src/pages/[cert]/[exam]/[subject]/[slug].astro`
  - 기존 공개 필터를 통과한 문항에만 선택적 이미지 메타데이터 주입
- `src/components/QuestionHistory.astro`
  - 본문과 선택지 사이에 Astro 이미지 렌더링
  - 원본 비율, 고유 크기, 지연 로딩, 비동기 디코딩, 대체 텍스트 지원
  - 작은 화면에서 세부 내용을 확대할 수 있는 원본 크기 보기 링크
  - 이미지형 선택지 placeholder의 화면 문구 보정
  - 모달 이름, 제어 연결, 정답 공개 상태 알림과 텍스트 표시 추가
  - 모달을 열 때 문제 상단으로 스크롤·초점 초기화
- `src/styles/global.css`
  - 모바일·가로 화면의 모달 최대 높이와 내부 스크롤
  - 반응형 이미지, 모바일 버튼 폭, 키보드 포커스 표시

Astro는 `src`의 로컬 이미지를 정적으로 import해야 하며, 동적 이미지 묶음은 `import.meta.glob()`을 사용할 수 있다. 그러나 이번 게이트에서 32개를 glob 후보로 등록하면 관계가 0이어도 빌드 자산으로 방출될 수 있으므로 사용하지 않았다. 공개 승인을 받은 항목만 개별 정적 import하는 구조로 제한했다.

- Astro imports 안내: <https://docs.astro.build/en/guides/imports/>
- 잘못된 로컬 이미지 문자열 경로 안내: <https://docs.astro.build/en/reference/errors/local-image-used-wrongly/>
- Astro assets API: <https://docs.astro.build/en/reference/modules/astro-assets/>
