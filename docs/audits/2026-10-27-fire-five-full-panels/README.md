## 제작 및 검수

이미지 제작 전 `CHAPTER_WRITING_GUIDE.md`와 `docs/standards/learning-image-design-system-v1.md` v1.2를 확인. §1의 캡션/학습 질문은 기존 브리프와 `prompts.json`, `chapters.json`에 기록. §§2–4의 전체 장치 식별성, 구조·상태 의미와 직접 라벨, §§5–6의 전체 판과 번호별 텍스트/확대 보기, §§7–9의 관계 검수와 단계별 완료 상태를 적용했다.

내장 이미지 생성으로 새 4장을 제작. 수신기는 이전 승인 이미지와 같은 기기 배치를 유지하는 편집, 배관과 준비작동식은 학습 범위의 새 이미지다. PNG는 생성 원본으로 보존하고 공개 에셋은 무손실 WebP로 인코딩. `image-validation.json`의 모든 RGB 픽셀 비교 통과. 기존 SVG 5개는 보존했다.

- 수신기 동작시험: 동작시험/자동복구만 파랑 선택, 다이얼 1, 화재/1회로 켜짐, 발신기 꺼짐, 도통 결과 두 표시 꺼짐 확인
- 발신기 입력: 모든 시험 해제, 다이얼 OFF, 화재/3회로/발신기 켜짐 확인. 번호가 3회로 글자를 가리던 부분 보정
- 배관: 흡입→펌프→분기점→시험 개폐밸브→유량계→조절밸브→수조 환수를 추적. 초기 생성본의 흡입관 합류 환수를 폐기하고 별도 수조 입구로 보정. 닫힌 설비측 뒤에는 흐름 화살표를 두지 않음
- 준비작동식: A/B 켜짐, SVP 꺼짐, 명령과 개방 확인을 별도로 표현. 헤드 방수나 펌프 운전을 임의로 표시하지 않음
- 그림 안 제목은 승인한 전체 판 스타일을 유지하는 예외. HTML 캡션은 다른 판독 질문을 제공하고, 상세 설명은 번호별 HTML 텍스트로 제공. 부분 확대 카드는 추가하지 않음

## 근거와 한계

기존 공개 본문, 기존 SVG, 사용자 제공 자막 기반의 선행 브리프 및 연결 공개 문항을 대조했다. 문항 ID별 근거는 `docs/audits/2026-10-27-fire-priority-chapters/figure-briefs.json`에 있으며 이번 작업은 같은 풀이 범위를 유지한다. 실제 원본 동영상 프레임을 새로 시청했다고 주장하지 않는다.

배관의 분기와 유량계 앞/뒤 배치는 기존 NFTC 102 2.3.7.1 검수 내용을 유지. 준비작동식의 두 독립 회로, 수동 기동, 명령/개방 확인/헤드 방수 구별도 기존 본문과 문항의 조건을 유지한다. 공식 사이트 검색은 시도했으나 NFTC 전문을 새로 완전히 확인한 것이 아니므로 현행 전문 재검증이나 제조사별 결선 검증으로 기록하지 않는다.

전체 판은 학습용 재구성이며 제조사 실물 정본이나 실제 시공도가 아니다. 배관 그림의 흡입밸브·체크밸브·순환배관·압력계 생략을 인접 본문에 유지했다. 수치·성능 곡선·설정 압력은 생성하지 않았다. 밸브 개방과 실제 헤드 방수의 구별도 유지했다.

## 구현과 보호

기존 79개 챕터의 ID·slug·order·practiceChapter·문제 배정·정답·승인 상태 유지. 이미 완성된 FSM2-077은 그대로 재사용하며 나머지 4개 본문과 그림을 개편했다. 입력 비교 정보는 본문에 남겨 그림이 한 상태를 보여주어도 A만/A+B/SVP, 감지기/발신기의 차이를 학습할 수 있게 했다.

이전 스냅샷은 수정하지 않았다. `review.json.gz`는 이번 정확한 이전/현재 바이트, 새 에셋, 현재 소스·공개 HTML과 문제 파일의 해시를 기록한다. 현재 검사는 원본 파일을 직접 읽고, 역사 검사는 정확한 전체 해시가 일치하는 개편만 되돌린다. 모르는 변경과 추가 파일은 숨기지 않는다. 격리 history guard에는 새 helper와 메타데이터를 함께 제공한다.

실행한 정적 검사와 브라우저 결과는 별도 JSON에 기록한다. 실제 단말/Safari, main 병합/배포/Production 검증은 각 실행 시점의 증거로 구분한다.
