## 문제와 판단

기존 카테고리 검색 제목은 ‘취업·커리어’, ‘시설 이야기’ 등 화면 이름과 공통 브랜드만 사용하고, 설명에는 공통 탐색 안내를 붙였다. 검색 결과에서 시설관리 분야와 글 모음의 차이를 판단하기 어렵다는 적용 추론에 따라, 실제 공개 주제를 드러내는 고유 제목·설명으로 보완한다. 한글 브랜드 ‘겟패랩’과 홈 설명의 `GetPassLab`을 함께 제공한다.

이는 검색 의도를 설명하는 편집 개선이다. 검색량·순위·CTR 증가를 확인한 실험이 아니며, 특정 키워드의 수요나 경쟁도를 조사한 결과로 해석하지 않는다. 회원 게시물·질의응답 서비스가 있는 것처럼 구조화 데이터를 바꾸지 않는다. 현재 Article·Breadcrumb·canonical·robots와 공개 32편을 보존한다.

## 검증과 보호

`manifest.json`은 변경 전 소스 2개와 정확한 변경 후 해시, HTML 7개의 제목·설명 치환만 기록한다. 기존 검증기는 이 변경만 되돌려 과거 불변 검사를 이어가므로 관련 없는 수정은 계속 실패한다. 과거 manifest는 수정하지 않았다.

- 변경 전·후 각각 594페이지 빌드. 출력 목록 1,005개 동일.
- HTML 7개만 변경. 제목·설명과 각각의 OG/Twitter 신호를 복원하면 이전 HTML 전체와 바이트 일치. 나머지 998개 파일은 그대로다.
- 공개글 본문·이미지·H1·링크·시리즈 순서·기존 URL, CSS/JS, 자격증 출력은 동일하다. 화면 영향이 없는 메타정보 변경이므로 추가 육안 브라우저 QA는 실행하지 않는다.
- 실행 결과와 공개/검토 모드 구분은 `validation.json` 참조. SEO 기존 경고 12건은 게시글 제목 11건·소방 설명 길이 1건이며 이번 7개 페이지에는 해당하지 않는다.
