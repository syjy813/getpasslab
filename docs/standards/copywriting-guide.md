# GetPassLab 카피라이팅 가이드

- 버전: v1.0 / 2026-10-29
- 범위: 페이지 제목, 요약, 버튼·메뉴, 배지, 캡션, 안내·오류 문구
- 원칙: **대상과 결론을 먼저 말하고, 확인하지 않은 성과를 약속하지 않음**

## 반드시 지킬 기준
1. **구체적 이름 사용:** ‘대표 단서’보다 ‘자격 요건’, ‘자세히 알아보기’보다 실제 행동인 ‘기출 풀기’처럼 목적이 드러나는 표현을 우선
2. **한 문장에 하나의 판단:** 필요한 수치·조건은 생략하지 않되 중복 설명 삭제
3. **입증되지 않은 수식어 금지:** ‘무조건’, ‘완벽’, ‘국내 최고’, ‘100% 합격’, ‘합격 보장’, ‘반드시 출제’ 등 사용하지 않음
4. **빈도·최신성은 근거 필요:** ‘최빈출’, ‘매년 출제’, ‘최신’은 집계 범위·기준일이 있을 때만 사용
5. **행동 문구는 정확하게:** 버튼이 실행하는 동작과 텍스트가 같아야 함. 링크·다운로드·모의고사·채점 구분
6. **보조 설명은 필요할 때만:** 화면에서 이미 명백한 조작법, 장식적 안내, 중복된 제목·캡션은 제거

## 문구 유형별 짧은 기준
| 위치 | 원칙 | 예시 |
| --- | --- | --- |
| 제목 | 핵심 대상 + 구별할 기준 | ‘기계설비유지관리자 초급 자격 요건’ |
| 한 줄 요약 | 무엇을 판단할 수 있는지 | ‘자격과 경력에 따른 초급 인정 조건’ |
| 링크·버튼 | 동사+대상 또는 명확한 기능명 | ‘챕터 보기’, ‘기출 풀기’, ‘답안 제출’ |
| 상태·배지 | 실제 확인 가능한 상태만 | ‘기출 연결’, ‘미응답’, ‘정답’ |
| 오류·안내 | 현재 상태 + 가능한 다음 행동 | ‘답안을 선택한 뒤 제출하세요’ |
| 이미지 캡션 | 대상·상태 중심, 그림 제목 반복 금지 | ‘압입통풍의 송풍기 위치’ |

위 예시는 새 카피의 작성 기준이며 실제 사이트에 현재 노출 중인 문구라고 뜻하지 않음.

## 문체 구분
- **학습 본문:** CHAPTER_WRITING_GUIDE.md에 따라 명사형, ‘~함/임’, 마침표 생략을 기본으로 하되 이해를 해치지 않음
- **안내·오류·일반 정보 글:** 자연스러운 존댓말 또는 서술문을 사용. 학습 본문 문체를 메뉴·알림에 기계적으로 적용하지 않음
- **표:** 요건이 여러 개면 줄바꿈. 독립된 문장을 가운뎃점으로 연결하지 않음. AND는 ‘및’, OR는 ‘또는’처럼 실제 의미를 표시
- **원문 보존:** 기출 선택지·법령 인용·수식·숫자·단위·고유 용어를 문체 통일 명목으로 수정하지 않음

## 공개 전 체크
- 이 문장을 삭제해도 기능·판단에 지장이 없으면 삭제했는가?
- ‘합격’, ‘최고’, ‘빠른’, ‘빈출’, ‘최신’에 주장 수준의 근거가 있는가?
- 동일한 내용을 제목·설명·버튼·그림에 반복하지 않았는가?
- CTA 문구와 실제 이동·실행 결과가 일치하는가?
