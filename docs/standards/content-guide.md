# GetPassLab 콘텐츠 작성 가이드

- 버전: v1.0 / 2026-10-29
- 범위: 자격증 학습 콘텐츠 및 향후 시설관리 정보 콘텐츠의 공통 편집 원칙
- 자격증 상세 정본: **CHAPTER_WRITING_GUIDE.md**. 이 문서는 핵심만 요약하며 상세 기준을 대체하지 않음

## 반드시 지킬 기준
1. **독자가 얻을 판단을 먼저 정함.** 그 판단에 필요한 사실·조건·예시만 본문에 남김
2. **원본을 확인함.** 기출은 문제·선택지·정답·이미지, 법령과 시험 기준은 적용 시점·출처를 확인
3. **추측을 사실로 쓰지 않음.** 미제공·미확인과 검증 완료를 구분. AI가 생성한 해설·그림은 근거 자료가 아님
4. **조건을 생략하지 않음.** 결과가 달라지는 법령 시점·버전·단위·적용 대상은 본문에 직접 표시
5. **중복을 제거함.** 정의·표·그림·마지막 요약으로 같은 내용을 반복하지 않음
6. **기존 연결을 보호함.** 공개 URL, slug, subject_id, question_id, 연결 기출의 배정을 임의로 바꾸지 않음

## 콘텐츠 유형별 구성
| 유형 | 기본 흐름 | 추가 확인 |
| --- | --- | --- |
| 자격증 챕터 | **문제 단서 → 필요한 개념 → 적용 예시 → 오답 판단 → 연결 기출** | 원문·정답 대조, 챕터 경계, 실제 적용 가능 여부 |
| 계산·설정 | **입력값/조건 → 적용 과정 → 결과** | 공식·수치 검산, 버전·메뉴 위치 |
| 비교·구별 | **구별할 단서 → 핵심 차이 → 오답 제거** | 비교 기준의 일치 |
| 시설관리 정보(확장 예정) | **질문 → 결론 → 자격/선임 조건 → 예외·확인 방법** | 법령·기관·공고 원문, 기준일, 법정 의무와 채용 우대의 구별 |

**시설관리 정보 유형은 향후 집필 기준의 제안**이며, 현재 main에 해당 서비스가 구현되었다는 뜻은 아님.

## 출처와 정보 수준
- **기출:** 원본 PDF·기출 원문 우선. JSON과 충돌하면 원본을 재확인
- **제도·법령:** 공식 원문과 시행일 확인. 과거 기출 기준과 현행 기준을 나눠 적음
- **채용·선임:** 채용공고의 자격요건, 우대사항, 법정선임 조건을 별도로 표시
- **출제 빈도:** 실제 집계 범위를 밝힐 수 있을 때만 ‘빈출’ 등의 표현 사용. 수록 문항 수를 전체 출제 빈도로 확대 해석하지 않음
- **미확인:** 근거 없는 숫자·자격요건·합격률·출제 경향은 넣지 않음. 검토 필요 사항은 편집 메모에 남김

## 작성·검수 절차
1. 대상 독자와 해결할 질문 한 개를 정함
2. 원문·선택지·공식 근거를 확인하고 출처와 기준일을 기록
3. 결론과 필요한 근거만 작성. 도식·표는 판단에 도움이 될 때만 사용
4. 모든 연결 기출에 본문을 적용해 정답·주요 오답 판단을 확인
5. 수치·단위·표 셀·링크·이미지·모바일 읽기 흐름 검수
6. 확인하지 못한 사항과 검수 범위를 기록. 배포와 실제 Production 확인은 별도 판정
