# GetPassLab 디자인 가이드

- 버전: v1.0 / 2026-10-29
- 범위: 사이트 전체의 공통 시각 규칙. **현행 main 코드 기준**이며 새로운 디자인을 적용한 문서가 아님
- 상세 정본: src/styles/global.css / 학습 그림은 learning-image-design-system-v1.md

## 반드시 지킬 기준
1. **정보 위계가 먼저임.** 페이지 제목 → 설명 → 주요 행동 → 보조 정보 순서로 읽히도록 구성
2. **기존 디자인 토큰 재사용.** 개별 페이지에서 임의의 색상·글꼴·간격 체계를 추가하지 않음
3. **강조는 목적이 있을 때만.** 버튼은 행동, 배지는 상태·분류, 색상은 정보 구분에 사용
4. **컴포넌트는 일관되게.** 같은 역할의 카드·버튼·모달은 같은 기준을 사용. 예외는 사유를 기록
5. **모바일에서 읽을 수 있어야 함.** 그림 축소로 글자가 안 보이면 별도 배치나 확대 기능을 검토
6. **타 서비스 복제 금지.** 토스피드는 간결한 정보 위계·밀도·가독성의 참고 사례일 뿐 브랜드 표현과 화면 구성을 그대로 사용하지 않음

## 학습 이미지에는 별도 규칙 적용
- 장치 구조·흐름·수치가 보기 좋은 구성보다 우선
- 그림 캡션은 HTML이 담당하고, 그림 내부에는 장치명·상태·흐름처럼 해석에 필요한 라벨을 남김
- 유체·상태 색상은 기존 학습 이미지 정본을 사용. 사이트의 파란 버튼색을 기술 도식의 매체색으로 대신 사용하지 않음
- 상세 제작 브리프·원본 보존·320/390px 검수는 [학습 이미지 정본](learning-image-design-system-v1.md) 참고

## 적용 전 확인
- 같은 역할의 기존 컴포넌트가 있는가?
- 제목·설명·그림에 중복된 문구가 없는가?
- 모바일과 PC의 읽기 순서·대비·터치가 적절한가?
- 공통 변경으로 다른 과목이나 화면이 영향을 받는가?
