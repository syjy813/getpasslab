# GetPassLab 운영 가이드 — 시작하기

- 버전: **v1.3 / 2026-10-29**
- 목적: 운영자가 알아야 할 **결정 기준을 앞에**, 실제 작업에 필요한 **세부 적용·검수 기준을 뒤에**, 변경 이유는 **각 문서 부록**에 배치
- 적용 범위: 현재 GetPassLab `main`의 코드·기존 학습 콘텐츠와 향후 서비스 확장 시의 작업 기준
- 상태: **PR 검토용 운영 문서**. 기능 변경·배포 완료를 뜻하지 않음

## 가장 먼저 숙지할 6가지

1. **독자의 질문에 바로 답한다.** 목적 없는 서론·추임새·중복 안내를 삭제
2. **내용이 사실인지 확인한다.** 기출 원문, 법령 적용 시점, 수치·단위·선임 요건은 출처와 함께 검증
3. **필요한 내용은 충분히 쓴다.** 요약하려다 정답·선임·안전 판단을 바꾸는 조건을 삭제하지 않음
4. **디자인은 기존 시스템을 재사용한다.** 토큰·컴포넌트·기술 도식 정본을 먼저 확인
5. **사용자 동작이 명확해야 한다.** 버튼·상태·닫기·채점·모바일 탐색의 의미를 일관되게
6. **확인한 결과만 완료로 기록한다.** 집필·수정·테스트·빌드·배포·Production을 구분

**모든 문서를 매번 처음부터 읽을 필요 없음.** 해당 작업의 가이드에서 1장(필수 규칙)과 적용·완료 기준을 확인. 필요한 경우 중간의 예시·세부 규격을 참조. 과거 결정 경위가 필요할 때만 부록 확인.

## 가이드 간 역할·우선순위

| 영역 | 정본·근거 | 이 문서에서 하지 않는 것 |
| --- | --- | --- |
| 프로젝트 실행·배포 | `AGENTS.md` | 배포 승인 규칙을 별도로 변경하지 않음 |
| 기출·자격증 집필 | `CHAPTER_WRITING_GUIDE.md` | 기출 원문·문항 ID·기존 챕터 범위 변경하지 않음 |
| 학습 이미지 기술 도식 | `learning-image-design-system-v1.md` (본문 버전 v1.3) | 이미지 색상·기호를 새로 임의 정의하지 않음 |
| 사이트 스타일·구현 | 실제 `src/styles/global.css` 및 컴포넌트 | 문서 수치만으로 Production 구현을 주장하지 않음 |
| 공통 편집·UX 결정 | 이 디렉터리의 네 가지 가이드 | 다른 정본과 중복하여 새 규칙을 만들지 않음 |

문서와 코드가 다르면 **현재 구현 상태는 코드로**, 새로 적용할 기준은 **해당 영역의 정본과 승인된 설계로** 판단. 충돌은 조정 후 단일 문서에 기록하고 다른 문서는 링크로 참조.

## 다음 작업 요청 시 최소 기록

```text
작업 목적 / 대상 페이지:
독자 또는 사용자의 해결할 문제:
적용한 가이드와 기준:
변경/유지 대상:
확인한 자료·버전·근거:
수행한 검증 / 미수행 검증:
변경 이력에 남길 결정 이유:
```

**시설의 모든 것 / 자격증의 모든 것** 서비스 분리 및 토스피드 참고 스타일은 별도 추진 과제. 코드 반영과 Production 확인 전에는 현행 서비스 구현으로 기록하지 않음.

## v1.2 토스피드 참고 및 후속 UI 적용 순서

**도입할 원칙:** 서비스 선택과 콘텐츠 탐색 분리, 추천/주제 목록 구분, 제목·결론·조건의 정보 위계, 중복 없는 문구와 다음 행동을 예상할 수 있는 버튼.

## v1.3 재검증 결론과 주의할 부분

**[토스피드 참고 재검증 원문](../audits/2026-10-29-tossfeed-reference-revalidation.md)**을 먼저 확인하고 UI 변경 작업을 시작할 것.

- **직접 확인된 사실:** 연결된 Chrome의 열린 메인·아티클 탭 텍스트/링크/버튼 명칭을 읽었고, 토스피드 공개 메인·카테고리·정보형 아티클·공식 글쓰기 원칙을 확인. GetPassLab은 GitHub `main`의 코드로 현재 구현 파악
- **정정:** 토스피드 상단은 한 플랫폼 안의 **콘텐츠 영역 구분**. GetPassLab의 두 서비스 선택 GNB는 프로젝트 자체 결정이며 토스피드와 같은 구현이라는 증거는 없음
- **참고할 부분:** 추천/주제별 목록, 정보형 아티클의 제목·조건·근거, 버튼의 목적, 문장/화면/화면 간 중복 제거
- **복사하지 않을 부분:** 토스 브랜드·카드/색상/픽셀값의 임의 모방, 모든 글에 스토리형 문체 적용, 시험 문제·채점 화면의 기사형 변경
- **미실행:** Chrome 직접 클릭·스크롤·뷰포트 전환·PC 1440px/모바일 390/320px 스크린샷 및 실제 렌더 검증. 현재 문서는 **시각 QA PASS가 아님**

| 다음 실제 UI 변경 | 이번 재검증에 따라 확정한 기준 | 현재 단계 |
| --- | --- | --- |
| GNB 두 서비스 선택 | 토스피드 정보구조는 참고만. 활성 서비스·자격증 목차·키보드/모바일 기준을 별도 구현 | 설계·수용 기준 문서화 |
| 시설관리 홈·목록 | 소수의 대표 콘텐츠, 실제 카테고리와 기사 목록. 글·데이터가 없으면 '인기'·'추천'을 만들지 않음 | 설계·수용 기준 문서화 |
| 시설관리 상세 | 정보형 기사와 같이 결론·기준일·요건·근거가 보이도록 구성 | 설계·수용 기준 문서화 |
| 자격증 읽기 화면 | 기존 기출·문항·해설 유지. 글자·간격·도식만 필요한 범위에서 개선 | 설계·수용 기준 문서화 |

**다음 작업에서 화면 수치를 확정하려면** 토스피드와 GetPassLab을 실제 브라우저로 조작하고 비교 캡처를 먼저 확보해야 함. 그전에는 색상/폰트/간격을 '토스와 동일'이라고 표기하지 않음.
