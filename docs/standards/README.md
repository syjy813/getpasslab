# GetPassLab 운영 가이드 — 읽기 안내

- 버전: v1.0 / 2026-10-29
- 확인 기준: GitHub main의 소스·기존 문서. Production 전 화면의 최신 반영 여부와 모든 반응형 동작은 이번 문서 정리에서 검증하지 않음
- 목적: 운영자가 숙지할 결정만 본문에 남기고, 상세 규격과 변경 경위는 정본 문서·각 문서의 부록으로 분리

## 먼저 기억할 5가지
1. **정확성 우선:** 기출·법령·시험 조건을 확인하지 않은 내용을 사실로 쓰지 않음
2. **하나의 정보, 하나의 역할:** 제목·본문·표·그림에서 같은 설명을 반복하지 않음
3. **짧고 구체적으로:** 과장보다 대상·조건·결론을 먼저 안내
4. **모바일 기준 검토:** 핵심 정보를 390px 화면에서 읽을 수 있는지 확인하고, 320px도 점검
5. **확인된 상태만 기록:** 구현·Build·배포·Production 동작을 구분

## 기존 정본을 대체하지 않음
- **AGENTS.md:** Git·배포·보호 대상 등 실행 지침
- **CHAPTER_WRITING_GUIDE.md:** 자격증 챕터 집필의 상세 정본
- **docs/standards/learning-image-design-system-v1.md:** 학습 이미지 제작·검수의 상세 정본(문서 내용 v1.3)
- **src/styles/global.css 및 실제 컴포넌트:** 현재 사이트에 구현된 시각·동작의 확인 근거

상충하는 규칙이 있으면 해당 영역의 상세 정본과 실제 코드를 확인하고, 문서를 임의로 복제하지 않음. **'시설의 모든 것 / 자격증의 모든 것' 서비스 분리 및 토스피드 참고 방향은 별도 진행 중인 설계 과제이며, main에 구현 완료된 규칙으로 기록하지 않음.**
