# 시설 인포그래픽 생성기
이 스크립트는 `docs/standards/facility-content-guide-v1.4.md` §5.13.6~7의 SVG 헤더 및 1~4장 카드 제작 규칙을 코드로 고정한다.
호출 예: `node scripts/generate-facility-infographic.mjs docs/standards/facility-infographic-templates/example-3.json /tmp/facility-3.svg`
캔버스 1440×1080, 제목 x80/top140/64px Bold, 부제 30px/16px 간격, 로고 210×34 x1150/y80, 카드 상단은 헤더 행 수에 따라 자동 계산한다.
카드 개수: 1장 단일 본문, 2장 좌우 비교, 3장 3열 비교, 4장 2×2 컴팩트 비교. 카드 수에 따라 달라지는 것은 카드 좌표와 내부 정보 밀도뿐이다.
**4장 전용 높이:** 한 줄 제목·부제 기준 각 행 카드 236px(기존 268px 대비 -32px), 행 간격 20px, 최종 카드 하단 y=830 및 핵심 메시지 시작 y=930(100px 여유). 두 줄 헤더 등으로 확보 공간이 줄면 카드 최소 높이 230px을 지키며, 부족한 경우 생성 오류로 처리한다. 1~3장 높이와 공통 헤더·로고·푸터는 그대로 유지한다.
생성 결과는 편집 가능한 SVG이며 기존 공개 WebP 및 원본과 별개이다. 발행은 별도의 이미지 검수/반영 절차를 따르고, 모바일에서 긴 텍스트 가독성을 확인해야 한다.

## 카드형 이미지 제작 필수 절차

1. 카드형 시설 인포그래픽을 새로 만들거나 수정할 때는 **이 디렉터리에 등록된 템플릿**(카드 1·2·3·4장) 가운데 실제 내용에 맞는 형식을 반드시 선정한다.
2. 선정한 `example-N.json`을 참고해 내용만 교체하고 `scripts/generate-facility-infographic.mjs`로 렌더링한다. 제목·부제·로고·색·좌표는 같은 렌더러를 사용한다. AI가 이 영역을 임의로 다시 그리게 하지 않는다.
3. 콘텐츠 요구에 맞는 템플릿이 **없으면 작업을 해당 이미지에 한해 보류**한다. 별도 시안을 최종 이미지로 사용하거나 기존 SVG를 임의 변형하지 않는다.
4. 신규 템플릿이 필요한 이유, 정보 구조, 카드 배치, 모바일 가독성, 기존 공통 헤더 재사용 방안을 정리해 **사용자 승인**을 받는다.
5. 승인 후 기존 렌더러를 확장하고, 구분 가능한 신규 템플릿명·SVG 샘플·JSON 입력 예제·자동 테스트·이 README·정본 가이드 §5.13.7을 **같은 PR에서 갱신**한다. 기존 1~4장 샘플의 출력과 Production 경로는 보호한다.
6. 신규 템플릿은 재생성 일치, 충돌·잘림, 320/390px 모바일과 1440px PC의 실제 표시를 검증한 뒤 콘텐츠에 사용한다. 이미지 공개 및 Production 배포는 별도 승인 대상이다.

**정본 원칙:** 이 디렉터리와 `docs/standards/facility-content-guide-v1.4.md` §5.13.7이 카드형 이미지 제작 기준이다. 채팅에서 일회성으로 만든 이미지나 미등록 SVG는 정식 템플릿이 아니다.
