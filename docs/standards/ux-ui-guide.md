# GetPassLab UX/UI 가이드

- 버전: v1.0 / 2026-10-29
- 범위: 탐색, 학습 읽기, 문제풀이, 반응형, 접근성
- 확인 기준: main의 GNB.astro, BaseLayout.astro, ReadableChapter.astro, global.css. **브라우저·실서버 전 화면 QA를 수행했다는 뜻은 아님**

## 반드시 지킬 기준
1. **지금 무엇을 할 수 있는지 보여줌.** 사용자 행동의 목적·다음 단계가 명확해야 함
2. **학습의 연속성을 지킴.** 챕터 읽기 → 연결 문제 → 해설 → 관련 챕터의 흐름을 불필요하게 끊지 않음
3. **상태를 구분함.** 선택·미응답·정답·오답·비활성·진행 중 표시를 혼동하지 않음. 색상만으로 구별하지 않음
4. **같은 동작은 같은 UI.** 닫기, 정답 표시, 선택지, 모달의 공통 규칙을 재사용. 서로 다른 시험 화면의 목적이 다르면 차이를 명시
5. **모바일을 우선 확인함.** 메뉴·표·그림·팝업·하단 탐색이 실제 작은 화면에서 잘리지 않고 겹치지 않아야 함
6. **기존 URL·데이터·학습 상태를 보호함.** UI 개편 과정에서 링크·question_id·저장/채점 로직을 무단 변경하지 않음

## 현재 main에서 확인된 동작
| 영역 | 코드상 확인된 기준 |
| --- | --- |
| 상단 탐색 | 로고 및 자격증·과목 메뉴. 챕터에서는 ‘챕터 목차’ 표시 |
| 메뉴 조작 | 외부 클릭·Escape로 닫기, 현재 챕터 위치로 목차 스크롤 |
| 챕터 탐색 | PC(1024px 이상) 측면 목차, 작은 화면에서 이전·다음 하단 탐색 |
| 읽기 화면 | 섹션 구분, 본문·표·이미지·기출 이력·관련 챕터의 시각 위계 |
| 문제 표시 | 일부 기출 화면은 dialog 레이어에 문제·선택지·답 공개 동작을 구현 |
| 학습 이미지 | 확대 dialog, 닫기 버튼, 대체 텍스트/캡션 관련 규칙 |
| 터치 | 공통 목표값 44px, 모바일 챕터 하단 링크 최소 높이 48px |
| 광고 | 기존 광고 컴포넌트가 있으므로 내비게이션·정답 보기 흐름을 막지 않는지 변경 때 점검 |

‘시설의 모든 것 / 자격증의 모든 것’ 토글 GNB는 **별도 추진 중인 변경 방향**이며 위 현행 구현 목록에 포함하지 않음.

## 화면 변경 시 최소 검수
- **탐색:** 현재 위치·뒤로가기·닫기·다음 행동 명확성, 키보드 Escape/초점 복귀
- **표·그림:** 320px·390px에서 가로 넘침·글자 축소·중요 정보 잘림이 없는가
- **문제풀이:** 선택/수정, 정답·오답·미응답, 제출·해설, 취소·닫기 동작을 실제 수행했는가
- **반응형:** 최소 320·390·768·1024·1440px에서 변경 영역 확인
- **공통 영향:** 산업안전기사·에너지관리기능사·컴활 2급·소방안전관리자 2급에 영향이 없는가
- **검증 보고:** 코드 확인 / Test / Build / 브라우저 QA / Deploy / Production을 각각 별도 기록

위 항목은 **향후 검수 기준**이며 이 문서 작성 시 전 항목을 실행해 통과했다고 의미하지 않음.
