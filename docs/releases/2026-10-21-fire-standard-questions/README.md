# 심화 740문항 일반형 교체

복합 사례의 가·나 판단을 다시 판정하는 문제가 과도하게 복잡하다는 사용자 의견에 따라, 74개 챕터의 심화 10문항씩을 일반적인 4지선다형으로 교체했다. 대괄호로 붙인 챕터명·복합 사례 제목, 가의 기록·나의 기록, 수정 대상 조합·옳은 의견 개수 묻기를 모두 제거했다.

단순한 등급 사례 10개, 옳은 설명 선택 292개, 옳지 않은 설명 선택 438개다. 기존 일반형과 같은 학습 개념은 반복되지만 지문·선택지 전체의 동일 복제는 없고, 기존 기본 문항과 공통 선택지가 2개를 넘지 않도록 했다. 여러 사례의 결론을 조합하는 단계 대신 일반 시험의 설명 선택 형태를 사용한다. 실제 수험생 정답률·변별력으로 난도를 측정한 것은 아니다.

| 항목 | 교체 전 | 교체 후 |
|---|---:|---:|
| 일반 | 740 | 1,480 |
| 심화 | 740 | 0 |
| 복원 원문 | 500 | 500 |
| 원문별 변형 | 500 | 500 |
| 전체 / 공개 / 보류 | 2,480 / 2,328 / 152 | 동일 |

원문500·변형500·기존 일반740은 행 전체를 보존했다. 교체740의 ID·과목·정답번호·원문/출처/핵심 표시·공개 여부도 그대로 유지한다. 원문500의 출제 유력 배지는 유지하며, 교체 문항에는 심화 표시가 나오지 않는다. 문항 수가 줄거나 보류 문항이 풀에 추가되지 않는다.

## 근거와 검수 범위

- 기존 `chapter-facts.txt`의 730개 사실·오개념 카드를 재활용하고, 앞선 승인 교정의 청각 정보·심한 기도폐쇄 조건·옷에 붙은 불의 대응을 반영했다. 피난 보조·대형소화기·트래킹·고체연료처럼 독립 선택지의 주어가 빠지면 뜻이 모호한 문장은 주어를 보완했다.
- 각 보기의 참·거짓, 옳은 설명/옳지 않은 설명의 방향에서 정답을 하나로 도출한다. 해설에는 네 보기의 올바른 내용을 기재하고, 이론은 문제풀이 화면 하단의 기존 다시 보기 링크로 제공한다. 긴 원문 URL은 해설 본문에 중복 출력하지 않는다. 등급 10문항은 단일 대상물 조건에서 별도로 등급을 계산한다.
- 모델이 사실 카드와 현재 챕터를 기준으로 편집·대조한 검수다. 같은 근거를 사용한 정답 대조는 독립 블라인드 QA가 아니며, 교재 전 페이지와 공식 기출 원문을 새로 전수 감사했다고 표현하지 않는다.
- 발신기·배선의 적용 기준은 [2026년 시행 NFTC 203 공식 원문](https://www.law.go.kr/LSW/flDownload.do?flSeq=161946047), 응급처치 보완의 최신 지침 배포는 [질병관리청 2025 한국 심폐소생술 가이드라인](https://www.kdca.go.kr/bbs/kdca/49/309908/artclView.do?layout=unknown)을 확인했다. 이 두 자료 확인을 모든 법령·의료 수치의 별도 전수 검증으로 확대하지 않는다.

`assertions.json`에 사실·오개념, `review.json`에 740문항의 보기별 판정·실제 챕터 경로/SHA·현재 문항 SHA, `replacements.json`에 적용 필드, `before-rows.json`에 이전 740행을 보존한다. `revision.json`은 각 자료 및 새/이전 관리표·실제 빌드 HTML의 해시를 연결한다.

이전 심화 제작 풀과 167문항 보완 기록·공개 승인 근거는 변경하지 않는다. 과거 검사에서만 정확한 새 해시를 확인하고 이전 자료로 복원한다. 새 검사는 복원하지 않은 실제 관리표와 공개 payload를 직접 검사하며 임의 내용 변경을 거부한다. 재생성 도구도 과거 승인 내용 확인 후 이 교체본을 적용하므로 옛 심화가 되살아나지 않는다.

## 검증과 배포

로컬 Astro build와 문항·공개·보호 검사 결과 및 최종 PR HEAD의 CI를 구분한다. 브라우저 QA는 320/390/1440px 지문·선택지·해설, 2,328개 지문 보존, 팝업·채점·재도전·미응답·과목별 추출 회귀를 확인한다. 실제 실행 결과는 PR Checks/첨부 아티팩트에 기록한다.

이 변경은 검토용 브랜치다. main 병합·실서버 배포는 아직 하지 않았다.

```bash
npm run build
node scripts/check-fire-standardization.mjs
node scripts/verify-fire-question-table.mjs
for check in scripts/check-*.mjs; do node "$check" || exit; done
```
