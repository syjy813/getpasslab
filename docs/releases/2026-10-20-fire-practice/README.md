# 소방안전관리자 2급 문제 풀기 공개

사용자가 2026-10-20 ‘검수 통과 문항 공개 + 문제 풀기 기능 배포, 보류 152문항 제외’ 범위를 확인한 뒤 실서버 반영을 명시적으로 요청했다.

| 공개 구분 | 문항 수 |
|---|---:|
| 1과목 | 1,421 |
| 2과목 | 907 |
| **공개 합계** | **2,328** |
| 검수 보류·비공개 | 152 |

공개 문항은 핵심 원본 365개, 핵심 변형 483개, 일반 기본 740개, 일반 심화 740개다. 원본 핵심 500개 전체를 공개했다고 표현하지 않는다. 74개 모든 챕터에 최소 20개의 공개 문항이 있다.

## 공개 결정과 데이터 보호

첫 전수 QA의 문항별 선택 답안에 명시적 재판정 4개를 적용한 후, 보완 대상 167개·추가 해설 보완 42개의 재검수 결과를 반영했다. 답을 선택하지 못한 152개는 제외했다. [공개 승인 목록](publication.json)은 수정 전 기준 커밋 `92a29f3`, ID별 전체 행 해시·기존 내용 상태, 검수 기록 해시와 제외 ID를 고정한다. 생성기는 검수한 문항 내용이 달라지면 공개를 자동 승계하지 않고 실패한다.

공개 대상의 `reviewStatus=approved`, `publicationStatus=published`, `examEligible=true`, `contentStatus=draft_complete`만 전환했다. 원본 추출문·문제 지문·선택지·정답·해설·ID·과목·핵심 태그는 유지한다. `draft_complete`는 현재 서비스에 필요한 내용이 갖춰졌다는 상태이며 공식 기출 원문을 시각적으로 인증했다는 의미가 아니다.

과거 내용 검수의 2,480행 해시·보완 전 원본·524개 학습 본문 해시는 덮어쓰지 않는다. 현재 상태를 명시적 공개 승인 기록으로 먼저 검증한 뒤, 정확한 승인 내용에서 상태값만 되돌려 과거 내용 검사를 수행한다. 별도 현재 공개 검사는 승인 집합과 실제 직렬화된 문항을 다시 일치시킨다.

## 제공 기능

- 챕터별 전체 공개 문제: 한 문제씩 정답·해설 확인, 연결 이론 다시 보기
- 전체 모의고사: 1과목 25문제 + 2과목 25문제, 60분, 원본과 그 변형의 중복 출제 방지
- 과목별 점수·과락·평균 기준 판정과 문항별 해설

같은 모델의 챕터 기준 비블라인드 QA를 통과한 문항이다. 공식 기출문제 인증이나 실제 수험생 정답률·난도 실험은 아니다. 별도 보류 152개는 선택지 미분리 47개·도판 누락 60개·챕터 근거 부족 45개다.

## 검증·배포

빌드·현재/과거 데이터 검사와 브라우저 QA 결과는 배포 전 검증 기록에 추가한다. `qa-fire-publication.cjs`는 실제 공개 풀 전체 2,328개 일치 및 보류 제외를 확인하고 모바일 390px·PC 1440px에서 실제 문항의 챕터 정답·해설과 과목별 25개·총50개 모의고사 제출·100점 채점을 검증한다. 기존 합성 문항으로 한 경계값·타이머 테스트도 유지한다.

실서버 배포 완료는 Pages 작업 성공과 별도 `Fire production publication QA`에서 https://getpasslab.co.kr 의 실제 풀이 성공을 확인한 뒤 기록한다. 커밋·빌드 성공만을 실서버 반영 완료로 간주하지 않는다.

배포 전 로컬 검증: Build 545경로 및 전체 39개 검사 통과. 2,328문항의 상태값 전환 외 문제·선택지·정답·해설·원본은 전체 2,480행에서 동일함을 확인했다. 브라우저·배포 결과는 다음 증거 기록에 이어 적는다.
